# Coding Tools 0.8.32

## English

### Improvements
- ChatGPT turns always run on GPT-6, chosen in ChatGPT's model list. They never run on another model, since other models are billed on top: Codex quota on Plus, money on Team. ChatGPT's picker now opens on a Power slider. On Plus "Default", its upper stops are other models (6.1 Sol, 6 Astra), and the app used to move that slider by position, so it could land on 6.1 Sol. A turn now opens the list and picks GPT-6 by its exact name: "GPT-6 Sol" on Plus, "6" on Team and Pro. It then moves GPT-6's own slider to the stop labelled with the chosen effort, such as "6 High", reading each stop's label instead of trusting its position. If any step fails, the turn stops instead of running on another model or effort (PR #660, PR #662).
- Team and Pro accounts get GPT-6's Extra High and Pro efforts again. The account check reads GPT-6's own slider: 5 stops on Team and Pro, up to "6 Pro"; 3 on Plus, up to "6 High" (PR #662).
- The model picker is found by an attribute that does not change with ChatGPT's language, and the account check no longer fails on the new picker (PR #660).
- Each project in the chat list has a New chat button on hover, like Codex's compose button (PR #654).
- Email reaches every address, not just the first 50 of over 1,000. The address list is searched on the server and loads more as you scroll. A name that does not exist yet can be captured with one click, and mail opens faster and reads clearly in dark mode (PR #657).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from this branch and confirm CI before publication.
- Everything in 0.8.31 is included.

## 繁體中文

### 更新內容
- ChatGPT 回合一律在 ChatGPT 模型清單中選用 GPT-6，不會使用其他模型：其他模型要另外收費（Plus 扣減 Codex 額度，Team 要付費）。ChatGPT 的模型選擇器現在會先顯示「Power」滑桿；在 Plus 的「預設」下，滑桿較高的位置是其他模型（6.1 Sol、6 Astra），應用程式以前按位置移動這個滑桿，可能選到 6.1 Sol。現在每個回合會打開模型清單，按完整名稱選取 GPT-6（Plus 上是「GPT-6 Sol」，Team 和 Pro 上是「6」），再把 GPT-6 自己的滑桿移到標示所選強度的一格（例如「6 High」），每一格都讀取其標示，不依賴位置；任何一步失敗，回合都會停止，而不會改用其他模型或強度（PR #660、PR #662）。
- Team 和 Pro 帳戶可再次使用 GPT-6 的 Extra High 和 Pro 強度：帳戶檢查會讀取 GPT-6 自己的滑桿，Team 和 Pro 有 5 格（最高「6 Pro」），Plus 有 3 格（最高「6 High」）（PR #662）。
- 模型選擇器改以不受 ChatGPT 介面語言影響的屬性尋找；帳戶檢查在新的選擇器上不會再失敗（PR #660）。
- 對話清單中每個項目在滑鼠移上時會顯示「New chat」按鈕，與 Codex 的撰寫按鈕相同（PR #654）。
- 電郵可開啟所有地址，不再只限一千多個地址中的前 50 個：地址清單在伺服器上搜尋，捲動時會載入更多；尚未存在的名稱按一下即可建立；郵件開啟更快，在深色模式下也清楚易讀（PR #657）。

### 驗證及限制

- 包含 0.8.31 的所有內容。
