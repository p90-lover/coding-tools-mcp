# Coding Tools v0.8.172

## English

### SSH hosts
- **Choose which SSH servers agents may reach.** A new SSH hosts page under Connections lists the servers you allow. Adding a server approves nothing. Coding Tools fetches the key the server shows, and you compare its fingerprint with one read on the server itself: paste it, or confirm you compared it yourself. Agents can't use a host until you do.
- **A server that shows a different key is blocked.** If a server later shows another key, every entry for that server and port is blocked. The warning shows the approved key and the new one side by side, and only a pasted fingerprint that matches replaces the key.
- **Open a terminal to an approved host.** Each approved host has Open terminal. It runs Windows' own OpenSSH, trusts only the keys you approved on this page, and turns off forwarding and the `~` escape keys. Output from the server is treated as untrusted: links in it don't open, pasted text loses control characters, and files can't be dropped in. One terminal is open at a time, and it closes when the window reloads, when the app restarts its background service, and when the app quits.
- **Agents' SSH commands are screened.** Tunnels and port forwarding, ProxyCommand, agent forwarding, weaker host-key checks, and writes to SSH trust files (known_hosts, authorized_keys, SSH configs and this hosts list) are always refused. SSH to a server you haven't approved, an interactive remote shell, and any command on a host marked Production wait for you; no model can approve them. A command for an approved host goes to the reviewer with the exact remote command. Only `ssh -V` and `ssh-add -l` run without review.
- **Agents can't change the list or use your terminal.** The hosts list is hidden from the app tools agents use, and only the SSH hosts page changes it. The background service hides SSH terminals from its terminal list, and opening, typing into or closing one needs a key that only Coding Tools holds.
- Known limits: Codex chats on "Approve for me" use Codex's own reviewer, which these rules don't see, as with Coding Tools' other command rules. An agent's own `ssh` checks your known_hosts file, not the keys you approved here; an agent SSH tool that uses the approved keys comes next. A program running under your Windows account can still reach an open SSH terminal through the app's debugging port or the terminal host's local port, so close terminals to Production hosts when you're done.

### Connect an app
- **SHA and Shadow SHA can use Coding Tools' tools.** When one of them asks to connect, Coding Tools asks you in its own window. The question names the program that asked, found from the connection itself, and you choose the project it may use, or Don't allow. Don't allow is the default. A connected app gets its own key for that project: files and commands in its folder (commands ask you, as in chats) and computer use. It never sees your chats, and chat-only tools are refused.
- **Computer use for an app is asked in Coding Tools.** An app has no chat to show a card in, so Coding Tools asks: "Allow SHA to use Notepad?" with Always allow, Allow until it disconnects, or Don't allow. Each app's answers are its own, never a chat's or another app's. Once you allow an app, its steps in that window don't ask again, as in chats.
- **Settings > Computer use > Connected apps** lists each connected program with its project folder and program path, never its key. Disconnect stops the key at once. The app asks again before it can reconnect, and its "until it disconnects" answers go with the key. A connection unused for a month ends by itself.

### Approve for me
- **Protected files stay protected through wildcards.** A shell write can no longer reach a protected file through a wildcard or a trailing dot (for example `Set-Content AGENTS.m?` or `'AGENTS.md.'`, which Windows opens as AGENTS.md). The protected list now also covers .npmrc, .yarnrc, .pnpmfile.cjs, opencode.json, .opencode, .pi, .gemini, .mcp-paths, AGENTS.override.md, CLAUDE.local.md, GEMINI.md and conftest.py. Copying from a wildcard source (`Copy-Item dist\* out`) is still fine.

### Antivirus
- **Coding Tools no longer launches programs in the background the way malware does.** Bitdefender's record of the Nov 27 quarantine shows what Coding Tools did that apps like Claude and ChatGPT never do. It now:
  - **Checks extra MCP tunnels without launching tunnel-client every 10 seconds.** It launched about 7,000 times over a 19-hour run. Between full checks it now only confirms each tunnel's process is still running, and runs the full check every 5 minutes. A tunnel that stops is still noticed and restarted within seconds. The main tunnel's fallback check is limited the same way.
  - **Reads a chat's branch list once a minute instead of every 15 seconds.** Each read starts about a dozen git processes. The list still refreshes as soon as you return to the window or open the branch menu.
  - **Checks whether a screen reader is running without hidden PowerShell.** It ran a hidden PowerShell script that built code in memory to call Windows directly, the pattern of PowerShell attack tools. It now reads the value screen readers save in your Windows profile.

### Under the hood
- **First phase of a lighter, faster-to-patch app is done.** Everything Coding Tools needs from Electron (saved secrets, clipboard, links, notifications, sleep and power events, windows and dialogs, the built-in browser, app start and quit, and messages between the window and the app) now goes through one internal interface. Nothing changes on screen. This completes phase 1 of moving to a small WebView2-based app whose updates replace only code.

Includes all changes from v0.8.171.

## 繁體中文

### SSH 主機
- **選擇代理可以連線的 SSH 伺服器。** 「連線」底下新增了「SSH 主機」頁面，列出你允許的伺服器。新增伺服器本身不會核准任何東西。Coding Tools 會取得伺服器出示的金鑰，由你把它的指紋與在伺服器上直接讀到的指紋比對：貼上指紋，或確認你已自行比對。在你完成之前，代理無法使用這台主機。
- **出示不同金鑰的伺服器會被封鎖。** 如果伺服器之後出示了另一把金鑰，同一伺服器與連接埠的所有項目都會被封鎖。警告會並排顯示已核准的金鑰與新金鑰，只有貼上相符的指紋才能取代金鑰。
- **開啟連到已核准主機的終端機。** 每台已核准的主機都有「開啟終端機」。它使用 Windows 內建的 OpenSSH，只信任你在這個頁面核准的金鑰，並關閉轉送與 `~` 跳脫鍵。伺服器的輸出一律視為不可信任：其中的連結不會開啟，貼上的文字會移除控制字元，也無法拖放檔案進去。一次只能開啟一個終端機；視窗重新載入、應用程式重新啟動背景服務，以及應用程式結束時，終端機都會關閉。
- **代理的 SSH 指令會經過審查。** 通道與連接埠轉送、ProxyCommand、代理程式轉送、放寬主機金鑰檢查，以及寫入 SSH 信任檔案（known_hosts、authorized_keys、SSH 設定檔與這份主機清單）一律拒絕。連線到你尚未核准的伺服器、互動式遠端 shell，以及在標示為「正式環境」的主機上執行任何指令，都會等你決定；任何模型都無法核准。對已核准主機的指令會連同完整的遠端指令交給審查者。只有 `ssh -V` 和 `ssh-add -l` 不經審查直接執行。
- **代理無法更改清單，也無法使用你的終端機。** 代理使用的應用程式工具看不到這份主機清單，只有「SSH 主機」頁面可以更改它。背景服務不會在終端機清單中列出 SSH 終端機，而開啟、輸入或關閉它都需要只有 Coding Tools 持有的金鑰。
- 已知限制：使用「Approve for me」的 Codex 對話由 Codex 自己的審查者處理，這些規則看不到，與 Coding Tools 其他指令規則相同。代理自己執行的 `ssh` 會檢查你的 known_hosts 檔案，而不是你在這裡核准的金鑰；接下來會推出使用已核准金鑰的代理 SSH 工具。以你的 Windows 帳戶執行的程式，仍可能透過應用程式的偵錯連接埠或終端機主機的本機連接埠存取已開啟的 SSH 終端機，因此用完連到「正式環境」主機的終端機後請關閉它。

### 連接應用程式
- **SHA 與 Shadow SHA 可以使用 Coding Tools 的工具。** 當其中一個應用程式請求連接時，Coding Tools 會在自己的視窗中詢問你。問題會列出提出請求的程式（從連線本身辨識），由你選擇它可以使用的專案，或選擇「不允許」；預設為「不允許」。已連接的應用程式會取得該專案專屬的金鑰：可使用該資料夾中的檔案與指令（指令會像對話中一樣詢問你），以及電腦操作。它看不到你的對話，僅限對話使用的工具也會被拒絕。
- **應用程式的電腦操作在 Coding Tools 中詢問。** 應用程式沒有對話可以顯示卡片，因此由 Coding Tools 詢問：「Allow SHA to use Notepad?」，選項為「永遠允許」、「允許直到中斷連線」或「不允許」。每個應用程式的回答只屬於它自己，不會套用到任何對話或其他應用程式。允許某個應用程式後，它在該視窗中的步驟不會再詢問，與對話相同。
- **「設定 > Computer use > Connected apps」** 會列出每個已連接的程式、其專案資料夾與程式路徑，但絕不顯示金鑰。「中斷連線」會立即停用金鑰；應用程式重新連接前會再詢問你，其「允許直到中斷連線」的回答也會隨金鑰一併移除。一個月未使用的連線會自動結束。

### Approve for me
- **受保護的檔案不會因萬用字元而失守。** shell 寫入不能再透過萬用字元或結尾的句點寫到受保護的檔案（例如 `Set-Content AGENTS.m?` 或 `'AGENTS.md.'`，Windows 會把它開成 AGENTS.md）。受保護清單現在也涵蓋 .npmrc、.yarnrc、.pnpmfile.cjs、opencode.json、.opencode、.pi、.gemini、.mcp-paths、AGENTS.override.md、CLAUDE.local.md、GEMINI.md 與 conftest.py。從萬用字元來源複製（`Copy-Item dist\* out`）仍然可以。

### 防毒軟體
- **Coding Tools 不再以類似惡意程式的方式在背景啟動程式。** Bitdefender 對 11 月 27 日隔離事件的紀錄，顯示了 Coding Tools 做了哪些 Claude、ChatGPT 等應用程式從不會做的事。現在它會：
  - **檢查額外的 MCP 通道時，不再每 10 秒啟動一次 tunnel-client。** 它先前在一次 19 小時的執行中啟動了約 7,000 次。現在兩次完整檢查之間只確認每個通道的處理程序仍在執行，完整檢查每 5 分鐘一次。停止的通道仍會在數秒內被發現並重新啟動。主要通道的備援檢查也同樣受到限制。
  - **對話的分支清單改為每分鐘讀取一次，而不是每 15 秒。** 每次讀取會啟動約十幾個 git 處理程序。回到視窗或打開分支選單時，清單仍會立即更新。
  - **檢查是否有螢幕閱讀器執行時，不再使用隱藏的 PowerShell。** 先前它會執行隱藏的 PowerShell 指令碼，在記憶體中建構程式碼直接呼叫 Windows，這正是 PowerShell 攻擊工具的模式。現在它改為讀取螢幕閱讀器儲存在你 Windows 使用者設定中的值。

### 底層改進
- **更輕量、更新更快速的應用程式，第一階段已完成。** Coding Tools 需要 Electron 提供的一切（已儲存的機密資料、剪貼簿、連結、通知、睡眠與電源事件、視窗與對話方塊、內建瀏覽器、應用程式的啟動與結束，以及視窗與應用程式之間的訊息），現在都透過同一個內部介面。畫面上不會有任何變化。這完成了改用小型 WebView2 應用程式的第一階段，未來的更新只需替換程式碼。

包含 v0.8.171 的所有變更。
