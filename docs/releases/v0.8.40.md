# Coding Tools 0.8.40

## English

### Computer control
- A chat asks for computer control on a card in that chat, like ChatGPT desktop. There's no separate window any more. The card sits with the agent's other requests at the end of the conversation, and lists the windows it may control, the screen-capture tick when needed, and the duration, with Deny and Start. Nothing takes the focus; if the app is in the background, its taskbar button flashes (PR #725).
- The control bar's Stop button works. In 0.8.39 the picker's Start and the bar's Stop never reached the app, so control could not be turned on at all. Ctrl+Alt+Escape still stops control at once.

### Chats
- A tool call that times out no longer stops the chat. Before, "Headless request timed out" showed "Step failed" and waited for a click, even with "Retry automatically" on. Now the chat keeps going by itself and shows one red line saying a tool call timed out (PR #722).
- "Retry automatically" no longer gives up when its own retry fails for a moment (for example while the local service restarts). It tries again after the next pause (PR #722).
- A chat that the agent service could not reconnect to after a restart is resumed, not left showing "Running" with nothing behind it (PR #721).
- An open chat dragged from the sidebar into another split moves there and leaves its old pane (PR #723).
- A compacted chat shows new messages beside their own turns (PR #724).
- The context meter shows what a Claude model's CPA API key has spent, from CPA Helper's request log. The Mission chat and Native ChatGPT Web tabs are gone (PR #716).

### App
- Retired-service snapshots that nothing read are no longer kept (PR #715).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from this branch, and confirm CI before publication.
- Everything in 0.8.39 is included.

## 繁體中文

### 電腦控制
- 對話要求電腦控制時，會在該對話中以卡片形式詢問，與 ChatGPT 桌面版相同，不再另開視窗。卡片與代理的其他請求一同顯示在對話末尾，列出可控制的視窗、需要時的螢幕擷取勾選方塊及時長，並附有「拒絕」及「開始」。不會搶走焦點；若應用程式在背景，其工作列按鈕會閃爍（PR #725）。
- 控制橫條的「停止」按鈕現在可以使用。在 0.8.39 中，選擇器的「開始」及橫條的「停止」都無法傳達到應用程式，因此根本無法開啟控制。Ctrl+Alt+Escape 仍可立即停止控制。

### 對話
- 工具呼叫逾時不再令對話停止。過去「Headless request timed out」會顯示「Step failed」並等待你點擊，即使已開啟「Retry automatically」亦然。現在對話會自行繼續，並以一行紅字顯示有工具呼叫逾時（PR #722）。
- 「Retry automatically」本身的重試若短暫失敗（例如本機服務正在重新啟動），不再就此放棄，而會在下一次暫停後再試（PR #722）。
- 代理服務重新啟動後無法重新連線的對話會被恢復，而不是一直顯示「Running」卻沒有任何程序在執行（PR #721）。
- 從側邊欄將已開啟的對話拖到另一個分割窗格時，對話會移到該處並離開原本的窗格（PR #723）。
- 壓縮過的對話會把新訊息顯示在其所屬的回合旁（PR #724）。
- 內容用量計量會顯示 Claude 模型經 CPA API 金鑰的花費（取自 CPA Helper 的請求紀錄）。「Mission chat」及「Native ChatGPT Web」分頁已移除（PR #716）。

### 應用程式
- 不再保留無人讀取的已停用服務快照（PR #715）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由本分支編譯及通過 CI 才能公開。
- 包含 0.8.39 的所有內容。
