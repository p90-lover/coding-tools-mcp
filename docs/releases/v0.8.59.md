# Coding Tools 0.8.59

## English

### Chats
- Chats that run a GPT model use your unified-agent-tools for files. A GPT model on any agent (Codex, or Claude Code and OpenCode through CPA) gets its Read, Grep, Glob and Edit tools. The app's own read_file, search_text and apply_patch are left out of that chat, so it has one tool for each job. GPT agents used to search with shell rg or findstr and read whole files with Get-Content. On a large project that timed out or flooded the context, and the agent concluded that a file wasn't there (PR #957, unified-agent-tools PR #3).
- These searches honor .gitignore, finish within 25 seconds and say whether they were complete. Large files are read 2,000 lines at a time, and the tool says where to continue.
- The tools work only inside the chat's own folder, have no shell, web or screen access, and run on the app's own executable, so there is nothing extra to install.

### Verification and limitations
- Measured on this project's repository, with a warm cache: finding one symbol took 0.5 s and was complete, against 1.9 s and truncated before (340 s on a cold cache). Listing all `*.rs` files found 211 of 211 in 0.4 s, against 21 of 211 before. Reading a 2,648-line file returns a 40 KB window instead of 339 KB.
- Tests cover launching and resuming GPT chats with the tools, hiding the duplicate file tools, the installer check of the server against its pinned hash, and starting the server the way a chat does. GPT chats in the installed app have not been tried yet.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.58 is included.

## 繁體中文

### 對話
- 使用 GPT 模型的對話現在以你的 unified-agent-tools 處理檔案。任何代理上的 GPT 模型（Codex，或經 CPA 的 Claude Code 及 OpenCode）都會取得其 Read、Grep、Glob 及 Edit 工具。該對話不會再列出應用程式本身的 read_file、search_text 及 apply_patch，讓每項工作只有一個工具。過去 GPT 代理會以 shell 的 rg 或 findstr 搜尋，並以 Get-Content 讀取整個檔案；在大型專案中這會逾時或塞滿上下文，代理便以為檔案不存在（PR #957，unified-agent-tools PR #3）。
- 這些搜尋會遵守 .gitignore，在 25 秒內完成，並說明搜尋是否完整。大型檔案每次讀取 2,000 行，工具會說明從哪裡繼續。
- 這些工具只能在對話自己的資料夾內運作，沒有 shell、網路或螢幕存取權，並以應用程式本身的執行檔執行，因此不需要另外安裝任何東西。

### 驗證及限制
- 在本專案的存放庫上量測（快取已暖）：尋找一個符號需時 0.5 秒且結果完整，過去需時 1.9 秒且結果被截斷（快取未暖時需 340 秒）。列出所有 `*.rs` 檔案在 0.4 秒內找到 211 個中的 211 個，過去只找到 211 個中的 21 個。讀取 2,648 行的檔案時會傳回 40 KB 的區段，而非 339 KB。
- 測試涵蓋以這些工具啟動及恢復 GPT 對話、隱藏重複的檔案工具、安裝程式依固定雜湊檢查伺服器，以及以對話的方式啟動伺服器。尚未在已安裝的應用程式中試用 GPT 對話。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.58 的所有內容。
