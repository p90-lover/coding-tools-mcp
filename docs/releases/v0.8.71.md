# Coding Tools 0.8.71

## English

### Codex bridge
- When an update's bridge upgrade fails at launch because ChatGPT was not ready, it runs again by itself once ChatGPT is signed in. On 0.8.67 and 0.8.68 the Browser tab's ChatGPT page sat on Cloudflare's "Just a moment..." check, the upgrade (bridge 5.0.6 to 6.1.17) gave up after 60 s, and the bridge stayed down until Setup → Install models or a restart. Now completing the check in the Browser tab is enough: about 10 s after ChatGPT signs in, the upgrade, the bridge and Codex's route run again.
- If ChatGPT was already signed in when the upgrade failed, it is tried again about 10 s later.
- The retry waits while something else is using the runtime or the browser: a setup, a bridge connect, a sign-in, a ChatGPT turn or an account switch. It checks every 10 s for up to 10 minutes, then waits for the next sign-in (PR #993).
- It runs once per launch. If it fails too, the error stays on screen and Setup → Install models is still the way to finish. If Setup has already upgraded the bridge, nothing runs again (PR #993).

- Fresh model setup no longer fails with "Browser helper returned invalid ChatGPT session evidence". The app still checked a field the bundled browser helper no longer sends (PR #995).

### Freezes
- The app no longer freezes for one to two minutes when the network stack holds new connections, as Bitdefender's network filter did for five minutes after its service crashed on 2026-11-03. The proxy checks (every 30 s, at startup, and the Proxy page's test) now connect from a worker thread. Before, closing a connection that hadn't finished blocked the main thread, and every window with it: 76 s, 122 s and 89 s that morning (PR #990).

### Chats
- In a split chat, the lower pane keeps its 320 px minimum after a restore or a window resize. Before, an 800 px window could show it at 120 px. When the window is too short for both, they share it equally. Dragging, the keyboard and dropping a pane all use the same sizes (PR #989).
- Dragging a pane no longer leaves listeners behind after it closes, and a late drag can't bring a closed pane back or overwrite a newer layout (PR #989).
- A Preview pane selected while the window is hidden or minimized still takes screenshots. Before, its screenshot hung until the 50-second watchdog (PR #997).

### Workspaces
- A project edit that fails partway, on a linked folder or while saving the project, now undoes the linked-folder changes it had already made, with the original bytes and permissions. Before, it could leave the edit half applied. Changes made by something else in the meantime are kept and reported as conflicts (PR #985).

### Verification and limitations
- Tested with the launch code itself: a launch failed by the Cloudflare check, then a sign-in, ends with the bridge upgraded, started and connected. The tests also cover the waits, the one-retry limit and a sign-out before the retry. All 52 test files that read the launcher's main code pass, as does the browser test file (165 tests).
- Not yet seen on a live Cloudflare check: only a person can pass it.
- Freezes: new tests check that the probe connects from the worker, answers by its deadline when the worker is held, and falls back to the main thread when no worker can start. The freezes depend on the network stack holding connects, so they were not reproduced (PR #990).
- Split chats: 16 focused tests pass, and the sizes were measured in Chrome with the real controls (480/320 at 800 px, 250/250 at 500 px) (PR #989). Hidden-window Preview: 50 tests and Electron's native Preview test pass (PR #997).
- Session check: all 166 browser-host tests pass with the helper's current reply (PR #995). Workspaces: 7 native tests and 6 regressions pass, including a real failed save on Linux, Windows and macOS (PR #985).
- None of these is checked in the installed app yet.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.70 is included.

## 繁體中文

### Codex 橋接
- 更新後啟動時，若因 ChatGPT 尚未就緒而令橋接升級失敗，ChatGPT 登入後會自動再執行一次。在 0.8.67 及 0.8.68，「瀏覽器」分頁的 ChatGPT 頁面停在 Cloudflare 的「Just a moment...」驗證，升級（橋接 5.0.6 升至 6.1.17）在 60 秒後放棄，橋接一直停止，直至執行「設定 → 安裝模型」或重新啟動。現在只需在「瀏覽器」分頁完成驗證：ChatGPT 登入約 10 秒後，升級、橋接及 Codex 的路由會再次執行。
- 若升級失敗時 ChatGPT 已經登入，約 10 秒後會再試一次。
- 若執行階段或瀏覽器正被其他工作使用（設定、橋接連線、登入、ChatGPT 回合或切換帳戶），重試會等待。它每 10 秒檢查一次，最多 10 分鐘，之後等待下一次登入（PR #993）。
- 每次啟動只重試一次。若重試亦失敗，錯誤訊息會保留在畫面上，仍可用「設定 → 安裝模型」完成。若「設定」已升級橋接，則不會再執行（PR #993）。

- 全新設定模型時不會再出現「Browser helper returned invalid ChatGPT session evidence」錯誤。應用程式過去仍檢查內附瀏覽器輔助程式已不再傳送的欄位（PR #995）。

### 凍結
- 當網絡堆疊扣住新連線時，應用程式不會再凍結一至兩分鐘。2026-11-03 Bitdefender 服務當機後，其網絡過濾器就這樣扣住連線五分鐘。代理檢查（每 30 秒、啟動時及代理頁面的測試）現在改由背景執行緒連線。過去關閉一個未完成的連線會阻塞主執行緒，連同所有視窗：當天早上分別凍結 76、122 及 89 秒（PR #990）。

### 對話
- 分割對話中，下方窗格在還原或調整視窗大小後仍保持 320 px 的最小高度。過去 800 px 高的視窗可能只顯示 120 px。視窗高度不足以容納兩者時，兩個窗格平均分配。拖曳、鍵盤及放下窗格都使用相同的大小（PR #989）。
- 拖曳窗格後，關閉的窗格不會再留下監聽器，過時的拖曳亦不會令已關閉的窗格重新出現或覆蓋較新的版面（PR #989）。
- 在視窗隱藏或最小化時選取的「預覽」窗格仍可截圖。過去截圖會卡住，直至 50 秒的監察逾時（PR #997）。

### 工作區
- 專案編輯若在中途失敗（處理連結資料夾或儲存專案時），現在會以原本的內容及權限復原它已作出的連結資料夾變更。過去可能留下只完成一半的編輯。期間由其他程式作出的變更會被保留，並以衝突形式報告（PR #985）。

### 驗證及限制
- 以啟動程式碼本身測試：啟動時被 Cloudflare 驗證導致失敗，之後登入，最終橋接完成升級、啟動及連線。測試亦涵蓋等待、只重試一次的限制，以及重試前登出的情況。所有讀取啟動器主程式碼的 52 個測試檔案均通過，瀏覽器測試檔案（165 項測試）亦通過。
- 尚未在真實的 Cloudflare 驗證上觀察：只有使用者本人能通過驗證。
- 凍結：新測試檢查探測由背景執行緒連線、在背景執行緒被扣住時仍於期限前回應，以及無法啟動背景執行緒時改回主執行緒執行。凍結取決於網絡堆疊扣住連線，因此未有重現（PR #990）。
- 分割對話：16 項針對性測試通過，並在 Chrome 中以實際控制項量測大小（800 px 時 480/320，500 px 時 250/250）（PR #989）。隱藏視窗的預覽：50 項測試及 Electron 原生預覽測試通過（PR #997）。
- 工作階段檢查：以輔助程式目前的回覆，所有 166 項瀏覽器主機測試通過（PR #995）。工作區：7 項原生測試及 6 項回歸測試通過，包括在 Linux、Windows 及 macOS 上真實的儲存失敗（PR #985）。
- 以上各項尚未在已安裝的應用程式中檢查。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.70 的所有內容。
