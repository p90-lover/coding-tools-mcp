# Coding Tools 0.8.71

## English

### Codex bridge
- When an update's bridge upgrade fails at launch because ChatGPT was not ready, it runs again by itself once ChatGPT is signed in. On 0.8.67 and 0.8.68 the Browser tab's ChatGPT page sat on Cloudflare's "Just a moment..." check, the upgrade (bridge 5.0.6 to 6.1.17) gave up after 60 s, and the bridge stayed down until Setup → Install models or a restart. Now completing the check in the Browser tab is enough: about 10 s after ChatGPT signs in, the upgrade, the bridge and Codex's route run again.
- If ChatGPT was already signed in when the upgrade failed, it is tried again about 10 s later.
- The retry waits while something else is using the runtime or the browser: a setup, a bridge connect, a sign-in, a ChatGPT turn or an account switch. It checks every 10 s for up to 10 minutes, then waits for the next sign-in.
- It runs once per launch. If it fails too, the error stays on screen and Setup → Install models is still the way to finish. If Setup has already upgraded the bridge, nothing runs again.

### Verification and limitations
- Tested with the launch code itself: a launch failed by the Cloudflare check, then a sign-in, ends with the bridge upgraded, started and connected. The tests also cover the waits, the one-retry limit and a sign-out before the retry. All 52 test files that read the launcher's main code pass, as does the browser test file (165 tests).
- Not yet seen on a live Cloudflare check: only a person can pass it.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.70 is included.

## 繁體中文

### Codex 橋接
- 更新後啟動時，若因 ChatGPT 尚未就緒而令橋接升級失敗，ChatGPT 登入後會自動再執行一次。在 0.8.67 及 0.8.68，「瀏覽器」分頁的 ChatGPT 頁面停在 Cloudflare 的「Just a moment...」驗證，升級（橋接 5.0.6 升至 6.1.17）在 60 秒後放棄，橋接一直停止，直至執行「設定 → 安裝模型」或重新啟動。現在只需在「瀏覽器」分頁完成驗證：ChatGPT 登入約 10 秒後，升級、橋接及 Codex 的路由會再次執行。
- 若升級失敗時 ChatGPT 已經登入，約 10 秒後會再試一次。
- 若執行階段或瀏覽器正被其他工作使用（設定、橋接連線、登入、ChatGPT 回合或切換帳戶），重試會等待。它每 10 秒檢查一次，最多 10 分鐘，之後等待下一次登入。
- 每次啟動只重試一次。若重試亦失敗，錯誤訊息會保留在畫面上，仍可用「設定 → 安裝模型」完成。若「設定」已升級橋接，則不會再執行。

### 驗證及限制
- 以啟動程式碼本身測試：啟動時被 Cloudflare 驗證導致失敗，之後登入，最終橋接完成升級、啟動及連線。測試亦涵蓋等待、只重試一次的限制，以及重試前登出的情況。所有讀取啟動器主程式碼的 52 個測試檔案均通過，瀏覽器測試檔案（165 項測試）亦通過。
- 尚未在真實的 Cloudflare 驗證上觀察：只有使用者本人能通過驗證。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.70 的所有內容。
