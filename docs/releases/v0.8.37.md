# Coding Tools 0.8.37

## English

### Smoother, fewer freezes
- These calls no longer hold every window. Each one was measured in 0.8.35's own main-thread log:
  - saving chat goals: up to 1.4 s, 8 times in 8 hours;
  - starting the bundled runtime for doctor, route status and the model catalog: up to 2 s;
  - the Processes view's sampler: 1.6 s;
  - saving agent tool leases: 0.8 s (PR #710).
- Goal saves are still flushed to disk before they replace the old file, and a quit waits for the last one (PR #710).
- The AO daemon's program loads off the main thread before it starts: 4.8 s at an AO start (PR #702).
- The database checks before each AO start no longer block the app: 1.85 s (PR #704).
- The start-up sweep of set-aside agent runtimes runs in the background: 1.15 s (PR #705).
- The launcher warns about a failing or full disk and about growing memory (PR #708).

### Chats
- Chats keep going in the background: queued messages, unread steers, and resuming after a restart. The launcher's own requests wait their turn instead of being refused when the background service is full (PR #706).
- A chat whose retried start is still running launches instead of failing on "already exiting" (PR #699).
- A single chat's retried card gets its turn back (PR #701).
- Models are scored on finished Team missions, and the score shows in the model picker (PR #707).
- Chat details show the chat's processes and model logos; browser accounts switch in place, and CPA accounts are listed (PR #688).
- A repository opened through a junction or a short name is the same repository, and the branch bar never shows a slow read as detached (PR #709).

### Clawd
- Clawd lives in its house: sleeps in its bed, cooks and eats, bathes, works and reads (PR #703).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from this branch, and confirm CI before publication.
- Everything in 0.8.36 is included.

## 繁體中文

### 更流暢、更少停頓
- 以下操作不再令所有視窗停頓，每項均取自 0.8.35 本身的主執行緒記錄：
  - 儲存對話目標：最長 1.4 秒，8 小時內出現 8 次；
  - 為 doctor、路由狀態及模型目錄啟動內建執行環境：最長 2 秒；
  - 「Processes」檢視的取樣：1.6 秒；
  - 儲存代理工具租約：0.8 秒（PR #710）。
- 對話目標仍會先寫入磁碟才取代舊檔案，結束程式時會等待最後一次儲存完成（PR #710）。
- AO 常駐程式的執行檔會先在背景執行緒載入才啟動：AO 啟動時原本停頓 4.8 秒（PR #702）。
- 每次啟動 AO 前的資料庫檢查不再阻塞應用程式：原本 1.85 秒（PR #704）。
- 啟動時清理暫存代理執行環境的工作改在背景執行：原本 1.15 秒（PR #705）。
- 磁碟故障或已滿、記憶體持續增長時，啟動器會發出警告（PR #708）。

### 對話
- 對話可在背景繼續：排隊中的訊息、未讀的引導訊息、重新啟動後繼續。背景服務已滿時，啟動器本身的請求會排隊等候，而不是被拒絕（PR #706）。
- 重試中的對話啟動仍在進行時，會正常啟動，而不是因「already exiting」失敗（PR #699）。
- 單一對話的重試卡片會取回其回合（PR #701）。
- 模型會依已完成的 Team 任務評分，分數顯示在模型選擇器中（PR #707）。
- 對話詳情顯示該對話的程序及模型標誌；瀏覽器帳戶可即時切換，並列出 CPA 帳戶（PR #688）。
- 經由 junction 或短檔名開啟的儲存庫會被視為同一儲存庫；分支列不再把緩慢的讀取顯示為 detached（PR #709）。

### Clawd
- Clawd 住進了牠的房子：在床上睡覺、煮飯吃飯、洗澡、工作和閱讀（PR #703）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由本分支編譯及通過 CI 才能公開。
- 包含 0.8.36 的所有內容。
