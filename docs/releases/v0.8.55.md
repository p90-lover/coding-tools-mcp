# Coding Tools 0.8.55

## English

### Chats
- "Let the model judge" no longer leaves a request waiting for you. With it on, a command or tool request still landed on its card for you in three cases:
  - The reviewer failed three times in a row, for example while CPA was restarting.
  - Asked a second time to choose, the reviewer still couldn't decide.
  - The reviewer couldn't decide on one of the app's own screen tools, such as computer control.

  Each of these is now denied in doubt. The agent is told why and goes another way. With the switch off, nothing changes: these requests wait for you as before.
- Still yours with the switch on: a question the agent asks you, a plan it asks you to approve, and letting computer control use an app.

### Verification and limitations
- Covered by tests: a reviewer that never answers, and one that can't decide on a screen tool. The full chat workflow and agent tools suites pass (511 tests). It hasn't yet been checked in the installed app.
- In the running app, the switch was already on and saved, and goal rounds were being judged. Commands that came up while it was being watched were each answered within 40 seconds. So the cases above were found by reading the code, not by catching one live.
- Everything in 0.8.54 is included.

## 繁體中文

### 對話
- 「Let the model judge」不再讓請求等候你處理。開啟此選項時，以下三種情況下指令或工具請求仍會停留在卡片上等你決定：
  - 審查者連續三次失敗，例如 CPA 重新啟動期間。
  - 再次要求審查者作出選擇時，它仍無法決定。
  - 審查者無法就應用程式自身的螢幕工具（例如電腦控制）作出決定。

  以上情況現在一律在有疑問時拒絕。代理會收到原因並改用其他方法。關閉此選項時行為不變：這些請求照舊等候你處理。
- 開啟此選項時仍由你處理的項目：代理向你提出的問題、要求你批准的計劃，以及允許電腦控制使用某個應用程式。

### 驗證及限制
- 已有測試涵蓋：從不回應的審查者，以及無法就螢幕工具作出決定的審查者。完整的對話工作流程及代理工具測試均通過（511 項）。尚未在已安裝的應用程式中檢查。
- 在執行中的應用程式裡，此選項已開啟並已儲存，目標回合亦有由模型判斷。觀察期間出現的指令都在 40 秒內得到回應。因此上述情況是透過閱讀程式碼找出的，並非在實際運行中捕捉到。
- 包含 0.8.54 的所有內容。
