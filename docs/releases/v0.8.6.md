Coding Tools 0.8.6

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Fewer freezes:

- With RTK on, every command an agent ran made the whole app wait for RTK to answer (about a third of a second each time, up to 3 s on a busy machine). RTK now runs in the background.
- One chat with a large conversation was read again and again with no pause between reads, which kept the Agent Orchestrator busy. A slow read is now reused for a little longer, so light chats still update every second.
- A long-running chat turn is lighter to redraw: it keeps its newest 600 steps on screen while it works (a finished turn still shows all of them), and finished turns are no longer re-compared in full every second.
- The main process stays free while an update downloads and while chats sit open.
- The Agent Orchestrator writes a chat's streamed text once per batch.

Chat:

- Chats are easier to move in the sidebar: a chat waiting on you (red dot) stays where you drop it, and letting go anywhere in the chat's own list counts.
- Steering shows at once, and a fast turn never loses its steps.
- A tool request is answered by clicking its option.

Everything in 0.8.5 is included.
