# Coding Tools 0.8.76

## English

### Browser
- The Browser tab opens ChatGPT's plain home (`chatgpt.com`) instead of a Temporary Chat, whatever "Save chats in ChatGPT" says. This covers the first page at startup, sign-in, sign-out, passkey sign-in and a new tab. Task turns and connector checks still open the chat the setting chooses (PR #1038).
- While ChatGPT shows Cloudflare's security check, the app no longer reloads the page for its connector check. That reload only added a request and a flash, then failed on the same check after a minute. The check is now named straight away. The page's own refresh every few minutes comes from Cloudflare's check script, not from the app (PR #1038).
- Camoufox is an App plugin under App plugins > Browser. It installs and updates from GitHub, checks the download's SHA-256 and reuses unchanged font files, so an update writes about 0.5 GB instead of 2.5 GB (PR #1036).

### Chats
- Stopping a chat while its sandbox is still being set up no longer lets the cancelled command start afterwards (PR #1030).
- A hidden chat page pauses its pet's animation and timers; they come back when the page is shown (PR #1031).
- The context cache saves one snapshot at a time, in order, and a stopped runtime can no longer overwrite its replacement's readings (PR #1033).

### Tools
- With a default working directory set, `apply_patch` and `patch_check` resolve a relative path against it once. Before, `src` was added twice (`src/src/local.txt`) (PR #1032).

### Verification and limitations
- Browser: 348 tests across the 12 files that load the browser code pass, including new ones for the plain home with saved chats off and for no reload on the check page (PR #1038). The installed app was watched for 10 minutes on 0.8.75: 0 responses with 429, and every reload came from Cloudflare's script.
- The other PRs were tested in their own PRs: 132 chat-agent and sandbox tests (PR #1030), 72 chat UI and pet tests (PR #1031), the Rust patch tests on Windows, Linux and macOS (PR #1032), 13 context and lifecycle tests (PR #1033).
- None of these is checked in the installed app yet. Passing Cloudflare's check is not part of this release; that depends on the proxy exit or the browser.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.75 is included.

## 繁體中文

### 瀏覽器
- 「瀏覽器」分頁會開啟 ChatGPT 的一般首頁（`chatgpt.com`），而不是臨時對話，不論「在 ChatGPT 中儲存對話」如何設定。這涵蓋啟動時的第一個頁面、登入、登出、密碼金鑰登入及新分頁。任務回合及連接器檢查仍會開啟設定所選的對話類型（PR #1038）。
- 當 ChatGPT 顯示 Cloudflare 安全檢查時，應用程式不會再為連接器檢查而重新載入頁面。該次重新載入只會多送一個請求並令畫面閃動，一分鐘後仍因同一檢查而失敗。現在會立即指出是安全檢查。頁面每隔數分鐘的自行重新整理來自 Cloudflare 的檢查程式，而非應用程式（PR #1038）。
- Camoufox 成為「應用程式外掛 > 瀏覽器」下的應用程式外掛。它從 GitHub 安裝及更新，檢查下載檔的 SHA-256，並重用未變更的字型檔案，因此一次更新只寫入約 0.5 GB，而非 2.5 GB（PR #1036）。

### 對話
- 在沙箱仍在設定時停止對話，已取消的指令不會在之後啟動（PR #1030）。
- 隱藏的對話頁面會暫停寵物的動畫及計時器；頁面再次顯示時會恢復（PR #1031）。
- 情境快取每次只按順序儲存一個快照，已停止的執行階段不會再覆寫取代它的執行階段的讀數（PR #1033）。

### 工具
- 設定了預設工作目錄時，`apply_patch` 及 `patch_check` 只會以它解析相對路徑一次。過去 `src` 會被加上兩次（`src/src/local.txt`）（PR #1032）。

### 驗證及限制
- 瀏覽器：載入瀏覽器程式碼的 12 個測試檔案共 348 項測試均通過，包括關閉儲存對話時開啟一般首頁、以及在檢查頁面不重新載入的新測試（PR #1038）。已在安裝的 0.8.75 上觀察 10 分鐘：沒有 429 回應，所有重新載入都來自 Cloudflare 的程式。
- 其他 PR 已在各自的 PR 中測試：132 項對話代理及沙箱測試（PR #1030）、72 項對話介面及寵物測試（PR #1031）、在 Windows、Linux 及 macOS 上的 Rust 修補測試（PR #1032）、13 項情境及生命週期測試（PR #1033）。
- 以上各項尚未在已安裝的應用程式中檢查。通過 Cloudflare 檢查不屬於此版本；這取決於代理出口或瀏覽器。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.75 的所有內容。
