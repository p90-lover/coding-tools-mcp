# Coding Tools 0.8.76

## English

### Chats
- Opening a chat no longer draws its whole conversation in the click. The click draws the chat with its newest three turns; the rest of its newest 16 follow in one background render once that frame is on screen, and only while the chat is shown. The Mission Board's task graph, hidden behind the chat, is no longer rebuilt and measured each time you open a chat. In a test with 10 chats side by side (16 turns each), a chat showed in about 95 ms instead of about 160 ms, and the longest freeze fell from about 170 ms to about 135 ms (PR #1038).
- Stopping a chat while its sandbox is still being set up no longer lets the cancelled command start afterwards (PR #1030).
- A hidden chat page pauses its pet's animation and timers; they come back when the page is shown (PR #1031).
- The context cache saves one snapshot at a time, in order, and a stopped runtime can no longer overwrite its replacement's readings (PR #1033).
- A message with more than ten images keeps the newest ten, and says which were left out, instead of the first ten (PR #1040).

### Sidebar and chat
- The GPT Browser no longer goes black while the sidebar slides over it: a still of the page stands in until the sidebar leaves (PR #1043).
- The sidebar has one toggle, the one in the title bar; its own toggle and the logo on the collapsed rail are gone. Opening and closing glide on one eased curve instead of a spring (PR #1043).
- The goal bar keeps one row at every width: a long goal ends in "…", and the state and running time always show in full. Model judges is an icon toggle there, and hovering it says what it does (PR #1043).
- "Allow … to run this command" and other requests float, slimmer, over the bottom of the chat just above the chat box, instead of pushing the conversation up (PR #1043).

### Browser
- The Browser tab opens ChatGPT's plain home (`chatgpt.com`) instead of a Temporary Chat, whatever "Save chats in ChatGPT" says. This covers the first page at startup, sign-in, sign-out, passkey sign-in and a new tab. Task turns and connector checks still open the chat the setting chooses (PR #1038).
- While ChatGPT shows Cloudflare's security check, the app no longer reloads the page for its connector check. That reload only added a request and a flash, then failed on the same check after a minute. The check is now named straight away. The page's own refresh every few minutes comes from Cloudflare's check script, not from the app (PR #1038).
- Camoufox was added as an App plugin (PR #1036) and removed again (PR #1037) before this release, so nothing changes for it.

### Tools
- With a default working directory set, `apply_patch` and `patch_check` resolve a relative path against it once. Before, `src` was added twice (`src/src/local.txt`) (PR #1032).
- A Codex patch whose paths start with `a/` or `b/` keeps those folders, both when it runs and in its approval. Before, they were stripped as if it were a unified diff, and the patch went to the wrong file (PR #1039).
- A patch is refused before anything is replaced if an existing file can't be read for its backup. Before, a later failure could leave that file empty (PR #1035).
- Git status reads ahead/behind counts from bracketed tracking info, and names a new branch with no commits correctly (PR #1042).

### Updates and runtime
- When an update fails and its rollback fails too, the recovery files are kept, the incomplete restore is reported as such, and the app relaunches only after a verified recovery (PR #1041).
- Checks that chat hosts are alive run on a worker instead of the app's main thread, and AO responses are capped before they are buffered: 900 KB, or 16 MB for a conversation (PR #1029).

### Verification and limitations
- Chats: 262 + 58 + 67 chat tests and 475 workflow tests pass, plus the other renderer suites that load the chat (PR #1038). The timings above come from the real chat code with production React in a GPU window, against main's code on the same data, not from the installed app.
- Browser: 348 tests across the 12 files that load the browser code pass (PR #1038). The installed app was watched for 10 minutes on 0.8.75: 0 responses with 429, and every reload came from Cloudflare's script.
- The other PRs were tested in their own PRs: 206 sidebar, GPT Browser and chat UI tests (PR #1043), 132 chat-agent and sandbox tests (PR #1030), 72 chat UI and pet tests (PR #1031), the Rust patch tests on Windows, Linux and macOS (PR #1032, PR #1039), 13 context and lifecycle tests (PR #1033), 42 prompt tests (PR #1040), and their own checks (PR #1029, PR #1035, PR #1041, PR #1042).
- None of these is checked in the installed app yet. Passing Cloudflare's check is not part of this release; that depends on the proxy exit or the browser.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.75 is included.

## 繁體中文

### 對話
- 開啟對話時，不會再在點擊當下繪製整段對話。點擊時只繪製對話及其最新三個回合；最新 16 個回合中的其餘部分，會在該畫面顯示後以一次背景繪製補上，而且只在對話顯示時進行。隱藏在對話後面的「任務看板」任務圖，不會再在每次開啟對話時重建及量度。在 10 個對話並排（每個 16 個回合）的測試中，對話約 95 毫秒便顯示，而非約 160 毫秒；最長的停頓由約 170 毫秒減至約 135 毫秒（PR #1038）。
- 在沙箱仍在設定時停止對話，已取消的指令不會在之後啟動（PR #1030）。
- 隱藏的對話頁面會暫停寵物的動畫及計時器；頁面再次顯示時會恢復（PR #1031）。
- 情境快取每次只按順序儲存一個快照，已停止的執行階段不會再覆寫取代它的執行階段的讀數（PR #1033）。
- 含超過十張圖片的訊息會保留最新的十張，並說明哪些被略去，而非保留最先的十張（PR #1040）。

### 側邊欄及對話
- 側邊欄滑過 GPT 瀏覽器時不會再變黑：在側邊欄離開前，會以頁面的靜態畫面代替（PR #1043）。
- 側邊欄只有一個開關，即標題列上的那個；側邊欄本身的開關及收合欄上的標誌已移除。開啟及關閉改為沿同一條緩動曲線滑動，而非彈簧效果（PR #1043）。
- 目標列在任何寬度都保持一行：過長的目標以「…」結尾，狀態及執行時間永遠完整顯示。「模型判斷」在目標列上是圖示開關，滑鼠停留時會說明其作用（PR #1043）。
- 「允許 … 執行此指令」等請求會以更精簡的樣式浮現在對話底部、對話框正上方，不再把對話往上推（PR #1043）。

### 瀏覽器
- 「瀏覽器」分頁會開啟 ChatGPT 的一般首頁（`chatgpt.com`），而不是臨時對話，不論「在 ChatGPT 中儲存對話」如何設定。這涵蓋啟動時的第一個頁面、登入、登出、密碼金鑰登入及新分頁。任務回合及連接器檢查仍會開啟設定所選的對話類型（PR #1038）。
- 當 ChatGPT 顯示 Cloudflare 安全檢查時，應用程式不會再為連接器檢查而重新載入頁面。該次重新載入只會多送一個請求並令畫面閃動，一分鐘後仍因同一檢查而失敗。現在會立即指出是安全檢查。頁面每隔數分鐘的自行重新整理來自 Cloudflare 的檢查程式，而非應用程式（PR #1038）。
- Camoufox 曾加入為應用程式外掛（PR #1036），並在此版本前再次移除（PR #1037），因此其相關部分沒有任何改變。

### 工具
- 設定了預設工作目錄時，`apply_patch` 及 `patch_check` 只會以它解析相對路徑一次。過去 `src` 會被加上兩次（`src/src/local.txt`）（PR #1032）。
- 路徑以 `a/` 或 `b/` 開頭的 Codex 修補，在執行及批准時都會保留這些資料夾。過去它們會被當作統一差異格式而被移除，令修補寫到錯誤的檔案（PR #1039）。
- 若現有檔案無法讀取以作備份，修補會在取代任何內容前被拒絕。過去其後的失敗可能令該檔案變成空白（PR #1035）。
- Git 狀態會從加上括號的追蹤資訊讀取領先及落後數目，並正確顯示尚未有提交的新分支名稱（PR #1042）。

### 更新及執行階段
- 更新失敗而還原亦失敗時，會保留復原檔案，如實回報還原未完成，並只在確認復原後才重新啟動應用程式（PR #1041）。
- 檢查對話主機是否仍在運作的工作改在背景執行緒進行，而非應用程式的主執行緒；AO 回應在緩衝前已設上限：900 KB，對話則為 16 MB（PR #1029）。

### 驗證及限制
- 對話：262 + 58 + 67 項對話測試及 475 項工作流程測試均通過，另有其他載入對話的渲染程序測試套件（PR #1038）。上述時間來自以正式版 React 在 GPU 視窗中執行的實際對話程式碼，並以相同資料與 main 的程式碼比較，而非來自已安裝的應用程式。
- 瀏覽器：載入瀏覽器程式碼的 12 個測試檔案共 348 項測試均通過（PR #1038）。已在安裝的 0.8.75 上觀察 10 分鐘：沒有 429 回應，所有重新載入都來自 Cloudflare 的程式。
- 其他 PR 已在各自的 PR 中測試：206 項側邊欄、GPT 瀏覽器及對話介面測試（PR #1043）、132 項對話代理及沙箱測試（PR #1030）、72 項對話介面及寵物測試（PR #1031）、在 Windows、Linux 及 macOS 上的 Rust 修補測試（PR #1032、PR #1039）、13 項情境及生命週期測試（PR #1033）、42 項提示測試（PR #1040），以及各自的檢查（PR #1029、PR #1035、PR #1041、PR #1042）。
- 以上各項尚未在已安裝的應用程式中檢查。通過 Cloudflare 檢查不屬於此版本；這取決於代理出口或瀏覽器。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.75 的所有內容。
