Coding Tools 0.8.3

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Chat:

- Approve for me now reviews requests with Codex's own auto-review model. It was never used before (CPA hides it from model menus), and the model used instead kept answering "ask", so commands kept stopping for you.
- The approval card is Codex's size: the chat box's width, its 13px text, 28px options and buttons.
- Switching to another project shows its chats right away (or "Loading chats…") instead of "No chats yet", and a chat opened from another project's list opens on its own run.
- Subagents work: chat agents are told they may hand a self-contained part of the work to your subagents, and the Runtime > Subagents page is readable again.
- A Native Codex card shows the commands and tools it is running; a reworked reviewer keeps its verdict; a failed step can retry itself; agy offers every pool model, with brand logos in a compact picker.
- Clawd is Claude Code's own Clawd, with a house, and can be dragged anywhere.

Stability:

- The app's log is written in the background: on a busy hard disk, writing each line used to hold the whole app (an action could wait 14 s).
- A window that stalls for a few seconds on a slow disk is no longer killed and reloaded; only one hung for a full minute is.
- The Activity page shows real problems: the bridge's routine progress is no longer logged as warnings.
- The proxy gateway finds a leftover relay holding its port instead of rotating its key over and over.
- Team runs: the reviewer's verdict needs no person, tool titles are folded, and Activity errors can be traced.

Everything in 0.8.2 is included.
