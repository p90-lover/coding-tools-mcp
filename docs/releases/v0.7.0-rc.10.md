# Coding Tools v0.7.0-rc.10

## English

This prerelease is the next exact-source Windows publish after frozen `v0.7.0-rc.8` and `v0.7.0-rc.9`. It packages the current `release/codex-router-multiprovider-0.7.0-rc.8` tree, including Desktop shell restoration (#177) and original CPA / Codex Router Control Center wiring (#180), without rewriting those earlier tags.

### Why a new version

- `v0.7.0-rc.8` already points at `5aa516e35e8f9824d3309a4016f3f309f33d956c`.
- `v0.7.0-rc.9` is already published as a separate prerelease.
- Later merges on the rc.8 release branch therefore publish as `v0.7.0-rc.10` instead of moving an existing tag.

### Desktop contents carried forward

- Original Desktop shell navigation (Workspace, Configuration, Runtime, Settings) with live MCP tool wiring.
- Original CPA management panel and Codex Router Control Center, hosted as managed local runtimes.
- Architecture B five-stack control plane, Provider Hub, installer identity, and per-user NSIS/MSI migration remain unchanged.

### Packaging and migration

- Electron Builder publication autodetection stays disabled; only the exact-source release publisher may upload GitHub assets.
- The Windows installer keeps the validated legacy NSIS and MSI migration path, the stable Electron app id, and user data.
- Release validation covers identity alignment, focused five-stack contracts, isolated renderer inspection, Windows packaging, packaged launcher smoke, migration acceptance, checksums, provenance, and remote asset readback.

### Exact-source provenance

- The publisher checks out the immutable triggering SHA and refuses publication if the remote release branch advances during verification.
- Existing tags are never force-moved: if `v0.7.0-rc.10` already exists on another SHA, publication fails closed.
- Windows installer assets are uploaded only after the packaging, migration, and no-deletion gates pass.

### Validation boundary

Automated validation does not consume paid provider quota. Live account and external local-service acceptance remains an explicit manual boundary.

## 繁體中文

呢個 prerelease 係凍結咗 `v0.7.0-rc.8` 同 `v0.7.0-rc.9` 之後嘅下一個 exact-source Windows 發佈。佢會打包而家 `release/codex-router-multiprovider-0.7.0-rc.8` 樹上嘅 Desktop shell 還原（#177）同原始 CPA / Codex Router Control Center 接線（#180），而且唔會改寫舊 tag。

### 點解要用新版本

- `v0.7.0-rc.8` 已經指向 `5aa516e35e8f9824d3309a4016f3f309f33d956c`。
- `v0.7.0-rc.9` 已經作為另一個 prerelease 發佈。
- 所以 rc.8 release branch 上之後嘅合併會發佈做 `v0.7.0-rc.10`，而唔會移動現有 tag。

### 帶住嘅 Desktop 內容

- 原本 Desktop shell 導航（Workspace、Configuration、Runtime、Settings）同 live MCP tool 接線。
- 原本 CPA management panel 同 Codex Router Control Center，以 managed local runtime 形式托管。
- 架構 B 五項控制平面、Provider Hub、installer identity，同 per-user NSIS/MSI migration 保持不變。

### 打包同 Migration

- 仍然停用 Electron Builder 自動推斷 publication；只有 exact-source release publisher 可以上傳 GitHub asset。
- Windows installer 保留已驗證嘅舊 NSIS／MSI migration 流程、穩定 Electron app id，同使用者資料。

- Publisher 只會 checkout 觸發 workflow 嘅固定 SHA；如果驗證期間遠端 release branch 有更新，就會拒絕發佈。
