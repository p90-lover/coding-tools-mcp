# Coding Tools 0.8.31

## English

### Improvements
- ProxyBridge Nova now runs as part of Coding Tools. It starts with the app (before, a new install only started it after "Start ProxyBridge Nova" was pressed, so every request went to a proxy with nothing behind it). It is started again if it stops, and it stops when Coding Tools quits. A restart from inside the app keeps it running (PR #652).
- Quitting or updating Coding Tools ends every process it started, including chat hosts and their agents. Before, they could keep running for days. A spent Cline Pass window is now reported as a 429 instead of a 502, so CPA and Claude Code no longer retry it dozens of times per turn (PR #650).
- Long chats are much lighter: an edit's diff is built only when you open it. Folded diffs made up most of the window's elements. An update that would be refused is now refused before it downloads (PR #651).
- Clawd stays visible when dragged over the Preview pane. A model whose quota is used up pauses the goal instead of retrying, while a short "too many requests" cooldown is still retried (PR #649).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from this branch and confirm CI before publication.
- Everything in 0.8.30 is included.

## 繁體中文

### 更新內容
- ProxyBridge Nova 現在是 Coding Tools 的一部分：它會隨應用程式啟動（之前新安裝後要按下「Start ProxyBridge Nova」才會啟動，期間所有請求都會送往一個沒有服務的代理），停止後會自動重新啟動，並在 Coding Tools 結束時一併停止。在應用程式內重新啟動時，它會繼續執行（PR #652）。
- 結束或更新 Coding Tools 時，會結束它啟動的所有程序，包括對話主機及其代理；之前它們可能持續執行好幾天。Cline Pass 額度時段用完時，現在會回報 429 而不是 502，CPA 和 Claude Code 不會再在每個回合重試數十次（PR #650）。
- 長對話明顯更輕：編輯的差異內容要在打開時才會建立；之前摺疊的差異佔了視窗大部分元素。會被拒絕的更新現在會在下載前便被拒絕（PR #651）。
- 把 Clawd 拖到預覽窗格上時，它會保持可見。模型額度用完時目標會暫停而不是重試；短暫的「請求過多」冷卻仍會重試（PR #649）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由本分支編譯及通過 CI 才能公開。
- 包含 0.8.30 的所有內容。
