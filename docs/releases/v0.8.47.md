# Coding Tools 0.8.47

## English

### Browser and accounts
- MCP setup in Browser Management no longer finishes after its account or tunnel changed, and no longer reuses a same-name connector without the tunnel's current identity (PR #828).
- An account row and its action show the same, latest status, so an older success no longer covers a newer failure; connecting is disabled while the account is being removed (PR #828).
- Workspace owner and admin setup and subscription detection from 0.8.46 are kept (PR #828).

### Updates
- An automatic update rollback no longer forces the app to quit when new work starts during its health check; it checks again right before handing off and keeps the work (PR #827).

### Search
- Text search and grep stop at their time budget inside very long lines and directory walks, and report that the budget ran out, while keeping whole lines and partial results (PR #826).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from main, and confirm CI before publication.
- Not included: PR #814 (its CI fails), PR #815 (conflicts with main), PR #816 (no CI run) and the draft "rescue:" snapshots #829–#854 (conflict or blocked).
- Everything in 0.8.46 is included.

## 繁體中文

### 瀏覽器與帳號
- 瀏覽器管理中的 MCP 設定不會在帳號或通道改變後才完成，也不會在缺少通道目前身分時重用同名連接器（PR #828）。
- 帳號列與其操作顯示同一個最新狀態，舊的成功訊息不再蓋過較新的失敗；移除帳號期間會停用連接（PR #828）。
- 保留 0.8.46 的工作區擁有者及管理員設定與訂閱偵測（PR #828）。

### 更新
- 健康檢查期間開始新工作時，自動更新回復不再強制結束程式；它會在交接前再次檢查並保留工作（PR #827）。

### 搜尋
- 文字搜尋和 grep 在很長的行和資料夾走訪中也會遵守時間預算，並回報預算已用完，同時保留完整的行和部分結果（PR #826）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由 main 編譯及通過 CI 才能公開。
- 未包含：PR #814（其 CI 失敗）、PR #815（與 main 衝突）、PR #816（沒有執行 CI）及草稿「rescue:」快照 #829–#854（衝突或受阻）。
- 包含 0.8.46 的所有內容。
