# Coding Tools 0.8.73

## English

### Chats
- Long chats no longer slow the app down. Each chat drew every turn it ever had. With ten chats open on 0.8.68, the window held 164,000 elements, up to 41,500 of them in one long goal chat. In the visible window, restyling them kept the renderer busy about 70% of the time, with frames of up to 1 second, and a mouse move waited 3.4 seconds for a response. A chat now draws its newest 16 turns. A "Show 16 earlier turns" row above them brings back more, 16 at a time. Folded goal rounds keep their row. Switching chats starts again from the newest 16 (PR #1003).

### Verification and limitations
- A new test covers which turns are drawn, including a folded run of goal rounds. All 721 chat tests pass, and the type check is clean.
- The numbers above were measured in the installed 0.8.68 over 30 seconds with the window visible. The same measurement on this version is still to be taken.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.72 is included.

## 繁體中文

### 對話
- 長對話不會再拖慢應用程式。過去每個對話都會繪製它所有的回合。在 0.8.68 開啟十個對話時，視窗共有 164,000 個元素，單一長目標對話多達 41,500 個。視窗可見時，重新計算這些元素的樣式令渲染程序約 70% 時間處於忙碌狀態，單一畫格最長達 1 秒，移動滑鼠要等 3.4 秒才有回應。現在每個對話只繪製最新的 16 個回合，上方的「Show 16 earlier turns」列可再載入更早的回合，每次 16 個。已摺疊的目標回合仍保留其摺疊列。切換對話時，會重新從最新的 16 個回合開始（PR #1003）。

### 驗證及限制
- 新測試涵蓋繪製哪些回合，包括已摺疊的目標回合。所有 721 項對話測試均通過，型別檢查亦無錯誤。
- 上述數字是在已安裝的 0.8.68 中，於視窗可見時量測 30 秒所得。此版本的同一量測仍待進行。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.72 的所有內容。
