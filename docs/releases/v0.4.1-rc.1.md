# Coding Tools MCP v0.4.1-rc.1 — Live permissions

## English

Permission-only saves now apply to active MCP and Actions listeners without a
service restart, tunnel restart, new OAuth secret or MCP relink. Current revision
and permission mode are visible in server_info. Short-operation concurrency is
fenced; a busy Save fails without partial persistence and can be retried. Changed
policies invalidate prior approval grants and request termination of active owned
command sessions, retaining their output and refusing further stdin. Submitted
OS actions cannot be recalled. Turning off capture or restricting computer input
revokes the affected workspace's control.

Includes the SaaS control center, local delivery board and read-only Paseo/Anneal
management adapters from v0.4.0, plus remembered Always enabled, approved background
observation, RAM-only screenshots, exact-agent/live monitor and emergency Stop.
Adds local update_plan, get_plan, tool_search, get_current_time and
codex_tools_status. They run without Codex inference or a second AI reviewer.

Tool-profile/catalog changes may require a client tool-list refresh; permission
mode changes do not. Authentication, root or port changes are separate lifecycle
changes. Remembered application consent stays security-configuration-bound, so a
changed security configuration may require local application reapproval.

This is NOT all of Codex or the complete upstream Paseo/Anneal engines. Agent
inference, autonomous reviews/merges, mobile relay and voice are not bundled.
The native command sandbox remains withheld; exec_command remains policy_only.
Silent ChatGPT connector creation/reauthorization and the user's live
Cloudflare/ChatGPT environment are not verified. Native computer input is
Windows-only. Windows is publisher-unsigned; macOS is ad-hoc signed, not notarized.

Release gates include a real same-listener authenticated HTTP permission-switch
fixture, atomicity/stale-grant checks, local tool round trips, frontend build,
existing computer/vision/management checks, real Windows input/background capture,
and packaged binary/version/license verification. Assets are downloaded and their
SHA-256 hashes compared before publication. No files or older releases are deleted.

## 繁體中文

只變更權限時，儲存會即時套用至運行中的 MCP／Actions，不必重啟服務、重啟隧道、
更換 OAuth 憑證或重新連接 MCP。server_info 會顯示目前權限及修訂版。
短操作受並行保護；若儲存時忙碌，會拒絕而不部分儲存，可以直接重試。
權限變更會撤銷舊授權，要求停止運行中的所屬命令程序，保留輸出並拒絕後續輸入；
已送出的作業系統操作不能追回。關閉截圖或限制電腦輸入會撤銷該工作區的控制。

保留 v0.4.0 的 SaaS 控制中心、本機交付看板及唯讀 Paseo／Anneal 介接器，
亦保留記住持續啟用、已批准背景視窗觀察、記憶體截圖、GPT 所見／即時監控及緊急停止。
新增 update_plan、get_plan、tool_search、get_current_time、codex_tools_status，
均不啟動 Codex 模型或另一個 AI 審查員。

工具目錄／設定檔改動可能需要用戶端刷新工具清單；權限模式變更不需要。
認證、工作區路徑及連接埠變更屬於另一類服務生命週期變更。
已記住的程式批准仍與安全設定綁定，變更安全設定後可能需要本機重新批准程式。

並非完整 Codex、Paseo 或 Anneal 引擎；未包含模型 Agent、自動審查／合併、手機中繼及語音。
原生命令沙箱仍未納入，exec_command 仍只受軟體策略限制。靜默建立／重新授權
ChatGPT 連接，以及你的實際 Cloudflare／ChatGPT 環境未經驗證。電腦輸入只支援 Windows。
Windows 沒有發佈者簽署；macOS 為 ad-hoc 簽署，未公證。

發佈閘門涵蓋同一個已認證 HTTP 監聽服務上的權限切換、原子儲存／過期授權檢查、
本機工具往返、前端建置、現有電腦／視覺／介接器檢查、真實 Windows 輸入／背景截圖，
以及安裝程式內實際執行檔、版本及授權條款檢查。公開前重新下載並核對 SHA-256。
沒有刪除檔案或舊版本。
