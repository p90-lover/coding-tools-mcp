Coding Tools 0.7.0-rc.24

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Fixes:
- Chat: DeepSeek V4.1 Flash on Cline Pass offers None, Low, High, and Max. Max stays max in the provider request; it is not sent as xhigh. The provider receives its original model name.
- Chat Terminal: the command tool tells the agent which Windows shell it uses and to keep servers attached to the chat, with their output in Terminal and their page in Preview.
- Cline Pass: Windows line endings no longer break the provider-probe patches in the bundled plugin.

Everything in rc.23 is included.
