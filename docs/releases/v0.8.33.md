# Coding Tools 0.8.33

## English

### Improvements
- The Browser tab holds several ChatGPT accounts, each with its own sign-in. A switcher in the tab's toolbar adds, switches and removes accounts, in the Browser tab's own style. Codex's WebGPT chats run on the account in use, and the plan check re-reads the new account's plan after a switch. A switch waits while a chat turn, a manual operation or a sign-in is running (PR #665).
- ChatGPT browser management, a new page under Browser in the sidebar, lists every ChatGPT account. It shows which one is in use and signed in, how many tabs it has open and running, and the proxy bound to it with its latency or last error. Each account can be checked, used or removed from the list (PR #666).
- One proxy per ChatGPT account. An account can bind a proxy that no other account holds, and its browser session keeps that proxy even when Global Routing is on. A proxy's sign-in request is answered only with that proxy's own sign-in. If a bound proxy is removed or disabled, the account falls back to Global Routing and its row says so (PR #666).
- Decodo proxies sync into the app. Enter the Decodo proxy user, country, number of proxies and session length, and "Sync from Decodo" fetches sticky endpoints, the same call ProxyBridge Nova makes. They become proxy profiles that keep their identity, so a later sync updates them in place and keeps every binding. "Give each one its own Decodo proxy" binds a free endpoint to every account without one (PR #666).
- Every program the app starts gets the proxy from launch: AO, the Codex bridge and the MCP tunnel no longer start before the proxy is applied. Node programs (MCP servers, CLIs and the tunnel's codex.js) now use it too instead of going direct (PR #664).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from this branch and confirm CI before publication.
- Decodo's API takes the proxy user's password as a request parameter; the app stores it encrypted and never shows it.
- Everything in 0.8.32 is included.

## 繁體中文

### 更新內容
- 「Browser」分頁可容納多個 ChatGPT 帳戶，各自保留登入資料：分頁工具列上的切換器可新增、切換和移除帳戶，樣式與「Browser」分頁一致。Codex 的 WebGPT 對話在使用中的帳戶上執行，切換後會重新讀取新帳戶的方案；對話回合、手動操作或登入進行期間，切換會等待完成（PR #665）。
- 側邊欄「Browser」下新增「ChatGPT browser management」頁面，列出所有 ChatGPT 帳戶：哪個正在使用及是否已登入、開啟及執行中的分頁數目，以及綁定的代理伺服器與其延遲或最近錯誤；每個帳戶都可在清單中檢查、使用或移除（PR #666）。
- 每個 ChatGPT 帳戶各綁定一個代理伺服器：帳戶可綁定其他帳戶未佔用的代理，即使開啟「Global Routing」，其瀏覽器工作階段仍使用該代理；代理的登入要求只會以該代理自己的登入資料回應。綁定的代理被移除或停用時，帳戶會改用「Global Routing」，清單中會顯示提示（PR #666）。
- Decodo 代理可同步至應用程式：輸入 Decodo 代理使用者、國家、代理數目和工作階段長度後，「Sync from Decodo」會取得固定工作階段的端點（與 ProxyBridge Nova 使用相同的請求），轉為保留識別的代理設定檔；之後再同步會直接更新，所有綁定都會保留。「Give each one its own Decodo proxy」會為每個尚未綁定的帳戶綁定一個空閒端點（PR #666）。
- 應用程式啟動的每個程式從啟動起就使用代理：AO、Codex 橋接器和 MCP 通道不會再在套用代理前啟動；Node 程式（MCP 伺服器、命令列工具及通道的 codex.js）現在也會使用代理，不再直接連線（PR #664）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由本分支編譯及通過 CI 才能公開。
- Decodo 的 API 以請求參數傳送代理使用者的密碼；應用程式以加密方式儲存，不會顯示密碼。
- 包含 0.8.32 的所有內容。
