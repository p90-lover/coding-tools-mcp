# Coding Tools 0.8.100

## English

### Every harness can use CPA's models
- **Pi and Unreal Agent list the whole CPA pool.** Before, Pi offered only the Web GPT models and Unreal Agent offered only its own model, because the CPA gateway reached Claude Code, Codex, opencode and Antigravity only. Agent Orchestrator now points Pi and Unreal Agent at CPA too.
- **How Pi gets there.** Pi has no setting for another server address. AO's own Pi extension adds CPA as a provider named `coding-tools-cpa`, and only for a chat that runs a CPA model. The key is passed by environment variable and never written to a file. Your own Pi providers and settings are not changed.
- **Pi can set a context window, but only on a CPA model.** Unreal Agent has no window setting.
- Cline still offers only its own models. It has no way to take another server address for one run without changing its saved configuration.

### Gemini and its provider are always allowed
- **Antigravity's Gemini and Claude models are offered on Claude Code again.** They had been hidden there and marked "not available" since 2026-10-22, after Antigravity answered requests with Claude Code's identity line with a misleading "quota exhausted". A subagent on one of those models is no longer refused at launch. This is your choice: if Antigravity refuses such a request again, the chat shows that error instead of hiding the model.

### Harness logos are AO's own
- **Every harness shows the logo Agent Orchestrator itself shows for it.** The picker used to take logos from several places, and some were the wrong brand:
  - Claude Code showed the Claude app's starburst.
  - Codex and Native Codex showed OpenAI's knot.
  - Pi showed a GitHub avatar that looked like an arrow.
  - AO's Unreal Agent showed the Unreal Engine logo.
- The logos are copied unchanged from the pinned AO frontend. Model logos are unchanged.

### Verification and limitations
- GitHub Actions is still unavailable, so this release depends on local checks. It does not claim that CI passed.
- **App tests:** the workflow, subagent, harness picker, chat UI, Codex chat view and changed-file suites pass, and the renderer type check is clean. The logos were checked in a renderer harness in light and dark themes, with no broken images. They were not yet checked in the installed app.
- **AO tests:** the new AO tests pass, as do AO's `ports` and Unreal Agent packages. The `pi` and `session_manager` packages each have Windows-only failures (2 and 9 tests). These fail the same way without this change.
- **Pi, tested live (Pi 1.5.0 through CPA):** Pi listed the registered model and answered a turn. A model id with a slash and an effort suffix reached CPA, and Gemini 3.8 Flash ran a file-read tool.
- Unreal Agent on CPA has been checked only by tests, not in a live chat.
- Includes everything in 0.8.99.

## 繁體中文

### 每個 harness 都能使用 CPA 的模型
- **Pi 與 Unreal Agent 會列出整個 CPA 模型池。** 先前 Pi 只提供 Web GPT 模型，Unreal Agent 只提供它自己的模型，因為 CPA 閘道只連接 Claude Code、Codex、opencode 與 Antigravity。Agent Orchestrator 現在也讓 Pi 與 Unreal Agent 使用 CPA。
- **Pi 如何連上 CPA。** Pi 沒有可指定其他伺服器位址的設定。AO 自己的 Pi 擴充功能會把 CPA 加為名為 `coding-tools-cpa` 的 provider，而且只在執行 CPA 模型的對話中才加入。金鑰透過環境變數傳遞，從不寫入檔案。你自己的 Pi provider 與設定都不會被更改。
- **Pi 可以設定 context window，但只限 CPA 模型。** Unreal Agent 沒有 window 設定。
- Cline 仍只提供它自己的模型。它無法在不更改已儲存設定的情況下，為單次執行改用其他伺服器位址。

### Gemini 及其 provider 一律允許使用
- **Claude Code 再次提供 Antigravity 的 Gemini 與 Claude 模型。** 自 2026-10-22 起，這些模型在 Claude Code 中被隱藏並標示為「not available」。原因是 Antigravity 對帶有 Claude Code 身分說明的請求，回覆了誤導性的「quota exhausted」。使用這些模型的子代理也不會再於啟動時被拒絕。這是你的選擇：若 Antigravity 再次拒絕這類請求，對話會顯示該錯誤，而不是隱藏模型。

### Harness 標誌改用 AO 自己的標誌
- **每個 harness 都顯示 Agent Orchestrator 本身為它顯示的標誌。** 選擇器先前從多個來源取用標誌，部分是錯誤的品牌：
  - Claude Code 顯示 Claude 應用程式的星芒標誌。
  - Codex 與 Native Codex 顯示 OpenAI 的結形標誌。
  - Pi 顯示看起來像箭頭的 GitHub 頭像。
  - AO 的 Unreal Agent 顯示 Unreal Engine 的標誌。
- 這些標誌原封不動地取自目前釘選的 AO 前端。模型標誌不變。

### 驗證與限制
- GitHub Actions 仍無法使用，因此本版本依靠本機檢查，並不宣稱 CI 已通過。
- **應用程式測試：** workflow、子代理、harness 選擇器、對話 UI、Codex 對話檢視及變更檔案等測試套件全部通過，renderer 型別檢查沒有錯誤。標誌已在 renderer 測試頁面中以淺色與深色主題檢查過，沒有破損的圖片，但尚未在已安裝的應用程式中檢查。
- **AO 測試：** 新增的 AO 測試通過，AO 的 `ports` 與 Unreal Agent 套件也通過。`pi` 與 `session_manager` 套件各有只在 Windows 上失敗的測試（分別 2 個和 9 個）；沒有這項變更時，它們同樣會失敗。
- **Pi 實際測試（Pi 1.5.0 經由 CPA）：** Pi 列出了註冊的模型並回覆了一個回合。含斜線與 effort 後綴的模型 ID 有送達 CPA，Gemini 3.8 Flash 也執行了讀取檔案的工具。
- CPA 上的 Unreal Agent 只經過測試檢查，尚未在實際對話中檢查。
- 包含 0.8.99 的所有內容。
