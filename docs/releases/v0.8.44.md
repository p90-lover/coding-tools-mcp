# Coding Tools 0.8.44

## English

### Smoother app
- Hidden chat panes and the Email tab stop their background checks until you open them again (PR #776).
- Working shimmers that start while the window is minimized pause too, not just the ones already running (PR #769).
- A long message with an unmatched backtick no longer slows the chat while it is drawn (PR #774).
- Large HTML emails are previewed and cleaned within a bounded amount of work (PR #780).
- Usage accounting skips reading conversations it does not need for sessions it already measured (PR #760).

### Chats
- Unsent text, files and annotations stay with their pane and project when you switch views or open the Board (PR #765).
- A message you just sent shows only in its own project and pane (PR #790).
- The file viewer shows the reply to your latest request, not an older one (PR #788).
- Sent image previews release their memory once settled (PR #781).
- Goals ignore stale evaluations and queued continuations from an earlier run (PR #758).
- AO keeps a turn's ownership when a stop fails or a request errors, and steering no longer waits on a held lock (PR #773).
- WebGPT's local tools and stateful panels are back in both chats (PR #735).

### WebGPT and Codex
- A failed send's retries stop with their turn, stale connector approvals are cancelled, and an action cancelled by its own turn is reported as cancelled, not as an error (PRs #786, #787, #791).
- A Connect started before Stop is refused instead of attaching to the stopped session, and an explicit revoke is kept when a Stop races it (PRs #785, #789).
- Approval locks are released before an expired approval shuts down (PR #775).

### Browser, Email and credentials
- Tab limits count the tabs of parked accounts too (PR #757).
- An unreadable account file, saved key or credential store is kept for a later read instead of being replaced (PRs #762, #771, #778).
- Each Email account's reader state and replies stay with that account (PR #770), and attachments you add are not pasted into the message text (PR #792).

### Reliability
- The headless service reserves request IDs and keeps replacement AO connections when cleaning up stale ones (PRs #761, #772).
- Startup can be retried after a failed preparation or snapshot, and MCP setup keeps the launcher's metadata (PRs #767, #782, #784).
- The updater cleans its staging folders and keeps rollback bundles (PR #759).
- Saved outcomes survive a failed backup cleanup, and history reports and archive reads are bounded (PRs #763, #783).
- Command tools resolve folders from the chosen working folder and honour output size limits; process trees are found completely, and macOS reads parent processes correctly (PRs #766, #768, #777, #779).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from main, and confirm CI before publication.
- Not included: PR #733 (its CI fails), PR #793 (it conflicts with #785 and needs a rebase) and PR #794 (opened after this release was cut).
- Everything in 0.8.43 is included.

## 繁體中文

### 更流暢
- 隱藏的對話窗格和電郵分頁會暫停背景檢查，直到你再次打開（PR #776）。
- 視窗最小化時才開始的「處理中」閃動效果也會暫停，而不只是已在執行的（PR #769）。
- 含有未配對反引號的長訊息不再拖慢對話的繪製（PR #774）。
- 大型 HTML 電郵的預覽和清理工作量有上限（PR #780）。
- 用量統計不再為已計算的工作階段讀取不需要的對話（PR #760）。

### 對話
- 切換檢視或打開 Board 時，未傳送的文字、檔案和註解會留在原本的窗格和專案（PR #765）。
- 剛傳送的訊息只會顯示在它所屬的專案和窗格（PR #790）。
- 檔案檢視器顯示你最新請求的回覆，而不是較早的回覆（PR #788）。
- 已傳送的圖片預覽在完成後會釋放記憶體（PR #781）。
- 目標會忽略較早執行留下的過時評估和排隊中的延續（PR #758）。
- 停止失敗或請求出錯時，AO 會保留回合的擁有權，引導指令不再等待被佔用的鎖（PR #773）。
- WebGPT 的本機工具和有狀態面板在兩種對話中恢復（PR #735）。

### WebGPT 與 Codex
- 傳送失敗的重試會隨回合一同停止，過時的連接器核准會被取消，被自身回合取消的動作會顯示為已取消而非錯誤（PR #786、#787、#791）。
- 在停止前開始的連線會被拒絕，不會連到已停止的工作階段；明確撤銷在與停止競爭時會被保留（PR #785、#789）。
- 核准過期關閉前會先釋放核准鎖（PR #775）。

### 瀏覽器、電郵與憑證
- 分頁上限也會計算已停放帳號的分頁（PR #757）。
- 無法讀取的帳號檔、已儲存的金鑰或憑證儲存會被保留以便稍後讀取，而不是被取代（PR #762、#771、#778）。
- 每個電郵帳號的閱讀狀態和回覆會留在該帳號（PR #770），你加入的附件不會被貼到訊息內文中（PR #792）。

### 可靠性
- 無介面服務會預留請求 ID，並在清理過時連線時保留替換的 AO 連線（PR #761、#772）。
- 準備或快照失敗後可以重試啟動，MCP 設定會保留啟動器的中繼資料（PR #767、#782、#784）。
- 更新程式會清理暫存資料夾並保留回復套件（PR #759）。
- 已儲存的結果在備份清理失敗後仍會保留，歷史報告和封存讀取有上限（PR #763、#783）。
- 指令工具從所選的工作資料夾解析資料夾並遵守輸出大小上限；能找出完整的程序樹，macOS 能正確讀取上層程序（PR #766、#768、#777、#779）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由 main 編譯及通過 CI 才能公開。
- 未包含：PR #733（其 CI 失敗）、PR #793（與 #785 衝突，需要重新整合）及 PR #794（在此版本切出後才開啟）。
- 包含 0.8.43 的所有內容。
