# Coding Tools 0.8.44

## English

### Smoother app

- Hidden chat and Email views pause background checks, and working animations pause while the window is hidden or minimized.
- Long messages, large HTML email previews and transcript windows do less repeated parsing and rendering.

### Chats

- Drafts, files and annotations stay with their project and pane across view changes, and rejected queued messages return to their originating chat.
- Late message and file-preview replies apply only to their owning chat or request; IME confirmation keys no longer send messages or select slash commands.
- Goals keep running while minimized and ignore outdated evaluations after you pause, edit or change models.
- Updated WebGPT local-tool discovery and stateful panel transport in both chat views.

### Browser, Email and MCP

- Unreadable account files, saved keys and credential stores are kept for recovery instead of being overwritten.
- Account removal confirmation stays with the selected account, and a task tab that changes conversations cannot be reused or deleted as the original task.
- Email reader state and late replies stay with their Worker, and explicit attachments remain separate from message bodies.
- Browser Management can set up and verify MCP for the selected account, and connector setup waits for the Personal plugin to finish loading.
- Register starts automatically and syncs newly registered accounts to CPA.
- CPA model lists honor provider switches and retain working API-key models.

### Connections and updates

- Native Codex Connect, Stop and revoke actions stay with the intended session; WebGPT retries and connector approvals stop with their turn.
- Startup can be retried after a failed load, MCP setup refreshes saved connection details, and manual download proxy mode uses the configured URL.
- Command tools respect the selected working folder and output limits, with complete child-process lookup and corrected macOS parent-process handling.
- GUI updates clean temporary downloads and retain rollback bundles; saved results survive backup-cleanup failures.

### Security and runtimes

- The app and bridge reject distrusted eMudhra certificate chains, including cross-signed chains, and check tunnel downloads against pinned hashes.
- Updated Bun to 1.4.4 and Electron to 45.2.1; the AO daemon is built with Go 1.27.3.

### Verification and limitations

Includes updates since the previous public release, 0.8.39. Automated source checks do not establish installed-app responsiveness or live panel behavior; those acceptance checks remain outstanding.

## 繁體中文

### 更流暢

- 隱藏的對話和電郵檢視會暫停背景檢查，視窗隱藏或最小化時也會暫停處理中的動畫。
- 長訊息、大型 HTML 電郵預覽和獨立對話視窗會減少重複解析及繪製。

### 對話

- 切換檢視時，草稿、檔案和註解會留在原本的專案及窗格；排隊失敗的訊息會回到原本的對話。
- 延遲的訊息及檔案預覽回覆只會套用到原本的對話或請求；輸入法確認鍵不再誤送訊息或選取斜線指令。
- 視窗最小化時目標仍會繼續執行，暫停、編輯或切換模型後也會忽略過時的評估結果。
- 更新兩種對話檢視中 WebGPT 的本機工具探索及有狀態面板傳輸。

### 瀏覽器、電郵與 MCP

- 無法讀取的帳號檔、已儲存的金鑰和憑證資料會被保留以便復原，不會遭到覆寫。
- 移除帳號的確認只對目前選取的帳號有效；任務分頁切換到另一個對話後，不會再被當成原本的任務重用或刪除。
- 電郵閱讀狀態和延遲回覆會留在原本的 Worker，明確指定的附件也會與訊息內文分開。
- 瀏覽器管理可為所選帳號設定並驗證 MCP，連接器設定也會等待 Personal 外掛載入完成。
- Register 會自動啟動，並將新註冊的帳號同步至 CPA。
- CPA 模型清單會遵守供應商開關，並保留可用的 API 金鑰模型。

### 連線與更新

- 原生 Codex 的連線、停止和撤銷操作會套用到正確的工作階段；WebGPT 重試及連接器核准會隨其回合一同停止。
- 載入失敗後可重試啟動，MCP 設定會更新已儲存的連線資訊，手動下載代理模式也會使用指定網址。
- 指令工具會遵守所選工作資料夾及輸出上限，並完整查找子程序，以及修正 macOS 的上層程序處理。
- 介面更新會清理下載暫存並保留回復套件；備份清理失敗也不會丟失已儲存的結果。

### 安全性與執行環境

- 應用程式及橋接服務會拒絕不受信任的 eMudhra 憑證鏈，包括交叉簽署的憑證鏈；通道下載檔也會比對程式內固定的雜湊值。
- Bun 更新至 1.4.4，Electron 更新至 45.2.1，AO 服務使用 Go 1.27.3 編譯。

### 驗證及限制

包含上一個公開版本 0.8.39 之後的更新。原始碼的自動化檢查無法證明已安裝程式的操作反應或實際面板行為，這些項目仍待驗收。
