# Coding Tools 0.8.88

## English

### CPA
- **Usage and cost on every Auth Files card.** CPA's Auth Files page showed each Codex account's 5-hour and weekly limits, but not what the account had used or what it cost. Each card now has two lines under its size and date:
  - **Last 5 h**, the same window as the 5-hour limit, and **Last 7 days**, the weekly window: requests (and how many failed), tokens, and cost.
  - Hover a line for its input, output, cached and reasoning tokens.
  - The cost is CPA Helper's own price where it has one, otherwise an estimate from list prices (shown with ≈). A "+" means some models had no price, so the real cost is higher.
  - The numbers refresh every 2 minutes while the page is open, and show at once when you come back to it.
- Each card is matched by its auth file name, so two Codex accounts on the same email each show their own numbers.

### Verification and limitations
- New tests run the card script on a stand-in page: both windows, matching by file name, failed requests, unpriced models, unused accounts, and no lines when usage is unavailable. All 134 CPA tests pass.
- In the running app, the script was fed CPA Helper's real per-file records and matched all 14 cards. The finished cards were not seen on screen; the panel was hidden at the time.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.87.

## 繁體中文

### CPA
- **每張「Auth Files」卡片都會顯示用量和費用。** CPA 的 Auth Files 頁面過去只顯示各 Codex 帳戶的 5 小時及每週上限，沒有顯示帳戶實際用了多少、花了多少。現在每張卡片的大小與日期下方多了兩行：
  - **最近 5 小時**（與 5 小時上限相同的時段）及 **最近 7 天**（每週時段）：請求數（及失敗數）、token 數和費用。
  - 將滑鼠移到該行上，可查看輸入、輸出、快取及推理 token。
  - 費用優先採用 CPA Helper 自己的價格；沒有時則按定價估算（以 ≈ 標示）。「+」表示部分模型沒有價格，實際費用會更高。
  - 頁面開啟期間每 2 分鐘更新一次，回到頁面時會立即顯示上次的數字。
- 每張卡片以其 auth 檔案名稱對應，因此同一電郵下的兩個 Codex 帳戶會各自顯示自己的數字。

### 驗證及限制
- 新測試在模擬頁面上執行卡片腳本：兩個時段、按檔案名稱對應、失敗請求、沒有價格的模型、未使用的帳戶，以及用量不可用時不加任何內容。全部 134 項 CPA 測試均通過。
- 在執行中的應用程式中，以 CPA Helper 真實的逐檔案記錄驅動腳本，14 張卡片全部正確對應。完成後的卡片未能在畫面上確認，因為當時面板處於隱藏狀態。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.87 的所有內容。
