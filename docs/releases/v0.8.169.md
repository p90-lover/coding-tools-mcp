# Coding Tools v0.8.169

## English

### Sidebar
- **The Orchestrator's own app is now Runtime > Chats.** It was "Agent Orchestrator", folded under More. It now sits right after Chat, which stays the chat built on the Orchestrator, and its header and loading text say "Orchestrator".

### Approvals
- **A team's commands wait for its Command approver, also on Approve for me cards.** In a team whose Command approver had not approved yet, a card set to Approve for me had its commands and tool requests allowed after 20 seconds, with nothing having reviewed them. They now wait for the Command approver or for you, as the card already showed. The agent's questions and plans keep their usual waits.

Includes all changes from v0.8.168.

## 繁體中文

### 側邊欄
- **Orchestrator 自己的應用程式現在位於「Runtime > Chats」。** 它原本是收在「更多」底下的「Agent Orchestrator」，現在緊接在 Chat 之後；Chat 仍是建立在 Orchestrator 上的對話。它的標題列與載入文字也改稱「Orchestrator」。

### 核准
- **團隊的指令會等待其指令核准者，設為「替我核准」的卡片也一樣。** 在指令核准者尚未核准的團隊中，設為「替我核准」的卡片先前會在 20 秒後自動允許其指令與工具請求，而這些請求從未經過任何審查。現在它們會等待指令核准者或你處理，與卡片上原本顯示的一致。代理的問題與計畫仍維持原本的等待時間。

包含 v0.8.168 的所有變更。
