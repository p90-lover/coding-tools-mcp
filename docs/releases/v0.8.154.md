# Coding Tools v0.8.154

## English

- **Antigravity (Gemini) through CPA**: CPA now removes the runtime-context lines, agent-harness identity sentences and third-party framework blocks from the system prompt before it reaches upstream Gemini, which answers them with 429 errors. Harness names are rewritten to a plain coding assistant. Coding Tools writes this filter into CPA's managed configuration on every start and replaces a saved copy whole, so a removed rule never lingers; other saved OAuth settings are kept.

Everything in 0.8.153 is included.

## 繁體中文

- **透過 CPA 使用 Antigravity（Gemini）**：CPA 現在會先從系統提示詞移除執行環境說明、代理框架身分宣告與第三方框架區塊，再送往上游 Gemini，避免上游以 429 錯誤回應。框架名稱會改寫為一般的程式設計助理。Coding Tools 每次啟動都會把這份篩選規則寫入 CPA 的受管設定，並整份取代已儲存的版本，移除的規則不會殘留；其他已儲存的 OAuth 設定會保留。

包含 0.8.153 的所有變更。
