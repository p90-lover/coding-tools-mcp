# Coding Tools 0.8.72

## English

### Chat
- The stats line under a reply no longer drops out. When CPA has no numbers yet, the chat asks again, waiting longer each time (up to a minute), until they arrive. A missed read no longer blanks numbers already shown.
- Split panes show more of the chat:
  - The gap between the last reply and the branch bar is 10 px (it was 32 px).
  - The chat's head is a thin veil, so more of the chat shows under it. The title and buttons sit on small plates so that lines behind them don't cross them.
  - In a pane that isn't focused, the head's buttons dim instead of disappearing.
- The chat box keeps all its buttons in one row in every pane:
  - The down arrows are gone, the branch's included.
  - When room runs short, the model's name gives it up first. The name fades out where it is cut instead of ending in "…". The effort shrinks only once the model is at its smallest.
  - Only a pane 360 px wide or narrower takes two rows.
- Fixed from 0.8.70: a squeezed model name wrapped inside its chip. The rule that keeps chip names on one line looked for the down arrow after the name, and 0.8.70 removed that arrow.

### Image preview
It now follows Codex's image preview (Codex 26.1016).
- **Header.** The Image menu at the left shows the file's name and folder. At the right are the zoom menu (25–200 % and Zoom to fit), Download and Close. Their right end stops short of the window's minimize, maximize and close buttons.
- **Tool bar.** A dark tool bar at the bottom holds Markup, Comment, Remove BG, Erase and Resize.
  - To move it, drag its handle or use the arrow keys; Home puts it back. Its position is remembered.
  - Comment opens Markup with the comment pin ready.
  - Remove BG and Resize (1:1, 3:4, 9:16, 4:3, 16:9) put the image in the chat box with Codex's own instruction.
  - Erase: paint over what should go, with a brush of 5–130. The image and a mask of the strokes go to the chat box.
- **Zoom and closing.** Ctrl + / − / 0 and Ctrl + wheel zoom. A zoomed image pans with a drag. A click outside the image closes the preview; a drag or a click on the scrollbars doesn't.
- **Theme.** The preview follows the chat's light or dark theme.
- **Differences from Codex:**
  - The tools put their result in the chat box for you to send; they don't send it themselves.
  - Not included: Codex's "Open in" app list, the previous/next arrows, and the opening animation.

### Verification and limitations
- **Chat box layout:**
  - Measured in the running 0.8.68 app with the new styles applied: ten split panes 392–513 px wide each kept one row, with nothing past the box's edge.
  - On 0.8.70's 28 px buttons, measured in a browser harness at 300–480 px: one row down to 361 px.
- **Image preview:** checked in a browser harness rendering the real component:
  - the menus
  - each tool's instruction
  - Erase's mask
  - Esc
  - what closes the preview and what doesn't
  - the dark theme

  The window-button clearance uses the formula the app's other bars use, but it was not seen under Windows' own title bar.
- The 407 tests in the 7 related test files pass, and the type check is clean.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.71 is included.

## 繁體中文

### 對話
- 回覆下方的統計列不會再消失。CPA 尚未有數據時，對話會再次查詢，每次等候更久（最多一分鐘），直至取得數據。一次讀取失敗，亦不會清空已顯示的數據。
- 分割窗格可顯示更多對話內容：
  - 最後一則回覆與分支列之間的空隙縮至 10 px（原為 32 px）。
  - 對話頂欄改為一層薄紗，下方可見更多對話。標題與按鈕各有小底板，後面的文字不會穿過它們。
  - 未聚焦窗格的頂欄按鈕會變淡，而非消失。
- 每個窗格的輸入框按鈕都保持同一行：
  - 移除向下箭頭，分支的箭頭亦已移除。
  - 空間不足時，模型名稱先讓出位置。名稱在截斷處淡出，而非以「…」結尾。待模型縮至最小，推理強度才會縮小。
  - 只有 360 px 或更窄的窗格才分兩行。
- 修正 0.8.70 的問題：被擠壓的模型名稱會在按鈕內換行。令按鈕名稱保持一行的規則，要找名稱後的向下箭頭，而 0.8.70 已移除該箭頭。

### 圖片預覽
改為跟隨 Codex 的圖片預覽（Codex 26.1016）。
- **頂欄。** 左邊的「Image」選單顯示檔案名稱及資料夾。右邊是縮放選單（25–200 % 及「Zoom to fit」）、下載及關閉。右端會避開視窗的最小化、最大化及關閉按鈕。
- **工具列。** 底部的深色工具列有 Markup、Comment、Remove BG、Erase 及 Resize。
  - 拖動其把手或使用方向鍵即可移動，按 Home 復位，位置會被記住。
  - Comment 會開啟 Markup，並預備好留言圖釘。
  - Remove BG 及 Resize（1:1、3:4、9:16、4:3、16:9）會把圖片連同 Codex 本身的指示放入輸入框。
  - Erase：以 5–130 的筆刷塗抹要移除的部分。圖片及筆畫遮罩會放入輸入框。
- **縮放及關閉。** 以 Ctrl + / − / 0 及 Ctrl + 滾輪縮放。放大後的圖片可拖動平移。在圖片外按一下即關閉預覽；拖動或按捲軸則不會關閉。
- **主題。** 預覽跟隨對話的淺色或深色主題。
- **與 Codex 的分別：**
  - 工具會把結果放入輸入框，由你自行傳送，不會自動傳送。
  - 未包括：Codex 的「Open in」應用程式清單、上一張／下一張箭頭及開啟動畫。

### 驗證及限制
- **輸入框排版：**
  - 在執行中的 0.8.68 套用新樣式量度：十個 392–513 px 寬的分割窗格，各自保持一行，沒有超出輸入框邊緣。
  - 以 0.8.70 的 28 px 按鈕，在瀏覽器測試頁量度 300–480 px：361 px 或以上保持一行。
- **圖片預覽：** 在瀏覽器測試頁以真實元件檢查：

  - 哪些操作會關閉預覽、哪些不會
  - 深色主題

  避開視窗按鈕的位置，用的是程式其他工具列相同的公式，但未在 Windows 本身的標題列下親眼確認。
- 7 個相關測試檔案的 407 項測試全部通過，型別檢查無錯誤。
