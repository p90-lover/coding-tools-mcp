# Coding Tools 0.8.77

## English

0.8.76 was never published: this release follows 0.8.75 and holds everything merged since.

### GPT Browser
- **One GPT Browser.** The GPT Browser page now shows the browser that the Codex bridge and ChatGPT browser management use, so there is no separate "Browser" entry. Its address bar takes a typed address. The page opens in the tab you are looking at, or in a new tab from ChatGPT's own page (#1044).
- **GPT Browser sign-ins move over.** At the first start, each account signed in to the old GPT Browser joins the browser's account list. Its cookies and storage come along, so nobody signs in again.
  - An account that is already in the list is not added twice. Its extra copy goes to Trash.
  - Accounts that don't fit in the 12-account list stay where they were, for a later start (#1044).
- The browser opens ChatGPT's plain home (`chatgpt.com`) instead of a Temporary Chat, whatever "Save chats in ChatGPT" says. This covers the first page at startup, sign-in, sign-out, passkey sign-in and a new tab. Task turns and connector checks still open the chat the setting chooses (#1038).
- While ChatGPT shows Cloudflare's security check, the app no longer reloads the page for its connector check. That reload only added a request and a flash, then failed on the same check after a minute. The check is now named straight away. The page's own refresh every few minutes comes from Cloudflare's check script, not from the app (#1038).
- The GPT Browser keeps showing a still of its page while the sidebar slides over it, instead of going black (#1043, #1044).
- Camoufox, added after 0.8.75 (#1036), is removed again (#1037), so nothing changes for it.

### Chats
- **Opening a chat is faster.** The click draws the chat with its newest three turns; the rest of its newest 16 follow in one background render once that frame is on screen, and only while the chat is shown. The Mission Board's task graph, hidden behind the chat, is no longer rebuilt and measured each time you open a chat. With 10 chats side by side (16 turns each), a chat showed in about 95 ms instead of about 160 ms, and the longest freeze fell from about 170 ms to about 135 ms (#1038).
- The sidebar has one toggle and a smoother slide. The goal bar stays on one row, Model judges is an icon toggle, and approvals float above the chat instead of pushing it up (#1043).
- Stopping a chat while its sandbox is still being set up no longer lets the cancelled command start afterwards (#1030).
- A hidden chat page pauses its pet's animation and timers; they come back when the page is shown (#1031).
- The context cache saves one snapshot at a time, in order, and a stopped runtime can no longer overwrite its replacement's readings (#1033).

### Fixes
- Agent Orchestrator host probes stay off the main thread (#1029).
- Codex patch paths and rollback snapshots are kept safe (#1035, #1039, #1041).
- With a default working directory set, `apply_patch` and `patch_check` resolve a relative path against it once; before, `src` was added twice (#1032).
- Images are budgeted correctly for plain prompts (#1040).
- Git tracking counts are correct (#1042).

### Verification
- Focused tests cover the account move: a merged sign-in, a duplicate, an id collision, a full list and a resumed move. They also cover the address bar and the still under the sidebar (#1044).
- Chats: 262 + 58 + 67 chat tests and 475 workflow tests pass. The timings above come from the real chat code with production React in a GPU window, against the previous code on the same data, not from the installed app (#1038).
- Browser: 348 tests across the 12 files that load the browser code pass. The installed 0.8.75 was watched for 10 minutes: 0 responses with 429, and every reload came from Cloudflare's script (#1038).
- The other PRs were tested in their own PRs.
- GitHub Actions builds the Windows installer, portable archive and updater packs. A live chat through the bridge on the merged browser has not been run yet, and passing Cloudflare's check depends on the proxy exit or the browser.
- Includes all changes in 0.8.75.

## 繁體中文

0.8.76 從未發佈：此版本緊接 0.8.75，包含其後合併的所有變更。

### GPT 瀏覽器
- **合併為單一 GPT 瀏覽器。** GPT 瀏覽器頁面現在顯示的，就是 Codex 橋接及 ChatGPT 瀏覽器管理所用的瀏覽器，不再另設「瀏覽器」項目。網址列可輸入網址，會在目前的分頁開啟；如目前顯示的是 ChatGPT 本身的頁面，則會開啟新分頁（#1044）。
- **GPT 瀏覽器登入資料一併移轉。** 首次啟動時，舊 GPT 瀏覽器中每個已登入的帳戶都會加入瀏覽器的帳戶清單，Cookie 及儲存資料隨之移轉，無須重新登入。
  - 清單中已有的帳戶不會重複加入，多出的副本會移至垃圾桶。
  - 帳戶清單上限為 12 個，放不下的帳戶會保留原處，待日後啟動時再移轉（#1044）。
- 瀏覽器會開啟 ChatGPT 的一般首頁（`chatgpt.com`），而不是臨時對話，不論「在 ChatGPT 中儲存對話」如何設定。這涵蓋啟動時的第一個頁面、登入、登出、密碼金鑰登入及新分頁。任務回合及連接器檢查仍會開啟設定所選的對話類型（#1038）。
- 當 ChatGPT 顯示 Cloudflare 安全檢查時，應用程式不會再為連接器檢查而重新載入頁面。該次重新載入只會多送一個請求並令畫面閃動，一分鐘後仍因同一檢查而失敗。現在會立即指出是安全檢查。頁面每隔數分鐘的自行重新整理來自 Cloudflare 的檢查程式，而非應用程式（#1038）。
- 側邊欄滑過 GPT 瀏覽器時，頁面會顯示靜止畫面，而不會變黑（#1043、#1044）。
- 在 0.8.75 之後加入的 Camoufox（#1036）已再次移除（#1037），因此其相關部分沒有任何改變。

### 對話
- **開啟對話更快。** 點擊時只繪製對話及其最新三個回合；最新 16 個回合中的其餘部分，會在該畫面顯示後以一次背景繪製補上，而且只在對話顯示時進行。隱藏在對話後面的「任務看板」任務圖，不會再在每次開啟對話時重建及量度。在 10 個對話並排（每個 16 個回合）的測試中，對話約 95 毫秒便顯示，而非約 160 毫秒；最長的停頓由約 170 毫秒減至約 135 毫秒（#1038）。
- 側邊欄只保留一個切換按鈕，滑動更流暢。目標列維持單行，「模型評審」改為圖示切換，審批卡片浮於對話上方，不再把對話往上推（#1043）。
- 在沙箱仍在設定時停止對話，已取消的指令不會在之後啟動（#1030）。
- 隱藏的對話頁面會暫停寵物的動畫及計時器；頁面再次顯示時會恢復（#1031）。
- 情境快取每次只按順序儲存一個快照，已停止的執行階段不會再覆寫取代它的執行階段的讀數（#1033）。

### 修正
- Agent Orchestrator 的主機探測不再佔用主執行緒（#1029）。
- Codex 補丁路徑及回滾備份得到妥善保護（#1035、#1039、#1041）。
- 設定了預設工作目錄時，`apply_patch` 及 `patch_check` 只會以它解析相對路徑一次；過去 `src` 會被加上兩次（#1032）。
- 純文字提示的圖片額度計算正確（#1040）。
- Git 追蹤計數正確（#1042）。

### 驗證
- 針對性測試涵蓋帳戶移轉的各種情況：成功移轉登入資料、重複帳戶、ID 衝突、清單已滿及中斷後繼續移轉，亦涵蓋網址列及側邊欄下的靜止畫面（#1044）。
- 對話：262 + 58 + 67 項對話測試及 475 項工作流程測試均通過。上述時間來自以正式版 React 在 GPU 視窗中執行的實際對話程式碼，並以相同資料與先前的程式碼比較，而非來自已安裝的應用程式（#1038）。
- 瀏覽器：載入瀏覽器程式碼的 12 個測試檔案共 348 項測試均通過。已在安裝的 0.8.75 上觀察 10 分鐘：沒有 429 回應，所有重新載入都來自 Cloudflare 的程式（#1038）。
- 其他 PR 已在各自的 PR 中測試。
- GitHub Actions 建置 Windows 安裝程式、可攜式封存檔及更新套件。尚未在合併後的瀏覽器上經橋接進行實際對話測試；能否通過 Cloudflare 檢查取決於代理出口或瀏覽器。
- 包含 0.8.75 的所有變更。
