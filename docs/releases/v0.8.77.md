# Coding Tools 0.8.77

## English

- **One GPT Browser.** The GPT Browser page now shows the browser that the Codex bridge and ChatGPT browser management use, so there is no separate "Browser" entry. Its address bar takes a typed address. The page opens in the tab you are looking at, or in a new tab from ChatGPT's own page (#PR).
- **GPT Browser sign-ins move over.** At the first start, each account signed in to the old GPT Browser joins the browser's account list. Its cookies and storage come along, so nobody signs in again.
  - An account that is already in the list is not added twice. Its extra copy goes to Trash.
  - Accounts that don't fit in the 12-account list stay where they were, for a later start (#PR).
- The GPT Browser keeps showing a still of its page while the sidebar slides over it, instead of going black (#1043, #PR).
- The sidebar has one toggle and a smoother slide. The goal bar stays on one row, Model judges is an icon toggle, and approvals float above the chat instead of pushing it up (#1043).
- The unused Camoufox plugin is removed (#1037).
- Fixes:
  - Agent Orchestrator host probes stay off the main thread (#1029).
  - Codex patch paths and rollback snapshots are kept safe (#1035, #1039, #1041).
  - Images are budgeted correctly for plain prompts (#1040).
  - Git tracking counts are correct (#1042).

### Verification

Focused tests cover the account move: a merged sign-in, a duplicate, an id collision, a full list and a resumed move. They also cover the address bar and the still under the sidebar. GitHub Actions builds the Windows installer, portable archive and updater packs. A live chat through the bridge on the merged browser has not been run yet. Includes all changes in 0.8.75.

## 繁體中文

- **合併為單一 GPT 瀏覽器。** GPT 瀏覽器頁面現在顯示的，就是 Codex 橋接及 ChatGPT 瀏覽器管理所用的瀏覽器，不再另設「瀏覽器」項目。網址列可輸入網址，會在目前的分頁開啟；如目前顯示的是 ChatGPT 本身的頁面，則會開啟新分頁（#PR）。
- **GPT 瀏覽器登入資料一併移轉。** 首次啟動時，舊 GPT 瀏覽器中每個已登入的帳戶都會加入瀏覽器的帳戶清單，Cookie 及儲存資料隨之移轉，無須重新登入。
  - 清單中已有的帳戶不會重複加入，多出的副本會移至垃圾桶。
  - 帳戶清單上限為 12 個，放不下的帳戶會保留原處，待日後啟動時再移轉（#PR）。
- 側邊欄滑過 GPT 瀏覽器時，頁面會顯示靜止畫面，而不會變黑（#1043、#PR）。
- 側邊欄只保留一個切換按鈕，滑動更流暢。目標列維持單行，「模型評審」改為圖示切換，審批卡片浮於對話上方，不再把對話往上推（#1043）。
- 移除不再使用的 Camoufox 外掛（#1037）。
- 修正：
  - Agent Orchestrator 的主機探測不再佔用主執行緒（#1029）。
  - Codex 補丁路徑及回滾備份得到妥善保護（#1035、#1039、#1041）。
  - 純文字提示的圖片額度計算正確（#1040）。
  - Git 追蹤計數正確（#1042）。

### 驗證

針對性測試涵蓋帳戶移轉的各種情況：成功移轉登入資料、重複帳戶、ID 衝突、清單已滿及中斷後繼續移轉，亦涵蓋網址列及側邊欄下的靜止畫面。GitHub Actions 建置 Windows 安裝程式、可攜式封存檔及更新套件。尚未在合併後的瀏覽器上經橋接進行實際對話測試。包含 0.8.75 的所有變更。
