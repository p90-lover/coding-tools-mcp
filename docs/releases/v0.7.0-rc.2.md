# Coding Tools v0.7.0-rc.2

## English

v0.7.0-rc.2 unifies the v0.7 provider, image, Paseo, Anneal, native subagent, OAuth, ChatGPT Web, and Electron control-center work into one exact-source Windows release candidate.

### Provider Center

- Adds a first-class Electron **Provider Center** with multiple provider instances per workspace.
- Supports the approved built-in provider surfaces:
  - Codex OAuth
  - Claude OAuth
  - ChatGPT Web
  - AI Studio Reverse Proxy
  - Gemini Reverse Proxy
  - AIStudioToAPI
  - CLIProxyAPI / Antigravity
  - CommandCode Proxy
- Displays provider authentication type, protocol, supported capabilities, model catalogue, and Paseo/Anneal availability.
- Supports explicit model discovery from compatible provider model endpoints.
- Keeps provider credentials request-only in RAM; credentials are not written into project data, renderer responses, release assets, or normal application state.
- Supports multiple saved non-secret provider profiles while keeping each runtime credential session separate.

### Paseo and Anneal execution

- Connects the Electron GUI to the authenticated local execution bridge for provider configuration, observation, and mission preparation.
- Allows approved provider/model bindings to be selected for Paseo or Anneal.
- Preserves workspace-root, policy-revision, permission-mode, and explicit-cost-consent checks before external execution.
- Keeps uncertain writes fail-closed and does not silently replay a provider request under a new request key.
- Restores evidence-backed Anneal completion detection, bounded web-task execution, observation deduplication, and terminal-failure handling.

### Structured Anneal orchestrator — Plan A

- Adds a structured orchestrator editor before the later visual graph editor.
- Supports ordered stages with a provider and model per stage.
- Supports per-stage retries, timeout, approval mode, and completion rule.
- Persists non-secret orchestrator profiles locally and supports JSON export.
- Prepares owned Anneal stage missions against existing workspace tasks through the authenticated execution bridge.
- Requires an approved, connected, scope-valid Anneal provider binding for every stage.
- Custom orchestrators may be used as subagents, while recursive orchestrator delegation remains fail-closed.

### Images and Gemini / AI Studio adapters

- Adds bounded image-generation contracts for AI Studio Reverse Proxy, AIStudioToAPI, and CLIProxyAPI / Antigravity-compatible backends.
- Supports OpenAI-style URL or base64 image output and Gemini inline image data through dedicated media adapters rather than forcing image requests through a text-only Responses path.
- Makes image-capable provider metadata available to Paseo and Anneal routing.
- Keeps generated artifacts and retained validation evidence bounded and attributable to the requesting mission.

### Multi-provider subagents and routing

- Preserves Codex Router namespaced model routing and scalable managed native V2 `agent_type` definitions.
- Keeps CommandCode Proxy as a first-class generic provider with dynamic model discovery.
- Preserves the restricted loopback Coding Tools Web ingress without exposing native or OpenAI routes and without creating a routing loop.
- Preserves `/goal` internal context, provider capability checks, proxy isolation, and bounded browser hot-path improvements.

### Electron, headless service, and localization

- Ships the Provider Center and structured orchestrator in the packaged Electron control center, not only in the development Svelte surface.
- Includes the authenticated headless Rust service and typed Electron IPC boundary for execution operations.
- Includes Traditional Chinese localization for the rc.2 control-center surfaces.
- Retains existing onboarding, project-owner links, update controls, diagnostics, browser-profile isolation, and local permission boundaries.

### Safety and release integrity

- No project file or branch is deleted by the integration or release process.
- Temporary and retained validation material remains under `aiTemp/` and `aiTemp/Trash/`.
- The Windows installer remains per-user and does not request elevation.
- Publication is bound to one exact tested source SHA.
- The release includes `SHA256SUMS.txt`, `provenance.json`, and `validation-evidence.json`.
- Automated validation includes Electron type checking, renderer build, provider contracts, proxy isolation, subagent/orchestrator contracts, Anneal monitor contracts, execution-bridge contracts, package verification, and packaged launcher smoke checks.

### Validation boundary

Live acceptance with real paid-provider accounts, OAuth identities, browser sessions, and provider-specific quotas remains an explicit manual acceptance boundary. Automated release proof does not require spending provider quota.

## 繁體中文

v0.7.0-rc.2 將 v0.7 嘅供應商、生圖、Paseo、Anneal、原生 subagent、OAuth、ChatGPT Web 同 Electron Control Center 工作，整合成一個綁定精確 source SHA 嘅 Windows release candidate。

### Provider Center／供應商中心

- Electron 正式加入一級 **Provider Center／供應商中心**，每個工作區可以建立多個 provider instance。
- 支援已批准嘅內置供應商介面：
  - Codex OAuth
  - Claude OAuth
  - ChatGPT Web
  - AI Studio Reverse Proxy
  - Gemini Reverse Proxy
  - AIStudioToAPI
  - CLIProxyAPI／Antigravity
  - CommandCode Proxy
- 顯示 authentication 類型、protocol、capability、模型清單，以及可否畀 Paseo／Anneal 使用。
- 支援由相容 provider model endpoint 明確執行 model discovery。
- Provider credential 只會喺請求期間保留喺 RAM；唔會寫入 project data、renderer response、release asset 或一般 application state。
- 可以保存多個不含 secret 嘅 provider profile，而每個 runtime credential session 仍然互相分隔。

### Paseo 同 Anneal 執行

- Electron GUI 會經已驗證嘅本機 execution bridge，處理 provider 設定、觀察同 mission preparation。
- 可以為 Paseo 或 Anneal 選擇已批准嘅 provider／model binding。
- 外部執行前繼續驗證 workspace root、policy revision、permission mode 同明確費用同意。
- 結果不確定嘅 write 會維持 fail-closed，唔會用新 request key 靜默重播 provider request。
- 恢復以 evidence 為基礎嘅 Anneal 完成判定、有限制嘅 web-task 執行、observation 去重，以及 terminal failure 處理。

### Structured Anneal Orchestrator — Plan A

- 先加入結構化 orchestrator editor，視覺 Node Graph Editor 留到下一階段。
- 支援有順序嘅 stage，而每個 stage 可以指定 provider 同 model。
- 每個 stage 可以設定 retry、timeout、approval mode 同 completion rule。
- 不含 secret 嘅 orchestrator profile 會本機保存，亦可以匯出 JSON。
- 透過已驗證 execution bridge，為現有 workspace task 建立由系統擁有嘅 Anneal stage mission。
- 每個 stage 都必須配對一個已批准、已連線而且 scope 有效嘅 Anneal provider binding。
- Custom orchestrator 可以作為 subagent 使用，但 recursive orchestrator delegation 仍然 fail-closed。

### 圖片、Gemini 同 AI Studio Adapter

- 為 AI Studio Reverse Proxy、AIStudioToAPI 同 CLIProxyAPI／Antigravity 相容 backend 加入有界限嘅 image-generation contract。
- 專用 media adapter 支援 OpenAI-style URL、base64 image output，同 Gemini inline image data；唔會強行將生圖塞入只處理文字嘅 Responses 路線。
- Paseo 同 Anneal routing 可以使用 image-capable provider metadata。
- 生成 artifact 同保留驗證證據都會有限制，並可追溯到發出要求嘅 mission。

### 多供應商 Subagent 同 Routing

- 保留 Codex Router namespace model routing，同可擴展、由專案管理嘅原生 V2 `agent_type` 定義。
- CommandCode Proxy 繼續係一級 generic provider，並支援動態 model discovery。
- 保留受限制嘅 loopback Coding Tools Web ingress，唔會暴露 native／OpenAI route，亦唔會造成 routing loop。
- 保留 `/goal` internal context、provider capability check、proxy isolation 同有限制嘅 browser hot-path 優化。

### Electron、Headless Service 同本地化

- Provider Center 同 Structured Orchestrator 會正式放入已打包嘅 Electron Control Center，唔只係 development Svelte 畫面。
- 包含已驗證嘅 headless Rust service，同 execution operation 嘅 typed Electron IPC boundary。
- rc.2 Control Center 畫面加入繁體中文本地化。
- 保留原有 onboarding、project owner link、update control、diagnostics、browser profile isolation 同本機權限邊界。

### 安全同 Release 完整性

- Integration 同 release 流程唔會刪除任何 project file 或 branch。
- 臨時同保留驗證資料只會放喺 `aiTemp/` 同 `aiTemp/Trash/`。
- Windows installer 維持 per-user 安裝，唔會要求提升權限。
- 發佈會綁定一個已測試嘅精確 source SHA。
- Release 會附有 `SHA256SUMS.txt`、`provenance.json` 同 `validation-evidence.json`。
- 自動驗證包括 Electron typecheck、renderer build、provider contract、proxy isolation、subagent／orchestrator contract、Anneal monitor contract、execution bridge contract、package verification 同 packaged launcher smoke check。

### 驗證範圍

使用真實付費 provider 帳戶、OAuth 身份、browser session 同 provider-specific quota 嘅 live acceptance，仍然會清楚標記為手動驗證邊界。自動 release proof 唔需要消耗 provider quota。
