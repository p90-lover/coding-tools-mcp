# Coding Tools MCP v0.4.2-rc.1 — MCP discovery, native Codex and task board

## English

This release integrates the MCP connection repair, the explicitly opted-in native
Codex App Server bridge, and the draggable local delivery board in one build.

MCP supports legacy initialize negotiation for 2025-06-18 / 2025-11-25 and the
2026-07-28 stateless request/discovery path. The full profile now exposes the real
complete registered catalog rather than silently falling back to core. Catalog
visibility does not grant execution permission: current authorization is checked
on every admitted call. Permission-only saves retain the listener and OAuth
identity. Authentication failures, initialized notifications, SSE negotiation and
protocol mismatch behavior are covered by focused HTTP regression fixtures.

The optional native bridge uses a hash-verified, separately installed official
Codex executable. It supports owned text sessions, follow-up messages, inline
review, native compaction, interruption and unsubscribe. It retains the parent
review ID when Codex forwards a nested delegate start; completed review output is
no longer discarded. Every ordinary turn explicitly retains the built-in
`:read-only` profile. Native read access may extend beyond the project; read-only
is not a workspace-only confidentiality boundary. Local visible consent, request
and lifetime limits, fail-closed unsupported approvals and Stop remain in place.
The installed native runtime/provider may consume its own quota when enabled.

The local board supports creation in a chosen column, drag-and-drop movement and
ordering, keyboard status changes and reopening while preserving checklist
evidence. Accessible select labels work in English and Traditional Chinese.
Moving a card to Done is not a claim that its twelve review steps were performed.
Paseo and Anneal remain read-only adapters to separately managed services.

Release verification runs the actual native Codex 0.153.4 lifecycle against an
isolated loopback synthetic Responses provider on Windows and Apple Silicon macOS,
plus focused scope/notification regressions, production board reducer checks,
browser interaction with synthetic desktop IPC, MCP HTTP tests, frontend checks
and installer inspection. This is not a real AI review, paid inference test,
user-machine acceptance or live ChatGPT/provider verification. Release assets
include source provenance, SHA-256 checksums and the actual validation records.

Install the new version, restart the application to load the new binary, and use
your client's tool refresh/scan for the updated catalog. ChatGPT app availability,
action enablement and approvals remain client/account/admin controlled. The app
cannot silently create or reauthorize a connector. Do not delete your project or
OAuth state as a troubleshooting shortcut. A supported older negotiated MCP
version is not by itself proof that a client must disconnect.

This is a prerelease, not complete internal Codex tool parity or a certified
security sandbox. Native command-sandbox helper binaries remain withheld;
`exec_command` is policy-only. Native desktop input remains Windows-only.
Windows installers are publisher-unsigned. macOS is ad-hoc signed, not notarized.
Existing files, branches, tags and releases are retained.

## 繁體中文

本版本將 MCP 連線修正、須明確啟用的原生 Codex App Server 橋接，以及可拖曳的
本機交付看板整合至同一個建置。

MCP 支援 2025-06-18／2025-11-25 舊版 initialize 協商，以及 2026-07-28 的
無狀態請求與探索方式。full 設定檔現在會提供真正完整的已註冊工具目錄，不再
默默退回 core。看得到工具不代表獲准執行；每次接受呼叫時仍檢查目前權限。
只變更權限不會重建監聽服務或 OAuth 身分；認證失敗、初始化通知、SSE 協商及
協定不符處理均有針對性的 HTTP 回歸驗證。

選用的原生橋接使用另外安裝、經 SHA-256 核對的官方 Codex 執行檔，支援所屬
文字會話、後續訊息、行內審查、原生壓縮、中斷與取消訂閱。Codex 轉發內部委派
回合開始事件時，會保留原本的審查回合 ID，不再丟棄已完成的審查結果。
一般回合均明確沿用內建的 `:read-only` 權限。原生可讀範圍可能超出專案；唯讀
並不等於只能讀取工作區的保密界線。本機可見同意、請求與期限上限、不支援
授權的拒絕處理及停止功能均保留。啟用後，原生執行環境／供應商可能消耗其額度。

本機看板支援直接在指定欄位建立任務、拖曳移動與排序、鍵盤狀態選單，以及
重新開啟任務並保留清單依據。選單的無障礙標籤支援英文及繁體中文。
把卡片移到完成欄不代表已執行十二個審查步驟；Paseo／Anneal 仍是獨立服務的
唯讀介接器。

發行驗證在 Windows 及 Apple Silicon macOS 上，以真正的 Codex 0.153.4
執行完整操作流程，但模型端只使用隔離的本機模擬 Responses 服務。另有範圍／
通知回歸測試、正式看板 reducer 檢查、使用模擬桌面 IPC 的瀏覽器操作、MCP HTTP
測試、前端檢查與安裝包檢查。這不代表真實 AI 審查、付費推論、你的電腦驗收，
或實際 ChatGPT／供應商連線已經驗證。附件提供來源、SHA-256 及實際驗證紀錄。

安裝後重新啟動應用程式以載入新執行檔，再於用戶端刷新／掃描工具目錄。
ChatGPT 功能資格、操作啟用及批准仍由用戶端、帳戶與管理員控制；本程式不能
靜默建立或重新授權連接器。不要以刪除專案或 OAuth 狀態作為排錯捷徑。
協商至双方均支援的較舊 MCP 版本，本身不代表用戶端必須中斷。

這是預覽候選版，不是完整 Codex 內部工具對等實作，也不是已認證的安全沙箱。
原生命令沙箱輔助程式仍未納入；`exec_command` 仍只受軟體策略限制。
原生桌面輸入僅支援 Windows；Windows 沒有發佈者簽署，macOS 是 ad-hoc 簽署、
未公證。現有檔案、分支、標籤及舊版本均保留。
