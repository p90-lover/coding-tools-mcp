# Coding Tools v0.8.143

## English

### Chat

- A latest message that was saved but never started can now be resent instead of being permanently blocked by “This chat's messages are still synchronizing; reload before rewind.” The app reuses that saved message, without duplicating it or hiding earlier replies.
- Recovery requires the chat's own history read to succeed, exactly one message without a run, and timestamps proving every earlier run started before the latest message's minute. Ambiguous rewinds, failed history reads and running-turn safeguards remain blocked rather than guessing.

### Verification

- The focused regression reproduces the reported error on the old code. After the repair, all 9 focused resend and rewind checks pass, including no duplicate message, no lost earlier replies, ambiguous timestamps, unavailable history and existing compacted/busy-project behavior.
- Release identity checks verify matching product/package versions. GitHub Actions runs the coordinated batch checks, builds the Windows installer and verifies release files before publication.
- No account credentials, user prompts or live chat data are changed by this release. Runtime behavior is verified only after the supported local update; active chats are not forcibly stopped to install it.

## 繁體中文

### 聊天

- 最新訊息已儲存、卻從未啟動回合時，現在可安全重新傳送，不再永久卡在「訊息仍在同步，請重新載入後再倒回」。App 會重用原本的訊息，不會重複新增，也不會隱藏先前的回覆。
- 恢復操作必須成功讀取該聊天的歷史、確認只有一則訊息沒有回合，且所有既有回合均早於最新訊息所在的分鐘啟動。時間不明、歷史讀取失敗或仍在執行中的情況，仍保留原有安全限制，不會猜測或刪除歷史。

### 驗證

- 新增的針對性測試可在舊程式重現相同錯誤；修復後 9 項重新傳送與倒回測試全數通過，涵蓋不重複訊息、不遺失先前回覆、時間不明、歷史無法讀取及既有摘要聊天行為。
- 版本識別檢查確認產品與套件版本一致。GitHub Actions 執行整合檢查、建置 Windows 安裝程式並在發布前驗證發行檔案。
- 此版本不修改帳號憑證、使用者提示或現有聊天資料。執行中的 App 行為會在受支援的本機更新後確認；安裝時不會強制停止活躍聊天。
