# Coding Tools 0.8.34

## English

### Improvements
- More MCP tunnels, one per ChatGPT account. An OpenAI tunnel belongs to one OpenAI account, and ChatGPT attaches a connector only through a tunnel of its own account, so the MCP page's "Connect the tunnel" step now lists more tunnels beside the main one. Add one with a name, its Browser account, Tunnel ID and API key; reconnect, remove, or create its ChatGPT connector in that account. Each tunnel runs its own tunnel client and MCP process, all reaching the same Codex bridge, and each serves every ChatGPT chat of its account at once. They start, stop and survive updates with the main tunnel, and one that loses readiness is restarted (PR #674).
- Each Codex session runs on its own ChatGPT account. A session joins the account in use on its first turn and keeps it, reopening its own chat there even after the Browser tab switches account. Archiving, unarchiving or deleting a session in Codex does the same to its chats, and ChatGPT browser management lists every session with its account (PR #669).
- A new CPA always replaces the old one, so CPA runs the version and proxy this app ships (PR #670).
- Nothing is stored on the C: drive: the app's code no longer falls back to C: folders (PR #668).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from this branch and confirm CI before publication.
- Extra tunnels have been tested against a stand-in tunnel client, not yet with real OpenAI tunnels.
- Everything in 0.8.33 is included.

## 繁體中文

### 更新內容
- 支援多個 MCP 通道，每個 ChatGPT 帳戶一個：OpenAI 通道屬於單一 OpenAI 帳戶，而 ChatGPT 只能透過自己帳戶的通道連接 connector，因此 MCP 頁面的「Connect the tunnel」步驟現在可在主通道以外列出更多通道。輸入名稱、對應的 Browser 帳戶、Tunnel ID 和 API key 即可新增；可重新連線、移除，或在該帳戶中建立 ChatGPT connector。每個通道各自執行通道用戶端和 MCP 程序，全部連到同一個 Codex 橋接器，並可同時服務該帳戶的所有 ChatGPT 對話；它們與主通道一同啟動、停止及在更新後保留，失去就緒狀態時會自動重新啟動（PR #674）。
- 每個 Codex 工作階段在自己的 ChatGPT 帳戶上執行：工作階段在第一個回合加入使用中的帳戶並保持不變，即使「Browser」分頁切換帳戶，也會在原帳戶重新開啟自己的對話。在 Codex 封存、取消封存或刪除工作階段時，其對話也會同步處理；「ChatGPT browser management」會列出每個工作階段及其帳戶（PR #669）。
- 新版 CPA 一律取代舊版，因此 CPA 執行本應用程式附帶的版本和代理（PR #670）。
- 不再在 C: 磁碟儲存任何資料：應用程式程式碼不再退回使用 C: 的資料夾（PR #668）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由本分支編譯及通過 CI 才能公開。
- 額外通道已以模擬的通道用戶端測試，尚未以真實的 OpenAI 通道測試。
- 包含 0.8.33 的所有內容。
