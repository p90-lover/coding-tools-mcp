# Coding Tools 0.8.51

## English

### Chats
- A chat's model effort and context settings are remembered per harness, provider, account and model (PR #888).
- `/compact` compacts the chat's own AO or native conversation. The chat shows it as pending and keeps queued messages until that compaction finishes; a lost start reply is matched by its request ID instead of being sent twice, and `/context` no longer reports board storage limits as model capacity (PR #888).
- Command output split into pages no longer breaks characters such as Chinese text or emoji at page edges, and a still-running command's last partial character waits for the rest instead of being garbled (PR #899).

### Web GPT
- Native Web GPT chats pick the exact GPT-6 row and effort you asked for and check it again before sending, instead of downgrading or refusing because of another account's options. A compacted chat keeps its thread and the account it was bound to (PR #902).

### Plugins
- Plugins → MCPs has a Ready to add list: GitHub, Playwright, Chrome DevTools, Context7 and Sequential Thinking. Servers that need nothing are added in one click; the others ask only for their token, and GitHub can use your GitHub CLI sign-in. You can also paste a server's README snippet to add it (PR #900).

### Verification and limitations
- Built and published by GitHub CI from main; no local build was made for this version.
- Not included: PR #891 (unfinished).
- Everything in 0.8.50 is included.

## 繁體中文

### 對話
- 對話的模型推理強度及上下文設定，會按 harness、供應商、帳號及模型記住（PR #888）。
- `/compact` 會壓縮對話本身的 AO 或原生對話。對話會顯示等待中，並保留排隊中的訊息直至該次壓縮完成；若開始的回覆遺失，會以請求 ID 配對而不會重複送出，`/context` 亦不再把看板儲存上限當作模型容量（PR #888）。
- 分頁顯示的指令輸出不會再在頁邊截斷中文或表情符號等字元；仍在執行的指令最後不完整的字元會等待其餘部分，而不會變成亂碼（PR #899）。

### Web GPT
- 原生 Web GPT 對話會選取你要求的確切 GPT-6 選項及推理強度，並在送出前再次確認，不會因其他帳號的選項而降級或拒絕。壓縮後的對話會保留其對話串及原本綁定的帳號（PR #902）。

### 外掛
- 「外掛 → MCP」新增「可直接加入」清單：GitHub、Playwright、Chrome DevTools、Context7 及 Sequential Thinking。不需設定的伺服器一按即可加入，其他只會要求輸入權杖，GitHub 亦可使用你的 GitHub CLI 登入。你也可以貼上伺服器 README 的設定片段來加入（PR #900）。

### 驗證及限制
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 未包含：PR #891（未完成）。
- 包含 0.8.50 的所有內容。
