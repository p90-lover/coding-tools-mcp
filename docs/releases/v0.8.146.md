# Coding Tools v0.8.146

## English

- Chats now wait for you when the agent reports that authentication is required, instead of automatically retrying a refusal. This also applies when Coding Tools starts again. Temporary failures can still retry, and **Retry step** is still available after you address the refusal.
- This does not change provider sign-in, account eligibility or routing. If Vertex refuses a request with HTTP 403, the provider must accept the account or configuration before that request can succeed.

Everything in 0.8.145 is included.

## 繁體中文

- 當代理程式回報需要驗證時，聊天會等待你處理，不再反覆自動重試遭拒的請求。重新啟動 Coding Tools 後也適用。暫時性錯誤仍可重試；解決遭拒的原因後，也可手動選擇 **重試步驟**。
- 此修正不會改變供應商登入、帳戶資格或路由。如果 Vertex 拒絕請求並回傳 HTTP 403，必須先使用符合供應商要求的帳戶或設定，請求才能成功。

包含 0.8.145 的所有變更。
