# Coding Tools 0.8.21

## English

### Fixes
- Preserve the ChatGPT browser conversation assigned to a Codex task when a newer instruction supersedes an already-submitted response.
- Stop the previous generation in the retained tab before sending the replacement instruction, without refreshing unrelated tasks' tabs.
- Display a short, stable Codex task identifier on GPT Browser tabs. The full task ID and ChatGPT conversation address are available in the tab tooltip.
- Keep the existing safeguards for saved/temporary chat ownership and abandoned browser start requests.

This release includes all changes from v0.8.20.

### Updating
In-app updating is supported from rc.19 and later. For rc.18 or earlier, close Coding Tools before installing the Windows installer or extracting the portable ZIP.

## 繁體中文

### 修正內容
- 當新的 Codex 指令取代已送出的舊回應時，保留該任務原有的 ChatGPT 瀏覽器對話。
- 在同一個保留分頁停止舊回應生成，再送出新指令；不會重新整理其他任務的分頁。
- GPT Browser 分頁顯示簡短且穩定的 Codex 任務識別碼，滑鼠移至分頁可查看完整任務 ID 和 ChatGPT 對話網址。
- 保留現有的儲存／臨時對話擁有權驗證，以及瀏覽器啟動要求中斷時的安全機制。

本版本包含 v0.8.20 的所有更新。

### 更新方式
rc.19 或更新版本可使用程式內更新。rc.18 或更早版本請先關閉 Coding Tools，再執行 Windows 安裝程式或解壓可攜版 ZIP。
