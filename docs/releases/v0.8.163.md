# Coding Tools v0.8.163

## English

### Chats & Context Windows
- **Context window persistence, 1M input-budget choices, and subagent windows.** Resizing a chat's context window in place now stays on the chat's card across tab switches, reloads, and automatic follow-ups instead of reverting to the initial launch window. Opening an existing chat no longer replaces an unset window or effort with the new-chat 400K default, and cards sent before the CPA catalog loaded continue their live session once the catalog fills in the model's default effort. Saved model capabilities from earlier versions clean up CPA's 272K stock fallback on non-GPT models, 1M models with 872K or 1,047,576 input budgets list a single `1M` top choice across the composer and Native Codex, subagents receive their model's full context window and keep it across restarts, and the context breakdown popup scales against the launched window.
- **Chat tools move into add-ons.** One button beside the chat opens optional panels such as Preview, Terminal, Files, Changes, Plans, and Subagents. Existing tool and privacy settings live together under **Plugins › Chat add-ons**. Duplicate tool registrations and MCP server name conflicts show up in recent diagnostics without recording messages, tool arguments, or credentials. Sending, drafts, and approvals work as before.

### Runtime
- **Runtime › App layout & model-editable architecture map.** Added an **App layout** tab under **Runtime** that shows the complete picture of Coding Tools across its 6 core categories (*Chats & Agents*, *Tools, MCP & Permissions*, *Models, Accounts & Providers*, *Browser & ChatGPT Web Bridge*, *Network, Components & Updates*, and *Settings & Diagnostics*), 4 architectural layers (*Sidebar Navigation*, *Unified Settings Map*, *Built-in `coding-tools` MCP Server*, and *Background Services & Component Categories*), and current overlaps/misplacements. Both you (directly in the **App layout** tab) and chat models (via the new `app_layout` MCP tool on the built-in `coding-tools` server) can read, add, edit, or reset categories, layer rows, and overlaps with live updates.

### Computer Use
- **Computer-use window selection waits for the visible control toolbar.** Selecting a window now waits until the visible control toolbar confirms the same session. Stop and cancellation invalidate delayed starts, and a failed toolbar closes without reporting control as ready. Selecting a window only brings it to the foreground when explicitly requested.

### Accounts
- **Automatic MCP checks run in the background and yield to chats.** Automatic MCP checks now keep running while Coding Tools is in the background, once you have opened it this session. A chat that needs the ChatGPT browser stops a running check first, and a check is never stopped halfway through creating, connecting, or publishing a connector.
- **MCP identity check failures name the check that failed.** When an account's existing MCP connector fails its identity check, the account's error now says which check stopped it—for example, that ChatGPT's plugin list did not show the connector or that it is saved with a different Tunnel ID—instead of only "identity is unverified".

### Agent Instructions
- **Direct workflow choices override defaults.** Where `AGENTS.md` gives a default, the user's direct choice of scope, order, or workflow wins; a fix request covers applying confirmed in-scope changes without another go-ahead, and a review-only request stays report-only.

Includes all changes from v0.8.162.

## 繁體中文

### 對話與上下文視窗
- **上下文視窗保持、1M 輸入預算選項與子代理視窗。** 在聊天中直接調整的上下文視窗現在會在切換分頁、重新載入與自動後續回合中保留在卡片上，不再退回啟動時的視窗大小。開啟既有聊天時不再以新聊天的 400K 預設值覆蓋未設定的視窗或推理強度；在 CPA 目錄載入前送出的卡片，當目錄補上模型的預設推理強度後仍會接續原本的代理工作階段。舊版儲存的模型能力會自動清理非 GPT 模型上的 272K 預設上限，具備 872K 或 1,047,576 輸入預算的 1M 模型在輸入框與 Native Codex 中皆顯示單一 `1M` 最高選項，子代理會取得模型的完整上下文視窗並在重啟後保留，且上下文明細面板會依啟動視窗計算比例。
- **聊天工具改為附加模組。** 聊天旁以一個按鈕開啟預覽、終端機、檔案、變更、計畫及子代理等選用面板。既有工具和隱私設定集中在「外掛 › 聊天附加模組」。工具重複註冊或 MCP 伺服器名稱衝突會顯示於診斷記錄，不會記錄訊息、工具參數或憑證。傳送、草稿和核准流程維持不變。

### Runtime
- **Runtime › App layout 與模型可編輯架構圖。** 在 **Runtime** 下新增 **App layout** 分頁，完整呈現 Coding Tools 的 6 大核心類別（*對話與代理*、*工具、MCP 與權限*、*模型、帳號與供應商*、*瀏覽器與 ChatGPT Web 橋接*、*網路、元件與更新*、*設定與診斷*）、4 大架構層級（*側邊欄導覽*、*統一設定映射*、*內建 `coding-tools` MCP 伺服器*、*背景服務與元件類別*）以及目前的重疊與錯置項目。使用者（直接在 **App layout** 分頁中）與對話模型（透過內建 `coding-tools` 伺服器新增的 `app_layout` MCP 工具）皆可即時檢視、新增、編輯或重設各類別、層級列與重疊項目。

### 電腦操作
- **電腦操作視窗選取會等待可見的控制工具列確認。** 選取電腦操作視窗後，會等到可見的控制工具列確認同一個工作階段才回報成功。按下停止或取消後，延遲的啟動回覆不會重新開啟工具列；工具列無法啟動時也不會誤報成功。只有明確要求時，才會將選取的視窗帶到前景。

### 帳戶
- **自動 MCP 檢查支援背景執行並禮讓對話。** 本次開啟 Coding Tools 後，自動 MCP 檢查現在會在背景繼續執行。需要 ChatGPT 瀏覽器的對話會先停止正在進行的檢查，而檢查絕不會在建立、連接或發布連接器的中途被停止。
- **MCP 身分檢查失敗時會標明未通過的檢查項目。** 帳戶現有的 MCP 連接器未通過身分檢查時，帳戶的錯誤訊息現在會說明是哪一項檢查未通過，例如 ChatGPT 的外掛清單沒有顯示該連接器，或該連接器儲存的 Tunnel ID 不同，不再只顯示「身分未驗證」。

### 代理指示
- **使用者直接指定的流程優先於預設值。** `AGENTS.md` 提供預設做法時，以使用者直接指定的範圍、順序或流程為準；要求修正即包含套用已確認的範圍內變更，無須再次確認；明確只要求審查時仍只回報結果。

包含 v0.8.162 的所有變更。
