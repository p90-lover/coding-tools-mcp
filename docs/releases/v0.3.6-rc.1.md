# Coding Tools MCP v0.3.6-rc.1 — remembered apps, background vision and native sandbox

## English

Adds explicit persistent application approval, restart recovery and current-user Windows sign-in startup alongside Always enabled. Approved applications are bound to canonical executable path/SHA-256 and workspace security settings; Stop/Pause suspend automatic restoration. No unlock, invisible control, target-app auto-launch or replacement-process guessing.

Adds `computer_list_windows` and `computer_select_window` for background window discovery and switching among approved applications without taking focus by default. Supported non-minimized background windows can be observed through native UIA/RAM screenshots. Minimized windows are listed but not silently restored. Physical mouse/keyboard input remains foreground-only. Live target / Exact agent frame and local emergency Stop remain.

Adds a dedicated upstream Codex Windows sandbox-library integration for `sandbox_exec`, not Codex agent inference. The helper is source-pinned and hash-bound to this installer, with local-only one-time OS preparation, read-only workspace/platform access and restricted networking. It does not wrap GUI tools or existing command tools. See native-command-sandbox.md and release verification evidence for scope and checks.

Screenshots stay memory-only. No screenshot files, galleries or disk image cache. No Codex model session/cloud task/AI review is invoked by this work. Existing Cloudflare recovery/OAuth refresh/assisted ChatGPT setup remain. Silent account connector creation or reauthorization is not supported; user consent and a stable configured endpoint remain necessary. The user's actual ChatGPT/Cloudflare environment is not verified.

Public release candidate. Windows x64 installer is publisher-unsigned; macOS ARM64 is ad-hoc signed and not notarized. Mac retains vision but not Windows input/sandbox execution. Checksums, source/helper provenance and focused build/native verification accompany the installers. No old releases, branches or project files are deleted.

## 繁體中文

新增明確的程式永久記住授權、重啟恢復及目前使用者 Windows 登入啟動，與原有持續啟用並存。授權綁定程式路徑／SHA-256 及工作區設定；暫停／停止會暫停自動恢復。不繞過鎖定、不隱藏控制、不自動啟動目標程式，也不猜測替代程序。

新增背景視窗探索及已批准視窗切換，預設不搶焦點。可透過 UIA／記憶體截圖觀察支援的非縮小背景視窗；縮小視窗只列出，不自動還原。真實鍵鼠仍使用 Windows 前台，兩種實時預覽及緊急停止保留。

新增獨立的上游 Codex Windows 沙箱函式庫後端供 `sandbox_exec` 使用，不呼叫 Codex Agent／模型。原始碼與輔助程式雜湊固定，首次系統設定須本機同意；僅唯讀工作區／平台存取及限制網絡，不會把 GUI 或既有命令工具自動納入沙箱。請參閱原生沙箱文件與驗證證據。

截圖仍只留在記憶體。ChatGPT 帳戶連接與重新授權仍須使用者同意，不宣稱已完成靜默設定或你的實機環境驗證。Windows 無發佈者簽署，macOS 為 ad-hoc 簽署且未公證；macOS 保留視覺工具但不含 Windows 輸入／沙箱。舊版本、分支與專案檔案均保留。
