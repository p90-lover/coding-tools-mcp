# Coding Tools MCP v0.3.6-rc.1 — Remembered control and background observation

This release delivers the Windows remembered-control/vision update. The separate upstream-derived native command sandbox is explicitly withheld: runtime compatibility/isolation checks did not all pass, and a subsequent privileged diagnostic write was blocked by the tool's safety checks. It is not bundled, does not run, and has no unsandboxed fallback. Its development source is preserved for review, not represented as a working released feature.

## Included

Always enabled retains the no-expiry session choice. New local options are **Remember this exact app**, **Restore after app restart**, **Start at Windows sign-in**, **Discover all window titles**, and **Start observation without taking focus**. Grants are bound to the approved workspace/security settings and canonical executable path plus SHA-256. Only an already-running, unambiguous approved application can be restored. Startup remains eligible while waiting; it does not give up after an arbitrary hour, launch target applications, unlock Windows, or operate on a secure desktop.

`computer_list_windows` provides bounded window discovery. `computer_select_window` defaults to `activate:false`, switches only to permitted applications, returns a fresh session ID and invalidates old snapshots. Supported non-minimized background windows can be captured or read through UI Automation without taking foreground focus. Real mouse/keyboard input still requires foreground control; this is not a separate virtual desktop.

The visible monitor retains Live target, Exact agent frame, timestamps, Pause/Resume/Stop and Ctrl+Alt+Esc. Exact agent frame shows the same latest image bytes returned through the computer tools. Pause/Stop or hiding/minimizing/closing the monitor suspends remembered restoration; a normal explicit app Quit preserves the remembered preference. Remote MCP cannot grant or resume local authority.

Screenshots and both preview modes remain RAM-only: no screenshot files, gallery, thumbnails, image logs or disk screenshot cache. Receiving clients and operating-system paging/crash dumps are outside this application-level guarantee. No Codex agent, model session, AI reviewer, or cloud task is invoked by this build/release flow.

Cloudflare process recovery, non-disruptive connection probing, fixed Named Tunnel guidance and assisted ChatGPT setup remain included. A changed Quick Tunnel origin still requires the ChatGPT connection to be updated/authorized; there is no silent account API or consent bypass.

## Verification and scope

The release must pass frontend, remembered permission/vision/tool-catalog checks, the real isolated Windows background observation/input fixture, explicit rejection of the withheld sandbox, and inspection of the actual installers. Windows installer inspection must confirm that no experimental sandbox helper binaries are present. Release metadata records `native_sandbox_verified:false` and `native_sandbox_bundled:false`; older experimental workflow failures are not relabeled as successes.

Windows x64 supports computer control. The macOS ARM64 package retains image tools but does not provide Windows UI Automation or native desktop input. Windows is publisher-unsigned; macOS is ad-hoc signed and not notarized. The user's actual Windows sign-in, Cloudflare and ChatGPT account environment has not been verified end to end. This is a public release candidate, not a claim that every earlier roadmap item is complete.

## Enable remembered/background control

Install the new build, enable authenticated MCP/screen capture and non-read-only permissions, then restart MCP. In Computer control select the application, choose Always enabled and the desired remember/restore/sign-in/discovery options, and confirm locally. Refresh the connected ChatGPT tool list. Keep the monitor visible. Changed applications or workspace security settings require renewed local approval.

## 繁體中文

此版本交付 Windows 記住授權、重啟／登入後恢復，以及背景視窗探索／觀察。原有持續啟用仍無時間上限。新增選項須在本機批准，並綁定工作區、安全設定、程式完整路徑及 SHA-256；不自動批准所有程式、不啟動目標程式、不解鎖 Windows 或繞過 UAC。

`computer_list_windows` 提供有界的視窗清單；`computer_select_window` 預設不搶焦點，只選取獲准目標。支援的非縮小背景視窗可截圖／讀取 UIA；真實鍵鼠仍使用前台，並非另一個虛擬桌面。即時畫面、GPT 所見相同圖片、暫停／停止及緊急停止皆保留，截圖只留在記憶體。

獨立的上游衍生命令沙箱尚未通過全部 Windows 相容性／隔離驗證，後續一項特權診斷寫入亦被工具安全檢查攔截，因此不隨此版本打包、不允許啟動，也不退回無沙箱執行。開發原始碼保留；此限制不影響獨立的電腦操作及視覺功能。

發佈必須通過重點權限／視覺／工具檢查、真實 Windows 背景觀察與鍵鼠測試，以及實際安裝程式檢查；安裝程式不得含未驗證沙箱輔助程式。Cloudflare 恢復及輔助 ChatGPT 設定保留，但不會靜默批准帳戶授權。沒有啟動 Codex Agent／模型／審查任務。Windows 未作發佈者簽署；Mac 使用 ad-hoc 簽署且未公證；你的實際登入與 ChatGPT／Cloudflare 環境仍未完成端到端驗證。
