# Coding Tools MCP v0.3.6-rc.1 — remembered apps, background vision and native sandbox

## English

Adds explicit persistent application approval, restart recovery and current-user Windows sign-in startup alongside Always enabled. Approved applications are bound to canonical executable path/SHA-256 and workspace security settings; Stop/Pause suspend automatic restoration. No unlock, invisible control, target-app auto-launch or replacement-process guessing.

Adds `computer_list_windows` and `computer_select_window` for background window discovery and switching among approved applications without taking focus by default. Supported non-minimized background windows can be observed through native UIA/RAM screenshots. Minimized windows are listed but not silently restored. Physical mouse/keyboard input remains foreground-only. Live target / Exact agent frame and local emergency Stop remain.

Adds a dedicated upstream Codex Windows sandbox-library integration for `sandbox_exec`, not Codex agent inference. The helper is source-pinned and hash-bound to this installer, with local-only OS preparation, blocked workspace writes and restricted direct networking. Reads follow the dedicated sandbox account Windows ACLs, not a path whitelist: shared readable files outside the workspace may remain readable. It does not wrap GUI tools or existing command tools. See native-command-sandbox.md and verification evidence for the precise scope.

The offline helper uses app-owned Windows Filtering Platform identities and mandatory IPv4/IPv6 connect/receive denial for its dedicated account, including loopback. These filters do not target the normal desktop account or replace Codex-owned WFP identities. Older development setup markers do not qualify; preparing this policy requires the explicit local UI. Known stale sandbox-maintenance files are retained under protected Trash directories instead of permanently deleted.

Screenshots stay memory-only. No screenshot files, galleries or disk image cache. No Codex model session/cloud task/AI review is invoked by these features or their build. Existing Cloudflare recovery/OAuth refresh/assisted ChatGPT setup remain. Silent account connector creation or reauthorization is not included; user consent and a stable configured endpoint remain necessary. The user's actual ChatGPT/Cloudflare environment and full Windows reboot cycle have not been verified.

Release candidate: Windows x64 installer is publisher-unsigned; macOS ARM64 is ad-hoc signed and not notarized. Mac retains vision but not Windows input/sandbox execution. Publication is gated on matching-source installers, native isolation/desktop tests and binary checksums. No old releases, branches or project files are deleted.

## 繁體中文

新增明確的程式記住授權、重啟恢復及目前使用者 Windows 登入啟動，與原有持續啟用並存。授權綁定程式路徑／SHA-256 及工作區設定；暫停／停止會暫停自動恢復。不繞過鎖定、不隱藏控制、不自動啟動目標程式，也不猜測替代程序。

新增 `computer_list_windows`／`computer_select_window` 背景視窗探索及已批准視窗切換，預設不搶焦點。可透過 UIA／記憶體截圖觀察支援的非縮小背景視窗；縮小視窗只列出，不自動還原。真實鍵鼠仍使用 Windows 前台，兩種真實預覽及緊急停止保留。

新增獨立的上游 Codex Windows 沙箱函式庫後端供 `sandbox_exec` 使用，不呼叫 Codex Agent／模型。原始碼與輔助程式雜湊固定，首次系統設定須本機同意；阻止工作區寫入並限制直接網絡。讀取依據沙箱帳戶的 Windows ACL，而非路徑白名單：工作區外共用可讀檔案仍可能可讀。GUI 及既有命令工具不會自動納入沙箱。

離線輔助程式使用本應用程式專屬的 Windows Filtering Platform 識別，強制封鎖獨立沙箱帳戶的 IPv4／IPv6 連接及接收，包括迴路位址。不針對一般桌面帳戶，也不取代 Codex 自己的 WFP 識別。舊開發版的設定標記不會被接受，必須透過本機介面明確準備新策略。已知的舊沙箱維護檔案會保留在受保護的 Trash 目錄，不會永久刪除。

截圖仍只留在記憶體，不新增截圖檔、圖庫或磁碟圖片快取；功能及建置不啟動 Codex 模型會話。保留 Cloudflare 恢復與輔助式 ChatGPT 設定；帳戶建立／重新授權仍須使用者同意。你的實際 ChatGPT／Cloudflare 環境及完整 Windows 重啟流程尚未驗證。

這是候選版本。Windows 無發佈者簽署，macOS 為 ad-hoc 簽署且未公證；macOS 保留視覺工具但不含 Windows 輸入／沙箱。公開發佈前必須通過相同來源的安裝程式、原生隔離／桌面測試及校驗碼檢查。舊版本、分支及專案檔案均保留。
