Coding Tools 0.8.16

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Goals keep going:

- A goal carries on after an app restart, a retried round or a failure. A failed round no longer stalls it: the next round starts after a pause and is told why. Only three failures in a row stall the goal, and /goal resume starts the count afresh.
- A goal waiting out a pause is armed again after an app restart, and a round that runs again (Retry, or restart recovery) is judged again when it settles.
- A goal no longer sits at "Pursuing goal" under a Done chat. A round that waited on an approval is judged when it really finishes, and an active goal judged "not met" and left idle starts its next round.
- The goal bar's actions no longer leave a card in the chat.
- Agents wait with the app's wake-up. Claude Code's own timers (CronCreate) are off for chat agents, because they never fired there.

"Let the model judge" (off by default; the switch is in the goal bar and on an approval card the reviewer left to you):

- A goal round that ends needing you, or failed, is judged instead of stalling the goal. The checker either carries on, telling the agent to choose the safest option itself, or ends the goal with its reason ("Ended by the goal checker: …"), which you can resume.
- A request too long to review whole is judged on what the reviewer can see, and denied unless that shows it is safe.
- A chat whose requests the reviewer kept denying is not handed to you, and turning the switch on re-screens the requests already waiting. A reviewer that fails every try still asks you.

Chat:

- Retry on a failed step works while another chat is busy; before, it did nothing until every other action had finished.
- An agent that can't reconnect is stopped and replaced instead of leaving the chat stuck.
- A message whose send failed no longer shifts every later reply into the turn above it.
- Allow and Deny no longer show for an agent that has already stopped, so a click can't fail with "the agent controller for this session is not running".
- A request the reviewer answers at once no longer counts as waiting on you, so the "needs attention" notices stop for it.
- In split view Clawd stays on the top edge of its pane, where nothing cuts it off, and no longer hops between panes, so it goes home to nap.

Seeing the screen:

- New on-device OCR tools read the text in a window or a region of the screen, so a model reads a dialog or an error as text instead of a large screenshot.
- compare_images reports each changed region, not one box around all of them.
- view_app works for vision models.

Agent Orchestrator:

- AO starts after a reboot again. Before, its retention cleanup read the cold archive while holding the database writer, and every start timed out "getting ready".
- AO remembers a project's git details for a short while instead of asking git on every poll.

CPA:

- CPA Auto Review falls back across accounts and models when one is out of quota.
- Quota is shown when a provider opens, including Cline Pass's.
- The goal check skips models CPA no longer serves (404).

Less CPU:

- A hidden ChatGPT Web turn tab holds its animations still instead of redrawing at full rate.

Also:

- SvelteKit 3, for npm audit.

Everything in 0.8.15 is included.
