# Coding Tools v0.8.162

## English

### Accounts
- **"The account in use" no longer starts new sessions on an account that can't answer.** When "New sessions start on" is set to "The account in use" and that account is signed out, or ChatGPT has rejected its sign-in, a new session now starts on the least busy account that can take it instead. Seen on 2026-11-23: the account in use had had its sign-in rejected for two days, so every new session started there and failed while another account was signed in. If no account can take a session, it still starts on the account in use. "Always <account>" keeps using that account, and "The least busy account" is unchanged.

### Approve for me
- **Approve for me keeps reviewing a chat whose agent is still working, even after a hiccup in the app.** Each chat's run loop answers its agent's requests (auto-review, Guardian, the CPA reviewer, Let the model judge) and notices when its turn ends. When a check of the chat failed, for example because the app's local service was too busy to take the call, the loop stopped and marked the chat "held" while the agent went on working. "Retry automatically" passes over a step that is still running, so nothing started the loop again, and the agent's next request waited for you until you opened that chat. Seen on 2026-11-23: four chats' requests sat unreviewed for 3.5 hours after a burst of local load. The loop now starts again by itself (after 2 seconds, then up to a minute between tries) for as long as the agent works. A failed launch, or a chat that was deleted, still stops it as before.

### Chats
- **Resting the pointer on a link in a chat opens a preview of the page.**
  - After a moment on a link (or when it is focused with the keyboard), a card opens under it, or above it near the bottom of the window: the site's icon and name, the page's title and description, its share image, and the full address. It replaces the small address strip in the bottom-left corner.
  - Coding Tools reads only the top of the page, on the app's own network route and without your cookies. Addresses on this computer or your local network are never read: their card says "Local address: not previewed". A download says what it is ("PDF · 1.2 MB"), and a missing page says so ("Page not found (404)").
  - The card follows the chat's light or dark look, never blocks a click, and closes when the pointer leaves, on Escape, or when you scroll.

### Agent Orchestrator
- **A changed CPA key no longer restarts Agent Orchestrator in the middle of chat work.** The restart now waits while chats are working or their writes are in flight. Stop wins over an automatic restart, and the new process starts only after the old one is confirmed to have exited.

Includes all changes from v0.8.161.

## 繁體中文

### 帳號
- **「目前使用的帳號」不再把新工作階段開在無法回應的帳號上。** 當「新工作階段開始於」設為「目前使用的帳號」，而該帳號已登出或 ChatGPT 已拒絕其登入時，新工作階段現在會改開在可接受的帳號中最不忙的那個。2026-11-23 的實例：目前使用的帳號登入已被拒絕兩天，於是每個新工作階段都開在那裡並失敗，而另一個帳號其實已登入。若沒有任何帳號可接受，仍照舊開在目前使用的帳號。「一律使用 <帳號>」仍固定使用該帳號，「最不忙的帳號」維持不變。

### 代我核准
- **即使應用程式短暫出錯，「代我核准」也會繼續審查仍在工作的聊天。** 每個聊天的執行迴圈負責回覆代理的請求（自動審查、Guardian、CPA 審查員、讓模型判斷），並察覺回合何時結束。過去只要一次檢查失敗，例如應用程式的本機服務太忙無法受理，迴圈就會停止並把聊天標成「暫停」，但代理仍在繼續工作。「自動重試」會略過仍在執行的步驟，所以沒有任何東西重新啟動迴圈，代理的下一個請求只能等你打開那個聊天才會處理。2026-11-23 觀察到：一陣本機負載之後，四個聊天的請求有 3.5 小時沒有被審查。現在只要代理還在工作，迴圈就會自行重新啟動（先等 2 秒，之後每次最多間隔一分鐘）。啟動失敗或聊天已被刪除時，仍會像以前一樣停止。

### 對話
- **在對話中把指標停在連結上，就會開啟該頁面的預覽。**
  - 指標在連結上停留片刻（或用鍵盤聚焦連結）後，連結下方會出現一張卡片（靠近視窗底部時改在上方），顯示網站圖示與名稱、頁面標題與描述、分享圖片，以及完整網址。它取代了左下角原本的小網址列。
  - Coding Tools 只讀取頁面的開頭部分，經由 app 自己的網路路由，且不帶你的 cookie。這台電腦或區域網路上的位址一律不讀取，卡片會顯示「Local address: not previewed」。下載連結會標示檔案類型（「PDF · 1.2 MB」），找不到的頁面也會註明（「Page not found (404)」）。
  - 卡片跟隨對話的淺色或深色外觀，不會擋住點擊，並在指標離開、按 Escape 或捲動時關閉。

### Agent Orchestrator
- **CPA 金鑰變更不再在聊天工作進行中重啟 Agent Orchestrator。** 聊天仍在運作或請求尚未完成時，重啟會延後。手動停止優先於自動重啟；確認舊程序已結束後，才會啟動新程序。

包含 v0.8.161 的所有變更。
