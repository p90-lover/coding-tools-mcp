# Coding Tools v0.8.122

## English

### Proxy

- **The app works through your proxy on its own, with no outside proxy app.** Decodo stopped asking browsers for the proxy sign-in and closed their connections instead.
  - Unless ProxyBridge ran in front of the app, its ChatGPT view failed with "Can't reach chatgpt.com" (ERR_EMPTY_RESPONSE, then ERR_TOO_MANY_RETRIES), and the in-app update failed with HTTP 407.
  - The app now runs a small relay of its own that signs in to the proxy for every request from its windows, the Browser tab, Chrome sign-in and the update download.
  - Programs the app starts keep their route, which already carried the sign-in.
  - The error page now points to the Proxy page instead of telling you to start ProxyBridge.
- **The Proxy page tells you when a proxy refuses its sign-in (#1311).** Test used to check only that the proxy's address answered, so a proxy that refused its saved username and password showed as healthy ("64 ms") while every request through it failed.
  - Test now tries the saved sign-in too (HTTP and SOCKS5 proxies), and the page shows "Sign-in refused".
  - The app also marks a proxy by itself when its own requests are refused, and clears the mark when the proxy accepts the sign-in again.
  - A failed update now says "The proxy refused its sign-in (HTTP 407). Check the proxy's sign-in on the Proxy page." instead of "Update download failed with HTTP 407".
- **Each proxy shows its sign-in's username, and can have its own name (#1310).** The username appears on the card, in the route pickers and when editing, so proxies on the same address can be told apart. The password is never shown.

### Approvals

- **Quota-based reviews need your consent.** External command and screen reviews through CPA use account quota, even with a Codex CLI login.
  - They now run only with "Allow quota-based reviews" on in Chat settings. It is off by default, and turning it off also stops verdicts saved earlier from being reused.
  - With it off, safe rules still run, and anything else waits for you, even with "Let the model judge" on.

### Verification

- Proxy relay: a new test runs a proxy that drops unsigned requests, as Decodo does now. Five routing tests failed on the old code, and 145 routing-related tests pass.
  - Live, real Chromium through the real Decodo got ERR_EMPTY_RESPONSE on the bare route and 200 (exit US) through the relay.
- Sign-in check (#1311): its new test file passes 7/7, and its first five tests failed on `main`. With the relay merged in, 16 more proxy and update test files pass.
  - Real Electron against a local test proxy reports a wrong sign-in as refused once, and accepts a right one once.
- Usernames (#1310): merged with all CI green.
- Quota reviews: three new tests cover the opt-in, the wait for the user with the model judge on, and the setting surviving a restart.
- Release identity checks validate the matching product, package and packaging versions. Packaging and publication run through GitHub Actions.
- None of these changes was checked in the running app. This release does not install, patch or restart an already running app.
- Everything in 0.8.121 is included.

## 繁體中文

### 代理

- **App 現在可自行透過你的代理伺服器連線，不需外部代理程式。** Decodo 不再要求瀏覽器提供代理登入資訊，而是直接關閉連線。
  - 除非 App 前面有 ProxyBridge，否則 ChatGPT 檢視會顯示「Can't reach chatgpt.com」（ERR_EMPTY_RESPONSE，接著 ERR_TOO_MANY_RETRIES），App 內更新也會因 HTTP 407 失敗。
  - 現在 App 自己執行一個小型中繼，替視窗、瀏覽器分頁、Chrome 登入與更新下載的每個請求向代理伺服器登入。
  - App 啟動的程式維持原本已帶有登入資訊的路由。
  - 錯誤頁面改為引導至「代理」頁面，不再要求啟動 ProxyBridge。
- **代理伺服器拒絕登入時，「代理」頁面會告訴你（#1311）。** 以前「測試」只檢查代理伺服器的位址有沒有回應，所以即使它拒絕已儲存的帳號密碼、經過它的請求全部失敗，仍顯示為正常（「64 ms」）。
  - 現在「測試」也會試用已儲存的登入資訊（HTTP 與 SOCKS5 代理），頁面會顯示「登入被拒」。
  - App 自己的請求被拒絕時也會自動標示該代理，代理再次接受登入後會清除標示。
  - 更新失敗時改為顯示「The proxy refused its sign-in (HTTP 407). Check the proxy's sign-in on the Proxy page.」，不再是「Update download failed with HTTP 407」。
- **每個代理都會顯示其登入使用者名稱，也可自訂名稱（#1310）。** 使用者名稱會出現在卡片、路由選單及編輯時，方便分辨同一地址上的不同代理。密碼永遠不會顯示。

### 審批

- **需經你同意才會進行耗用額度的審查。** 透過 CPA 的外部指令與畫面審查會耗用帳號額度，即使使用 Codex CLI 登入亦然。
  - 現在只有在「對話設定」開啟「Allow quota-based reviews」時才會執行。此設定預設關閉；關閉後，先前保存的判定也不會再被沿用。
  - 關閉時，安全規則仍會執行，其餘動作會等你決定，即使已開啟「Let the model judge」。

### 驗證

- 代理中繼：新測試使用一個會丟棄未登入請求的代理伺服器（與 Decodo 目前的行為相同）。五個路由測試在舊程式碼上失敗，145 個路由相關測試通過。
  - 實測：真實的 Chromium 經由真實的 Decodo，直接連線時得到 ERR_EMPTY_RESPONSE，經由中繼時得到 200（出口在美國）。
- 登入檢查（#1311）：新的測試檔 7/7 通過，其中前五個在 `main` 上失敗。合併中繼後，另有 16 個代理與更新測試檔通過。
  - 以真實 Electron 對本機測試代理測試：錯誤的登入只回報一次被拒，正確的登入只接受一次。
- 使用者名稱（#1310）：合併時所有 CI 皆通過。
- 額度審查：三個新測試涵蓋需主動開啟、開啟模型判斷時仍等你決定，以及設定在重新啟動後保留。
- 發行識別測試確認產品、套件及封裝版本一致；封裝與發佈透過 GitHub Actions 執行。
- 以上變更皆未在執行中的 App 裡檢查；本次發行不會直接安裝、修改或重新啟動正在執行的 App。
- 包含 0.8.121 的所有內容。
