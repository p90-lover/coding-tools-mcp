# Coding Tools v0.8.148

## English

- **GPT Management:** Connect MCP for a signed-in account without switching to or taking over the Browser tab. Setup can find an installed connector in the verified workspace even when there is no Personal plugins tab. Account isolation, sign-in, workspace access, and consent checks are unchanged.
- **Antigravity sign-in:** Google HTTP 429 now ends the current sign-in attempt and shows when to try again. The app respects `Retry-After`, or waits a minute if Google does not provide a usable value.
- **Chat provider errors:** HTTP 403 is shown as access denied rather than sign-in refused. Check the account’s access to the model or choose another model.

Everything in 0.8.147 is included.

## 繁體中文

- **GPT 帳號管理：** 已登入的帳號可連接 MCP，不必切換到 Browser 分頁，也不會取代目前瀏覽的頁面。即使沒有「Personal」外掛分頁，也能在已驗證的工作區找到已安裝的連接器。帳號隔離、登入、工作區存取權及同意檢查維持不變。
- **Antigravity 登入：** Google 回傳 HTTP 429 時，會結束當前登入嘗試並顯示何時可再試。應用程式遵守 `Retry-After`；若沒有可用的值，則等待一分鐘。
- **聊天供應商錯誤：** HTTP 403 會顯示為「存取遭拒」，而不是「登入遭拒」。請確認帳號是否可使用該模型，或改用其他模型。

包含 0.8.147 的所有變更。
