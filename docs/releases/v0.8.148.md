# Coding Tools v0.8.148

## English

- **GPT Management:** Connect MCP for a signed-in account without switching to or taking over the Browser tab. Setup can find an installed connector in the verified workspace even when there is no Personal plugins tab. Account isolation, sign-in, workspace access, and consent checks are unchanged.
- **Antigravity sign-in:** Google HTTP 429 now ends the current sign-in attempt and shows when to try again. The app respects `Retry-After`, or waits a minute if Google does not provide a usable value.
- **Chat provider errors:** HTTP 403 is shown as access denied rather than sign-in refused. Check the account’s access to the model or choose another model.

- **Autobot Roll Out:** In a supported chat, confirm exactly which read-only commands the plugin may approve without calling a model. Other requests try Guardian first. The quota-based Model Judge is a fallback only if Guardian is unavailable and you have enabled both review settings.
- **Live plan checklist:** Chat shows the steps reported by Claude Code and Codex, with a check next to completed steps. `/plan` still asks for a plan without editing files.
- **Context sizing:** The DeepSeek V4 Flash alias uses its known 1M context when CPA reports the stock 272K value. Explicit lower limits stay in place. There is one 1M option for Gemini’s 1,048,576-token window.
- **Provider Manager:** New Windows installations bundle the previously published Provider Manager 0.10.3.

Everything in 0.8.147 is included.

## 繁體中文

- **GPT 帳號管理：** 已登入的帳號可連接 MCP，不必切換到 Browser 分頁，也不會取代目前瀏覽的頁面。即使沒有「Personal」外掛分頁，也能在已驗證的工作區找到已安裝的連接器。帳號隔離、登入、工作區存取權及同意檢查維持不變。
- **Antigravity 登入：** Google 回傳 HTTP 429 時，會結束當前登入嘗試並顯示何時可再試。應用程式遵守 `Retry-After`；若沒有可用的值，則等待一分鐘。
- **聊天供應商錯誤：** HTTP 403 會顯示為「存取遭拒」，而不是「登入遭拒」。請確認帳號是否可使用該模型，或改用其他模型。

- **Autobot Roll Out：** 在支援的對話中，可確認哪些唯讀指令不需呼叫模型即可核准。其他請求先交由 Guardian 審查；僅在 Guardian 無法使用且你已啟用兩項審查設定時，才以配額型模型審查作為備援。
- **即時計畫清單：** 對話顯示 Claude Code 與 Codex 回報的步驟，完成的項目會顯示勾號。`/plan` 仍只要求規劃，不修改檔案。
- **上下文大小：** 當 CPA 回報預設的 272K 時，DeepSeek V4 Flash 別名使用已知的 1M 上下文；明確指定的較低上限維持不變。Gemini 的 1,048,576 個權杖上下文只顯示一個 1M 選項。
- **Provider Manager：** 新的 Windows 安裝包含已發布的 Provider Manager 0.10.3。

包含 0.8.147 的所有變更。
