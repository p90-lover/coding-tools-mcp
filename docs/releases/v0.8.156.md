# Coding Tools v0.8.156

## English

- **Approve for me** now lets a shell request through when native Codex Guardian allows it as low risk but could not rate your authorization ("unknown"), as Codex itself does. About one in six harmless requests came back this way and used to wait for you. A request Guardian rates as not authorized by you still asks. (follow-up to #1359)
- **A request that waits on Allow quota-based reviews has that switch on its card.**
  - Approval cards read "Quota-based reviews are off" or "Native Guardian could not decide" and waited, even with **Let the model judge** on. The model judge also needs **Allow quota-based reviews**, which was off, but the card only showed the judge's switch, so review looked on.
  - Such a card now shows an **Allow quota-based reviews** switch below Let the model judge. Turning it on has the waiting requests reviewed at once. It's the same setting as Settings > Chat.
- **Correction to 0.8.155:** a clean re-measurement puts native Guardian's cost at about 0.5% of a Plus 5-hour window per 100 reviews, not 1%. The first measurement included another Codex session on the same account. OpenAI says auto-review is free with a ChatGPT sign-in, but these reviews still moved the counter.

Everything in 0.8.155 is included.

## 繁體中文

- **代我核准**：原生 Codex Guardian 判定為低風險並允許、但無法判斷你是否授權（「unknown」）的 shell 請求，現在會直接放行，與 Codex 本身的做法相同。約六分之一的無害請求屬於這種情況，以前都要等你處理。Guardian 判定你未授權的請求仍會詢問你。（#1359 的後續）
- **等待「Allow quota-based reviews」的請求，卡片上現在就有這個開關。**
  - 即使已開啟「Let the model judge」，核准卡片仍顯示「Quota-based reviews are off」或「Native Guardian could not decide」並持續等待。模型判斷也需要開啟「Allow quota-based reviews」，而它當時是關閉的；但卡片上只有模型判斷的開關，所以看起來像已開啟審查。
  - 這類卡片現在會在「Let the model judge」下方顯示「Allow quota-based reviews」開關。開啟後，等待中的請求會立即送審。它與「設定 > Chat」中的設定相同。
- **更正 0.8.155**：重新精確測量後，原生 Guardian 每 100 次審查約占 Plus 5 小時額度的 0.5%，而非 1%。第一次測量混入了同一帳號上另一個 Codex 工作階段的用量。OpenAI 表示以 ChatGPT 登入時自動審查免費，但這些審查仍使計數上升。

包含 0.8.155 的所有變更。
