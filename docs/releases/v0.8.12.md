Coding Tools 0.8.12

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Effort levels no longer get a launch stuck:

- The chosen effort now goes in the request body, as Claude Code and Codex send it, instead of in the model's name. A level a CPA plugin did not take used to fail the request, and Claude Code's retries made the chat look stuck at launching.
- Every model's effort menu starts with **Auto · the model's own**, which sends no effort at all.
- A level a model does not take runs at its nearest one (DeepSeek "Medium" runs at High) instead of failing. The Cline Pass plugin does the same for any level it receives.
- Claude Code sessions through CPA keep the chosen effort, and no longer fail to start over it.

Steering and stopping:

- A message you send to a working agent shows Claude Code's read receipt: "Sending…" on its way, a faded check (Unread) once the agent has it, and a double check (Read by Claude) once the model has read it.
- Stop on an agent that is still launching, or whose model is retrying, ends it within a few seconds. It used to wait about 30 seconds, then fail with "stop needs attention" while the agent kept running.
- A steered Claude Code turn ends properly (Claude Code ACP 0.94.0).

Chats that look stuck:

- A working agent's card says what it is doing and where it waits, not only "launching" or "running".
- A turn whose tool call never returns is stopped and retried when "Retry automatically" is on.
- Sending a message answers at once; queued messages look like Claude Code's.

Also:

- Projects in the chat sidebar stay where you put them; drag to reorder.
- Agent Orchestrator sessions unused for the chat archive's days are ended.
- Startup gives Agent Orchestrator's database cleanup at most 90 seconds, so a large cleanup can no longer hold the app at "starting".
- Agent Orchestrator caps its write-ahead log at 64 MB, and live chat polls read less data.

Everything in 0.8.11 is included.
