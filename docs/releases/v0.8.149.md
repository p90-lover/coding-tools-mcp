# Coding Tools v0.8.149

## English

- Pi chats now wait for the installed Pi ACP bridge to come up. On a slow Windows startup, the bridge's client could previously exit before its daemon was ready, so the chat could not start.
- When you choose a CPA model in Pi, Coding Tools supplies the model before opening the chat. The catalog belongs to that session and does not store the CPA credential or change your ordinary Pi profile. Pi's supported permission modes are unchanged.
- Agent Orchestrator fix: [#57](https://github.com/p90-lover/agent-orchestrator/pull/57). Focused tests and an isolated Windows Pi startup and loopback reply passed. Includes all changes in 0.8.148.

## 繁體中文

- Pi 對話現在會等待已安裝的 Pi ACP 橋接程式就緒。先前在 Windows 啟動較慢時，用戶端可能在背景程式就緒前結束，導致對話無法啟動。
- 在 Pi 選擇 CPA 模型時，Coding Tools 會在開啟對話前先提供模型。模型清單僅用於該工作階段，不會儲存 CPA 憑證或修改原有的 Pi 設定。Pi 支援的權限模式不變。
- Agent Orchestrator 修正：[ #57 ](https://github.com/p90-lover/agent-orchestrator/pull/57)。重點測試、隔離的 Windows Pi 啟動與本機測試回覆皆通過。包含 0.8.148 的所有變更。
