Coding Tools 0.7.0-rc.19

If "Update to v0.7.0-rc.18" failed with "getaddrinfo ENOTFOUND github.com", or the app stopped starting after an update, install this release once by hand: download Coding.Tools_0.7.0-rc.19_win_x64_portable.zip (unzip it over your portable folder, with the app closed) or Coding.Tools_0.7.0-rc.19_win_x64.exe (the installer). From rc.19 on, updates download through the app's own network and install in-app again.

New:
- Chat: agents start in the background. The chat shows your message at once and the agent picks it up as soon as it is running, instead of the chat waiting about 20 seconds for the whole start. A second chat in the same project no longer waits for the first one's agent to come up, and model and sign-in checks are answered from cache.
- Chat, "Approve for me" (and "Full access"): a request nobody answers within 20 seconds is answered for you, so the agent keeps working. Commands and tool requests are allowed once, a plan is accepted with edits allowed, and a question gets its recommended answer. Anything the command approver's safety rules block (pushing, deleting outside the project, secrets) still waits for you. "Ask for approval" always waits for you.
- Chat, Terminal pane: a dev server the agent starts in the background shows as running, with its live output, and stays listed until it stops.

Fixes:
- The app could not be started again after its window crashed, or after an update left a file still in use ("Packaged runtime did not fully materialize"). A crashed window now reloads, launching the app again revives it, files an update set aside no longer stop startup, and a launch during an update waits for it to finish.
- Codex: removing the Coding Tools bridge could leave Codex pointed at 127.0.0.1:17841, so it still could not reach OpenAI directly. Removing it now clears any bridge route; click "Remove Codex integration" again to clean up an older one. After an app crash, Codex turns through the bridge wait for the app to come back instead of failing with 502.
- Chat, "Approve for me": a Claude Code command already approved on its card is not asked about again in a dialog, and the app's prompts no longer fail when the window is not focused.
- Lower GPU use while idle on Windows: the sidebar and workspace no longer run a full-window blur, and chat previews nobody is looking at stop rendering after 30 seconds.
- Updates: checks and downloads go through the app's network (the Global Routing proxy, else the system proxy, and Chromium's DNS) instead of Node's, so a machine that reaches GitHub through a proxy, or whose resolver misses github.com once, can update. A failed lookup or connection is retried twice before the update gives up.

Everything in rc.18 is included: the CPA account usage view, CPA 8.0.32, the chat model-list, effort/window and launch-time fixes, and kept WebGPT replies.
