Coding Tools 0.7.0-rc.19

If "Update to v0.7.0-rc.18" failed with "getaddrinfo ENOTFOUND github.com", install this release once by hand: download Coding.Tools_0.7.0-rc.19_win_x64_portable.zip (unzip it over your portable folder, with the app closed) or Coding.Tools_0.7.0-rc.19_win_x64.exe (the installer). From rc.19 on, updates download through the app's own network and install in-app again.

Fixes:
- Updates: checks and downloads go through the app's network (the Global Routing proxy, else the system proxy, and Chromium's DNS) instead of Node's, so a machine that reaches GitHub through a proxy, or whose resolver misses github.com once, can update. A failed lookup or connection is retried twice before the update gives up.

Everything in rc.18 is included: the CPA account usage view, CPA 8.0.32, the chat model-list, effort/window and launch-time fixes, and kept WebGPT replies.
