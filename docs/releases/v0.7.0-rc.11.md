# Coding Tools v0.7.0-rc.11

## English

This prerelease is the next exact-source Windows publish after frozen `v0.7.0-rc.8`, `v0.7.0-rc.9`, and `v0.7.0-rc.10`. It completes original visual UI and original managed functions for all five stacks inside Coding Tools Desktop:

| Stack | Original UI | Managed functions |
| --- | --- | --- |
| Codex Router | Original Control Center (Usage / Status / Models / Local / Harness / Context / Settings) | Pin, prepare, start/stop/restart, caller-secret health on `127.0.0.1:4202` |
| CPA / CLIProxyAPI | Original `management.html` hash routes, full-bleed with section tabs | Checksum-pinned v7.3.7 binary, loopback `127.0.0.1:8317`, install/repair/start/stop, copy management key |
| CommandCode Proxy | Original CLI banner, loopback URLs, Check/Start/Stop/Restart | Managed process on `127.0.0.1:9090`, `GET /` health + `/v1/models`, Provider Hub accounts |
| Paseo | Real Expo routes (`/sessions`, `/open-project`, `/settings`) auto-embedded | Managed install/start, loopback `127.0.0.1:6768` |
| Anneal | Original hash routes (`#/tasks`, `#/inbox`, …) from app-managed web | Managed WSL2/Docker topology, web `127.0.0.1:5173`, API `127.0.0.1:3000` — no user SSH port-forward |

One-app setup adds **Install and start all** / **Retry all** through the managed bootstrap coordinator. Loopback, encrypted credentials, focused-window IPC, and no-delete/Trash retention stay in force.

### Why a new version

- `v0.7.0-rc.10` is already published (Windows release run 35316776366 succeeded). This PR does not move that tag.
- The five-stack original-UI gaps remaining after #177/#180/#181/#189 are closed here instead of rewriting rc.10.

### Packaging and migration

- Electron Builder publication autodetection stays disabled; only the exact-source release publisher may upload GitHub assets.
- The Windows installer keeps the validated legacy NSIS and MSI migration path, the stable Electron app id, and user data.
- Release validation covers identity alignment, focused five-stack original-parity and bootstrap contracts, isolated renderer inspection, Windows packaging, packaged launcher smoke, migration acceptance, checksums, provenance, and remote asset readback.

### Exact-source provenance

- The publisher checks out the immutable triggering SHA and refuses publication if the remote branch advances during verification.
- Existing tags are never force-moved: if `v0.7.0-rc.11` already exists on another SHA, publication fails closed.
- Frozen publishers for `v0.7.0-rc.8` and `v0.7.0-rc.10` remain `workflow_dispatch` only.
