Coding Tools 0.7.0-rc.26

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Fixes:
- Subagent stops keep their concurrency slots until the agent has stopped and retry pending cancellations after backend recovery.
- Team stop and relink actions wait for cancellation to settle and report failures.
- Chat commands cancel waiting approvals when stopped, keep their ownership through session renewal and stop on session end while preserving terminals the user opened.
- Preview approvals cannot recreate a browser after its window or request ends.
- Switching chats preserves unsent drafts, approval ownership and terminal output positions when older requests finish late.
- Project renames preserve running commands, output and plans, while root changes and project removal retire old contexts and their commands.

Everything in rc.25 is included, including the DeepSeek V4.1 Flash None, Low, High and Max effort choices.
