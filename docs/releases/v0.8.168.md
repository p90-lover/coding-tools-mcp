# Coding Tools v0.8.168

## English

### Approvals
- **Every approval request is auto-reviewed, also in chats on Ask for approval.** A chat on Ask for approval showed a command card with no reviewer, no **Let the model judge** and no quota switch, and waited for you: only Approve for me chats had a reviewer.
  - New switch in Settings > Chat: **Auto-review every approval request**, on by default. A request that needs approval goes to the reviewer in every chat, as in Approve for me, and an agent's question gets its recommended answer after your **Agent questions** wait.
  - What the reviewer cannot decide still waits for you, with the reviewer's note and the **Let the model judge** and **Allow quota-based reviews** switches on its card. A card no reviewer takes (a native card, a team whose Command approver has not approved yet) still waits for you and is never approved on a timer.
  - Turned off, only Approve for me chats are reviewed. A request that waits only because of it says so on its card and offers the switch (and, in a single chat, the Approve for me button).

Includes all changes from v0.8.167.

## 繁體中文

### 核准
- **所有核准請求都會自動審查，設為「要求核准」的對話也一樣。** 設為「要求核准」的對話先前會顯示沒有審查者、沒有「Let the model judge」也沒有配額開關的指令卡片，並一直等你處理：只有設為「替我核准」的對話有審查者。
  - 「設定 > Chat」新增開關「Auto-review every approval request」，預設開啟。每個對話中需要核准的請求都會交給審查者，與「替我核准」相同；代理的問題會在你設定的「Agent questions」等待時間後採用建議答案。
  - 審查者無法判斷的請求仍會等你處理，卡片上會顯示審查者的說明以及「Let the model judge」與「Allow quota-based reviews」開關。沒有審查者接手的卡片（原生卡片，或指令核准者尚未核准的團隊）仍會等你處理，絕不會因計時而自動核准。
  - 關閉後只會審查設為「替我核准」的對話。僅因此開關關閉而等待的請求，卡片上會說明原因並提供此開關（單一對話中也會提供「替我核准」按鈕）。

包含 v0.8.167 的所有變更。
