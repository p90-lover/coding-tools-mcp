# Coding Tools 0.8.116

## English

### Chats (#1279, #1268, #1281)
- **Chat agents can run independent read-only tool calls together (#1279),** and keep a record of what they already verified. That avoids reading things one at a time and re-running tests that already passed. Approvals and the release checks are unchanged.
- **Hover a link to see where it goes, in a slim box, without opening it (#1268).** Keyboard focus shows it too.
- **A busy chat on screen uses much less CPU and GPU (#1281).** Its pulsing dots and spinners now move in steps, together, instead of redrawing on every screen refresh, and Clawd no longer stalls the page while picking a spot.

### MCP servers and accounts (#1285, #1284)
- **Chrome DevTools, Playwright and Sequential Thinking MCP servers start in chats again (#1285).** They showed as failed because npx downloaded them again each time a chat started, which took longer than the agent waits for an MCP server. Once installed, they now start from the installed copy in seconds. Their npm cache moved into the app's data folder.
- **CPA opens without the extra price strip and the "Running inside Coding Tools" notice (#1285).** Provider Manager still shows usage.
- **MCP setup failures say which check stopped them, in the Activity log (#1284).** When automatic MCP setup or an account's plan check stops with "MCP ownership metadata is unavailable or exceeded its bound.", the log now records which check on the ChatGPT or Platform page failed, for example a security check page instead of the workspace list. The message you see doesn't change.

### Freezes and false warnings (#1267, #1280)
- **Restarting or stopping CPA no longer freezes every window while the disk is busy (#1267).** CPA's saved process record is now written, read and removed off the main thread, in order, so a stop never leaves a record that names a process that has gone.
- **No false "A disk is reporting errors" warning (#1280).** Windows notes that a disk is healthy each time one is attached (a virtual disk, a USB drive), and Coding Tools read that note as a disk error. Only real disk and file system errors raise the warning now.

### Verification and limitations
- Each PR was merged into `main` by its own session, with its own checks:
  - #1279: 12 batch-helper tests and 9 focused receipt, batching and approval-order tests pass. Its code-graph check rated the change CRITICAL (141 symbols, 28 flows), so this release's full desktop suite is its real gate.
  - #1285: chat-mcp-servers and original-ui-reload 13/13; agent-orchestrator-upstream's MCP test 1/1. Real starts through the installed copies: Sequential Thinking in 1.4 s, Playwright in 3.3 s, Chrome DevTools in 9.9 s.
  - #1268: 4 focused tests and a strict module typecheck; not checked in a live preview.
  - #1267, #1280, #1281, #1284: their own focused tests.
- Not checked in the running app.
- Built from the merged `main` after the full desktop suite and both typechecks.
- Includes everything in 0.8.115.

## 繁體中文

### 對話（#1279、#1268、#1281）
- **聊天代理可同時執行互不相關的唯讀工具呼叫（#1279），**並保留已驗證項目的紀錄，避免逐一讀取與重複執行已通過的測試。核准流程與發行檢查不變。
- **將滑鼠停在連結上，即可在精簡提示框中查看目的網址，無須開啟連結（#1268）。**鍵盤焦點亦適用。
- **畫面上有忙碌的對話時，CPU 與 GPU 用量大幅降低（#1281）。**閃動的圓點與轉圈圖示改為一起分段更新，不再每次螢幕更新都重繪；Clawd 選位置時也不再卡住頁面。

### MCP 伺服器與帳號（#1285、#1284）
- **Chrome DevTools、Playwright 與 Sequential Thinking MCP 伺服器又能在對話中啟動（#1285）。**先前每次開始對話，npx 都會重新下載這些伺服器，所需時間超過代理程式等待 MCP 伺服器的上限，因此顯示為失敗。安裝完成後，現在會直接從已安裝的版本啟動，只需數秒。它們的 npm 快取已移到 App 的資料資料夾。
- **CPA 開啟時不再顯示多餘的價格列與「Running inside Coding Tools」提示（#1285）。**用量仍可在 Provider Manager 中查看。
- **MCP 設定失敗時，活動記錄會說明是哪項檢查中止（#1284）。**自動 MCP 設定或帳號方案檢查以「MCP ownership metadata is unavailable or exceeded its bound.」中止時，記錄現在會記下 ChatGPT 或 Platform 頁面上是哪一項檢查失敗，例如出現安全檢查頁面而不是工作區清單。您看到的訊息不變。

### 凍結與誤報（#1267、#1280）
- **硬碟忙碌時，重新啟動或停止 CPA 不再讓所有視窗凍結（#1267）。**CPA 已儲存的程序記錄現在改在主執行緒之外依序寫入、讀取和移除，因此停止時不會留下指向已結束程序的記錄。
- **不再誤報「磁碟回報錯誤」（#1280）。**每次連接磁碟（虛擬磁碟、USB 磁碟機）時，Windows 都會記錄該磁碟狀態良好，Coding Tools 先前把這則記錄當成磁碟錯誤。現在只有真正的磁碟或檔案系統錯誤才會發出警告。
