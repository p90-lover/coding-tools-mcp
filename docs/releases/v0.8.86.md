# Coding Tools 0.8.86

## English

### Chat
- **Claude Code chats on CPA models start again (#1060).** Every Claude Code chat on a model CPA serves that isn't a Claude model (GPT, DeepSeek through OpenCode Go and the like) failed at start with "Invalid value for config option model". CPA lists those models to Claude clients under its own Claude-style name, and Claude Code accepts only the names on that list. The app now asks for the model by CPA's name, effort kept, and CPA routes it to the real model. Claude models and the other agents are unchanged.
  - Seen live: `opencode-go/deepseek-v4.1-flash(max)` since 11-03, and `gpt-6.1-sol(xhigh)` 9 times on 11-03 16:59–17:35 UTC, each retry making a new failed session.

### CPA
- **Account usage shows once, inside CPA Provider Manager (#1049).** The app's usage strip above the CPA page repeated what Provider Manager 0.2.2 and later show themselves (tokens, cost, Codex and Cline quota per account), so the strip is gone. The chat's context meter is unchanged.

### Verification and limitations
- #1060 was checked against the running Agent Orchestrator and CPA: the plain id was refused with "Invalid value for config option model", and CPA's name for both models above started ready.
- The CI of each pull request passed. Built and published by GitHub CI from main; no local build was made for this version.
- Until this version is installed, the installed app keeps failing those chat starts.
- Includes all changes in 0.8.85.

## 繁體中文

### 對話
- **使用 CPA 模型的 Claude Code 對話可以再次啟動（#1060）。** 過去凡是 Claude Code 對話使用 CPA 提供的非 Claude 模型（GPT、經 OpenCode Go 的 DeepSeek 等），都會在啟動時以「Invalid value for config option model」失敗。CPA 以自己的 Claude 式名稱向 Claude 用戶端列出這些模型，而 Claude Code 只接受清單上的名稱。現在應用程式以 CPA 的名稱要求模型，並保留推理強度，CPA 再把它轉到實際的模型。Claude 模型及其他代理不受影響。
  - 實際觀察到：`opencode-go/deepseek-v4.1-flash(max)` 自 11 月 3 日起失敗，`gpt-6.1-sol(xhigh)` 在 11 月 3 日 16:59–17:35（UTC）失敗 9 次，每次重試都產生一個新的失敗工作階段。

### CPA
- **帳戶用量只在 CPA Provider Manager 內顯示一次（#1049）。** 應用程式在 CPA 頁面上方的用量列，與 Provider Manager 0.2.2 及之後版本自己顯示的內容（各帳戶的 token、費用及 Codex 和 Cline 配額）重複，因此已移除。對話的上下文用量指示不變。

### 驗證及限制
- #1060 已針對執行中的 Agent Orchestrator 和 CPA 檢查：原本的 ID 被拒絕並顯示「Invalid value for config option model」，而上述兩個模型使用 CPA 的名稱均可正常啟動。
- 每個拉取請求的 CI 均通過。由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 安裝此版本之前，已安裝的應用程式仍會在這些對話啟動時失敗。
- 包含 0.8.85 的所有內容。
