# Coding Tools v0.8.120

## English

### Chats

- Recover follow-ups recorded after a successful turn's last model output. These messages return to the next-turn queue in their original order instead of being forgotten just because the earlier task finished.
- Messages already read are not replayed. Text-only answers, missing or unavailable timeline evidence, and an explicit Stop do not trigger a duplicate follow-up.
- Ordinary queued messages continue automatically when their chat's turn ends, including when that chat view is closed.

### Verification

- The new unread-follow-up regression failed before the fix; all nine focused queue and read-receipt checks passed afterward.
- Release identity checks validate the matching product, package and packaging versions. Required CI and package verification run through the coordinated GitHub release process.
- Packaging and publication use GitHub Actions. This release does not install, patch or restart an already running app.

## 繁體中文

### 聊天

- 修正上一輪工作成功結束時，最後一次模型輸出之後才記錄的追問可能被遺漏的問題。這些訊息會依原本順序回到下一輪的待傳送佇列，不再僅因前一項工作完成就被清除。
- 已讀訊息不會重複傳送。純文字回覆、缺少或無法取得時間軸證據，以及使用者明確按下「停止」，都不會觸發重複追問。
- 一般排隊訊息會在該聊天的一輪工作結束後自動傳送，即使聊天畫面未開啟亦然。

### 驗證

- 新增的未讀追問回歸測試在修正前失敗；修正後九項針對佇列及已讀判定的測試全部通過。
- 發行識別測試確認產品、套件及封裝版本一致；必要的 CI 與封裝檢查由協調後的 GitHub 發行流程執行。
- 透過 GitHub Actions 封裝並發佈；本次發行不會直接安裝、修改或重新啟動正在執行的應用程式。
