# Coding Tools 0.8.64

## English

### Chats
- A chat's top row (folder, name, status and buttons) fades into the chat instead of being a solid strip. The chat scrolls on under it, so a little more of it shows. Clicks in the row's empty space reach the chat, and a running plan stays pinned just below the row.
- When a long chat is compacted, the text of yours that it keeps is measured in tokens, as the limit always said, not in characters. Chinese text kept 56,004 tokens against a 20,000-token limit, while English that fit the limit was cut early. The newest part that fits is kept, cut on a whole character (PR #965).
- Scores: switching the model shows only that model's mission history. A slower answer for the previous model can no longer replace it or show an error after you've moved on, and Clear refreshes the model you're looking at (PR #967).

### Verification and limitations
- Measured on a test page with the app's stylesheet: the chat's first line starts below the 48 px top row, a line scrolled under it shows through its lower half, a running plan stops 0 px below it, and a click in the row's empty space reaches the chat. Not yet checked in the installed app.
- Compaction: 19 tests pass, including three that failed before the fix. Scores: 9 tests pass, and a browser test page with a fake app connection showed the old history, out-of-order answer, late error and Clear cases before the fix and none after. Neither has been tried in the installed app (PR #965, PR #967).
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.63 is included.

## 繁體中文

### 對話
- 對話頂部一行（資料夾、名稱、狀態及按鈕）不再是實心橫條，而是逐漸淡入對話。對話會在它下方繼續捲動，因此可以多看到一點內容。點擊這一行的空白處會落到對話上，執行中的計劃則會固定在這一行下方。
- 壓縮長對話時，保留你的文字會以 token 計算（一如上限所寫），而非以字元計算。過去中文文字在 20,000 token 的上限下保留了 56,004 個 token，而符合上限的英文卻被提早截斷。現在會保留符合上限的最新部分，並在完整字元處截斷（PR #965）。
- 評分：切換模型時只會顯示該模型的任務記錄。前一個模型較慢的回應不會再取代它，也不會在你切換後顯示錯誤；「清除」會重新整理你正在檢視的模型（PR #967）。

### 驗證及限制
- 在使用應用程式樣式表的測試頁面上量測：對話第一行從 48 px 高的頂部一行下方開始，捲到它下方的內容會透過其下半部顯示，執行中的計劃停在它下方 0 px 處，點擊這一行的空白處會落到對話上。尚未在已安裝的應用程式中檢查。
- 壓縮：19 項測試通過，包括三項在修正前失敗的測試。評分：9 項測試通過；在使用模擬應用程式連線的瀏覽器測試頁面上，修正前會出現舊記錄、回應次序錯亂、延遲錯誤及「清除」的問題，修正後全部消失。兩者都尚未在已安裝的應用程式中試用（PR #965、PR #967）。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.63 的所有內容。
