# Coding Tools 0.8.48

## English

### Browser and accounts
- A verified MCP connection stays successful when a new chat turn or browser inspection begins while its status is being saved (PR #857).
- ChatGPT accounts that display the model as “GPT-6” can select it with the requested reasoning effort (PR #857).

### Smoother start
- Each launch checks the packaged and the installed runtime (about 6,150 files each) without holding the main thread, with many disk requests in flight at once; on the busy hard disk this check had frozen the app 22.7 s + 6.5 s before its window opened (PR #858).

### Verification and limitations
- Everything in 0.8.47 is included.

## 繁體中文

### 瀏覽器與帳號
- MCP 連線確認成功後，即使儲存狀態期間開始新的對話回合或瀏覽器檢查，也不會誤報失敗（PR #857）。
- ChatGPT 帳號將模型顯示為「GPT-6」時，現在可選取該模型並使用指定的推理強度（PR #857）。

### 更流暢的啟動
- 每次啟動檢查內建及已安裝的執行環境（各約 6,150 個檔案）時不再佔住主執行緒，並同時送出多個磁碟請求；在忙碌的硬碟上，這項檢查曾令程式在視窗開啟前停頓 22.7 秒加 6.5 秒（PR #858）。

### 驗證及限制
- 包含 0.8.47 的所有內容。
