# Coding Tools 0.8.23

## English

### Fixes
- Fix an unresponsive/disabled **Update to v…** button when the app reports an active Codex operation or browser turn.
- Clicking **Update to** during active work now queues the update; the button changes to **Update queued (click to cancel)**.
- Once active work finishes, the app starts its existing checksum-verified full-app updater without interrupting a running task.
- Clicking the queued action again cancels the request; queued requests clear if the update is no longer available.
- Existing download/install progress continues to disable repeat clicks until the operation finishes.

### Update notes
- This release preserves the v0.8.22 ChatGPT conversation URL reuse/task steering fixes.
- Existing installations with the old disabled button can install the official Windows x64 executable once to receive the new behavior. The existing updater's automatic idle-time installation remains supported.
- The release includes the Windows portable app and incremental in-app update packs, verified by SHA-256.

## 繁體中文

### 修正
- 修正有 Codex 任務或瀏覽器回合正在執行時，「更新至 v…」按鈕被停用、按下沒有反應的問題。
- 工作進行期間按下更新，會先排程更新；按鈕改為「更新已排程（按一下取消）」。
- 工作結束後才啟動原有、經 SHA-256 校驗的程式更新流程，不會為更新而中斷正在執行的工作。
- 再按一下可取消排程；若更新不再可用亦會清除排程。
- 下載或安裝期間繼續防止重複按下更新按鈕。

### 更新須知
- 保留 v0.8.22 的 ChatGPT 對話網址重用及任務導向修正。
- 舊版若因按鈕被停用而無法更新，可以先安裝官方 Windows x64 安裝檔一次，之後即可使用新按鈕功能。原有的閒置自動更新功能不變。
- Windows 安裝檔、免安裝壓縮檔及增量更新套件會經 SHA-256 驗證。
