# Coding Tools v0.6.0 — Electron Full Codex Harness

## English

Coding Tools v0.6.0 is the first Electron-first release that integrates the pinned `miuuyy/codex-chatgpt-web` v5.0.6 runtime with the retained Coding Tools Rust control core.

### Included

- Embedded application-owned ChatGPT browser profile and sign-in flow.
- ChatGPT Web models exposed through a Responses-compatible Codex route.
- Browser-only, Full Harness, and Zero Risk modes.
- Native Codex task context, image handling, task-bound browser tabs, compaction handoff, cancellation, and subagent support.
- Official OpenAI tunnel-client integration with checksum-pinned package inputs.
- Supervised `coding-tools-headless` Rust sidecar for workspaces, local tools, permission policy, long-running commands, history, and computer-control boundaries.
- Turn-scoped capability brokering so a ChatGPT Web turn receives only the tools granted to that exact task and turn.
- Per-user Windows x64 installer with elevation disabled.

### Pinned source boundary

- Upstream repository: `miuuyy/codex-chatgpt-web`
- Upstream version: `v5.0.6`
- Upstream commit: `e85e3693fdb4e3e033348c08df0298c20fcdb612`
- Application ID: `dev.codingtools.fullharness`
- ChatGPT Web model namespace: `chatgpt-web/`

The vendored upstream source, MIT notice, and generated third-party notices are retained in the release source. The integration does not follow a moving upstream branch.

### Security and account boundaries

This release does not bypass ChatGPT plan limits, model eligibility, quotas, workspace policy, provider limits, Developer Mode requirements, or connector authorization. The app uses its own browser profile and does not copy cookies from Chrome, Edge, another application, or another OS account.

Model access, local-tool access, computer control, and provider spending remain separate grants. Unknown-result browser submissions, tool calls, process starts, and input writes are not automatically replayed. The installer is configured for per-user installation with elevation disabled.

Automated package verification covers product identity, vendored-source integrity, Electron/runtime tests, Rust sidecar tests, package composition, installer format, source provenance, and SHA-256 checksums. Live-account behavior still depends on the signed-in account and current service policy. A fresh visible connector authorization and authenticated MCP round trip remain the authoritative acceptance check for a specific account.

### Published assets

1. `Coding.Tools_0.6.0_windows_x64_setup.exe`
2. `provenance.json`
3. `validation-evidence.json`
4. `SHA256SUMS.txt`

The publisher uploads to a draft release, reads every asset back, verifies its byte length and SHA-256, creates only a non-forced `v0.6.0` tag at the exact tested source commit, and then publishes the release as the repository's latest stable release.

### Preservation and rollback

No historical tag, release, Tauri source, user data, or project file is deleted. Temporary build and validation data stays under `aiTemp/`; superseded material is retained under `Trash/`. Existing v0.4.x installers remain available as rollback artifacts.

## 繁體中文

Coding Tools v0.6.0 係第一個以 Electron 為主要桌面介面、同時整合固定版本 `miuuyy/codex-chatgpt-web` v5.0.6 runtime 及保留 Coding Tools Rust 控制核心嘅正式版本。

### 已包含功能

- 程式自有嘅 ChatGPT browser profile 同登入流程。
- 經 Responses-compatible Codex route 提供 ChatGPT Web 模型。
- Browser-only、Full Harness 同 Zero Risk 三種模式。
- 原生 Codex 任務 context、圖片處理、任務綁定 browser tabs、compaction handoff、取消功能同 subagent 支援。
- 使用 checksum 固定輸入嘅官方 OpenAI tunnel-client 整合。
- 受監管嘅 `coding-tools-headless` Rust sidecar，負責 workspace、本機工具、權限政策、長時間指令、history 同電腦控制界線。
- Turn-scoped capability broker，令每個 ChatGPT Web turn 只取得該任務同該輪明確授權嘅工具。
- Windows x64 每位使用者安裝程式，停用 elevation。

### 固定原始碼界線

- Upstream repository：`miuuyy/codex-chatgpt-web`
- Upstream version：`v5.0.6`
- Upstream commit：`e85e3693fdb4e3e033348c08df0298c20fcdb612`
- Application ID：`dev.codingtools.fullharness`
- ChatGPT Web model namespace：`chatgpt-web/`

固定 upstream source、MIT 聲明同產生嘅第三方授權資料都會保留喺 release source。整合唔會直接跟隨持續變動嘅 upstream branch。

### 安全同帳戶界線

呢個版本唔會繞過 ChatGPT 方案限制、模型資格、配額、workspace policy、provider 上限、Developer Mode 要求或 connector 授權。程式使用自己管理嘅 browser profile，唔會由 Chrome、Edge、其他程式或者其他作業系統帳戶複製 cookie。

模型使用、本機工具、電腦控制同 provider 消費係分開授權。結果未知嘅 browser submission、工具呼叫、程序啟動同輸入寫入唔會自動重播。Installer 設定為每位使用者安裝，而且停用 elevation。

自動化 package verification 會檢查產品識別、固定 source 完整性、Electron/runtime 測試、Rust sidecar 測試、package 組成、installer 格式、source provenance 同 SHA-256。真實帳戶行為仍然視乎登入帳戶同當時服務政策；對指定帳戶而言，新一次可見 connector 授權同已認證 MCP round trip 仍然係最終驗收依據。
