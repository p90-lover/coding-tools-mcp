# Coding Tools 0.8.90

## English

### Browser
- **Accounts not on screen pass Cloudflare's check too.** Every signed-in account except the one shown in the Browser tab sat on ChatGPT's "Just a moment..." page, and the Codex bridge could not use it. Cloudflare's check runs as script in the page and finishes only in a page that renders. The app keeps the other accounts' pages loaded but hidden, and a hidden page gets no frames and runs its timers about once a second (measured: 0 frames a second on every stuck page), so the check never finished and retried for good. The account you were looking at passed in seconds.
  - While a ChatGPT page shows the check, it now renders off-screen at full speed. Once the check passes, or after 2 minutes, the page is hidden and slowed down again.
  - A check that still fails after 3 tries is left alone until you open that account, so a page that can't pass doesn't keep using the processor.
- The app no longer asks ChatGPT for the account's sign-in state while the check page is showing. Those requests were challenged too (8 in 6 seconds) and only added failed requests.

### Electron
- Electron is updated from 45.2.1 to 45.2.2, in the app and in the bundled bridge launcher.

### Verification and limitations
- 358 tests in the browser test files pass, including new ones: a parked account's check page renders off-screen and goes back to hidden when it passes, a check that keeps failing stops after 3 tries, a Codex task's tab keeps its own setting, and the sign-in probes skip the check page.
- The cause was found on the installed app: the account shown in the Browser tab passed the check while hidden ones did not, and opening a stuck account let it pass. The new behaviour itself was tested with stand-in views, not yet in the installed app.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.89.

## 繁體中文

### 瀏覽器
- **不在畫面上的帳戶也能通過 Cloudflare 的檢查。** 過去除了「瀏覽器」分頁正在顯示的帳戶外，其他已登入的帳戶都停在 ChatGPT 的「Just a moment...」頁面，Codex 橋接無法使用它們。Cloudflare 的檢查以腳本在頁面中執行，只有在頁面有繪製時才會完成。應用程式會讓其他帳戶的頁面保持載入但隱藏，而隱藏的頁面沒有任何畫面更新，計時器大約每秒才執行一次（實測：每個卡住的頁面每秒 0 幀），因此檢查永遠無法完成並不斷重試。你正在查看的帳戶則在數秒內通過。
  - 現在當 ChatGPT 頁面顯示檢查時，會在畫面外全速繪製。檢查通過後，或 2 分鐘後，頁面會再次隱藏並降速。
  - 嘗試 3 次仍未通過的檢查會暫停，直到你開啟該帳戶為止，避免無法通過的頁面持續佔用處理器。
- 檢查頁面顯示期間，應用程式不再向 ChatGPT 查詢帳戶的登入狀態。這些請求同樣會被檢查攔下（6 秒內 8 次），只會增加失敗的請求。

### Electron
- Electron 由 45.2.1 更新至 45.2.2，包括應用程式本身及隨附的橋接啟動器。

### 驗證及限制
- 瀏覽器測試檔案中的 358 項測試均通過，包括新測試：已停放帳戶的檢查頁面會在畫面外繪製並在通過後重新隱藏、持續失敗的檢查在 3 次後停止、Codex 任務分頁保留自己的設定，以及登入狀態查詢會略過檢查頁面。
- 問題原因是在已安裝的應用程式上找到的：「瀏覽器」分頁正在顯示的帳戶能通過檢查，隱藏的帳戶則不能；開啟卡住的帳戶後即可通過。新行為本身以模擬視圖測試，尚未在已安裝的應用程式中測試。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.89 的所有內容。
