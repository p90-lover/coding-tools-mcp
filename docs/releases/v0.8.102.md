# Coding Tools 0.8.102

## English

### Step times are right after a restart
- **"Steps took" no longer counts the hours the app was closed.** A chat showed "Steps took 316h" under "Worked for 1h 20m", and some thoughts read as about 12 hours.
- **The cause:** the model never marked some thoughts as finished. When AO restarted, it closed those thoughts and stamped them with the restart time. The chat then timed each thought up to that restart, and moved its end again at every later restart.
- **A thought closed that way now ends where the next step begins.** The model thinks until it acts or writes, so that is when the thought ended. The turn's last thought and tool calls closed by a restart show no time, because nothing records when they ended.
- **Old chats are corrected too.** Step times are read from AO each time a chat opens, so no chat history changes.

### Codex gets its model list again
- **Codex gets its model list again:** the Codex bridge now reads ChatGPT's redesigned effort slider, so its upgrade completes and it starts. Restart Codex once after updating.
- **The cause:** ChatGPT moved the slider's lock marking from its ticks onto the slider itself. It also now marks every tick up to the thumb as selected, not just the thumb's tick. The bridge's upgrade check couldn't read a stop from that, so the upgrade failed, the bridge never started, and Codex had no bridge to ask for models.
- The same reading picks the effort for every WebGPT turn on the GPT-6 picker, so those turns read the new slider too.

### Verification and limitations
- GitHub Actions is still unavailable, so this release depends on local checks. It does not claim that CI passed.
- **Step times (#1124):**
  - A new test covers a thought that a restart closed. The 119 tests in its suite pass, and 223 of 224 tests in the chat suites that use step times pass. The one failure needs `runtime-web`, which wasn't in that test checkout.
  - The real chat behind the report read "Steps took 352h 13m" before the fix and "31m 6s" after. Its longest thought fell from 24 h (the cap) to 1m 52s.
  - Not yet checked in the installed app.
- **Effort slider (#1125):**
  - New tests use the slider markup captured live: they read it, walk it and run the account check. The two new tests fail without the fix and pass with it.
  - The 104 session and account-capability tests and the runtime type check pass.
  - In the full runtime-web suite, 1,578 tests pass and 6 fail. Four fail the same way without the fix, and two passed alone after timing out under load.
  - It takes effect only once this version is installed. Not yet checked in the installed app.
- Includes everything in 0.8.101.

## 繁體中文

### 重新啟動後，步驟時間正確顯示
- **「Steps took」不再把應用程式關閉的時間算進去。** 曾有對話在「Worked for 1h 20m」下方顯示「Steps took 316h」，部分思考也顯示約 12 小時。
- **原因：** 模型沒有把部分思考標記為完成。AO 重新啟動時關閉了這些思考，並蓋上重新啟動的時間。對話因此把每個思考計時到那次重新啟動，之後每次重新啟動又把結束時間往後移。
- **以這種方式關閉的思考，現在在下一個步驟開始時結束。** 模型會一直思考到它採取行動或寫出內容為止，所以那就是思考結束的時間。回合的最後一個思考，以及因重新啟動而關閉的工具呼叫不顯示時間，因為沒有紀錄顯示它們何時結束。
- **舊對話也會修正。** 每次開啟對話時都會從 AO 讀取步驟時間，因此不會更改任何對話紀錄。

### Codex 重新取得模型清單
- **Codex 重新取得模型清單：** Codex 橋接器現在能讀取 ChatGPT 改版後的思考強度滑桿，升級得以完成並正常啟動。更新後請重新啟動 Codex 一次。
- **原因：** ChatGPT 把滑桿的鎖定標記從刻度移到了滑桿本身，而且現在會把滑桿把手之前的每個刻度都標記為已選取，而不只是把手所在的刻度。橋接器的升級檢查因此讀不出所選的檔位，升級失敗，橋接器沒有啟動，Codex 也就無法向橋接器取得模型清單。
- GPT-6 選單上每個 WebGPT 回合也用同樣的方式讀取思考強度，因此這些回合同樣能讀取新的滑桿。

### 驗證與限制
- GitHub Actions 仍無法使用，因此本版本依靠本機檢查，並不宣稱 CI 已通過。
- **步驟時間（#1124）：**
  - 新增的測試涵蓋被重新啟動關閉的思考。其測試套件中的 119 個測試通過，使用步驟時間的對話測試套件中 224 個測試有 223 個通過。唯一失敗的測試需要 `runtime-web`，而該測試用的工作目錄中沒有它。
  - 回報問題的實際對話，修正前顯示「Steps took 352h 13m」，修正後顯示「31m 6s」。其中最長的思考從 24 小時（上限）降到 1 分 52 秒。
  - 尚未在已安裝的應用程式中檢查。
- **思考強度滑桿（#1125）：**
  - 新增的測試使用實際擷取的滑桿標記：讀取滑桿、逐一走過各檔位，並執行帳號檢查。兩個新測試在沒有修正時失敗，修正後通過。
  - 104 個工作階段與帳號功能測試以及 runtime 型別檢查都通過。
  - 完整的 runtime-web 測試套件中，1,578 個測試通過，6 個失敗。其中 4 個在沒有修正時也以同樣方式失敗，另外 2 個是在負載下逾時，單獨執行時通過。
  - 必須安裝此版本後才會生效。尚未在已安裝的應用程式中檢查。
- 包含 0.8.101 的所有內容。
