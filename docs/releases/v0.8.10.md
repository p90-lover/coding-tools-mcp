Coding Tools 0.8.10

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Chat:

- A message sent while the agent waits on an approval no longer gets stuck: if the app cannot tell whether the agent is waiting, the message waits in the queue instead of being steered in. Before, such a steer could hang the chat, so later messages, approval answers and Stop all timed out until the request expired.
- Stopping a turn waits up to 15 seconds for it to actually end (it was 2), so restarting a stalled chat no longer fails with "stop needs attention" when the agent takes a moment to stop.

Agents:

- Agents left running after the orchestrator restarts are stopped by the idle cleanup. Before, each one kept a model process (about 280 MB) running for chats that had already moved on.

Everything in 0.8.9 is included.
