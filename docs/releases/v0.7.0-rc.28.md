Coding Tools 0.7.0-rc.28

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

New:

- Chat: a line under the chat box shows the latest turn at a glance: rounds and steps, time in the model, time to first token and output speed, prompt-cache hits, and input and output tokens (models served through CPA; CPA Helper's request log).
- Chat: the context panel (the ring beside the send button) is redesigned: a large percent, one stacked bar of the window that sweeps in and highlights each part under the pointer, token tiles, and compact rows for limits, Cline Pass keys and tool servers. Explanations moved into tooltips.
- Terminal pane: what is running comes first (the app the agent started, your own terminal); the agent's finished one-off commands fold away, and the text is larger and easier to read.

Fixes:

- Chat: in steer mode, a message typed while a request waits for its answer (each tool call does, for a moment, with "Approve for me") is steered in as soon as the request is answered, instead of waiting for the whole turn. The Queued notice shows the message.
- CPA: settings saved in CPA (a plugin's own settings, such as the account a plugin uses) are kept when CPA restarts, and an outdated plugin bundle is replaced after an update.

Everything in rc.27 is included.
