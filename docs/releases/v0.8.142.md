# Coding Tools v0.8.142

## English

### Retry starts the last answer over

- In a single-model Agent Orchestrator chat, clicking **Retry** now asks for a new answer to the same message. The new attempt has the earlier replies for context, but not the failed, partial, or completed answer it replaces.
- Retry does not add a duplicate user message or undo workspace changes. Automatic recovery still picks up interrupted work where it left off.
- Focused regression checks cover Retry after failed and completed answers, keeping earlier replies, and preserving ordinary follow-ups and automatic recovery. Everything in v0.8.141 is included.

## 繁體中文

### 重試會重新產生最後一則回覆

- 在 Agent Orchestrator 的單模型對話中，按下 **重試** 會針對同一則訊息重新作答。新回覆仍會參考更早的回覆，但不會接續這次要重試的回覆，不論它是失敗、未完成或已完成。
- 重試不會重複新增使用者訊息，也不會復原已經修改的工作區檔案。自動復原仍會接續中斷前的工作。
- 重點回歸測試涵蓋失敗與已完成回覆的重試、保留較早的對話內容，以及一般後續訊息與自動復原。包含 v0.8.141 的所有內容。
