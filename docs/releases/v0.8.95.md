# Coding Tools 0.8.95

## English

### Chrome sign-in and the misleading “passkey” timeout
- **Chrome sign-in is available on Windows and macOS using a dedicated, isolated Chrome profile.** It preserves the selected account's route and validates the imported ChatGPT session freshly; ordinary Chrome profile data is not read. Proxy authentication is handled through the account-owned route rather than silently changing it. (#1083)
- **The required Continue step stays visible while you work in Chat or another page.** The notice explains: sign in in the dedicated Chrome window, close it, then choose Continue. Repeated clicks are blocked while verification runs, and a failed request permits an explicit retry. The legacy `passkey-login` timeout now says **Chrome sign-in expired**, with instructions to restart and complete the flow, rather than an unexplained “Passkey login … 600 s” error. The ten-minute safety deadline and authentication checks are unchanged. (#1086)
- **Sign-in test fixtures stay under the project's aiTemp directory**, not the system temporary directory. (#1085)

### Sidebar and chat
- **The hover sidebar closes when the pointer enters an embedded page such as CPA Accounts.** A temporary, transparent outside-dismiss surface catches the pointer before an iframe swallows the exit event. It is absent when closed or deliberately pinned, adds no keyboard stop and preserves keyboard/Escape navigation. (#1080)
- **Codex-style chat responses separate findings, tool work and the final answer.** The completed-work summary reports tools, changed files, line changes, duration and trust without calling a blocked goal successful. CPA preview cost uses the selected model's pricing; an unknown cost is shown as `Null`, never a fabricated $0. (#1081)
- **Split-chat annotation popovers stay visible and belong to their pane.** Draft/sent details and note editors avoid clipped or transformed ancestors, follow scrolling/resizing, and clean up when their page is hidden. Shift+New chat uses a free split cell or another/new page without replacing occupied chats or discarding unsent drafts. Page arrows and wheel/trackpad navigation keep the active page visible without hijacking transcript scrolling or zoom. (#1087)
- **MCP tool calls return actionable execution results and goal feedback.** Approval of an MCP request no longer substitutes for actually running the requested command, and long-running tool results remain recoverable through their command handles. (#1079)

### Long-running work and reviews
- **Hung automatic review no longer holds the chat indefinitely.** A bounded whole-review deadline, bounded retry and fresh ownership/Stop checks prevent stale responses from reviving a retired request. Uncertain delivery is surfaced instead of blindly replaying a side effect. The reviewer chain remains Codex Auto Review only. Long-running commands retain their terminal, recovery and cancellation contracts. (#1082)
- **Bundled Codex Auto Review is updated to 0.2.1-codingtools.1.** Account selection is primary-first, with explicit fallback behavior; upgrading the bundled DLL preserves `selection.json`. The release pins the published DLL's SHA-256. (#1084)

### Verification and source preservation
- Each included PR is merged only after its final applicable CI checks pass; the combined release is built and published from the final main commit by the Windows release workflow.
- The sign-in continuation change passed 83 focused tests, renderer TypeScript and isolated desktop/narrow browser checks. The sidebar change passed 39 tests and a real cross-origin iframe comparison. The version/installer identity suite passed 18 tests. Account sign-in still requires the person's action in Chrome; no claim is made that every live account was signed in or connected automatically.
- At the user's explicit request, **12 historical source snapshots covering 247 source paths** were committed and pushed as screened archival branches. They were not blindly merged over newer main code. Credentials/live configuration, generated outputs and active owners' unfinished work were excluded. The audit and verified branch/commit list are recorded in `docs/audits/local-source-preservation-2026-11-07.md`.
- This release does not imply a local installation or app restart. It includes the source changes prepared for 0.8.94 and all changes in the previously published 0.8.93.

## 繁體中文

### Chrome 登入與容易誤解的「passkey」逾時訊息
- **Windows 與 macOS 可使用獨立的 Chrome 設定檔登入。** 保留所選帳戶的網路路由，並重新驗證匯入的 ChatGPT 工作階段；不會讀取一般 Chrome 設定檔。代理認證透過帳戶專用路由處理，不會悄悄切換連線方式。（#1083）
- **即使在 Chat 或其他頁面工作，也能看到必要的「繼續」步驟。** 提示會說明：在專用 Chrome 視窗登入，關閉該視窗，再按「繼續」。驗證期間防止重複送出，失敗後可明確重試。舊的 `passkey-login` 逾時訊息改為說明 Chrome 登入已逾時及重試步驟，不再只顯示難以理解的「Passkey login … 600 s」。十分鐘安全期限及認證檢查不變。（#1086）
- **登入測試資料保留在專案 aiTemp 目錄**，不使用系統暫存目錄。（#1085）

### 側邊欄與對話
- **游標移到 CPA Accounts 等內嵌頁面時，懸停側邊欄會關閉。** 暫時的透明離開偵測層會在 iframe 吞掉事件前處理游標移動。側邊欄關閉或刻意固定時不會啟用，亦保留鍵盤及 Escape 操作。（#1080）
- **Codex 風格回覆清楚區分發現、工具工作與最後答案。** 完成摘要顯示工具、改動檔案、行數、時間及可信狀態，不會把受阻的目標當作成功。CPA 預估費用依所選模型定價計算；未知費用顯示 `Null`，不會虛構為 $0。（#1081）
- **分割對話的註解彈出面板保持可見，並屬於自己的窗格。** 草稿／已送出註解及編輯器避免被裁切或受父層變形影響，跟隨捲動／調整大小，頁面隱藏時會清理。Shift＋新增對話會使用空白窗格或其他／新頁面，不會取代已有對話或丟失未送出的草稿。頁面箭頭、滾輪及觸控板導覽保留目前頁面可見，不會攔截對話捲動或縮放。（#1087）
- **MCP 工具回傳可採取行動的執行結果與目標回饋。** 批准請求不再等同已執行命令；長時間執行的工具結果可透過命令識別碼恢復。（#1079）

### 長時間工作與審批
- **自動審批卡住時不再無限佔住對話。** 整輪審批期限、有限重試及新的擁有權／停止檢查，可防止過期回覆重新啟動舊請求。送達狀態不確定時會明確指出，而非盲目重播副作用。審批鏈仍只使用 Codex Auto Review。（#1082）
- **內建 Codex Auto Review 更新至 0.2.1-codingtools.1。** 優先使用主要帳戶並明確處理備用帳戶；更新 DLL 時保留 `selection.json`，並固定已發佈 DLL 的 SHA-256。（#1084）

### 驗證與原始碼保存
- 只在各 PR 最終適用 CI 通過後合併；由 Windows 發佈流程從最終 main 提交建置及發佈。
- 登入提示通過 83 項相關測試、TypeScript 及桌面／窄版瀏覽器檢查；側邊欄通過 39 項測試及實際跨來源 iframe 比較；版本及安裝程式識別通過 18 項測試。實際登入仍需使用者在 Chrome 完成，不代表所有帳戶已自動登入或連接。
- 經使用者明確批准，**12 份歷史原始碼快照、共 247 個原始碼路徑**已提交至 GitHub 封存分支，沒有直接覆蓋較新的 main。憑證、即時設定、產物及其他工作階段未完成的改動不在封存範圍；分支及提交核對記錄見 `docs/audits/local-source-preservation-2026-11-07.md`。
- 不代表已在本機安裝或重新啟動。包含為 0.8.94 準備的原始碼改動，以及先前已發佈 0.8.93 的所有內容。
