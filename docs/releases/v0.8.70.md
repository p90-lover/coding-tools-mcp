# Coding Tools 0.8.70

## English

### Chats
- The chat box's buttons are redesigned to be as clean and small as they can be. Every control is 28 px tall with the same corners, icon-only controls are 28 px squares, and Send is a 28 px circle. Before, there were four heights (28–32 px).
- No more ▾ carets on the chips. The hover tint and each chip's tooltip show it opens a menu.
- The permission chip is its level's icon: a hand for Ask for approval, a shield for Approve for me, a warning sign for Full access. Its name is in the tooltip. Full access stays red, so the risky level still stands out.
- Single/Team is a plain icon like its neighbours instead of a tinted, bordered key. Team in use is shown in the accent colour.
- The model's effort and context window sit right beside it, instead of the window floating to the far right.
- The voice input button, which was never available, is gone.
- The chat box is a little tighter around its text. A chat box is 75 px tall instead of 87 px, and its row fits on one line from 480 px wide (560 px with a long model name such as DeepSeek V4.1 Flash), down from about 560 px before.

### Desktop accounts
- Clear acts only on the account you confirmed it for. A confirmation no longer survives an account switch, and a switch queued before Clear can no longer make it clear the newly active account instead. A stale request asks you to confirm again (PR #988).

### Verification and limitations
- Measured in a browser with the real chat box controls in panes from 250 to 720 px, in light and dark, with three model names and Team mode: never more than two rows, nothing past the box's edge, and no model name cut. Not yet checked in the installed app.
- Account Clear: tests run the real queue, switch and clear code with fake account and file effects, including a switch queued ahead of Clear. No installed app or real account was changed (PR #988).
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.69 is included.

## 繁體中文

### 對話
- 對話框的按鈕重新設計，盡量簡潔細小。所有控制項都是 28 px 高、圓角一致，只有圖示的控制項是 28 px 的正方形，「傳送」是 28 px 的圓形。過去高度有四種（28–32 px）。
- 選項不再有 ▾ 箭頭。滑鼠移過時的底色及提示文字會說明它會開啟選單。
- 權限選項只顯示其等級的圖示：「Ask for approval」是手、「Approve for me」是盾牌、「Full access」是警告標誌，名稱在提示文字中。「Full access」保持紅色，風險較高的等級依然顯眼。
- 「單一／團隊」切換改為與旁邊一樣的普通圖示，不再是有底色及外框的按鍵。使用團隊時會以強調色顯示。
- 模型的推理強度及上下文視窗緊貼在模型旁邊，視窗不再飄到最右方。
- 從未能使用的語音輸入按鈕已移除。
- 對話框文字周圍更緊湊。對話框高度由 87 px 減至 75 px，按鈕列在 480 px 寬起即可放在一行（使用 DeepSeek V4.1 Flash 等較長的模型名稱時為 560 px），過去約需 560 px。

### 桌面帳號
- 「清除」只會作用於你確認的帳號。確認不會再在切換帳號後保留，在「清除」之前排隊的切換亦不會再令它清除新啟用的帳號。過期的請求會要求你再次確認（PR #988）。

### 驗證及限制
- 在瀏覽器中以實際的對話框控制項，於 250 至 720 px 的窗格、淺色及深色主題、三個模型名稱及團隊模式下量測：最多兩行、沒有內容超出對話框邊緣，模型名稱亦沒有被截斷。尚未在已安裝的應用程式中檢查。
- 帳號清除：測試以假的帳號及檔案操作執行實際的排隊、切換及清除程式碼，包括在「清除」之前排隊的切換。沒有更改已安裝的應用程式或真實帳號（PR #988）。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.69 的所有內容。
