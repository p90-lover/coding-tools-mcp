# Coding Tools 0.8.91

## English

### Browser
- **ChatGPT pages load faster and use less proxy traffic.** The Browser tab's accounts and the GPT Browser no longer contact ChatGPT's experiment and analytics hosts (`ab.chatgpt.com`, `oaistatsig.com`). Measured on a signed-in page through the Decodo proxy: `ab.chatgpt.com` sent 751 KB in 2 requests on every load, more than the other 167 ChatGPT requests together. With it blocked, the page was ready in about 1.95 s instead of 2.17 s, and the chat box, the model picker and the sign-in all worked as before. Suggested on linux.do as a proxy reject rule.

### Verification and limitations
- 405 tests in the browser, GPT Browser and bundle test files pass, including new ones: both hosts are cancelled once per account, ChatGPT itself and Cloudflare's check stay reachable, and every Browser tab view and the GPT Browser use the block.
- The speed and page checks were done on the installed app with the hosts blocked through the debugging connection, 2 loads each way. The app's own block was tested with stand-ins, not yet in the installed app.
- ChatGPT uses these hosts to choose which experiments an account sees. Without them, an account gets ChatGPT's default version of each feature.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.90.

## 繁體中文

### 瀏覽器
- **ChatGPT 頁面載入更快，代理流量更少。** 「瀏覽器」分頁的帳戶及 GPT 瀏覽器不再連線至 ChatGPT 的實驗及分析主機（`ab.chatgpt.com`、`oaistatsig.com`）。經 Decodo 代理在已登入頁面上實測：`ab.chatgpt.com` 每次載入以 2 個請求傳送 751 KB，比其餘 167 個 ChatGPT 請求加起來還多。封鎖後，頁面約 1.95 秒就緒（原本約 2.17 秒），對話框、模型選單及登入狀態均如常運作。此做法源自 linux.do 上的代理封鎖規則建議。

### 驗證及限制
- 瀏覽器、GPT 瀏覽器及打包測試檔案中的 405 項測試均通過，包括新測試：兩個主機在每個帳戶只封鎖一次、ChatGPT 本身及 Cloudflare 檢查仍可連線，以及每個「瀏覽器」分頁視圖和 GPT 瀏覽器都套用封鎖。
- 速度及頁面檢查是在已安裝的應用程式上，經除錯連線封鎖這些主機後進行的，兩種情況各載入 2 次。應用程式本身的封鎖以模擬物件測試，尚未在已安裝的應用程式中測試。
- ChatGPT 以這些主機決定帳戶會看到哪些實驗功能。封鎖後，帳戶會看到各功能的 ChatGPT 預設版本。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.90 的所有內容。
