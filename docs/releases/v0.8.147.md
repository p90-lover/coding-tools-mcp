# Coding Tools v0.8.147

## English

- A chat approval no longer gets stuck with an old “Quota-based reviews are off” result if you enable quota-based reviews while native Guardian is still deciding. If Guardian has no verdict, the next approval check can send that still-pending request for review.
- Turning on **Let the model judge** still does not enable paid reviews. A real denial or request that requires your decision is not overridden.

Everything in 0.8.146 is included.

## 繁體中文

- 在原生 Guardian 審查期間開啟配額審查時，聊天的權限請求不再因舊的「配額審查已關閉」結果而卡住。如果 Guardian 未做出判定，下次檢查會重新審查仍在等待的請求。
- 開啟 **讓模型判斷** 仍不會自動啟用付費審查，也不會覆蓋已拒絕的請求或必須由你本人決定的請求。

包含 0.8.146 的所有變更。
