Coding Tools 0.7.0-rc.31

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Fixes:

- Chat: a queued message sent in the background no longer clears what you are typing. If it can't be sent, it goes back into the composer after your text instead of replacing it.
- Chat: in steer mode, a steer that fails is no longer retried over and over (with the error banner flashing); the message waits and is sent when the turn ends. A steer that gets through clears its "Queued" note.
- Chat: attachments, the command note and a goal being edited stay with their own chat, so a file attached in one chat is never sent with another chat's message.
- Chat: with compact activity on, a group or tool row you opened stays open while the same call repeats.
- Chat: opening "Worked", a group or a tool's output near the bottom no longer jumps the view past what you opened.
- Chat: a finished step's work is read back once when it ends, so it no longer misses its last items or keeps rows on "Running…".
- Chat: the workbench tabs stay in step with the chat: the browser chip and the agent opening a page work after you open a new tab, and with two new tabs the one you click is the one shown.
- Chat: the compact activity header and the sidebar's "Projects" header no longer share a style (odd spacing on one, a hover effect on the other), and the stats line under the chat box no longer blanks for a moment when a turn ends.
- Chat: after a steer, the context meter keeps showing how full the context is. A steer interrupts the model's request, and through CPA that request reported zero context, so the ring emptied until the next request finished. A compaction still empties it.
- Chat: when a follow-up can't continue the agent's existing session and starts a fresh one, the app log now says so (ao.continuation_lost).
- Chat: after the app updates its backend, no second agent service is started in the background.
- Chat: while CPA is not answering, sending to a team no longer waits for CPA's model list once per role; the remembered list answers for 15 seconds before CPA is asked again.
- Chat: a model remembered with a date ahead of the clock now still expires from the list.

Everything in rc.30 is included.
