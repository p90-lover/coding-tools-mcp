# Coding Tools 0.8.42

## English

### Smoother app: fewer freezes
- Switching ChatGPT accounts, starting or ending a turn, and closing a browser tab no longer freeze every window while the browser's descriptor is written. On the busy hard disk one write held the app up to 14.7 s (PR #737).
- The extra MCP tunnels' check every 10 s no longer reads its list from disk or checks its folders on the main process; one read held the app 23.7 s (PR #737).
- Restarted chats start one by one instead of all at once, and fewer state writes block the windows (PR #730).
- A closing app no longer holds its chats on the stopping service's errors (PR #738).
- Five more main-thread disk calls that froze the window, among them reading CPA's install state, now run off the main thread (PR #743).
- CPA's account sync and the saved model list, CPA's component status, the packaged runtime folder check, and the extra tunnels' list and key files are read and written off the main thread too. Recording a tunnel's connector held every window 14.5 s, and the runtime folder check up to 2.7 s (PRs #744, #746, #747).

### Browser accounts
- Bulk delete: tick accounts in Browser management, or press "Select not signed in", then "Remove N selected" (click again to confirm). The account in use goes last, and the Browser tab always keeps one account (PR #737).
- A bridge refresh started by one account switch steps aside when you switch again, instead of failing with "ChatGPT login was not completed" and asking you to run Install models again (PR #737).

### Chats
- Each reply opens with a head: who answered, its state and time, why it failed, and the files it changed (PR #740). Replies can be read as plans, in five styles (PR #743).
- Auto-compact leaves room for the next message; new /autocompact, /context, /effort and /clear commands; collapsed projects show their running chats (PR #734).
- move_chat lets the agent move its chat to another project; idle chats archive themselves; the harness picker shows brand logos (PR #736).
- WebGPT native chats get their own preview tools, revoked when the run stops (PR #742). Native tool names keep their namespace and the WebGPT catalog parses correctly (PR #732).
- When the command reviewer denies a request, the app sends the agent the reviewer's reason; the agent sees it once AO reads the field (PR #741).
- A project's spinner lines up with its chats' (PR #728). Model scores is a benchmark leaderboard (PR #726).

### CPA
- A usage bridge for CPA Provider Manager; Codex quota refreshes every minute, spread fairly across accounts (PR #739).

### MCP
- Account-owned workspace tunnels connect in the background (PR #731).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from main, and confirm CI before publication.
- Not included: PR #733 and PR #735 (their CI fails).
- Everything in 0.8.41 is included.

## 繁體中文

### 更流暢：更少卡頓
- 切換 ChatGPT 帳號、開始或結束回合、關閉瀏覽器分頁時，寫入瀏覽器描述檔不再令所有視窗卡住。在繁忙的硬碟上，一次寫入曾令應用程式停頓達 14.7 秒（PR #737）。
- 額外 MCP 通道每 10 秒的檢查不再在主程序讀取清單或檢查資料夾；一次讀取曾停頓 23.7 秒（PR #737）。
- 重新啟動的對話逐一啟動，不再同時啟動；更少狀態寫入阻塞視窗（PR #730）。
- 關閉應用程式時，不再因停止中服務的錯誤而卡住對話（PR #738）。
- 另外五個會令視窗卡住的主程序磁碟呼叫（包括讀取 CPA 的安裝狀態）改在主程序以外執行（PR #743）。
- CPA 的帳號同步和已存模型清單、CPA 元件狀態、封裝 runtime 資料夾檢查，以及額外通道的清單和金鑰檔案，同樣改在主程序以外讀寫。記錄通道的 connector 曾令所有視窗停頓 14.5 秒，runtime 資料夾檢查則達 2.7 秒（PR #744、#746、#747）。

### 瀏覽器帳號
- 批次刪除：在 Browser management 勾選帳號，或按「Select not signed in」，再按「Remove N selected」（再按一次確認）。使用中的帳號最後移除，Browser 分頁總會保留一個帳號（PR #737）。
- 由一次切換帳號觸發的 bridge 更新，在你再次切換時會自行讓路，不再以「ChatGPT login was not completed」失敗並要求重新執行 Install models（PR #737）。

### 對話
- 每則回覆開頭有標題列：由誰回答、狀態和時間、失敗原因及改動的檔案（PR #740）。回覆可以五種風格以計劃形式閱讀（PR #743）。
- 自動壓縮會為下一則訊息留出空間；新增 /autocompact、/context、/effort 和 /clear 指令；收合的專案會顯示執行中的對話（PR #734）。
- move_chat 讓代理把對話移到另一個專案；閒置對話自動封存；harness 選擇器顯示品牌標誌（PR #736）。
- WebGPT 原生對話有自己的預覽工具，執行停止時撤銷（PR #742）。原生工具名稱保留命名空間，WebGPT 目錄解析正確（PR #732）。
- 指令審查者拒絕請求時，應用程式會把審查者的理由傳給代理；待 AO 讀取該欄位後代理即可看到（PR #741）。
- 專案的轉圈圖示與其對話對齊（PR #728）。Model scores 成為基準排行榜（PR #726）。

### CPA
- 為 CPA Provider Manager 提供用量橋接；Codex 配額每分鐘公平地更新（PR #739）。

### MCP
- 帳號擁有的工作區通道在背景連線（PR #731）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由 main 編譯及通過 CI 才能公開。
- 未包含：PR #733 和 PR #735（其 CI 失敗）。
- 包含 0.8.41 的所有內容。
