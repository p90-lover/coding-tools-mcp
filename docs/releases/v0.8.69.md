# Coding Tools 0.8.69

## English

### Chats
- The image preview's Markup, Download and Close buttons stand in a column just right of the image, at its top. In the window's top right corner the title bar's minimize, maximize and close buttons covered them. While marking up, Add to chat and Back to image sit at the bottom right instead.
- A click anywhere outside the image and its buttons closes the preview, including the row beside the zoom control. A zoomed image's scrollbars still only scroll.
- The preview's backdrop is lighter (75% black instead of 90%), so the chat stays in view behind it.

### Browser
- When the launcher's ChatGPT page is stuck on Cloudflare's security check ("Just a moment..."), the bridge setup now says so: "ChatGPT is showing a Cloudflare security check. Open the Browser tab, complete the check, then run Setup → Install models." Before, it waited and then reported that the ChatGPT sign-in didn't finish, which sent people after a sign-in problem that wasn't there. The log records the page address without its challenge token (PR #984).

### Verification and limitations
- Browser: seen on 0.8.67 and 0.8.68 on 2026-11-03, where both launches failed to set the bridge up behind a Cloudflare check. The check detection was confirmed on the live stuck page, and 200 browser-host and wiring tests pass. The bridge setup still runs once per launch: after you pass the check, run Setup → Install models or restart the app (PR #984).
- Checked in a browser with the real preview component at 1280 × 800: the column sits 12 px right of the image and level with its top; a wide image leaves the column inside the window, and so does a zoomed one. Real clicks: on the image the preview stays open; beside the zoom control, left of the image and right of the column it closes. In Markup, its buttons end 127 px below the image. Not yet checked in the installed app.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.68 is included.

## 繁體中文

### 對話
- 圖片預覽的「Markup」、「下載」及「關閉」按鈕現在直列在圖片右側、與圖片頂部對齊。過去它們在視窗右上角，被標題列的最小化、最大化及關閉按鈕遮住。標記時，「Add to chat」及「Back to image」則改在右下角。
- 點擊圖片及其按鈕以外的任何地方都會關閉預覽，包括縮放控制旁邊的一行。放大後圖片的捲軸仍然只用來捲動。
- 預覽的背景變淺（由 90% 黑改為 75% 黑），後方的對話仍然可見。

### 瀏覽器
- 當啟動器的 ChatGPT 頁面停在 Cloudflare 安全檢查（「Just a moment...」）時，橋接設定現在會直接說明：「ChatGPT 正在顯示 Cloudflare 安全檢查。請打開瀏覽器分頁完成檢查，然後執行 Setup → Install models。」過去它會一直等候，之後回報 ChatGPT 登入未完成，令人誤以為是登入問題。記錄只保存不含檢查權杖的頁面位址（PR #984）。

### 驗證及限制
- 瀏覽器：於 2026-11-03 在 0.8.67 及 0.8.68 上觀察到，兩次啟動都因 Cloudflare 檢查而未能設定橋接。檢查偵測已在實際卡住的頁面上確認，200 項瀏覽器主機及連接測試通過。橋接設定每次啟動仍只執行一次：通過檢查後，請執行 Setup → Install models 或重新啟動應用程式（PR #984）。
- 在瀏覽器中以實際的預覽元件於 1280 × 800 檢查：按鈕列位於圖片右方 12 px 並與圖片頂部對齊；寬圖片及放大後的圖片都不會把按鈕列推出視窗。實際點擊：點擊圖片時預覽保持開啟；點擊縮放控制旁、圖片左方及按鈕列右方時預覽關閉。標記模式下，其按鈕位於圖片下方 127 px。尚未在已安裝的應用程式中檢查。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.68 的所有內容。
