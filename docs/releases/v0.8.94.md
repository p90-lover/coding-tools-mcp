# Coding Tools 0.8.94

## English

### Chat
- **Messages typed while a chat starts are sent as soon as its agent is ready.** Before, a message typed during launch could sit in the queue for 15 seconds, then 30, then a minute. It now goes out the moment the agent is seen working. Messages queued on purpose for the next turn, and chats waiting on an approval or a question, still wait. (#1064)
- **Recover works on a chat's first turn after a cold start.** The app now remembers the first running turn it confirmed, so Recover can inspect that exact turn instead of refusing a chat that was already working. Stop still wins. (#1072)
- **The harness and model pickers show the right logos and take less room.** Added the DeepSeek, Gemini CLI, Kimchi, OMP and Prime Agent marks. Logos keep their colours even when a harness isn't installed. The pickers are smaller, scroll within themselves, and sit on a slightly see-through blurred panel. (#1070)

### Sidebar
- **The hover panel opens only over the panel itself and closes when you leave.** It no longer opens near the window's edge or over title-bar buttons, and no longer stays open past its edge. Short delays stop it flickering. It closes on Escape and when the window loses focus. Its motion is smoother and respects reduced motion. (#1069)
- **Hovering the folded sidebar no longer covers the browser page with "Loading...".** The saved picture of the page stays visible. (#1073)

### Browser
- **The address field keeps what you type.** Background updates no longer replace it, Enter can't send the same address twice, Escape cancels, and Enter while composing Chinese or Japanese text doesn't send. A typed address still opens in a tab of your own, never the home page or a Codex turn's tab. (#1071, combined with the address bar 0.8.85 already had)
- **New ChatGPT account pages get a real size before they load.** Some started as a 0×0 page, which kept Cloudflare's check and the page itself from drawing. (#1074)

### Verification and limitations
- All seven pull requests were merged together on top of 0.8.92 and checked as one, then on top of 0.8.93 once it landed.
  - #1064's queue wake and 0.8.89's "answered requests don't hold a turn" rule touched the same line, and both are kept.
  - #1071 met the address bar that main already had; main's toolbar and its open-in-your-own-tab rule are kept, with #1071's input handling.
  - Two of the pull requests' own CI failures were tests that hadn't been updated for their own changes (#1069's sidebar), or had already been fixed on main (#1070's logos). Both pass now.
- The type check passes, and the sidebar, harness picker, address bar and chat tests pass. The full desktop test run is described in the pull request.
- Not checked in the installed app. Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.93 (Approve for me reviews only through Codex Auto Review, never a stand-in model), which was not published on its own.

## 繁體中文

### 對話
- **對話啟動期間輸入的訊息，會在代理就緒後立即送出。** 以往在啟動期間輸入的訊息可能在佇列中等 15 秒、再等 30 秒、再等一分鐘。現在一看到代理開始工作就會送出。刻意排到下一回合的訊息，以及正在等待審批或問題回覆的對話，仍會等待。（#1064）
- **冷啟動後，「恢復」可用於對話的第一個回合。** 應用程式現在會記住它確認過的第一個執行中回合，「恢復」便能檢查那個回合，而不會拒絕一個其實已在工作的對話。「停止」仍然優先。（#1072）
- **代理工具與模型選擇器顯示正確的標誌，並佔用較少空間。** 新增 DeepSeek、Gemini CLI、Kimchi、OMP 及 Prime Agent 的標誌。即使代理工具未安裝，標誌也保留原本顏色。選擇器更小、可在其內部捲動，並以略為透明的模糊面板顯示。（#1070）

### 側邊欄
- **懸停面板只在面板本身上方開啟，離開時關閉。** 不再在視窗邊緣附近或標題列按鈕上方開啟，也不再在面板邊緣以外保持開啟。短暫延遲可避免閃爍。按 Escape 或視窗失去焦點時會關閉。動畫更流暢，並遵從「減少動態效果」設定。（#1069）
- **懸停收起的側邊欄時，瀏覽器頁面不再被「Loading...」遮蓋。** 頁面的已儲存畫面會保持可見。（#1073）

### 瀏覽器
- **網址欄會保留你輸入的內容。** 背景更新不再覆蓋它，按 Enter 不會重複送出同一網址，按 Escape 可取消，輸入中文或日文時按 Enter 不會送出。輸入的網址仍會在你自己的分頁開啟，絕不會開在首頁或 Codex 回合的分頁。（#1071，與 0.8.85 已有的網址欄合併）
- **新的 ChatGPT 帳戶頁面在載入前便有實際大小。** 部分頁面以 0×0 開始，令 Cloudflare 的檢查及頁面本身無法繪製。（#1074）
