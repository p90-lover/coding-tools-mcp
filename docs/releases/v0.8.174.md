# Coding Tools v0.8.174

## English

### SSH hosts
- **Agents can run a command on an approved SSH host.** Chats get a new tool, `ssh_exec`, while at least one host on Connections > SSH hosts has a confirmed key. The agent names the host from that list and gives one command. Coding Tools builds the ssh command line itself, so nothing else the agent writes reaches ssh:
  - the host key you confirmed must match;
  - only key sign-in is tried, and nothing can stop to ask for a password;
  - there is no terminal, no input, no port forwarding and no file transfer.
- **Each command is checked first, with the host and the exact command.**
  - A production host, `sudo`, installs, recursive deletes, service stops, secrets, connections on to other machines and interactive programs wait for you. This holds whatever the chat's permission mode.
  - Everything else goes to the chat's reviewer, or to you when no reviewer checks the chat.
  - The hard safety rules refuse the rest outright.
- **The host's output is treated as untrusted.** Terminal control codes and invisible characters are removed, the output is capped, and it is labelled as data, never instructions. A command that runs past its time limit (1 minute by default, at most 2) is stopped.
- An agent's own `ssh` in a shell keeps working as before, under the same SSH rules. `ssh_exec` is the supported way, because it uses the host keys you confirmed.

Includes all changes from v0.8.173.

## 繁體中文

### SSH 主機
- **代理現在可以在已核准的 SSH 主機上執行指令。** 只要「連線 > SSH 主機」中至少有一台主機的金鑰已確認，對話就會多出新工具 `ssh_exec`。代理從清單中指定主機，並提供一個指令。ssh 的命令列由 Coding Tools 自行組成，代理寫的其他內容都不會傳到 ssh：
  - 主機金鑰必須與你確認的相符；
  - 只嘗試金鑰登入，不會停下來詢問密碼；
  - 沒有終端機、沒有輸入、沒有連接埠轉送，也沒有檔案傳輸。
- **每個指令執行前都會先連同主機與完整指令一起檢查。**
  - 正式環境主機、`sudo`、安裝套件、遞迴刪除、停止服務、讀取機密、再連往其他機器，以及互動式程式，都會等你決定，不論對話的權限模式為何。
  - 其餘指令交給對話的審查者；對話沒有審查者時則由你確認。
  - 其他的由硬性安全規則直接拒絕。
- **主機的輸出一律視為不受信任。** 終端機控制碼與不可見字元會被移除，輸出有長度上限，並標示為資料，絕不是指示。執行超過時間限制（預設 1 分鐘，最長 2 分鐘）的指令會被停止。
- 代理在 shell 中自行執行的 `ssh` 照舊可用，並受同樣的 SSH 規則約束。`ssh_exec` 才是建議的方式，因為它使用你確認過的主機金鑰。

包含 v0.8.173 的所有變更。
