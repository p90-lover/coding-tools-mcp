# Coding Tools 0.8.83

## English

### App
- **No more black band under the Chat after the window grows (#1054).** After maximizing or enlarging the window, the Chat could stop part of the way down, roughly 940 of 1392 px, with the window's black background below it, while the left icon bar still reached the bottom. The Chat's "fill the window" rule lived in the GPT Browser's stylesheet, and the Chat only got it when that file happened to be loaded; without it the Chat was only as tall as its content. The box every tab sits in now stretches its page to the window's full height itself, so no tab depends on its own stylesheet for that.

### Verification and limitations
- Measured in the running app with the new rule added: all 13 open tabs (Browser, ChatGPT management, Email, Register, Chat, Teams, Subagents and the content pages) filled 2508×1392; without it the Chat was 940 px tall.
- A new test pins the rule; it and the renderer wiring tests pass (60 tests).
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.82.

## 繁體中文

### 應用程式
- **視窗放大後，對話下方不會再出現黑色區塊（#1054）。** 將視窗最大化或拉大後，對話可能只顯示到一部分（約 1392 像素中的 940 像素），下方露出視窗的黑色背景，而左側圖示列仍延伸到底部。對話的「填滿視窗」樣式放在 GPT 瀏覽器的樣式表中，只有在該檔案剛好被載入時對話才會套用；缺少它時，對話的高度只等於其內容的高度。現在每個分頁所在的容器會自行把頁面拉伸到視窗的完整高度，任何分頁都不再需要依賴自己的樣式表。

### 驗證及限制
- 已在執行中的應用程式加入新規則後量度：13 個已開啟的分頁（瀏覽器、ChatGPT 管理、電郵、註冊、對話、團隊、子代理及各內容頁面）全部填滿 2508×1392；沒有此規則時，對話只有 940 像素高。
- 新增的測試固定了此規則；該測試與繪製連接測試均通過（60 項）。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.82 的所有內容。
