# v0.4.5 — Task monitor and a current stable Latest release

## English

GitHub's Latest endpoint previously returned v0.3.2 because subsequent deliveries were prereleases. This release is published as a stable release with make_latest=true after Windows verification and asset readback. Version 0.4.5 also advances the numeric patch component so an older comparator can distinguish it from 0.4.4-rc.5. The updater now compares full SemVer prerelease precedence, ignores build metadata for precedence, and rejects malformed versions.

Open **Task monitor** in the sidebar or from **Work board**, select an approved workspace, and inspect a task. The new main-window-only read command projects the actual Harness task index and task/event records; it does not scan the project or create a new task. The GUI shows objectives, IDs, recorded status, completed/pending steps, change/verification references, timestamps, tool/event outcomes, command handles and affected-file metadata when those fields were recorded. Initial event pages show the latest 50 complete events and can page backwards. Incomplete append tails are disclosed, not presented as successful results. Objectives and step text are bounded for display; original files remain untouched.

The same page reads current MCP listener receipts without requesting cached result bodies. It shows actual admission/dispatch states, receipt IDs, timestamps, current permission revision and listener identity. **Dispatch returned does not mean an external command or agent finished.** Workspace-wide receipts are not falsely attributed to the selected task. Missing or expired receipts mean unknown, not never executed. No tool call is replayed. The page auto-refreshes every three seconds while visible, with at most one request in flight; scope changes invalidate old responses, failed refreshes mark the last snapshot stale, and historical pages are not continually re-polled. Turning off Auto-refresh pauses observation only, not workers.

**Paseo sessions and Anneal tasks now have selectable detail panels.** They display record/provider/workspace identity, reported state, pending-permission counts, attention reason, source endpoint/version and snapshot time. Anneal additionally exposes the recorded chain ID/name/layer/index. The panels are bound to the selected source endpoint and current snapshot; they do not turn a read-only directory entry into a live worker handle.

Integration boundaries remain explicit: local coding tools, live permission/approved-root refresh, computer controls, optional native Codex bridge, native AppContainer and recovery are retained. The shared delivery board supports recorded steps and workspace-scoped MCP observations. Paseo's session directory and Anneal's board adapter remain read-only; complete upstream applications and autonomous planning/review/merge engines are not embedded. ChatGPT-controlled provider assignment, durable parent/worker scheduling, acknowledged pause/resume/close and mandatory subagent review are still separate implementation work. This release must not be described as integrating every Codex, Paseo or Anneal function.

Observation budgets are 20 indexed recent tasks, 8 MiB per task file, 32 MiB aggregate task/index reads, and a 512 KiB event window with at most 50 displayed records. An event above 64 KiB is omitted from this view with an explicit warning. A window occupied by a single oversized record can expose no earlier-page cursor; the stored history is retained for scoped inspection rather than unbounded scanning. Exact task IDs allow inspection beyond the recent index. Malformed metadata, foreign task/cursor identity and symbolic-link/reparse-point metadata paths are not followed. The eight-second native read deadline and two blocking-reader slots prevent unbounded retries; already-blocked OS I/O is not forcibly interruptible. These limits are not a guarantee of uninterrupted ChatGPT execution or Cloudflare availability.

Verification uses actual Harness writer/reader logic, Windows listener/security contracts and compiled Svelte pages with synthetic JSON IPC. Browser fixtures are not live user-account tests. Retain the rc.5 OAuth/extension v0.0.7, approved-root, live-permission, operation-recovery and native-isolation gates. No inference model, Codex agent, live game account or deletion command is run by this delivery. Existing files, branches and releases are preserved.

Windows x64 installer is publisher-unsigned. Before installing, resolve unknown in-flight operations because listener receipts are RAM-only; fully exit Desktop including its tray process, retain settings and the older executable, then install/open the new version. The installer is not silently deployed to the user's PC by publishing this release. Verify v0.4.5 in the GUI; retain extension v0.0.7. A stable Latest marker means this tested delivery is the default update, not that unfinished integrations have become complete.

## 繁體中文

GitHub 的 Latest 端點之前仍回傳 v0.3.2，因為之後的交付都是預發佈版本。本版通過 Windows 驗證及上傳後重新下載核對才以正式版公開，並設定 make_latest=true。使用 0.4.5 的數值修訂版本，亦讓舊比較器能辨認它比 0.4.4-rc.5 更新；更新器已改用完整 SemVer 優先次序，正確處理候選版數字，忽略 build metadata，並拒絕不合法版本。

在側欄或「任務看板」開啟 **任務監察**，選擇已批准的工作區，再檢視任務。新的主視窗專用唯讀指令會讀取真正的 Harness 任務索引及任務／事件紀錄，不掃描專案，也不建立新任務。畫面顯示目標、ID、已記錄狀態、完成／待辦步驟、變更／驗證參考、時間，以及曾記錄的工具結果、命令 handle 和受影響檔案。事件預設顯示最新 50 項完整紀錄，並可向前翻頁。尚在追加的尾端會明確提示，不會被當成成功結果；顯示文字有上限，原始檔案保持不變。

同一頁會讀取目前 MCP listener 的真正操作紀錄，但不要求快取結果本文。畫面顯示接受／分派狀態、操作 ID、時間、目前權限版本及 listener 身分。**分派已回傳，不代表外部命令或 Agent 已完成。** 整個工作區的操作不會被錯誤歸屬到所選任務；紀錄缺失或過期代表未知，不代表從未執行，也不會自動重做。頁面可見時每三秒刷新，最多一個請求進行中；切換範圍會作廢舊回應，失敗時標示快照已過時，歷史分頁不會不斷輪詢。取消「自動刷新」只停止觀察，不會暫停工作程序。

**Paseo 會話及 Anneal 任務已加入可點選詳情面板。** 可查看紀錄／供應商／工作區身分、回報狀態、待批准權限數量、注意原因、來源端點／版本及快照時間；Anneal 另顯示流程 ID／名稱／層級／索引。面板綁定所選來源端點及目前快照，不會把唯讀目錄項目假裝成真正工作程序 handle。

整合邊界仍清晰：保留本機編碼工具、即時權限／已批准 root 刷新、電腦控制、可選原生 Codex bridge、AppContainer 及操作恢復。共用交付看板支援步驟紀錄及工作區範圍內的 MCP 觀察。Paseo 會話目錄及 Anneal 看板介接器仍是唯讀；尚未嵌入完整上游應用程式及自主規劃／審查／合併引擎。ChatGPT 指派供應商工作、持久化主從排程、經確認的暫停／繼續／關閉，以及強制子 Agent 審查，仍需另行實作。不能把本版描述為已整合 Codex、Paseo、Anneal 的所有功能。

觀察上限為最近索引中的 20 項任務、每任務檔 8 MiB、任務／索引合計 32 MiB、事件視窗 512 KiB，最多顯示 50 項。超過 64 KiB 的事件會省略顯示並提示；若單一過大紀錄佔滿視窗，可能沒有較早分頁 cursor，原始歷史仍保留供有範圍的查閱，而非無上限掃描。可輸入完整任務 ID 查閱索引外的舊紀錄。格式損壞、跨任務／工作區 cursor，以及 symbolic link／reparse-point metadata 不會被跟隨。原生讀取有八秒期限及兩個 blocking-reader 名額，避免無上限重試；已阻塞的 OS I/O 不能被強行中斷，也不代表能保證 ChatGPT 或 Cloudflare 永不中斷。

驗證使用真正的 Harness 寫入／讀取、Windows listener／安全契約，以及配合模擬 JSON IPC 的編譯 Svelte 頁面。瀏覽器測試不是真實使用者帳戶驗收。保留 rc.5 的 OAuth／擴充功能 v0.0.7、批准 root、即時權限、操作恢復及原生隔離關卡；不啟動模型推論、Codex Agent、遊戲帳戶或刪除指令，既有檔案、分支及 Release 均保留。

Windows x64 安裝程式沒有發行者簽章。安裝前先核實結果未知的操作，因為 listener 操作紀錄只存在 RAM；完全退出 Desktop 及系統匣程序，保留設定和舊執行檔，再安裝／開啟新版本。公開 Release 不代表已偷偷安裝到使用者電腦。請在 GUI 核對 v0.4.5，保留擴充功能 v0.0.7。Latest 正式版標記代表這次經測試的交付成為預設更新，不代表尚未完成的整合突然全部完成。
