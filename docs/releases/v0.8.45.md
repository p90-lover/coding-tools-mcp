# Coding Tools 0.8.45

## English

### Security
- The eMudhra distrust now holds on every connection path: Electron's main process and its Node children, Chromium's certificate check, and every runtime `fetch` refuse a chain that holds one of the eight compromised keys (PR #803).
- Bun moves to 1.4.4 and Electron to 45.2.1 (Node 24.22.1), both of which refuse those certificates on their own; the package check rejects an older bundled Bun (PR #803).
- The AO daemon is built with Go 1.27.3 or newer, and the package check reads the Go version from the packaged daemon (PR #803).
- The tunnel-client download is checked against SHA-256 hashes pinned in the app, not a checksum file fetched over the same connection (PR #803).

### Chats and goals
- Goals and queued messages carry on while the window is minimized: a watch now checks every project with an active goal every five minutes, without waiting for the window to read its run list (PR #795).
- IME confirmation keys no longer trigger composer commands (PR #802).
- Chat windows reuse transcript markup that is already rendered (PR #807).

### Browser and accounts
- CPA's Codex sign-ins are no longer added as Browser accounts automatically; you add the accounts you want, and accounts already added stay until you remove them (PR #803).
- A removal confirmation is bound to the account it was opened for (PR #805).
- GPT Browser keeps its accounts when its saved state cannot be read at startup (PR #806).
- A retained browser conversation stays with the turn that owns it (PR #801).

### Register
- Register starts its configured project when you open its tab, or as soon as you choose a project; a manual Stop is respected (PR #794).
- Newly registered accounts are uploaded to the managed CPA through its authenticated session (PR #794).

### Reliability
- Stopping a recorded FRPC instance only stops its own process tree (PR #797).
- Manual download proxy mode uses the configured proxy URL (PR #804).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from main, and confirm CI before publication.
- Not included: PR #733 (its CI fails) and PR #800 (still open).
- Everything in 0.8.44 is included.

## 繁體中文

### 安全性
- eMudhra 不信任設定現已涵蓋所有連線路徑：Electron 主程序及其 Node 子程序、Chromium 的憑證檢查，以及執行環境的每個 `fetch`，都會拒絕含有八把已外洩金鑰之一的憑證鏈（PR #803）。
- Bun 升級至 1.4.4，Electron 升級至 45.2.1（Node 24.22.1），兩者本身都會拒絕這些憑證；套件檢查會拒絕較舊的內建 Bun（PR #803）。
- AO 常駐程式以 Go 1.27.3 或更新版本編譯，套件檢查會從打包的常駐程式讀取 Go 版本（PR #803）。
- tunnel-client 下載改以程式內固定的 SHA-256 雜湊驗證，不再依賴同一連線取得的校驗檔（PR #803）。

### 對話與目標
- 視窗最小化時，目標和排隊訊息仍會繼續：每五分鐘檢查所有有進行中目標的專案，不必等視窗讀取執行清單（PR #795）。
- 輸入法的確認按鍵不再觸發輸入框指令（PR #802）。
- 對話視窗會重用已轉譯的對話記錄標記（PR #807）。

### 瀏覽器與帳號
- CPA 的 Codex 登入不再自動加入為瀏覽器帳號；由你自行加入需要的帳號，已加入的帳號會保留直到你移除（PR #803）。
- 移除確認會綁定開啟它的帳號（PR #805）。
- 啟動時無法讀取已儲存狀態時，GPT Browser 仍會保留其帳號（PR #806）。
- 保留的瀏覽器對話會留在擁有它的回合（PR #801）。

### 註冊
- 開啟註冊分頁或選擇專案後，註冊會立即啟動已設定的專案；手動停止會被保留（PR #794）。
- 新註冊的帳號會透過已驗證的工作階段上傳到受管理的 CPA（PR #794）。

### 可靠性
- 停止已記錄的 FRPC 執行個體時只會停止它自己的程序樹（PR #797）。
- 手動下載代理模式會使用已設定的代理網址（PR #804）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由 main 編譯及通過 CI 才能公開。
- 未包含：PR #733（其 CI 失敗）及 PR #800（仍未合併）。
- 包含 0.8.44 的所有內容。
