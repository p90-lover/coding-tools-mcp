# Coding Tools 0.8.67

## English

### Codex bridge
- The Codex bridge starts again when the app's data folder is reached through a Windows junction. The bridge's settings named its folder through the junction (`C:\Users\…\.coding-tools`), while an app started with `CODING_TOOLS_HOME` set to the junction's target named it by the target. The app compared the two names as text, refused the settings, and didn't start the bridge. The watchdog then failed to read them every minute. The app now compares the folders' real locations (PR #978).

### Browser
- GPT Browser management shows each account's sign-in correctly. An account with saved conversations no longer looks signed out, and a late check can't update an account you've already switched away from (PR #976).
- The ChatGPT page no longer keeps reloading itself. Automatic recovery from a Cloudflare check now tries once per page, and it doesn't reload while a task is running or has just started. Refreshing saved sessions keeps the conversation you're on instead of going back to the home page (PR #976).

### Verification and limitations
- Bridge: seen on 0.8.60 on 2026-11-02, where the runtime failed at startup and 90 config reads failed in 90 minutes. A new test with a real junction checks that both names are accepted and that a different folder is still refused. Not yet checked in the installed app (PR #978).
- Browser: 292 tests pass, including ten that failed before the fix, and the management page was checked with test data (PR #976).
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.66 is included.

## 繁體中文

### Codex 橋接
- 當應用程式的資料資料夾經由 Windows 目錄聯接存取時，Codex 橋接現在可以再次啟動。橋接設定經由聯接（`C:\Users\…\.coding-tools`）指向其資料夾，但以 `CODING_TOOLS_HOME` 設為聯接目標啟動的應用程式則以目標路徑稱呼它。應用程式過去以文字比較這兩個名稱，因而拒絕設定並沒有啟動橋接，監察程式之後每分鐘都讀取設定失敗。現在應用程式會比較資料夾的實際位置（PR #978）。

### 瀏覽器
- GPT Browser 管理頁會正確顯示每個帳戶的登入狀態。有已儲存對話的帳戶不會再顯示為已登出，延遲完成的檢查也不會更新你已切換離開的帳戶（PR #976）。
- ChatGPT 頁面不會再不斷自行重新載入。Cloudflare 檢查的自動恢復現在每個頁面只嘗試一次，而且在任務執行中或剛開始時不會重新載入。重新整理已儲存的工作階段時會保留目前的對話，而不是回到首頁（PR #976）。

### 驗證及限制
- 橋接：於 2026-11-02 在 0.8.60 上觀察到，執行環境在啟動時失敗，90 分鐘內有 90 次讀取設定失敗。一項使用真實目錄聯接的新測試會檢查兩個名稱都被接受，而不同的資料夾仍會被拒絕。尚未在已安裝的應用程式中檢查（PR #978）。
- 瀏覽器：292 項測試通過，包括十項在修正前失敗的測試，管理頁亦已以測試資料檢查（PR #976）。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.66 的所有內容。
