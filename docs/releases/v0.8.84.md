# Coding Tools 0.8.84

## English

### GPT Browser is its own browser again
- **The GPT Browser is back in the sidebar, as it was before 0.8.77.** Since #1044 it showed the browser the Codex bridge drives, and its signed-in ChatGPT pages kept hitting Cloudflare's "Just a moment..." check. The old GPT Browser opens pages only while you look at them, one account at a time, and reached ChatGPT on every account.
- Its accounts come back at the first start of 0.8.84. A sign-in that went to Trash moves back. One that became a Browser tab account is copied back, caches left out, so the Browser tab keeps the account too. Nothing is signed out.
- The bridge's browser is called "Browser" again, as are its messages ("Open the Browser tab, complete the check…", "Use in Browser tab").

### Fewer automation signals for Cloudflare
- **Pages no longer announce themselves as automated.** The automation port the Codex bridge connects to made Chromium set `navigator.webdriver` to true on every page in the app, a signal Cloudflare's check treats as a bot. The port still works; the flag is now off.
- The browser's user agent no longer carries the app's own `CodingTools/x.y.z` token, only the Chrome version a normal browser sends.

### Verification and limitations
- 316 tests in the 9 browser test files pass, including new ones for the account restore (a trashed sign-in moves back, a Browser tab account is copied without caches, a second start changes nothing) and for the user agent and webdriver switch. The renderer typechecks.
- On the live 0.8.81 app, signed-in ChatGPT pages in the Browser tab sat on Cloudflare's check while a signed-out page, through the same proxy and exit address, loaded. Turning off `navigator.webdriver` and the app token with debugging commands did not clear the blocked pages by themselves. The Browser tab's background pages for the Codex bridge may still meet the check; complete it there once if they do.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.83.

## 繁體中文

### GPT 瀏覽器再次成為獨立的瀏覽器
- **GPT 瀏覽器重新回到側邊欄，與 0.8.77 之前一樣。** 自 #1044 起，它顯示的是 Codex 橋接驅動的瀏覽器，已登入的 ChatGPT 頁面不斷遇到 Cloudflare 的「Just a moment...」檢查。舊的 GPT 瀏覽器只在你查看時才開啟頁面，一次一個帳戶，每個帳戶都能正常進入 ChatGPT。
- 它的帳戶會在 0.8.84 首次啟動時回來。移到垃圾桶的登入會移回原處。已成為「瀏覽器」分頁帳戶的登入會複製回來（不含快取），因此「瀏覽器」分頁亦保留該帳戶。不會有帳戶被登出。
- 橋接所用的瀏覽器重新稱為「瀏覽器」，相關訊息亦然（「Open the Browser tab, complete the check…」、「Use in Browser tab」）。

### 減少 Cloudflare 會偵測到的自動化特徵
- **頁面不再表明自己受自動化控制。** Codex 橋接所連接的自動化連接埠，令 Chromium 在應用程式內每個頁面把 `navigator.webdriver` 設為 true，而 Cloudflare 的檢查會把這視為機械人。連接埠仍然可用，只是這個標記現已關閉。
- 瀏覽器的使用者代理字串不再帶有應用程式自己的 `CodingTools/x.y.z` 標記，只保留一般瀏覽器會傳送的 Chrome 版本。

### 驗證及限制
- 9 個瀏覽器測試檔案共 316 項測試均通過，包括帳戶還原的新測試（垃圾桶中的登入移回、「瀏覽器」分頁帳戶不含快取地複製、第二次啟動不作任何改動），以及使用者代理字串和 webdriver 開關的測試。渲染程式碼型別檢查通過。
- 在執行中的 0.8.81 應用程式上，「瀏覽器」分頁內已登入的 ChatGPT 頁面停在 Cloudflare 檢查，而經同一代理及出口位址的未登入頁面可以載入。單靠除錯指令關閉 `navigator.webdriver` 和應用程式標記，並未令被擋的頁面通過。「瀏覽器」分頁中供 Codex 橋接使用的背景頁面仍可能遇到檢查；如遇到，請在該處完成一次。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.83 的所有內容。
