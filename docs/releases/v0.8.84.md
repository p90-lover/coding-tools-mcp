# Coding Tools 0.8.84

## English

### App plugins
- **Agent Orchestrator is listed under Services (#1058).** Its row shows the Agent Orchestrator build inside the app against the newest on its GitHub fork (for example "265e9a3 → 7c1d2e0 · 3 new commits on main"). A newer Agent Orchestrator arrives in an app update.
- **Update all.** One button installs every update the app can install, one at a time, CPA last. CPA restarts once for all new plugins. A failed update doesn't stop the rest, and each row says what happened to it instead of a pop-up.
- **Auto-update per item.** Every item the app can update itself (CPA, Antigravity CLI, RTK, and CPA plugins with their own releases) has an Auto-update switch. With it on, a check a few minutes after the app starts, and then every 6 hours, installs new versions. Items that come with the app have no switch.
- **A cleaner page.** Rows line up in columns: name and repository, version old → new, the action, and the switch. The long description, the footer and the repeated explanations are gone. All items are checked at once, so the page fills sooner. A plugin with no release on GitHub yet shows "No releases" instead of an error.
- **RTK updates again.** When winget refused with "Unable to remove Portable package as it has been modified", the update failed. That refusal is now answered once with `--force`.

### Register and Team
- **Register shows only the project's own page.** The bar and the two notes above it are gone. Until the page is ready, one card in the app's colours offers Choose project, Start or Try again.
- **The Orchestrator Team page is dark like the rest of the app.** Its title, hints and footer are folded into one aligned toolbar with the save state, and quick workers are small chips. Changes save on their own; Save again appears only after a save fails.

### Verification and limitations
- The app plugins, RTK, Register and Team tests pass (77 tests), including new ones for the Agent Orchestrator row, Update all, auto-update and RTK's retry. The three pages were checked in a browser preview with stand-in data, not in the installed app.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.83.

## 繁體中文

### 應用程式外掛
- **服務中列出 Agent Orchestrator（#1058）。** 此列顯示應用程式內建的 Agent Orchestrator 版本，與其 GitHub 分支上的最新版本對照（例如「265e9a3 → 7c1d2e0 · main 上有 3 個新提交」）。較新的 Agent Orchestrator 會隨應用程式更新提供。
- **全部更新。** 一個按鈕即可逐一安裝應用程式能安裝的所有更新，CPA 最後安裝。所有新外掛只需重新啟動 CPA 一次。某項更新失敗不會中斷其餘更新，每一列會顯示該項的結果，不再彈出提示。
- **逐項自動更新。** 應用程式能自行更新的項目（CPA、Antigravity CLI、RTK，以及有自己發佈版本的 CPA 外掛）都有「自動更新」開關。開啟後，應用程式啟動數分鐘後及之後每 6 小時檢查一次，並安裝新版本。隨應用程式提供的項目沒有此開關。
- **頁面更簡潔。** 各列按欄對齊：名稱與儲存庫、版本（舊 → 新）、操作及開關。冗長的說明、頁尾及重複的解釋已移除。所有項目同時檢查，頁面更快顯示。尚未在 GitHub 發佈版本的外掛會顯示「沒有發佈版本」，而非錯誤。
- **RTK 可再次更新。** 以往 winget 回覆「Unable to remove Portable package as it has been modified」時更新會失敗。現在遇到此回覆會以 `--force` 重試一次。

### 註冊及團隊
- **註冊頁只顯示專案本身的頁面。** 頂部的工具列及兩條提示已移除。頁面就緒前，會以應用程式配色的卡片提供「選擇專案」、「啟動」或「重試」。
- **Orchestrator 團隊頁面與應用程式其他部分一樣採用深色。** 標題、提示及頁尾合併為一條對齊的工具列，並顯示儲存狀態；快速工作者改為小標籤。變更會自動儲存，只有在儲存失敗後才會出現「再次儲存」。

### 驗證及限制
- 應用程式外掛、RTK、註冊及團隊的測試均通過（77 項），包括 Agent Orchestrator 列、全部更新、自動更新及 RTK 重試的新測試。三個頁面已在瀏覽器預覽中以模擬資料檢查，並未在已安裝的應用程式中檢查。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.83 的所有變更。
