# Coding Tools 0.8.50

## English

### ChatGPT model selection
- Codex and Coding Tools Chat now recognize GPT-6 effort labels Instant, Medium, High, Extra High and Pro when ChatGPT omits the `6` prefix, keeping the effort selected for that chat.
- Before sending, GPT-6 chats check the selected model and effort again and stop with an error if labels repeat, the slider changes or the requested effort is locked.
- Automatic native chats keep the requested model and effort until the bound ChatGPT account validates them, avoiding downgrades caused by another account's limits.

### Chat recovery
- When compaction resumes a saved ChatGPT conversation, it now uses the Codex chat's original account and stops if that account binding is missing.

### MCP setup
- Account MCP setup can now use the configured main tunnel without an entry in More tunnels, after fresh account-ownership and workspace-permission checks.

### Orchestrator responsiveness
- Agent Orchestrator board refreshes share pending reads, reducing duplicated work during slow responses.

### Verification and limitations
- Includes all changes in 0.8.49.
- Interactive panels depend on the tools and permissions available in the host app.

## 繁體中文

### ChatGPT 模型選擇
- ChatGPT 的 GPT-6 選單只顯示 Instant、Medium、High、Extra High、Pro，沒有 `6` 前綴時，Codex 與 Coding Tools Chat 現在也能正確辨識，並維持該聊天選定的推理強度。
- 送出前會再次確認選定的 GPT-6 模型與推理強度；若標籤重複、滑桿在選擇期間改變，或要求的強度尚未開放，請求會停止並顯示錯誤。
- 以自動模式執行的原生聊天會依綁定的 ChatGPT 帳戶確認選定的模型與推理強度，避免受另一個帳戶的限制影響而自動降級。

### 聊天恢復
- 壓縮內容時若需接回已儲存的 ChatGPT 對話，會沿用該 Codex 聊天原本綁定的帳戶；原綁定遺失時則停止恢復。

### MCP 設定
- 為帳戶設定 MCP 時，主隧道不必再另外加入 More tunnels，連線前仍會重新確認帳戶擁有權與工作區權限。

### Orchestrator 回應速度
- Agent Orchestrator 看板更新時會共用尚未完成的讀取，減少回應較慢時重複送出的請求。

### 驗證及限制
- 包含 0.8.49 的所有變更。
- 互動面板仍需所在應用程式提供相應工具及權限。
