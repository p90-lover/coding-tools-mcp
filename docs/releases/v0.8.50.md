# Coding Tools 0.8.50

## English

### Agent Orchestrator
- When AO refuses a grant, the chat shows the actual reason (run or graph changed, workspace, task visibility, pending configuration or schedules, executable identity, live permissions) with a fixed recovery message, instead of always "AO run, graph, or executable changed". Error text from storage, private paths and file contents are never shown (PR #892).

### Services
- A delayed live-status reply can no longer overwrite a newer one after you edit an endpoint or the connection changes. An unfinished endpoint draft no longer blocks another source's status, and a late connect result leaves the current busy or error state alone (PR #893).

### Smoother app
- The Activity log stops rebuilding its table for every new log record while it's hidden or the window is minimized, and catches up at once when shown again (PR #894).

### Verification and limitations
- Built and published by GitHub CI from main; no local build was made for this version.
- Not included: PR #888 (its CI fails) and PR #891 (unfinished, no CI run).
- Everything in 0.8.49 is included.

## 繁體中文

### Agent Orchestrator
- AO 拒絕授權時，對話會顯示實際原因（執行或圖表已變更、工作區、任務可見性、待處理的設定或排程、執行檔身分、即時權限）及固定的復原訊息，不再一律顯示「AO run, graph, or executable changed」。儲存空間的錯誤文字、私人路徑及檔案內容一律不會顯示（PR #892）。

### 服務
- 編輯端點或連線變更後，延遲的即時狀態回覆不會再覆蓋較新的狀態。未完成的端點草稿不再阻擋其他來源的狀態，較晚的連線結果亦不會改變目前的忙碌或錯誤狀態（PR #893）。

### 更流暢的程式
- 「活動」記錄在隱藏或視窗最小化時，不再為每筆新記錄重建表格，再次顯示時會立即補上最新內容（PR #894）。

### 驗證及限制
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 未包含：PR #888（CI 失敗）及 PR #891（未完成，沒有執行 CI）。
- 包含 0.8.49 的所有內容。
