# Coding Tools MCP v0.3.5-rc.1 — Always enabled + connection recovery

## English

Adds an **Always enabled / Enable until stopped** option beside the existing ten-minute Windows computer-control mode. This removes the timer, not the visible monitor, local consent, selected-window scope, Pause/Stop or emergency shortcut. App restart does not silently re-arm control. The overlay shows the actual duration mode. Continuous sessions rotate bounded anti-replay request windows only when prior inputs are known and sequences are complete; old session IDs cannot replay.

Continues the connection work: owned Cloudflare child crash recovery with capped backoff; explicit Stop disables recovery; public-origin compare-before-update synchronization; live recovery/address-change status in ChatGPT setup; credential-free MCP/OAuth discovery verification without restarting a healthy tunnel; canonical endpoint handling; named tunnel tokens removed from command-line arguments; failed-start child cleanup.

Screenshots and previews stay memory-only. No screenshot files, image caches or screenshot payload logs are added. No Codex agent, model API or AI review is used. Existing Live target / Exact agent frame, Windows UIA/SendInput and assisted ChatGPT setup are retained.

This is a public release candidate with Windows x64 and macOS ARM64 installers. Computer input is Windows-only. Windows is publisher-unsigned; macOS is ad-hoc signed, not notarized. Checksums, source provenance and focused verification evidence accompany the assets. The actual user's Cloudflare/ChatGPT connection has not been verified. Silent ChatGPT registration/consent and upstream Codex OS sandbox integration are not included; these are the app's own local tools. OS paging/crash dumps and receiving-client retention remain outside the screenshot storage guarantee.

## 繁體中文

新增 **Always enabled／持續啟用** 及 **Enable until stopped／啟用直到停止**，保留原有十分鐘模式。取消的是倒數限制，不是可見監控、本機確認、指定視窗限制、暫停／停止或緊急快捷鍵。重啟程式不會自行重新授權。持續操作在可安全確認時切換有界請求時段，舊 ID 不能重播輸入。

繼續完成連線功能：自有 Cloudflare 子程序崩潰恢復、有上限退避重試、停止後不自動復活、公開位址同步、ChatGPT 設定頁顯示恢復及換網址狀態，以及不重啟現有隧道的真實 MCP／OAuth 探索驗證。修正重複 `/mcp` 路徑；Named Tunnel Token 不再放在命令列；啟動失敗時會終止自有子程序。

截圖與預覽仍只留在記憶體，不新增截圖檔、快取或圖片操作紀錄，也不使用 Codex Agent／模型 API／AI 審查。提供 Windows x64 及 macOS ARM64 候選安裝程式；電腦鍵鼠操作限 Windows。Windows 未作發佈者簽署，macOS 為 ad-hoc 簽署且未公證。使用者實際 Cloudflare／ChatGPT 連線、靜默建立連接及上游 Codex 作業系統沙箱不屬於已驗證／交付範圍。詳見附帶校驗碼、來源及驗證紀錄。
