# Coding Tools 0.8.46

## English

### Smoother app
- Bun and the AO daemon start from a worker thread, so Windows creating and scanning the program no longer freezes every window; on 0.8.40 one such start held them 47.8 s after a Browser sign-in, and the AO daemon start 15.4 s (PR #824).
- Primary-tunnel health checks and control commands no longer resolve paths, read alias metadata or create their temp directory on the main thread; one such step held every window 11.7 s (PR #822).
- A manual MCP refresh is tracked, so Stop, setup and a keep-bridge quit wait for it, and a second refresh is refused while one runs (PR #822).

### Chats
- A stuck chat's Restart becomes Recover: it checks the chat's existing work without sending a new message or adding one to the queue, and its pending state no longer shows in other chats (PR #823).

### Browser and accounts
- Browser Management checks an account's real workspace and creation controls, finds a signed-in owner or admin of that workspace when one is needed, publishes the MCP connector and then connects the original member (PR #821).
- Plan badges come from fresh subscription data and workspace roles instead of being guessed from model access (PR #821).
- Account inspection pauses in hidden and Zero Risk views, and old connection evidence is cleared when the signed-in identity changes (PR #821).

### Onboarding
- Onboarding finishes when the system refuses the optional start-at-login registration; the refusal is recorded as a warning (PR #820).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from main, and confirm CI before publication.
- Not included: PR #814 (its CI fails), PR #815 (checks blocked) and PR #816 (no CI run).
- Everything in 0.8.45 is included.

## 繁體中文

### 更流暢
- Bun 和 AO 常駐程式改由工作執行緒啟動，Windows 建立及掃描程式時不再令所有視窗停頓；在 0.8.40，瀏覽器登入後的一次啟動曾停頓 47.8 秒，AO 常駐程式啟動曾停頓 15.4 秒（PR #824）。
- 主要通道的健康檢查和控制指令不再於主執行緒解析路徑、讀取別名資料或建立暫存資料夾；其中一個步驟曾令所有視窗停頓 11.7 秒（PR #822）。
- 手動重新整理 MCP 會被追蹤，停止、設定及保留橋接的結束都會等待它完成；執行期間會拒絕第二次重新整理（PR #822）。

### 對話
- 卡住對話的「重新啟動」改為「復原」：它會檢查對話現有的工作，不會傳送新訊息或加入佇列，等待狀態也不再出現在其他對話（PR #823）。

### 瀏覽器與帳號
- 瀏覽器管理會檢查帳號實際的工作區和建立權限，需要時找出同一工作區已登入的擁有者或管理員，發佈 MCP 連接器後再連接原本的成員（PR #821）。
- 方案標籤改用最新的訂閱資料和工作區角色，不再由可用模型推測（PR #821）。
- 在隱藏及零風險檢視中會暫停帳號檢查，登入身分改變時會清除舊的連線證據（PR #821）。

### 首次設定
- 系統拒絕可選的開機自動啟動登記時，首次設定仍能完成；拒絕會記錄為警告（PR #820）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由 main 編譯及通過 CI 才能公開。
- 未包含：PR #814（其 CI 失敗）、PR #815（檢查受阻）及 PR #816（沒有執行 CI）。
- 包含 0.8.45 的所有內容。
