# Coding Tools 0.8.62

## English

### Chats
- The chat box keeps its controls on one row while they fit. In a narrow chat, such as a split pane or a narrowed window, the controls always used two fixed rows, both half empty, even when the chat was 700 px wide. Now they fill a row in order: attach, permissions, Single/Team, harness and model, effort and window, then Send at the right end. Only what doesn't fit moves to a second row. From about 560 px wide it is one row.
- The model's name stays whole whenever the row has room, and the controls never take more than two rows. In a chat narrower than 420 px, the second row holds effort, window and Send.
- In a chat narrower than 720 px, the permission chip shows only its level's icon (the name is on hover), and the voice input placeholder is hidden.
- Single and Team is now one switch: a click flips it. The person and group logos roll past each other as it switches. With reduced motion turned on, it switches without moving.

### Verification and limitations
- Measured on a test page with the app's stylesheet and the real chat box controls, in chats 250–700 px wide with three model names, including "DeepSeek V4.1 Flash 1017(high)". No width went past two rows, and nothing went past the chat box's edge. Not yet checked in the installed app.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.60 is included.

## 繁體中文

### 對話
- 對話框的控制項放得下時會保持在同一行。在狹窄的對話中（例如分割窗格或縮窄的視窗），控制項過去總是固定分成兩行，而且兩行都有一半是空的，即使對話寬 700 px 也一樣。現在它們會依次排滿一行：附件、權限、Single/Team、harness 和模型、effort 和 window，最後是右端的 Send，只有放不下的才會移到第二行。對話寬約 560 px 以上時只有一行。
- 只要該行還有空間，模型名稱就會完整顯示；控制項最多只佔兩行。對話窄於 420 px 時，第二行放 effort、window 和 Send。
- 在窄於 720 px 的對話中，權限晶片只顯示其等級的圖示（名稱在滑鼠停留時顯示），語音輸入的預留按鈕則會隱藏。
- Single 和 Team 現在是同一個開關，按一下即可切換；切換時，單人和群組圖示會互相滾動交替。開啟「減少動態效果」時則直接切換，不會移動。

### 驗證及限制
- 在使用應用程式樣式表及真實對話框控制項的測試頁面上量測，對話寬 250–700 px，使用三個模型名稱，包括「DeepSeek V4.1 Flash 1017(high)」。沒有任何寬度超過兩行，也沒有內容超出對話框邊緣。尚未在已安裝的應用程式中檢查。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.60 的所有內容。
