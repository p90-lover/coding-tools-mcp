Coding Tools 0.8.5

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Opening the app:

- A disk error while backing up retired services' data (a full disk, a folder Windows would not create) no longer stops the app from starting.
- A setup config saved with a byte order mark (as Windows PowerShell writes it) no longer stops the app from starting.
- A damaged runtime file in the app's folder (a stray backup, a missing or edited file) no longer stops the app when this version's installed copy is whole; removing an old runtime copy is best effort.
- A backend update carries every file the Agent Orchestrator needs; one could fail to load before.
- An update that has to roll back retries when a file is briefly held, and the relaunched app no longer inherits the closing app's proxy settings.

Fewer crashes and hangs:

- An unexpected error in the background is logged and the app keeps going, instead of a blocking error box that held the whole app (with the window in the tray it looked frozen).
- One chat message or page that cannot be shown shows a notice with Try again in its place, instead of blanking and reloading the whole window (which lost drafts and queued messages).
- The local service recovers after an internal error instead of refusing every request until the app restarts.
- Email links in the GPT Browser open your mail app.

Chat:

- Restarts no longer use up a step's retries, reads inside the project need no review, and Clawd's house sits beside the chat box.
- No blank minutes after a restart; another project's chats open directly.
- Goal rounds continue after a compaction, and the ChatGPT browser opens normal chats.
- RTK installed with winget is found, installed without a click, and the Agent Orchestrator starts with it.

Everything in 0.8.4 is included.
