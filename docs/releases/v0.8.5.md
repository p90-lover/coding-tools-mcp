Coding Tools 0.8.5

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Opening the app:

- A disk error while backing up retired services' data (a full disk, a folder Windows would not create) no longer stops the app from starting.
- A setup config saved with a byte order mark (as Windows PowerShell writes it) no longer stops the app from starting.
- A damaged runtime file in the app's folder (a stray backup, a missing or edited file) no longer stops the app when this version's installed copy is whole; removing an old runtime copy is best effort.
- A backend update carries every file the Agent Orchestrator needs; one could fail to load before.
- An update that has to roll back retries when a file is briefly held, and the relaunched app no longer inherits the closing app's proxy settings.

Fewer crashes and hangs:

- An unexpected error in the background is logged and the app keeps going, instead of a blocking error box that held the whole app (with the window in the tray it looked frozen).
- One chat message or page that cannot be shown shows a notice with Try again in its place, instead of blanking and reloading the whole window (which lost drafts and queued messages).
- The local service recovers after an internal error instead of refusing every request until the app restarts.
- Email links in the GPT Browser open your mail app.

Chat:

- A sent message shows at once and the box clears, instead of waiting for the whole board to reload.
- "Retry automatically" retries a failed step by itself once its pause is over (10 s, then 20 s, at most three tries), including a step whose launch timed out. Before, it showed the countdown and then waited for a click.
- Restarts no longer use up a step's retries, and reads inside the project need no review.
- "Approve for me" reviews a full script of up to 1,500 characters as a whole, approves the app's own subagent and wake-up tools, and asks its reviewer once more for allow or deny before leaving a request to you. A request too long to review whole waits for you instead of being refused after 20 seconds. A command with `git push` past that limit is still refused. A denied tool shows the reviewer's reason instead of "User refused permission".
- A subagent whose model keeps refusing requests (a third 429 in a row) is stopped, and its chat is told to go on without it. A running turn that is waiting out a model error says so ("the model is rate-limited (429), retrying (8 of 10)") instead of "may be stuck".
- Stop releases the chat's agents and their sub-agents, a chat whose agent never started can be archived, and a resumed chat waits until its agent is ready before sending.
- No blank minutes after a restart; another project's chats open directly.
- Goal rounds continue after a compaction, and the ChatGPT browser opens normal chats.
- RTK installed with winget is found, installed without a click, and the Agent Orchestrator starts with it.
- Clawd can be dragged anywhere on the screen, and its open house stands beside the chat box's right side. When the window is narrow, it stands on the box's top edge.

CPA and Cline Pass:

- CPA keeps your API providers across a managed restart, and its network proxy can be chosen separately.
- Cline Pass streaming through CPA works across the Claude, Responses and OpenAI Chat formats.

Windows and packaging:

- Profiles and state directories behind Windows junctions are resolved before the app writes to them.
- Portable runtime bundles can no longer mix versions.

Everything in 0.8.4 is included.
