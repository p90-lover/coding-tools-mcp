Coding Tools 0.7.0-rc.17

Portable edition: download `Coding.Tools_0.7.0-rc.17_win_x64_portable.zip`, unzip it anywhere and run `Coding Tools.exe`. No installer and no admin rights are needed. The portable app updates in place from the update packs below.

Updates in-app (no installer): only changed update packs download.

New:
- Portable Windows app, no installer needed.
- Chat: pick the branch chats work on from a branch bar above the chat box; a new question no longer starts a new branch.
- Chat: shorter, grouped model list; WebGPT tiers match ChatGPT and set the effort chip.
- Setup: an existing ChatGPT sign-in is found automatically.
- Native Codex: opt-in Auto-review in the connection panel (workspace mode with model use allowed), with the reviewer the native runtime reports back.

Fixes:
- Chat: a folder-mode chat's tools can use its project folder again.
- Chat: a finished WebGPT answer is kept when its prompt renders late.
- Chat: a working Native Codex card shows its reply as it streams.
- Chat: a provider retry shows why it is retrying (for example a rate limit).
- Chat: composer chips no longer overlap and show no defaults.
- WebGPT "Approve for me" no longer hangs on Codex's reviewer; the reviewer sees MCP tool input.
- WebGPT commands from AO cards run in Codex's sandbox instead of hanging.
- Startup: the runtime upgrade waits for a busy host; a proxy gateway that failed at launch is retried.
- Retired external-service state is no longer re-linked on startup.

Apps on 0.7.0-rc.15 or later update in-app; older versions need one manual install first.
