# Coding Tools MCP v0.4.0-rc.1 — Control center

## English

A rebuilt SaaS-style desktop control center with clear navigation, real workspace/service overview, a searchable page/workspace palette, a local delivery board, session directory, integration setup, and separate computer-control/connection surfaces. New screens support English/Traditional Chinese and light/dark themes; retained advanced forms share the redesign but some keep their existing language.

**Paseo** integration reads existing daemon sessions using its pinned WebSocket protocol and reuses its attributed attention/status sorting. **Anneal** integration reads the existing API task-board projection and reuses its layer-first chain ordering. A separate native twelve-stage operator checklist supports task creation, evidence, block/resume and lossless archive/restore. It does not execute a task specification or merge a PR.

These are actual management adapters and reused upstream modules, not complete bundled upstream engines. Paseo agent launch/chat, relay/mobile pairing and voice are not included; Anneal scheduling, agent reviews, runners and autonomous merge are not included. External services must already exist. Literal-loopback endpoints, no redirects, bounded reads, RAM-only credentials and no provider-agent launch preserve the no-Codex-inference boundary. Existing external agents can independently consume their provider quota.

Existing memory-only screenshot/preview, remembered approval, background-window observation, Pause/Stop and emergency shortcut behavior is retained. No screenshot files/cache are added. The previously withheld command sandbox remains disabled and absent from the installers.

Release gates cover native read-only HTTP/WebSocket protocol fixtures, board revision/evidence/archive semantics, frontend checks/build, existing computer/vision contracts, real Windows input/background capture, and actual installer version/binary inspection. Offline production-component UI verification used fixture data because managed Chromium denied local-server navigation; the policy was not bypassed. Live Paseo/Anneal instances and the user's actual Windows/ChatGPT environment were not end-to-end verified.

Windows x64 and macOS ARM64 installers, checksums, source provenance and validation evidence are provided. Windows is publisher-unsigned; macOS is ad-hoc signed and not notarized. Native computer input remains Windows-only. This is a public release candidate.

## 繁體中文

重新設計 SaaS 風格桌面控制中心，加入清楚導覽、真實工作區／服務總覽、頁面／工作區搜尋、本機交付看板、會話目錄、整合設定，以及獨立電腦操作與連線頁面。新頁面支援英文／繁體中文及深淺主題；部分沿用的進階表單保留既有語言。

Paseo 介接器透過固定 WebSocket 協定讀取既有會話，並使用附授權的狀態排序元件；Anneal 介接器讀取既有 API 看板，並使用上游流程排序。本機十二階段手動清單支援任務建立、依據記錄、受阻／恢復及不刪除記錄的封存／還原，不會執行規格或合併 PR。

此次整合的是實際管理介接器及上游元件，不包含完整 Agent 執行引擎。Paseo 語音、Relay 配對、Agent 啟動／對話，以及 Anneal Runner、排程、自動審查／合併均未包含。外部服務須已存在；連線限制於本機端點、禁止重新導向、有界讀取、Token 只在記憶體，並不啟動 Codex。外部已運行的 Agent 仍可能自行消耗配額。

既有記憶體截圖、記住授權、背景視窗觀察、暫停／停止及緊急快捷鍵保留；不新增截圖檔或快取。先前暫緩的命令沙箱仍停用且不打包。提供 Windows x64／macOS ARM64 安裝程式與驗證紀錄；此為候選版本，未驗證你的真實外部服務／帳戶，Windows 未簽署、Mac 未公證。
