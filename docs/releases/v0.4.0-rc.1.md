# Coding Tools MCP v0.4.0-rc.1 — Paseo + Anneal control center

## English

A redesigned local control center with a responsive navigation rail, Overview, Task board, Sessions, Connections, and a dedicated Computer control page. Search/Ctrl+K, light/dark styling, English/Traditional Chinese navigation, meaningful empty/error states, and shared styling across existing workspace/settings pages replace the old workspace-first landing flow.

Paseo integration reads existing agent directory metadata over its real WebSocket protocol, including bounded pagination and optional session password. Anneal integration reads its real task-board HTTP contract, including chain and review-gate metadata. Connections are local-loopback-only and read-only: no agents, prompts, approvals or merges are launched. Existing external agents may independently consume their own quota. Both upstream runtimes remain separately installed; this is not full embedding of phone/voice/relay or autonomous runners.

The new native planning board adapts Anneal's five-stage board semantics with local task specs, workspace filtering, priority, revision checks, reversible archive/restore and required review/verification notes before Done. Local completion is an operator record, not automated CI evidence. Credentials remain in Rust memory rather than saved settings.

Existing Windows remembered always-enabled access, background observation, RAM-only screenshots, exact agent-frame supervision, Pause/Stop and OAuth/tunnel controls are retained. The unverified command sandbox remains withheld. No Codex agent/model/reviewer was invoked for development, testing or publication.

This is a public release candidate. Windows x64 is publisher-unsigned; macOS Apple Silicon is ad-hoc signed and not notarized. GUI input is Windows-only. Native adapter tests exercise real loopback protocol fixtures; UI tests use explicitly labelled QA native-bridge fixtures. The user's real Paseo/Anneal/ChatGPT/Cloudflare installations and phone pairing are not end-to-end verified. Checksums, source provenance and focused verification evidence accompany the installers.

## 繁體中文

重新設計本機控制中心，加入響應式導覽、總覽、任務看板、會話、連線及獨立電腦操作頁。支援 Ctrl+K 搜尋、明暗主題及英文／繁體中文新介面；既有工作區和設定功能仍然保留，套用一致的視覺樣式。

Paseo 透過真實 WebSocket 協定唯讀查看既有 Agent 目錄；Anneal 透過真實 HTTP 協定顯示任務、流程及審查關卡。只接受本機回環連線，不會啟動 Agent、傳送提示、批准或合併。在其他介面啟動的 Agent 仍可能獨立消耗配額。上游程式仍需分開安裝，此版本不包含手機／語音／中繼或自主執行器。

本機看板採用 Anneal 五階段狀態，支援規格、優先次序、工作區篩選、版本衝突檢查及可還原封存。完成前須填寫審查與驗證紀錄，但不會把操作員紀錄說成 CI 證明。整合憑證只留在 Rust 記憶體。

保留 Windows 跨重啟持續授權、背景觀察、記憶體截圖、GPT 所見畫面、暫停／停止及 OAuth／隧道控制；未驗證沙箱仍停用。不呼叫 Codex Agent／模型／AI 審查。這是候選版本，實際個人環境尚未端到端驗證。Windows 未作發佈者簽署，Mac 為 ad-hoc 簽署且未公證。附校驗碼、來源及重點驗證紀錄。
