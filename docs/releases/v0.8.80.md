# Coding Tools 0.8.80

## English

### Packages
- **Every npm package in the app is on its newest usable release (#1046).**
  - The chat window and the launcher build with Vite 8 (was 6) and its React plugin 6.
  - Animations use motion 14 (was 12).
  - Types are checked with TypeScript 6.0.3 (was 5.9), and electron-builder is 26.18.
  - Node's type definitions now match Electron 45's Node 24 (were Node 22's).
  - The Svelte front end moves to Lucide icons 1.67, Svelte 5.57.3, SvelteKit 3.1.1 and Tailwind 4.3.4.
  - Electron itself was already the newest, 45.2.1.
- **Seven high-severity advisories in the launcher's networking library (undici) are closed by its update to 6.29.1 and 7.30.1 (#1046).** Among them is one where TLS certificate checks could be dropped. runtime-web picks up express 5.3.0 and jose 6.2.15.
- The GitHub button at the bottom of the sidebar keeps its icon. Lucide 1.0 removed brand logos, so the app now draws the same mark itself (#1046).

### Verification and limitations
- **TypeScript stays on 6.0.3, not 7.0.** TypeScript 7 is the compiler rewritten in Go. Its package no longer offers the JavaScript API that 73 of the app's test files use to load the chat window's code.
- **deepmerge stays pinned at 4.1.1.** Its advisory covers every later release, and no fixed version exists yet.
- Packaging still reports one moderate advisory, in minimatch, used only by electron-builder's packaging tools. The previous version had the same one, and no fix exists below minimatch 11.
- Local checks passed (#1046):
  - The chat window, launcher, runtime and Svelte front end all typecheck and build.
  - 1,647 desktop tests pass, and the chat window loads on Vite 8 with no console errors.
  - 1,565 runtime tests pass. One compaction test fails the same way on the previous packages.
- CI passed on Windows, Linux and macOS, including the Windows package build.
- Not yet checked in the installed app.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.79.

## 繁體中文

### 套件
- **應用程式中每個 npm 套件都已更新至可用的最新版本（#1046）。**
  - 對話視窗及啟動器改用 Vite 8（原為 6）及其 React 外掛 6 建置。
  - 動畫改用 motion 14（原為 12）。
  - 型別檢查改用 TypeScript 6.0.3（原為 5.9），electron-builder 為 26.18。
  - Node 型別定義改為對應 Electron 45 內建的 Node 24（原為 Node 22）。
  - Svelte 前端改用 Lucide 圖示 1.67、Svelte 5.57.3、SvelteKit 3.1.1 及 Tailwind 4.3.4。
  - Electron 本身已是最新的 45.2.1。
- **啟動器的網絡程式庫（undici）更新至 6.29.1 及 7.30.1，修補七項高嚴重性安全公告（#1046）。** 其中一項可令 TLS 憑證檢查被略過。runtime-web 亦更新至 express 5.3.0 及 jose 6.2.15。
- 側邊欄底部的 GitHub 按鈕保留原有圖示：Lucide 1.0 移除了品牌標誌，應用程式現自行繪製同一個標誌（#1046）。

### 驗證及限制
- **TypeScript 停留在 6.0.3，而非 7.0。** TypeScript 7 是以 Go 重寫的編譯器，其套件不再提供 JavaScript API，而應用程式有 73 個測試檔案靠這個 API 載入對話視窗的程式碼。
- **deepmerge 仍固定在 4.1.1。** 其安全公告涵蓋之後的所有版本，目前尚無修正版本。
- 封裝工具仍有一項中等嚴重性公告，來自 minimatch，只經 electron-builder 的封裝工具使用。上一版本已有同一項公告，而 minimatch 11 以下並無修正版本。
- 本機檢查均通過（#1046）：
  - 對話視窗、啟動器、runtime 及 Svelte 前端均通過型別檢查及建置。
  - 1,647 項桌面測試均通過，對話視窗在 Vite 8 下載入，主控台沒有錯誤。
  - 1,565 項 runtime 測試均通過。一項壓縮測試失敗，但在舊套件下同樣失敗。
- CI 在 Windows、Linux 及 macOS 上均通過，包括 Windows 封裝建置。
- 尚未在已安裝的應用程式中檢查。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.79 的所有內容。
