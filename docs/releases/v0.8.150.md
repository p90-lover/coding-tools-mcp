# Coding Tools v0.8.150

## English

- Images attached to queued chat messages now show thumbnails instead of filesystem paths. Open a thumbnail to see the full image, or expand a folded queue to see the remaining images. Captions, annotations, filenames, and queue controls stay available. The message sent to the agent is unchanged.
- Includes all changes in v0.8.149, including the Antigravity sign-in cooldown introduced in v0.8.148.

## 繁體中文

- 排隊中的聊天訊息會顯示附加圖片的縮圖，不再顯示檔案路徑。點擊縮圖可查看完整圖片，展開折疊的佇列可查看其餘圖片。文字說明、註解、檔名及佇列操作仍可使用，實際送給代理程式的訊息內容不變。
- 包含 v0.8.149 的所有變更，以及 v0.8.148 加入的 Antigravity 登入等待機制。
