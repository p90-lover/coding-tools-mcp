# Coding Tools 0.8.22

## English

### Fixes
- Continue a Codex task in its original ChatGPT conversation when a steering message arrives, rather than opening a different conversation.
- Retain the canonical ChatGPT conversation URL with the task-owned browser lease and return it to the runtime when the tab is reused.
- Verify that a retained tab is still displaying its original conversation before resuming, preventing cross-conversation reuse.
- Resume with only newly steered content instead of resubmitting already-sent prompts.
- Add browser-host, launcher, and adapter regression tests for conversation reuse.

This release includes all changes from v0.8.21.

### Updating
In-app updating is supported from rc.19 and later. For rc.18 or earlier, close Coding Tools before installing the Windows installer or extracting the portable ZIP.

## 繁體中文

### 修正內容
- Codex 任務收到新的 Steering 訊息時，繼續使用原本的 ChatGPT 對話，而不是另開對話。
- 將正式 ChatGPT 對話網址保留於任務專用的瀏覽器租約內，重用分頁時交回執行環境。
- 恢復任務前核對保留分頁是否仍在原本對話，避免不同對話被錯誤重用。
- 繼續執行時只送出新增的指令內容，避免再次提交先前已送出的提示。
- 增加瀏覽器主機、Launcher 及 Adapter 的對話重用回歸測試。

本版本包含 v0.8.21 的所有更新。

### 更新方式
rc.19 或更新版本可使用程式內更新。rc.18 或更早版本請先關閉 Coding Tools，再執行 Windows 安裝程式或解壓可攜版 ZIP。
