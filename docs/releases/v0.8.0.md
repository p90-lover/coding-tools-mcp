Coding Tools 0.8.0

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Chat:

- Every step the agent takes is shown: each tool call keeps its own row with its own command and output (calls to the same tool were folded into one "×3" row), long turns keep all their steps, and long answers are no longer cut at 4 KB.
- File edits open on the changed lines with old and new line numbers and a few lines around them, as Claude Code shows a change, instead of the whole file marked removed and added again.
- Approve for me: what its reviewer allows or denies runs at once, without the 20-second wait or a question popping up. A request the reviewer cannot judge (a script too long to read whole) now waits for you, with no timer.
- Questions and tool requests are asked as the Codex app asks them: pick a numbered option, change it if you like, then Submit (Enter); Deny or Dismiss with Esc. Once answered, the question and your answer stay in the chat as Claude Code shows them, and each call that needed approval shows who let it run.
- DeepSeek models are drawn as DeepSeek Harness draws a turn, with its response style.
- The context panel is laid out like Claude Code's Context card, shows its category split instead of only "Used", keeps its reading across new sessions, failed reads and steers, and notices Claude Code's own compactions.
- Less lag while a model streams fast: fewer refreshes and shared conversation reads, and the streaming answer redraws a few times a second instead of on every token.
- The Terminal pane opens only for servers and app launchers, not for every command the agent runs.
- Bit the pet, now Clawd, wanders, acts and reacts beside the chat box; the Overview side panel shows usage; pasted images show as thumbnails.
- Steering answers a pending request, restarts resume where they left off, and switching models keeps the context.
- Reopening a project resumes the chats an app restart left behind.
- An agent can bring the Terminal or Preview forward to show you something (show_in_chat).
- Clawd walks around the chat box, naps in a bed, and rides the pointer; drag it away from the box to lift it, and it stays at that height.

Agents and tools:

- Approve for me's reviewer reads its verdict from its final message, knows the workspace folder, and retries before asking.
- Agents get the `ao` CLI on their terminal's PATH, and AO sessions skip `~/.claude` settings.
- Claude Code is no longer offered Antigravity's Claude models, with the reason shown.
- ACP agents' token totals add up per prompt instead of being replaced by one prompt's, and a replayed prompt's usage is counted once.
- AO prunes its provider event archive's streaming chunks once nothing can replay them, so its database stops growing without bound; a finished reply no longer gets its text appended again when a chat resumes.
- WebGPT: chats are saved in ChatGPT (connectors work again), effort tiers are detected, prompts are sent as typed in Codex, turns stay in ChatGPT's Chat mode (never Work), old Codex chats open on ChatGPT Web, used chats can be deleted, and Codex's /goal works.
- Sandboxed commands start in the right folder (WebGPT commands no longer fail with error 203).
- Write leases held only for a moment are waited out instead of reported busy, and a released lease is free at once.
- The Codex Auto Review page signs in under its real plugin id.

Everything in rc.31 is included.
