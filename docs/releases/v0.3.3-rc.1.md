# Coding Tools MCP v0.3.3-rc.1 — memory-only vision

## English

Downloadable release candidate built from the pinned release source, not a relabel of v0.3.2.

Includes display/window screenshots, display/window discovery, cropped/redacted image viewing, image information, pixel comparison, and assisted ChatGPT MCP setup from PR #11.

Screenshot pixels are captured, transformed and encoded in memory and sent to the calling MCP client. The application does not save screenshot files, a screenshot cache, thumbnails, or a screenshot gallery. Destination-path/save arguments are rejected. No capture image payload is automatically written to the application's operation/history logs. Screen capture defaults OFF and requires local workspace opt-in plus any applicable OS consent; restart the MCP service after changing that setting.

A dependency audit found xcap 0.9.8 Linux/Wayland fallbacks that create temporary PNG files. This release therefore permits native capture only on the reviewed Windows/macOS backends, failing closed on other platforms before native access. Reading existing workspace images remains available; it does not overwrite them.

Memory-only refers to this app's capture pipeline: the OS may page process memory or collect crash dumps, and the connected client/ChatGPT may retain returned images. This is not secure memory erasure or a guarantee of no storage anywhere. No Codex agent, model API, OCR service, or background recorder is invoked by these tools or the release workflow.

Windows x64 installer and macOS Apple Silicon DMG are provided. The Windows build has no publisher Authenticode certificate; the macOS build is ad-hoc signed, not Developer-ID signed or notarized. Checksums verify asset integrity, not publisher identity.

Validation includes native compilation, focused vision/privacy tests, the MCP tool catalog, frontend checks/build, and executable version checks. Interactive capture/OS consent and end-to-end image delivery through the user's actual ChatGPT connection are not verified by automated tests. This is a prerelease; the existing stable release is unchanged. The earlier upstream Codex executor/OS sandbox integration remains outside this release.

## 繁體中文

這是從固定原始碼建置、可下載的候選版本，不是把 v0.3.2 的舊安裝程式改名。

包含 PR #11 的螢幕／視窗截圖、螢幕／視窗探索、圖片裁切／遮蓋、圖片資訊、像素比較及輔助式 ChatGPT MCP 設定。

截圖只在記憶體內擷取、處理和編碼，再傳給呼叫工具的 MCP 用戶端。應用程式不儲存截圖檔、截圖快取、縮圖或圖庫；輸出檔案路徑／儲存參數會被拒絕，也不會自動把截圖圖片內容寫入操作／歷史記錄。螢幕擷取預設關閉，必須在本機工作區啟用並取得適用的作業系統授權；更改設定後須重新啟動 MCP 服務。

相依套件檢查發現 xcap 0.9.8 的 Linux／Wayland 後備機制會建立暫存 PNG，因此此版本僅允許已檢查的 Windows／macOS 原生擷取路徑；其他平台在呼叫原生介面前便會拒絕。讀取既有工作區圖片仍可使用，而且不會覆寫圖片。

「僅限記憶體」指本應用程式的截圖流程，不代表作業系統分頁檔／當機傾印或 ChatGPT／用戶端完全不會保留資料。此功能與發佈流程不呼叫 Codex Agent、模型 API、OCR 服務或背景錄影。

提供 Windows x64 安裝程式及 macOS Apple Silicon DMG。Windows 未有發行者 Authenticode 簽章；macOS 使用 ad-hoc 簽章，並無 Developer ID 簽章或公證。雜湊校驗只能確認下載內容一致，不能代替發行者身分驗證。

驗證涵蓋原生編譯、重點視覺／私隱測試、MCP 工具目錄、前端檢查／建置及執行檔版本檢查。實機螢幕授權與截圖、使用者實際 ChatGPT 連接的圖片傳送仍未經端到端驗證，因此此版本標為預先發佈，不取代既有穩定版。先前提出的上游 Codex 執行器／作業系統沙箱整合不在此版本範圍內。
