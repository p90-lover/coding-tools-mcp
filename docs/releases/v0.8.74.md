# Coding Tools 0.8.74

## English

### Setup
- CPA setup reports ready only when CPA's final health check passes. Before, a health check whose connection was refused could still end setup as ready (PR #1012).

### Chats
- Erase keeps its mask with the image it edits. Before, the mask could be dropped silently at the attachment limit, or other images could be placed ahead of the pair the prompt names. A draft that is full, still uploading or has changed is refused without dropping anything (PR #1013).
- A chat's turn stats no longer stop appearing when a usage read comes back empty; the app tries again and keeps the numbers it already showed (PR #1013).

### Verification and limitations
- Setup: 33 bootstrap tests pass, including a real inspection against a healthy and a refusing HTTP server (PR #1012).
- Chats: 262 chat tests and 15 image tests pass, and the type check is clean (PR #1013).
- Not yet checked in the installed app.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.73 is included.

## 繁體中文

### 設定
- CPA 設定只會在 CPA 最終健康檢查通過後才報告就緒。過去即使健康檢查的連線被拒絕，設定仍可能以就緒完成（PR #1012）。

### 對話
- 「Erase」會讓遮罩與它所編輯的圖片保持在一起。過去在附件數量上限時遮罩可能被悄悄丟棄，其他圖片亦可能排在提示所指的圖片組之前。已滿、仍在上載或已更改的草稿會被拒絕，而不會丟失任何內容（PR #1013）。
- 用量讀取傳回空結果時，對話的回合統計不會再停止顯示；應用程式會再試，並保留已顯示的數字（PR #1013）。

### 驗證及限制
- 設定：33 項啟動設定測試通過，包括對健康及拒絕連線的 HTTP 伺服器進行實際檢查（PR #1012）。
- 對話：262 項對話測試及 15 項圖片測試通過，型別檢查亦無錯誤（PR #1013）。
- 尚未在已安裝的應用程式中檢查。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.73 的所有內容。
