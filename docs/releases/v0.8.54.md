# Coding Tools 0.8.54

## English

### Chats
- A pasted image shows its thumbnail at once, Send waits until the image is saved, and switching chats no longer moves or loses it. Folding a turn's work details keeps the model's replies visible, without repeating final answers (PR #920).
- An older reply restored from a chat's history can be deleted; it used to fail with "reply was not found; reload the chat" when it was outside the project's newest 100 runs (PR #923).

### MCP
- MCP connects on its own again. The automatic check waited until no Codex request was open, but Codex keeps its bridge connections open between turns, so with any chat open it never ran (9–12 were open at every sample, none of them using the browser). It also took the blank page the browser rests on for an unsent draft. It now waits only for the browser to be free; a failed check tries again after 1, 2, 5, 10 and 15 minutes; and a Codex turn that starts during the check waits for it instead of failing (PR #922).
- The ChatGPT connector is checked again, which reloads ChatGPT's connector list, whenever the MCP tunnel restarts or is taken over after an update, and after a sign-in or a browser account switch (PR #922).

### Plugins
- Connections → App plugins has an Agent tools section with Antigravity CLI and RTK. Each shows the installed version, GitHub's latest release, and an Update button when the newer version can be installed safely; downloads are checked against GitHub's size and SHA-256 (PR #919).

### Diagnostics
- Freeze, memory and error events keep their own in-memory list, so routine lines can no longer push them out. With several chats working, the Activity log used to drop them after about 16 minutes; the control server's activity route now reads this list (PR #925).

### Verification and limitations
- Built and published by GitHub CI from main; no local build was made for this version.
- The MCP change is covered by tests of the check, the tunnel and a turn that starts mid-check; it hasn't been run in the installed app yet. ChatGPT's own Refresh button on a connector is not pressed: the check reloads ChatGPT's connector list instead (PR #922).
- Everything in 0.8.53 is included.

## 繁體中文

### 對話
- 貼上的圖片會立即顯示縮圖，「傳送」會等到圖片儲存完成，切換對話亦不會再移動或遺失圖片。摺疊回合的工作詳情時，模型的回覆仍會顯示，且不會重複最終答案（PR #920）。
- 從對話歷史恢復的較舊回覆現在可以刪除；之前若它不在專案最新的 100 次執行內，會以「reply was not found; reload the chat」失敗（PR #923）。

### MCP
- MCP 會再次自行連接。自動檢查過去要等到沒有任何 Codex 請求開啟才執行，但 Codex 在回合之間會保持其 bridge 連線開啟，因此只要有對話開啟，檢查就從不執行（每次取樣都有 9–12 個連線開啟，沒有一個使用瀏覽器）。它亦把瀏覽器閒置時停留的空白頁面當成未送出的草稿。現在只等待瀏覽器空閒；檢查失敗時會在 1、2、5、10 及 15 分鐘後重試；在檢查期間開始的 Codex 回合會等待檢查完成，而不會失敗（PR #922）。
- 每當 MCP 通道重新啟動或在更新後被接管，以及登入或切換瀏覽器帳號後，都會再次檢查 ChatGPT 連接器，並重新載入 ChatGPT 的連接器清單（PR #922）。

### 外掛
- 「連線 → App 外掛」新增「代理工具」區塊，包括 Antigravity CLI 及 RTK。每項都會顯示已安裝版本、GitHub 上的最新版本，可安全安裝較新版本時另有「更新」按鈕；下載會以 GitHub 提供的大小及 SHA-256 檢查（PR #919）。

### 診斷
- 停頓、記憶體及錯誤事件會保存在獨立的記憶體清單中，日常記錄不會再把它們擠出。多個對話同時運作時，「活動」記錄過去約 16 分鐘便會遺失這些事件；控制伺服器的活動路由現會讀取此清單（PR #925）。

### 驗證及限制
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- MCP 變更已由檢查、通道及在檢查期間開始回合的測試涵蓋，尚未在已安裝的應用程式中執行。不會按下 ChatGPT 本身連接器上的「Refresh」按鈕，檢查會改為重新載入 ChatGPT 的連接器清單（PR #922）。
- 包含 0.8.53 的所有內容。
