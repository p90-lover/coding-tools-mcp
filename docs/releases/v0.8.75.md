# Coding Tools 0.8.75

## English

### Browser
- After you sign in to ChatGPT, the Browser tab no longer keeps refreshing itself into "Too many requests" (429). The app checks the sign-in from inside the ChatGPT page, and a 429 from that check counted as signed out. The next good answer then counted as a new sign-in. That started the bridge connect, which reloads the page, so ChatGPT got more requests and answered with more 429s. Now a check that gets no real answer (a 429, a server error, a security check or a timeout) leaves a signed-in page signed in. A real signed-out answer still signs it out (PR #1017).

### Chats
- A chat's chosen reasoning effort is kept on Codex chats routed through CPA, as it already was on Claude Code. Before, Sol's Extra High and Max and DeepSeek's Max were lost before the chat started. A command review on the card's own model uses that model's effort; a different reviewer keeps its own (PR #1023).
- An approval card you cancelled, or whose answer failed to send, can be clicked again. Before, it stayed disabled for good (PR #1022).
- The chat box sits 2 px under its branch bar instead of 6 px, and the two line up at every pane width (PR #971).
- Preview Read now also returns a native visualization's public state, so an agent can read a selection that isn't shown as text. Private state is left out (PR #1019).

### Settings
- CPA settings you've edited but not saved are no longer wiped by a background status update (PR #1018).

### ChatGPT connector
- Connector setup creates a connector only for a verified owner of the workspace, and checks the same account, workspace, role and tunnel again before each change. A connection that was already confirmed keeps its status (PR #977).

### Runtime
- Stopping the backend-bundle watcher cancels a scan it had already started, so the scan can't install a bundle or restart the backend during shutdown (PR #1021).
- Unsubscribing from events saves the change before removing the subscription from memory. Before, if the save failed, a retry reported success and the subscription came back on the next start (PR #1020).

### Also in 0.8.74 (not listed in its notes)
- A message queued while a chat compacts is read again when the compaction ends. A message you cleared, edited or replaced meanwhile is no longer sent in its old form (PR #1014).

### Verification and limitations
- Browser: 7 new tests cover the 429 loop (a 429, a 502, a failed fetch and a security check keep the sign-in; an empty session and a 401 still sign out). All 174 tests in the 11 other files that load the browser code pass. The fix has not been checked against a live 429 in the installed app yet (PR #1017).
- The other PRs were tested in their own PRs: 48 renderer tests (PR #1022), 40 renderer-wiring tests (PR #1018), 51 Preview tests and a real Electron run (PR #1019), 164 connector cases (PR #977), 13 backend-bundle tests (PR #1021), and a Rust regression test (PR #1020).
- None of these is checked in the installed app yet.
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.74 is included.

## 繁體中文

### 瀏覽器
- 登入 ChatGPT 後，「瀏覽器」分頁不會再不停自行重新整理，直至出現「Too many requests」（429）。應用程式在 ChatGPT 頁面內檢查登入狀態，而該檢查收到 429 時會被當作已登出。下一次正常回應便被當作新的登入，觸發橋接連線，而橋接連線會重新載入頁面，令 ChatGPT 收到更多請求，回應更多 429。現在若檢查得不到真正的回應（429、伺服器錯誤、安全檢查或逾時），已登入的頁面會保持登入。真正的已登出回應仍會令頁面登出（PR #1017）。

### 對話
- 經 CPA 轉送的 Codex 對話會保留所選的推理強度，與 Claude Code 一樣。過去 Sol 的「Extra High」及「Max」，以及 DeepSeek 的「Max」會在對話開始前遺失。以卡片本身模型執行的指令審查會使用該模型的推理強度；其他審查者則保留其自身設定（PR #1023）。
- 已取消或回應傳送失敗的批准卡片可以再次點擊。過去它會一直停用（PR #1022）。
- 對話框與分支列的間距由 6 px 縮減至 2 px，兩者在每個窗格寬度下都會對齊（PR #971）。
- 「Preview Read」現在亦會傳回原生視覺化的公開狀態，讓代理可讀取未以文字顯示的選取內容。私人狀態不會傳回（PR #1019）。

### 設定
- 已編輯但未儲存的 CPA 設定不會再被背景狀態更新清除（PR #1018）。

### ChatGPT 連接器
- 連接器設定只會為已驗證的工作區擁有者建立連接器，並在每次變更前再次檢查同一帳戶、工作區、角色及通道。已確認的連線會保留其狀態（PR #977）。

### 執行階段
- 停止後端套件監察器時，會取消它已開始的掃描，因此該掃描不會在關閉期間安裝套件或重新啟動後端（PR #1021）。
- 取消事件訂閱時，會先儲存變更，才從記憶體中移除訂閱。過去若儲存失敗，重試會回報成功，而訂閱會在下次啟動時重新出現（PR #1020）。

### 0.8.74 亦已包含（其說明未列出）
- 對話壓縮期間排隊的訊息會在壓縮完成後重新讀取。期間你清除、編輯或取代的訊息不會再以舊內容送出（PR #1014）。

### 驗證及限制
- 瀏覽器：7 項新測試涵蓋 429 迴圈（429、502、請求失敗及安全檢查都保持登入；空的工作階段及 401 仍會登出）。載入瀏覽器程式碼的其餘 11 個測試檔案共 174 項測試均通過。修正尚未在已安裝的應用程式中以真實的 429 檢查（PR #1017）。
- 其他 PR 已在各自的 PR 中測試：48 項渲染程序測試（PR #1022）、40 項渲染程序連接測試（PR #1018）、51 項預覽測試及實際 Electron 執行（PR #1019）、164 項連接器測試（PR #977）、13 項後端套件測試（PR #1021），以及一項 Rust 回歸測試（PR #1020）。
- 以上各項尚未在已安裝的應用程式中檢查。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.74 的所有內容。
