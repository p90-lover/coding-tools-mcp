# Coding Tools 0.8.75

## English

- ChatGPT session checks that receive a 429, server error, security challenge or timeout keep an already signed-in page signed in. A real signed-out session still signs it out (#1017).
- Publication approval verifies the repository and push destination independently. Protected or ambiguous pushes, shell wrappers and child-agent requests cannot gain approval just because a timer expires. The packaged backend includes the Git inspection module (#998).
- Chat composer spacing and workspace-owner connector checks are reconciled with current account state. Team refreshes preserve unsaved edits (#971, #977, #1016).
- Service settings preserve edits during refresh; Preview Read returns bounded public `modelContent` from native visualizations and excludes private UI state. Event unsubscribe saves successfully before changing live state (#1018, #1019, #1020).
- Stopping backend bundle discovery invalidates pending scans. Approval cards permit an explicit retry after a cancelled or failed attempt (#1021, #1022).
- Native CPA Codex sessions and same-model command reviews preserve the selected reasoning effort (#1023).
- Dependency-folder ownership survives failed saves and uncertain remote responses, so disabling reuse can still remove app-managed entries while preserving user entries (#1024).
- Windows DEV profiles reject case-only aliases of the production home (#1026).
- Automatic render-error recovery pauses if its reload budget cannot be read or saved; manual Reload remains available (#1027).
- FRP configuration correctly escapes quotes, backslashes and control characters, preventing invalid settings or altered tokens (#1028).

### Verification

Focused regressions cover the merged changes, including actual approval callbacks and backend bundle installation/loading. GitHub Actions builds the Windows installer, portable archive and updater packs from the release source. Installed-app, model, live-account and tunnel acceptance remain pending. Includes all changes in 0.8.74.

## 繁體中文

- ChatGPT 工作階段檢查收到 429、伺服器錯誤、安全檢查或逾時時，已登入頁面會保持登入。真正的登出回應仍會登出（#1017）。
- 發佈審批會獨立核實儲存庫及推送目的地。受保護或不明確的推送、Shell 包裝指令及子代理要求，不會因計時器到期而獲准。後端套件亦包含 Git 檢查模組（#998）。
- 對話輸入框間距及工作區擁有者連接器檢查已與目前帳戶狀態整合；團隊重新整理會保留未儲存的編輯（#971、#977、#1016）。
- 服務設定在重新整理時保留編輯；Preview Read 可傳回原生視覺化面板的公開 `modelContent`，內容大小受限，並排除私人介面狀態。取消事件訂閱會先成功儲存，再更改執行中狀態（#1018、#1019、#1020）。
- 停止後端套件掃描後，尚未完成的掃描會失效。審批取消或失敗後，可再次明確點擊重試（#1021、#1022）。
- 原生 CPA Codex 工作階段及使用相同模型的指令審查會保留所選推理強度（#1023）。
- 依賴資料夾的擁有權記錄可在儲存失敗或遠端回應不明確後恢復，停用重用時仍可移除應用程式管理的項目，並保留使用者項目（#1024）。
- Windows DEV 設定檔會拒絕僅大小寫不同的正式環境目錄別名（#1026）。
- 若無法讀取或儲存渲染錯誤的重新載入次數記錄，自動復原會暫停；仍可手動重新載入（#1027）。
- FRP 設定會正確跳脫引號、反斜線及控制字元，避免設定無效或權杖內容改變（#1028）。
