# Coding Tools v0.8.157

## English

- **An account whose sign-in ChatGPT rejected says so, and Sign in again works.**
  - ChatGPT can revoke an account's sign-in while the account still looks signed in. Its card said "Signed in", and Sign in only showed the page.
  - Once Connect MCP finds that ChatGPT no longer accepts the sign-in, the card shows **ChatGPT rejected this sign-in** with a **Sign in again** button. On Windows it signs the account in again through Chrome and replaces the rejected sign-in, after the usual check that Chrome is signed in to the same account.
- **Verification:** the new tests fail without the change and pass with it. The browser host, account card and preload suites pass, and TypeScript is clean on the changed files. Not checked in the installed app before release.

Everything in 0.8.156 is included.

## 繁體中文

- **ChatGPT 拒絕某帳號的登入時，卡片會直接說明，「Sign in again」也能正常運作。**
  - ChatGPT 可能撤銷某帳號的登入，但該帳號看起來仍是已登入。過去它的卡片顯示「Signed in」，按「Sign in」也只會顯示頁面。
  - 「Connect MCP」發現 ChatGPT 不再接受該登入後，卡片會顯示「ChatGPT rejected this sign-in」並提供「Sign in again」按鈕。在 Windows 上，它會透過 Chrome 重新登入該帳號，並在照常確認 Chrome 登入的是同一個帳號後，取代被拒絕的登入。
- **驗證：** 新測試在沒有此變更時失敗、加入後通過。browser host、帳號卡片與 preload 測試通過，變更的檔案通過 TypeScript 檢查。發佈前沒有在已安裝的應用程式中檢查。

包含 0.8.156 的所有變更。
