Coding Tools 0.8.14

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Fewer freezes on a busy disk:

- The app no longer hangs for seconds while the disk is saturated. Starting Agent Orchestrator, checking its daemon, polling ChatGPT and long-running Codex requests, reading the model lists, looking up rtk, stopping or inspecting processes, and saving the window's position all run off the main thread now.
- Agent Orchestrator's daemon is hashed once and remembered, instead of being read in full on every start.
- Settings files that did not change are no longer rewritten, and a healthy long-running Codex request saves its keep-alive state every 10 minutes instead of on every check.

Less background work:

- The branch bar and the Overview's change count pause while the window is in the background, and catch up when you come back to it.
- The Overview counts changes without building the full diff.
- Agent Orchestrator no longer re-reads every untracked file in a project each time it lists changes. Projects with tens of thousands of untracked files (build output, trash folders) kept the disk busy all the time.
- Agent Orchestrator answers the chat preview it polls four times a second from an index, reading a few pages of its database instead of about 150.
