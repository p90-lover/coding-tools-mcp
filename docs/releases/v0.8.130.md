# Coding Tools v0.8.130

## English

### Context, quotas and API credits

- The context panel now leads with the current provider and plan, compact 5-hour and weekly quota meters, and reset times. Select a CPA Codex account to inspect its own plan and limits. Context usage remains visible; token details, tool servers and provider spend are folded away.
- DeepSeek API accounts can show the balance reported by the official balance endpoint. OpenRouter shows the key's remaining budget, explicitly distinguished from account credits. Unsupported providers say **Not exposed**; estimated token spend is never presented as remaining credit.
- Balance requests use only supported official HTTPS hosts, reject redirects, ignore disabled or masked keys, and return sanitized amounts to the renderer. Verification uses fixtures, not live paid model requests.

### Model discovery and enabled accounts

- CPA's standard model list is merged with its enhanced capability catalog. Custom API model IDs that appear only in the standard list now load automatically, while enhanced context-window metadata and provider ownership are preserved.
- Enabled CPA accounts are detected on the next catalog refresh. Explicitly disabled providers remain unavailable; disabling an account again removes its models rather than reviving them from remembered history.
- The existing quota/reset-aware smart routing in bundled Provider Manager 0.7.1 remains in place. This release does not introduce a second account scheduler, override explicit account pins or route across incompatible provider pools.

### Verification

- Fifteen focused checks passed for context rendering, supported balances, complete model catalogs, disabled-provider handling, automatic account enable/disable refresh and existing context-meter behavior. The integrated renderer type check passed.
- The unchanged panel has prior Preview interaction coverage for account selection, folded details, API balances and a narrow dark layout. No fresh live Preview or real-account balance check was performed for this release.
- Release identity tests and the coordinated pull request's required CI checks gate publication. GitHub Actions builds the exact merged commit, verifies the packaged application and reads uploaded release assets back against their checksum manifest before publication.
- All changes from 0.8.129 are included. Local installation is coordinated through the supported updater; active chats are not force-closed.

## 繁體中文

### 上下文、配額與 API 餘額

- 上下文面板現在優先顯示目前的供應商與方案，並以精簡的進度條呈現 5 小時、每週配額及重設時間。可選擇 CPA Codex 帳號，查看該帳號自己的方案與限制。上下文用量仍直接顯示；token 明細、工具伺服器與供應商花費預設收合。
- DeepSeek API 帳號可顯示官方餘額端點回報的金額。OpenRouter 顯示該金鑰的剩餘預算，明確區別於帳戶點數。不支援的供應商會顯示 **Not exposed**；不會把估算的 token 花費當成剩餘點數。
- 餘額查詢只會連線至支援的官方 HTTPS 主機，拒絕重新導向，略過停用或已遮蔽的金鑰，並只將清理過的金額回傳至畫面。驗證使用測試資料，未發送付費模型請求。

### 模型探索與啟用帳號

- 合併 CPA 的標準模型清單與增強能力目錄。只出現在標準清單中的自訂 API 模型現在會自動載入，同時保留增強目錄的上下文視窗資料及模型所屬供應商。
- 啟用的 CPA 帳號會在下次目錄重新整理時被偵測。明確停用的供應商仍不可用；再次停用帳號時，也不會從歷史記錄恢復其模型。
- 保留內附 Provider Manager 0.7.1 既有的配額及重設時間智慧路由。此版本不新增第二套路由排程器、不覆寫指定帳號，也不會跨不相容的供應商帳號池路由。

### 驗證

- 15 項聚焦檢查通過，涵蓋面板呈現、支援的餘額、完整模型目錄、停用供應商、帳號啟用及停用後的自動重新整理，以及原有上下文指示器行為。整合後的畫面型別檢查通過。
- 未變更的面板已有先前的 Preview 互動驗證，涵蓋帳號選擇、收合明細、API 餘額，以及深色窄版配置。本次發行沒有重新執行即時 Preview，也沒有查詢真實帳號餘額。
- 發佈前須通過版本識別測試及整合拉取請求所需的 CI 檢查。GitHub Actions 會建置確切的合併提交、驗證封裝應用程式，並在發佈前重新下載資產，依校驗清單檢查。
- 包含 0.8.129 的所有變更。本機安裝透過支援的更新程式協調，不會強制關閉進行中的對話。
