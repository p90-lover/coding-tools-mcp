# Coding Tools v0.8.145

## English

### Native Codex Guardian for supported shell approvals

- With **Allow quota-based reviews** off, **Approve for me** and **Let the model judge** no longer send approval requests to CPA. Unsupported or unresolved calls wait for you instead of silently spending quota.
- With the stable Codex CLI from **App Plugins** and a current direct ChatGPT CLI sign-in, eligible Claude Code shell requests can use native Codex Guardian. The managed Claude adapter records the attached working directory before tool use; the app confirms the original pending call still matches before sending a verdict. The reviewer does not execute the proposed command. Harness-required human approvals, unknown execution context, and MCP/screen actions are not auto-approved by this route.
- Verification: 14 focused regressions passed. The pinned Claude ACP source transformation passed syntax checking and the Go overlay passed its apply check. An isolated real Codex 0.171.0 review returned a low-risk allow with explicit authorization; it did not execute the action or change the displayed quota counters. This is not a per-call billing guarantee.

Everything in 0.8.144 is included.

## 繁體中文

### 支援的 Shell 請求可使用原生 Codex Guardian 審查

- 關閉 **Allow quota-based reviews** 時，**Approve for me** 和 **Let the model judge** 不再透過 CPA 審查權限請求。不支援或無法確認的請求會等待你決定，不會自動耗用額度。
- 透過 **App Plugins** 安裝穩定版 Codex CLI，並直接使用 ChatGPT 登入 CLI 後，符合條件的 Claude Code Shell 請求可使用原生 Codex Guardian。受管理的 Claude 介面會在執行工具前記錄執行目錄；應用程式在送出判定前會再次確認仍是同一筆待處理請求。審查不會執行指令。需要人工確認、執行環境不明、MCP 或畫面操作的請求，不會經由此途徑自動核准。
- 驗證：14 項重點測試通過；已固定版本的 Claude ACP 轉換通過語法檢查，Go 修補可正常套用。以隔離的 Codex 0.171.0 實測，審查對明確授權的低風險請求回傳核准，未執行指令，亦未使顯示的額度比例變動；這不是每次請求的計費保證。

包含 0.8.144 的所有變更。
