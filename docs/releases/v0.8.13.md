Coding Tools 0.8.13

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Split view, as in Claude Code:

- Open a chat beside the one you have open: **Open in ▸ Split view** on its right-click menu (key 1), Ctrl-click it in the sidebar, or drag it onto the chat area. While you drag, a badge shows where it opens: **Split view** for a new place, **Open here** to replace a chat.
- Chats tile into an adaptive grid: one column per 360 px of width, up to five, each column one chat or a top and a bottom one. Drag the dividers to resize, double-click one to reset it. The chat you are not using is dimmed.
- A chat clicked in the sidebar opens in the focused pane, or focuses the pane already showing it.
- **New chat opens one more pane** while the window is split, instead of replacing a chat.
- **Close split view** is on every pane (its X, the ⋯ menu, Ctrl+Alt+W). Closing the window's own chat moves the next pane's chat into its place.
- Keys: Ctrl+] and Ctrl+[ for the next and previous pane, Ctrl+Alt+Arrow for the pane that way, Ctrl+Alt+\ and Ctrl+Alt+- for a new chat on the right or below.
- Your split layout is restored when the app starts.

Chats that get stuck:

- A turn that says "may be stuck" has a **Restart** button: it stops the turn and has the same agent carry on where it left off, without rerunning the call that never returned.
- A turn stuck on a tool call that never returns is restarted by shutting its agent down when it cannot be interrupted. Every "keep going" used to fail with "stop needs attention" and come back to the composer. The agent's session is kept, so it resumes with what it already knows.

Faster launches:

- A chat no longer waits minutes on a warm agent that never takes its message: past 10 seconds a fresh agent starts with it.
- The first chat in a project after the app starts no longer waits about 20 seconds before its agent is asked for.
- Agent Orchestrator no longer re-reads every usage source each time another Claude Code session writes its transcript (it held 50–100% of a core).

Also:

- A Cline Pass model Cline no longer serves fails at once with "model not found", instead of retrying for about 4 minutes while the chat looked stuck launching.
- Steered and queued messages sit above the project's branch bar, next to the chat box.
