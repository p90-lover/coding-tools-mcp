# Coding Tools v0.8.144

## English

### Computer use: keep the action result when its image is too large

- Snapshots and follow-up images now have an image budget that leaves room for the rest of the reply. If a reply is still too large, it omits oversized accessibility details first. If the image still cannot be sent after an action, the reply keeps the action or sequence receipt and asks the agent to observe again, not replay the input.
- A screenshot-only request and automatic follow-up snapshots no longer ask Codex for accessibility text. Replies include the native screenshot dimensions for callers using native screenshot coordinates.
- A sequence whose current step was never sent, but has a terminal receipt, no longer offers to resume that same step. Completed and uncertain input still never replay automatically. Local desktop approval, Stop and native policy are unchanged.
- Seven focused Rust checks passed against the changed production functions with test data. They cover size handling, screenshot-only follow-up requests and sequence receipts. Live Codex snapshot, OS input and cursor behavior were not verified in these checks.

### App Plugins: manage the official Codex CLI on Windows

- The new Codex CLI entry checks and installs the official stable Windows build in Coding Tools' managed tools directory. Manual install and opt-in automatic updates verify the package checksum and CLI version before selecting it. The app leaves global or explicit CLI installations, credentials and running chats alone.
- The focused App Plugins and CLI installer tests passed (22 total); the pinned Windows x64 package was also checked by SHA-512, extracted in isolation and checked for the expected executable version. This is not a change to approval routing or experimental Codex review.

### GPT Browser: reveal a signed-out page

- **Show browser** puts aside the app's sign-in screen so you can see the browser page; **Hide browser** brings the prompt back. The website still controls its own login. A focused regression and the real toolbar in Preview passed with a test account fixture.

### Windows: open agy without selecting a workspace

- **Open agy** can start its isolated Antigravity CLI profile before a workspace is selected. It still requires the configured proxy and a separate sign-in if the profile is empty. Fifteen focused tests and an isolated Windows terminal smoke check passed.

### Assistant instructions

- A requested plan followed by execution is one task. Start executing after planning, finish independent in-scope work if a step is blocked, and preserve permission and verification gates.

Includes everything in v0.8.143.

## 繁體中文

### 電腦操作：畫面太大時，仍保留操作結果

- 截圖與操作後的畫面會限制圖片大小，以保留回覆其他欄位所需的空間。若回覆仍過大，會先省略過大的無障礙資訊。操作後若仍無法傳送圖片，回覆會保留操作或序列的結果，請助理重新觀察，不要重送輸入。
- 僅要求截圖，以及操作後自動擷取畫面時，不再向 Codex 要求無障礙文字。回覆提供原生截圖尺寸，供使用原生座標的呼叫端換算。
- 如果序列中的步驟確定未送出，且已有不可重試的結果，就不再提示從同一步繼續。已送出或結果不確定的輸入仍不會自動重播。本機桌面權限、停止控制及原生安全規則維持不變。
- 七項針對實際 Rust 函式的測試通過，使用的是測試資料，涵蓋回覆大小、僅擷取畫面的後續要求，以及序列結果。這些測試沒有驗證實際 Codex 截圖、Windows 輸入或游標行為。

### 應用程式外掛：管理 Windows 上的官方 Codex CLI

- 新增 Codex CLI 項目，可查詢並安裝官方 Windows 穩定版至 Coding Tools 管理的工具目錄。手動安裝或選擇自動更新時，會先驗證套件雜湊與執行檔版本。這不會變更全域或手動指定的 CLI、登入資料或執行中的對話。
- 通過 22 項外掛管理及 CLI 安裝測試，並驗證 Windows x64 套件的 SHA-512、隔離解壓與執行檔版本。此變更不調整權限審查路徑，也未啟用實驗性的原生審查。

### GPT Browser：未登入時也能顯示網頁

- 按 **顯示瀏覽器** 可收起應用程式的登入提示並查看網頁，按 **隱藏瀏覽器** 可返回提示。網站仍依原本方式要求登入。已透過測試帳戶資料驗證回歸測試與預覽中的實際工具列。

### Windows：未選擇工作區也能開啟 agy

- **開啟 agy** 可在未選擇工作區時啟動獨立的 Antigravity CLI 設定檔。仍需設定代理伺服器；若設定檔沒有登入資料，需另外登入。已通過十五項針對性測試及隔離的 Windows 終端機檢查。

### 助理指令

- 使用者要求規劃後執行時，兩者是同一項工作。規劃完成即開始執行；有步驟受阻時，仍完成範圍內可獨立處理的工作，且保留權限與驗證關卡。

包含 v0.8.143 的所有內容。
