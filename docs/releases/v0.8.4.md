Coding Tools 0.8.4

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Speed and stability:

- The headless service no longer copies the whole app state on every read. While a chat ran, it sat at about a third of a CPU core; a run read now costs about a tenth of what it did.
- Tabs you have left stop polling in the background, and the Terminal pane reuses the chat's latest conversation read instead of fetching it again.
- Switching projects no longer freezes the app.
- AO's database gives back its empty space before AO starts, and AO, the bridge and CPA keep no log files.
- Chat agents get Claude Code-sized tool results, a chat's handoff summary is reused, and reviewer verdicts, titles and recovery advice are asked for once, not on every turn.

Chat:

- A step that lost the local proxy or the browser retries itself, and a reviewer keeps its earlier cycles, folded, so you can follow how a review got where it is.
- A failed step's card says which step failed and why.
- Finished turns keep their tool calls, and chats can be dragged into place in every sidebar list, Archived too.
- A steer reaches a turn whose reasoning hung, and Claude Code keeps the effort you chose.
- RTK compacts the commands chat agents run (Runtime > RTK).
- Antigravity takes the three permission modes, uses bare model names and keeps a model's own effort.

Fixes:

- Background chat calls (the archived chats list, agent pre-warm, the Retry automatically switch) no longer fail with "Click into the Coding Tools window" when the window is not focused.
- A project's branch reads as unknown, instead of failing, when Windows will not start git.

Everything in 0.8.3 is included.
