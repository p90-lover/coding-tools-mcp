# Coding Tools 0.8.97

## English

### Orchestrator model picker
- **Every provider's models in one list.** A card's model list used to show only its own agent's models, so Antigravity's Gemini models (and other providers' models) were missing unless that agent was picked first. It now lists every installed agent's models once, grouped by who serves them (Antigravity, Claude, Kimi, DeepSeek, Codex, Zhipu, Qwen, MiniMax, Grok, Web GPT…). Picking a model another agent runs moves the card to that agent.
- **Logos.** Every model shows its maker's logo, and every group shows its agent's or provider's logo. New marks for GLM (Zhipu), MiniMax and StepFun; Kimi, Qwen, Mistral and Llama models use their brands' marks too. A model that more than one agent runs shows those agents' logos to switch between.
- **Slimmer and cleaner.** Model, agent, effort and context window now sit in one 28 px row with no labels or frame. The explanations that were printed under the boxes are in their tooltips. This applies on the Team page, in the role editor, and in the New mission and Add worker sheets.

### Chat
- **Codex-style replies.** A single chat's answer ends with one quiet line (model · time · files changed), with copy and retry on hover; steps, LLM time and tokens move to the time's tooltip. Finished work folds under "Worked for 1m 53s" ("Failed after…", "Stopped after…"), keeping the agent's narration and hiding its tool calls until opened. A turn with one agent draws no header, so the request, steers and work sit in one column (#1104).
- **Harness menu.** The harness menu is a slim strip of logos; names show on hover; every harness is listed in one scrolling column that fades at its ends (#1103).

### Browser
- **Account checks stay on the normal ChatGPT home page.** Connector and account checks no longer switch the Browser tab to Temporary Chat; your task chats keep their own privacy setting (#1105).

### Verification and limitations
- GitHub Actions was unavailable for this release (no runs since 2026-11-06), so no CI ran. Verified locally instead on the merged source: desktop typecheck and the full desktop test suite; the model picker was also checked in a browser preview with stand-in model lists for four agents, not in the installed app.
- Built locally from main with `bun run package:win` and published to GitHub Releases.
- Includes all changes in 0.8.96.

## 繁體中文

### Orchestrator 模型選擇器
- **所有供應商的模型集中在一個清單。** 以往卡片的模型清單只顯示其代理的模型，因此除非先選擇該代理，否則看不到 Antigravity 的 Gemini 模型（及其他供應商的模型）。現在清單會列出每個已安裝代理的模型，每個模型只出現一次，並按提供者分組（Antigravity、Claude、Kimi、DeepSeek、Codex、智譜、Qwen、MiniMax、Grok、Web GPT 等）。選擇由其他代理執行的模型時，卡片會改用該代理。
- **標誌。** 每個模型都顯示其開發商的標誌，每個分組都顯示其代理或供應商的標誌。新增 GLM（智譜）、MiniMax 及 StepFun 的標誌；Kimi、Qwen、Mistral 及 Llama 模型亦使用其品牌標誌。可由多個代理執行的模型會顯示這些代理的標誌以供切換。
- **更精簡、更清爽。** 模型、代理、推理強度及上下文視窗現在排成一行，高 28 px，沒有標籤或外框。原本印在方框下的說明已移至提示文字。此變更適用於團隊頁面、角色編輯器，以及「新任務」和「新增工作者」表單。

### 對話
- **Codex 風格的回覆。** 單一對話的回答以一行簡潔資訊結尾（模型 · 時間 · 變更的檔案），游標停留時顯示複製及重試；步驟、LLM 時間及 token 數移至時間的提示文字。完成的工作會收合為「Worked for 1m 53s」（「Failed after…」、「Stopped after…」），保留代理的說明，工具呼叫則在展開後才顯示。只有一個代理的回合不再顯示標題，因此請求、引導訊息及工作排在同一欄（#1104）。
- **Harness 選單。** Harness 選單改為一條精簡的標誌列；名稱在游標停留時顯示；所有 harness 列在同一個可捲動的欄中，兩端淡出（#1103）。

### 瀏覽器
- **帳戶檢查停留在一般的 ChatGPT 首頁。** 連接器及帳戶檢查不再把瀏覽器分頁切換到臨時對話；任務對話仍保留其各自的隱私設定（#1105）。

### 驗證及限制
- 此版本發佈時 GitHub Actions 無法使用（自 2026-11-06 起沒有執行），因此沒有執行 CI。改為在合併後的原始碼上於本機驗證：桌面型別檢查及完整的桌面測試；模型選擇器亦已在瀏覽器預覽中以四個代理的模擬模型清單檢查，並未在已安裝的應用程式中檢查。
- 於本機以 `bun run package:win` 從 main 建置，並發佈至 GitHub Releases。
- 包含 0.8.96 的所有變更。
