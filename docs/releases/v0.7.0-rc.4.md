# Coding Tools v0.7.0-rc.4

## English

v0.7.0-rc.4 carries forward the complete v0.7.0-rc.3 multi-provider, Codex Router, Paseo, Anneal, proxy, and subagent integration. This hotfix repairs the packaged Electron **Provider Center** so the visible GUI now uses the same encrypted multi-account Provider Hub and execution planner as the backend.

### Provider Center account wiring

- Replaces the active renderer-only provider list with the encrypted Provider Hub surface.
- Supports multiple accounts for Codex OAuth, Claude OAuth, ChatGPT Web, OpenAI API, Anthropic API, Gemini API, AI Studio Reverse Proxy, Gemini Reverse Proxy, OpenRouter, AIStudioToAPI, CLIProxyAPI / Antigravity, CommandCode Proxy, Ollama, and custom OpenAI-compatible providers.
- Uses the typed Electron main-process APIs for account save, login launch, default selection, enable/disable state, and archival.
- Keeps account credentials transient in the renderer and stores them only through the encrypted main-process account boundary.
- Removes direct provider model requests and provider persistence from the active renderer surface.
- Preserves the superseded legacy component for audit; no source file or branch is deleted.

### Codex Router execution integrity

- Paseo and Anneal dispatch now names the selected Provider Hub account explicitly.
- Strict provider/account/model validation remains fail-closed.
- Optional fallback can select the next approved healthy account through the Codex Router planner.
- Account, provider, and global proxy policy precedence remains enforced.
- The renderer receives an ID-only credential handle; raw OAuth tokens, API keys, and proxy passwords remain outside renderer snapshots and execution plans.

### Existing v0.7 capabilities retained

- Multi-provider Codex Router subagents and managed native V2 `agent_type` definitions.
- Paseo Orchestrator and Anneal Tasks Electron surfaces.
- ChatGPT Web as an approved routed task model.
- Global, provider, and account proxy profiles with Paseo/Anneal scopes.
- CommandCode Proxy, OpenRouter, Ollama, Gemini-compatible, OpenAI-compatible, and image-generation adapters.
- Traditional Chinese control-center localization and optional GitHub/X onboarding links.
- Authenticated Rust headless service and typed Electron IPC boundary.

### Release integrity

- Windows x64 installer is built from one exact source SHA.
- Provider Hub regression contracts, Electron runtime syntax, strict TypeScript, production renderer build, package contents, launcher smoke, and release-asset readback are validated before publication.
- Release assets include the installer, `SHA256SUMS.txt`, `provenance.json`, and `validation-evidence.json`.
- Temporary and retained evidence stays under `aiTemp/` and `aiTemp/Trash/`.
- The per-user installer does not request administrative elevation.

### Validation boundary

Automated validation does not spend provider quota. Live acceptance with real OAuth identities, browser sessions, paid API quotas, and external Paseo/Anneal services remains an explicit manual boundary.

## 繁體中文

v0.7.0-rc.4 保留 v0.7.0-rc.3 完整嘅多供應商、Codex Router、Paseo、Anneal、代理同 subagent 整合。今次 hotfix 修正已打包 Electron **供應商中心**，令可見 GUI 真正使用同 backend 相同嘅加密多帳戶 Provider Hub 同 execution planner。

### 供應商中心帳戶接線

- 將目前使用中、只存在 renderer 嘅供應商清單，替換成加密 Provider Hub 介面。
- 支援為 Codex OAuth、Claude OAuth、ChatGPT Web、OpenAI API、Anthropic API、Gemini API、AI Studio Reverse Proxy、Gemini Reverse Proxy、OpenRouter、AIStudioToAPI、CLIProxyAPI／Antigravity、CommandCode Proxy、Ollama 同自訂 OpenAI-compatible provider 管理多個帳戶。
- 透過 typed Electron 主程序 API 處理帳戶儲存、開啟登入、預設帳戶、啟用／停用同封存。
- Credential 只會短暫存在 renderer 記憶體，並只經加密主程序帳戶邊界儲存。
- 目前使用中嘅 renderer 唔再直接請求 provider model，亦唔再自行持久化 provider。
- 已取代嘅舊 component 仍然保留作審計；冇刪除任何 source file 或 branch。

### Codex Router 執行完整性

- Paseo 同 Anneal dispatch 而家會明確指定所選 Provider Hub 帳戶。
- 嚴格 provider／account／model 驗證繼續 fail closed。
- 可選 fallback 可以經 Codex Router planner 選擇下一個已批准健康帳戶。
- 繼續執行 account、provider 同 global proxy policy 優先次序。
- Renderer 只會收到 ID-based credential handle；raw OAuth token、API key 同 proxy password 唔會進入 renderer snapshot 或 execution plan。

### 保留現有 v0.7 功能

- Multi-provider Codex Router subagent 同 managed native V2 `agent_type`。
- Electron Paseo Orchestrator 同 Anneal Tasks 介面。
- ChatGPT Web 作為已批准 routed task model。
- 支援 Paseo／Anneal scope 嘅 global、provider 同 account proxy profile。
- CommandCode Proxy、OpenRouter、Ollama、Gemini-compatible、OpenAI-compatible 同生圖 adapter。
- 繁體中文 Control Center，同可選 GitHub／X onboarding 連結。
- 已認證 Rust headless service 同 typed Electron IPC boundary。

### Release 完整性

- Windows x64 installer 由單一精確 source SHA 建立。
- 發佈前會驗證 Provider Hub regression contract、Electron runtime syntax、strict TypeScript、production renderer build、package contents、launcher smoke 同 release asset readback。
- Release asset 包括 installer、`SHA256SUMS.txt`、`provenance.json` 同 `validation-evidence.json`。
- 臨時同保留證據維持喺 `aiTemp/` 同 `aiTemp/Trash/`。
- Per-user installer 唔會要求管理員權限。

### 驗證邊界

自動驗證唔會消耗 provider quota。使用真實 OAuth identity、browser session、付費 API quota 同外部 Paseo／Anneal service 嘅 live acceptance，仍然係明確人工驗收邊界。
