Coding Tools 0.7.0-rc.27

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Fixes:

- The local service starts correctly when the Windows profile folder has been moved through a directory junction.
- Projects retry a failed startup lookup and refresh when the app regains focus, so a temporary error no longer leaves the list empty.
- Startup failures show a short, redacted service error instead of only an exit code.

Everything in rc.26 is included.
