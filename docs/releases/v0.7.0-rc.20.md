Coding Tools 0.7.0-rc.20

Updates in-app from rc.19. If you are on rc.18 or earlier and "Update" fails ("getaddrinfo ENOTFOUND github.com", "connect EACCES"), install this release once by hand: download Coding.Tools_0.7.0-rc.20_win_x64_portable.zip (unzip it over your portable folder, with the app closed) or Coding.Tools_0.7.0-rc.20_win_x64.exe (the installer).

New:
- Runtime › Subagents: set up helpers a chat's agent can start for a piece of its work (exploring the code, an independent change, a review). Each has a name, what it is for, instructions and its own model (or the page's default model); the page also sets how many run at once and per chat, a time limit, and their permissions. Chat agents (Claude Code, Codex, opencode) get tools to start a subagent, check on it and read its report; several can run in parallel. Subagents run unattended: their requests are approved for them, except what the command approver's safety rules block. The page lists running and recent subagents with their reports, and can stop one.

Fixes:
- Chat: a message sent to an agent that had stopped responding (a model request that never came back) now stops that turn and starts a new one with your message; "keep going" did nothing before.
- Chat: a message sent while the agent is still starting waits for it instead of failing, and stopping a chat while its agent starts cancels the start.
- Chat, "Approve for me": the 20-second auto-answer never allows a command the safety rules block, also when the command is very long or arrives inside a tool's arguments, and it waits for a reviewer still deciding.
- Chat: in a project whose chats work in the project folder, the agent's file, search and terminal tools work again ("The session root cannot be the workspace's own checkout", "This chat's session workspace is not one of AO's worktrees").
- Chat: the app's search tool skips what .gitignore ignores and returns what it found so far instead of failing when a search takes too long.
- Chat, preview browser: agents are told up front to open and check the pages they build in the chat's preview; opening a page switches the side panel to Preview; a page on localhost is retried on 127.0.0.1 when the connection is reset; the tools server no longer drops a reused connection (ECONNRESET).
- Windows: chat agents' hosts get a console and a complete environment (SystemRoot, TEMP, ComSpec, a capped PATH), which Git Bash needs to start commands (0xC0000142 / "fork: Resource temporarily unavailable").
- The window restarts on its third crash in two minutes, and is reloaded if the restart cannot happen.
- Updates: a request stalled behind a proxy fails and is retried instead of hanging, and an abandoned download closes its connection.
- Menu arrows (⌄) are drawn and centred on their text.

Everything in rc.19 is included.
