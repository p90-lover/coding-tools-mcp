# Coding Tools v0.8.152

## English

- **Approve for me** now tries native Codex Guardian for eligible shell approvals even when quota-based reviews are on. If Guardian cannot decide, those requests wait for you instead of falling back to CPA. Unsupported requests and separately enabled Autobot reviews still follow their own review settings.
- Queued messages resume when the agent is ready, even if readiness was reported during a retry. Delivery continues without an open chat window. An earlier queued message cannot answer a question that appeared after it was saved.
- New and reconnected chats keep the current request separate from earlier replies and summaries. Recovery reasserts the saved request, and goal checks no longer count missing progress as progress. `chat_read` accepts a known chat ID or recent Agent Orchestrator session ID directly; cross-project reads still require approval.

Everything in 0.8.151 is included.

## 繁體中文

- **代我核准** 現在會優先以原生 Codex Guardian 審查符合條件的 Shell 請求，即使已開啟配額審查也一樣。若 Guardian 無法判定，請求會等待你決定，不會改由 CPA 消耗配額。不支援的請求及另行啟用的 Autobot 仍遵循各自的審查設定。
- 即使代理程式已就緒的通知在重試期間送達，排隊的訊息也會繼續傳送，不必開著聊天視窗。先前排隊的訊息不會被當成後來問題的答案。
- 開啟或重新連線聊天時，本次請求會與先前的回覆和摘要分開。復原時會重述已保存的請求，目標檢查不再把缺少進度判定視為有進展。`chat_read` 可直接使用已知的聊天 ID 或近期的 Agent Orchestrator 工作階段 ID；跨專案讀取仍需授權。

包含 0.8.151 的所有變更。
