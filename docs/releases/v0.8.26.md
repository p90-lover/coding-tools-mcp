# Coding Tools 0.8.26

## English

### Improvements
- Recover an interrupted ChatGPT Web response in a fresh conversation with preserved native task context, a bounded recovery attempt and replay guards (PR #610).
- Use the Codex bridge's context window for WebGPT and lock the window controls when the bridge reports a fixed limit (PR #612).
- Improve WebGPT tool discovery, retain invocation receipts, and add app calls that require explicit confirmation (PR #596).
- Reduce desktop freezes during timers and approval reviews, and avoid repeated work in activity logs, canvas layout and WebGPT polling (PRs #611 and #617).
- Reduce the risk of API token exposure in MCP-server error logs and preserve environment-variable values exactly as entered (PR #609).
- Correct version-dependent release tests and prevent frozen historical RC pipelines from auto-publishing outdated builds (PR #608).
- Retain the long-horizon /goal, WebGPT context compaction and coding UI features shipped in v0.8.25.

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from the exact merged main commit and confirm CI before publication.
- A live installed-desktop WebGPT long-horizon test is still required; contract tests alone do not establish end-to-end reliability.
- App-call confirmation fails closed when the client lacks supported forms; live ChatGPT confirmation-form behavior remains unverified.
- The separate ChatGPT composer-integrity disconnect shown in user diagnostics needs further live reproduction; interrupted-response recovery alone does not prove that issue resolved.

## 繁體中文

### 更新內容
- 當 ChatGPT Web 回覆中斷時，以受限制的一次新對話嘗試延續原有 Codex 任務，同時保護已執行工具的結果，防止重複執行（PR #610）。
- WebGPT 使用 Codex Bridge 回報的上下文視窗；已知固定上限時，鎖定對話及角色編輯器的視窗設定（PR #612）。
- 改善 WebGPT 工具搜尋、保留執行回執，並新增需要明確確認的應用程式呼叫（PR #596）。
- 減少計時器及審批檢查造成的桌面卡頓，並避免活動紀錄、畫布排版及 WebGPT 輪詢重複處理相同資料（PR #611、#617）。
- 降低 MCP 日誌意外洩漏 API Token 的風險，並完整保留環境變數的輸入值（PR #609）。
- 修正版本測試及舊 RC 發佈程序，防止意外重新發佈過時版本（PR #608）。
- 保留 v0.8.25 已加入的長期 /goal 任務、WebGPT 上下文壓縮及介面改進。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由最終 main 提交編譯及通過 CI 才能公開。
- 仍需在實際安裝的桌面程式測試 WebGPT 長時間任務；通過單元測試不等於端到端可靠。
- 不支援確認表單的客戶端不會執行應用程式呼叫；ChatGPT 的實際確認表單互動仍未完成驗證。
- 截圖所見的 ChatGPT Composer 完整性中斷仍須實機重現；回覆中斷復原不代表它已完全修好。
