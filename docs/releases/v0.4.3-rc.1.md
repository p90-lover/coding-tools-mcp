# v0.4.3-rc.1 — shared workflow and model-free native commands

## English

Adds `workflow_list` / `workflow_update` for the same persistent board used by the local UI. Access is bound to the authenticated listener's workspace ID and canonical root; caller-selected workspaces, foreign task anchors, stale revisions and duplicate task identities are rejected. MCP observations remain distinct from human attestations and cannot advance the twelve review steps. Visible boards refresh without resetting input drafts or interrupting a drag.

Adds `codex_command_exec` through official Codex `command/exec` with a separate local command grant. It fixes the native permission profile to `:read-only`, uses bounded argv/time/output and cached request receipts, and creates no thread or model turn. Commands require the exact official native executable digest verified for this platform's build. Models stay separately opt-in; Stop and live permission changes revoke the native process. Only trusted commands should be used: a read-only native profile is not a workspace-only read boundary or universal network guarantee, and this is not a promise about arbitrary programs' behavior.

Compatibility catalogs now retain truthful write/destructive hints; a client must authorize writing tools rather than being told a writer is read-only. Permission-only changes retain MCP service, endpoint and OAuth identity. Full/Advanced may need one client catalog refresh for the new tools, not connector deletion. Installing an updated executable requires restarting the desktop binary once.

English/Traditional Chinese UI controls, README and a worked AI–human guide explain creation, observation, review and checkpoint flow. Screenshots remain RAM-only. Task notes persist; keep credentials out of them. Existing files and older releases are retained.

Focused release gates cover real native command execution and denied writes with no provider requests, replay/consent, workspace-scoped board updates through the actual data store, live permission revocation, current MCP HTTP/catalog behavior, frontend checks, browser board interaction and actual packaged binaries. Validation artifacts identify exactly which tests ran; they do not certify the user's machine or live ChatGPT connection.

This is a prerelease. Paseo/Anneal adapters remain read-only services, the old standalone sandbox helper remains withheld, and not all proprietary/internal Codex capabilities are exposed. Automatic ChatGPT registration/reauthorization cannot be completed by this desktop app. Windows is publisher-unsigned; macOS is ad-hoc signed and not notarized.

## 繁體中文

新增 `workflow_list`／`workflow_update`，與本機 UI 使用同一個持久化任務看板。範圍綁定經認證監聽服務的工作區 ID 及正規化根目錄；用戶端不能選擇其他工作區，跨工作區卡片、過期修訂版及重複任務身分均會拒絕。MCP 觀察與人類確認分開，不會推進十二個審查關卡。可見看板會刷新，不清空輸入草稿或打斷拖曳。

新增 `codex_command_exec`，透過官方 Codex `command/exec` 執行，須獨立本機命令授權。固定使用 `:read-only`、限制參數／時間／輸出並保留重試收據，不建立會話或模型回合。只接受本平台建置時驗證的官方原生執行檔雜湊。模型仍須另行啟用；停止及即時權限變更會撤銷原生程序。只應執行可信命令：原生唯讀不是只限工作區的讀取界線，也不是全面網絡保證，不能保證任意程式本身的行為。

相容目錄現會保留真實的寫入／破壞性提示，用戶端應批准寫入工具，而不是被告知寫入工具是唯讀。只變更權限仍保留 MCP 服務、端點及 OAuth 身分；新工具可能要在 Full／Advanced 目錄刷新一次，不必刪除連接器。安裝新版執行檔則要重新啟動桌面程式一次。

英文／繁體中文 UI、README 及協作指南說明建立、觀察、審查和檢查點流程。截圖仍只留在記憶體；任務筆記會持久保存，不應包含憑證。既有檔案及舊版本保留。

重點發行關卡包括真實原生命令與拒絕寫入、零供應商請求、重播／授權、透過實際資料庫的工作區看板變更、即時權限撤銷、MCP HTTP／目錄、前端、瀏覽器看板操作及實際安裝包檢查。附件精確記錄測試範圍，不代表你的電腦或實際 ChatGPT 連線已驗證。

本版為候選版本。Paseo／Anneal 仍是唯讀服務介接器，舊獨立沙箱輔助程式仍未納入，也不是所有 Codex 私有／內部功能對等實作。桌面程式不能自動完成 ChatGPT 註冊／重新授權。Windows 沒有發佈者簽署；macOS 是 ad-hoc 簽署，未公證。
