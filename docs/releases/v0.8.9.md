Coding Tools 0.8.9

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Chat:

- A new chat starts faster: its message waits for the agent being warmed for it, instead of starting a second agent beside it (two at once took a minute each on a busy machine; one took 20 seconds).
- A tool call a model writes as text (MiMo and other Qwen-style models) now runs as a real tool call, through Cline Pass and Command Code. A call shown as an example in a code block stays text.
- Approve for me: a request no review ever reached shows to you after about two minutes instead of hiding as "being reviewed"; requests of a chat no loop drives are reviewed; the chat's own tools are covered as they are added.
- While a request waits for an answer, the chat says "Waiting for approval" instead of "Running" or "Analyzing".
- A retried card's earlier attempts show above the new attempt.
- Chat agents are asked to post short progress notes and end with a summary.
- A running tool row's dot sits beside its name.

Everything in 0.8.8 is included.
