# Coding Tools 0.8.93

## English

### Approve for me
- **Reviews use only your Codex Auto Review accounts, never another model.** "Approve for me" asks Codex's review model, and CPA Auto Review serves it on the account you selected, then on your fallback accounts (CPA > Plugins > Codex Auto Review). When that review failed, the app tried other models on its own. Those were the chat's own model, then the first non-Codex model in CPA's list.
  - Seen on 2026-11-04: the review model failed, and in one day 5,493 reviews went to the chats' own OpenCode Go models (GPT-6 Luna, DeepSeek V4.1 Flash) until OpenCode Go's quota was gone. The first non-Codex model in CPA's list was Claude Fable 5.1, which is billed to an API key.
  - Now, if no Codex Auto Review account can answer, the review is tried again (3 tries) and then the request waits for you.
  - A team's Command approver card still tries the model you gave it first, then Codex's review model, and nothing else.
- When CPA doesn't serve the review model at all, the request says so: sign in to a Codex account in CPA and choose it in Plugins > Codex Auto Review.

### Verification and limitations
- Updated tests check that only the review model is ever asked: when it fails, when it answers nothing, when a paid model is listed first, and when CPA doesn't serve it. 474 workflow tests and 315 chat, permission and CPA plugin tests pass. One WebGPT catalog test fails in this checkout, the same as on main.
- Not checked in the installed app. CPA's usage history shows the problem: review-sized calls to OpenCode Go went from about 400 a day to 5,493 on 11-04, followed by 6,074 quota refusals.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.92.

## 繁體中文

### 「替我批准」
- **審查只使用你在 Codex Auto Review 中設定的帳戶，絕不改用其他模型。** 「替我批准」會詢問 Codex 的審查模型，由 CPA Auto Review 先用你選定的帳戶處理，再依次使用你的後備帳戶（CPA > Plugins > Codex Auto Review）。過去審查失敗時，應用程式會自行改用其他模型：先是對話本身的模型，再是 CPA 清單中第一個非 Codex 模型。
  - 2026-11-04 出現的情況：審查模型失敗後，一天內有 5,493 次審查轉到各對話自己的 OpenCode Go 模型（GPT-6 Luna、DeepSeek V4.1 Flash），直至 OpenCode Go 的額度用完。CPA 清單中第一個非 Codex 模型是 Claude Fable 5.1，費用從 API 金鑰扣除。
  - 現在若沒有任何 Codex Auto Review 帳戶能回答，審查會重試（共 3 次），之後請求會等你處理。
  - 團隊的「指令審批」卡片仍會先使用你指定的模型，再使用 Codex 的審查模型，不會使用其他模型。
- 若 CPA 完全沒有提供審查模型，請求會說明原因：請在 CPA 登入 Codex 帳戶，並在 Plugins > Codex Auto Review 中選擇它。

### 驗證及限制
- 更新後的測試確認只會詢問審查模型：包括它失敗、它沒有回答、清單中第一個是付費模型，以及 CPA 沒有提供它的情況。474 項工作流程測試及 315 項對話、權限和 CPA 外掛測試均通過。一項 WebGPT 目錄測試在此 checkout 中失敗，與 main 相同。
- 未在已安裝的應用程式中確認。CPA 的用量記錄顯示了問題：OpenCode Go 的審查大小請求由每天約 400 次增至 11-04 的 5,493 次，之後出現 6,074 次額度拒絕。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.92 的所有內容。
