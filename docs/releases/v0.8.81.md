# Coding Tools 0.8.81

## English

### GPT Browser
- **The GPT Browser looks like the GPT Browser again.** Since 0.8.77 the GPT Browser entry showed the bridge's browser with its old toolbar. It now has the GPT Browser's own single bar: the account picker with Add account, back, forward and reload, the address bar with Go, and zoom. It is still the same browser underneath, so the Codex bridge, sign-in, passkey sign-in, Zero Risk turns, account switching and ChatGPT browser management keep working on the same accounts and sign-ins.
- **Tabs as in any browser.** A tab strip sits under the bar. Every tab of yours has a close button, the first one included, and + opens a new tab on the shown account. Codex tasks' tabs sit beside yours, in italics, and close when their task ends (#1047's first-tab close is part of this).
- **More tabs of your own.** Your tabs now have their own allowance of 10 per account. Before, they shared 5 with Codex tasks, so a few running tasks left no room to open one. Codex tasks keep their limit of 5 per account, which caps the bridge's parallel traffic on one ChatGPT account. All pages together stop at 30 (was 15).

### App
- **An app started from inside an agent's chat no longer takes on that chat's settings (#1050).** When an agent installs or relaunches the app, the app used to inherit that one chat's environment and pass it on to everything it started. 0.8.80 was installed from a Codex chat, which caused three problems:
  - "Something went wrong: Codex integration journal belongs to C:\Users\simon\.codex\config.toml, not the active config …gateway-homes\codex\config.toml". The bridge was looking at Agent Orchestrator's private Codex folder instead of yours.
  - Every DeepSeek V4.1 Flash chat through Claude Code failed with "Invalid value for config option model", and automatic retry started a new attempt every few minutes. The inherited chat named its own model (GPT-6.1 Sol), so Claude Code was never offered the model the chat picked.
  - Every later agent ran with the Codex sandbox's network turned off and with that chat's model and session.
- At start the app now drops a chat's own settings when it finds it was started from one. It keeps your own settings: your own API addresses and keys, and a Codex folder you set yourself. It logs the names it dropped, never their values.

### Verification and limitations
- 563 tests across 35 browser, renderer and launcher test files pass, including new ones: Codex tasks' 5 tabs are counted apart from your 10, and every account's pages together stop at 30. The browser host's 170 tests run with an Electron stand-in. The new bar and tabs were checked in a preview with the app's own styles.
- **The page reloading every few minutes is not fixed by this release.** In the installed app all three ChatGPT pages showed Cloudflare's "Just a moment..." check, which reloads itself until it is passed. It comes from the proxy exit (Global Routing), which every browser in the app uses, the original GPT Browser included. Another exit on the Proxy page, or passing the check by hand, is what ends it.
- Not yet checked in the installed app.
- 4 new tests cover the environment seen on 2026-11-03, a person's own settings, and a normal start. The suites that read the app's main file pass, except files missing from the local checkout; CI runs them all (#1050).
- The app now running keeps the inherited settings until it is started again from the Start menu or taskbar, or updated to this version.
- The black lower part of the window seen in the same screenshot did not happen again while watched; it is not fixed here.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.80.

## 繁體中文

### GPT 瀏覽器
- **GPT 瀏覽器回復原本的樣子。** 自 0.8.77 起，「GPT 瀏覽器」項目顯示的是連接器的瀏覽器及其舊工具列。現在它回到 GPT 瀏覽器自己的單列工具列：帳戶選擇器及「新增帳戶」、上一頁、下一頁、重新載入、帶「前往」按鈕的網址列，以及縮放。底層仍是同一個瀏覽器，因此 Codex 連接器、登入、密碼金鑰登入、零風險回合、帳戶切換及 ChatGPT 瀏覽器管理，仍在相同的帳戶及登入上運作。
- **像一般瀏覽器一樣的分頁。** 工具列下方有一列分頁。你自己的每個分頁都有關閉按鈕，包括第一個分頁；「+」會在目前帳戶上開啟新分頁。Codex 任務的分頁以斜體顯示在你的分頁旁邊，並在任務結束時關閉（#1047 的第一個分頁關閉功能已包含在內）。
- **可開更多自己的分頁。** 你自己的分頁現在另有每個帳戶 10 個的上限。過去它們與 Codex 任務共用 5 個，幾個任務在執行時便無法再開分頁。Codex 任務仍維持每個帳戶 5 個的上限，以限制連接器在同一 ChatGPT 帳戶上的並行流量。所有頁面合計上限為 30 個（原為 15 個）。

### 應用程式
- **從代理對話內啟動的應用程式，不會再沿用該對話的設定（#1050）。** 當代理安裝或重新啟動應用程式時，應用程式過去會繼承那個對話的環境，並傳給它啟動的所有程式。0.8.80 是從一個 Codex 對話安裝的，因而導致三個問題：
  - 「Something went wrong: Codex integration journal belongs to C:\Users\simon\.codex\config.toml, not the active config …gateway-homes\codex\config.toml」。橋接程式看的是 Agent Orchestrator 的私有 Codex 資料夾，而不是你的。
  - 每個經 Claude Code 使用 DeepSeek V4.1 Flash 的對話都以「Invalid value for config option model」失敗，自動重試每隔數分鐘便開始新的嘗試。繼承的對話指定了自己的模型（GPT-6.1 Sol），所以 Claude Code 從未獲提供對話所選的模型。
  - 之後的每個代理都在 Codex 沙箱網絡關閉的狀態下運行，並沿用那個對話的模型及工作階段。
- 應用程式啟動時，若發現自己是從對話中啟動的，現在會移除該對話自身的設定，但保留你自己的設定：你自己的 API 位址和金鑰，以及你自行設定的 Codex 資料夾。被移除的名稱會記錄下來，但絕不記錄其值。

### 驗證及限制
- 35 個瀏覽器、介面及啟動器測試檔案共 563 項測試均通過，包括新測試：Codex 任務的 5 個分頁與你的 10 個分開計算，所有帳戶的頁面合計上限為 30 個。瀏覽器主機的 170 項測試以 Electron 替身執行。新的工具列及分頁已在套用應用程式樣式的預覽中檢查。
- **此版本不能解決頁面每隔數分鐘重新載入的問題。** 在已安裝的應用程式中，三個 ChatGPT 頁面都顯示 Cloudflare 的「Just a moment...」檢查，在通過之前會自行重新載入。它來自代理出口（全域路由），應用程式中每個瀏覽器都使用它，原本的 GPT 瀏覽器亦然。在「代理」頁面改用其他出口，或親自通過檢查，才能停止。
- 尚未在已安裝的應用程式中檢查。
- 4 項新測試涵蓋 2026-11-03 觀察到的環境、使用者自己的設定，以及正常啟動。讀取應用程式主檔案的測試套件均通過，只有本機簽出中缺少檔案的除外；CI 會執行全部測試（#1050）。
- 目前正在運行的應用程式會保留繼承的設定，直至從「開始」功能表或工作列再次啟動，或更新至此版本。
- 同一截圖中視窗下半部變黑的情況，在觀察期間沒有再出現；此版本並未修正。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.80 的所有內容。
