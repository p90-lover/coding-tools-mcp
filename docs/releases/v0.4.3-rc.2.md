# v0.4.3-rc.2 — truthful tool exposure / 真實工具公開狀態

## English

Fixes the existing Runtime policy form: saved `core` and canonical `advanced` profiles now have matching options; `full` maps visibly to Advanced / Full rather than appearing as an unmatched selection. Opening the form does not widen a profile or grant execution permission. Core, Advanced, read-only and compatibility remain separate choices.

ChatGPT setup now includes a local-only tool catalog inspector. With MCP running, it reports that listener's current effective profile, exact advertised names/count, profile-hidden names, metadata SHA-256 and unavailable advertised definitions. With MCP stopped it explicitly reports saved configuration only. Failed inspections clear the old result. `server_info.tool_catalog` provides the same server-side evidence, and protocol reporting references the actual supported protocol constants instead of an old hardcoded value.

This app has 70 registered definitions: core advertises 57, read-only 42 and Advanced / Full 70. These counts are verified against actual tools/list, not a promise that every definition can execute. `sandbox_exec` remains a clearly unavailable stub; native commands and computer input still need their existing local grants. No tools/list membership, execution permissions, authentication, endpoint or screenshot behavior is changed by this patch. Permission-only saves still do not restart or relink MCP. Installing a new binary requires restarting the desktop application once.

ChatGPT's loaded tools remain unknown to this inspector. A developer connection needs Refresh when metadata changes; published connections can require rescan, review, publication and enabling new actions. Select the intended connection in the chat. A recognized mention, a working tunnel or a server catalog is not proof that a particular chat has loaded it. Do not delete/recreate a working connection or relabel writing tools as read-only to bypass client approvals. Official setup links and evidence-based troubleshooting are in the paired English / Traditional Chinese tool-exposure guides.

This focused Windows release is gated on the real profile-form regression (red then green), rendered component interaction with explicitly synthetic Tauri IPC, two Rust catalog/live-policy regressions, the existing HTTP connection regressions, frontend checks and actual installer inspection. It does not test the user's live ChatGPT/OAuth/tunnel connection, native computer input or inference. No Codex executable, model or paid provider is invoked in these checks. The previously verified Windows native-command digest is retained in the build, not replaced with an unverified runtime.

Paseo/Anneal autonomous engines and unexposed Codex internal capabilities are not added by selecting Full; those remain outside this release. Automatic ChatGPT account registration/reauthorization and publisher signing are not silently completed. Windows is publisher-unsigned. This release provides the Windows x64 installer; the earlier release retains its macOS artifact. Existing files, credentials and releases are preserved; test/build data goes under aiTemp.

## 繁體中文

修正既有執行策略表單：已存的 `core` 及標準化 `advanced` 目錄現有相符選項；`full` 會清楚顯示為 Advanced／Full，不再成為沒有相符項目的選擇。開啟表單不會擴大目錄或授予執行權限，Core、Advanced、唯讀與相容目錄仍可分開選擇。

ChatGPT 設定新增只在本機讀取的工具目錄檢查。MCP 運行時，顯示該服務目前生效的目錄、實際公開名稱／數量、被目錄隱藏的名稱、中繼資料 SHA-256，以及有定義但不可用的項目。MCP 停止時會清楚標示只顯示已存設定，檢查失敗亦會清除舊結果。`server_info.tool_catalog` 提供相同服務端證據；協定資訊改用實際支援的常數，不再回報過時的固定值。

本程式有 70 個已註冊定義：Core 公開 57 個、唯讀 42 個、Advanced／Full 70 個。數量會與真正 tools/list 比對，不代表每個定義都能執行；`sandbox_exec` 仍明確標示不可用，原生命令及電腦操作仍需既有本機授權。本修正沒有更改 tools/list 成員、執行權限、認證、端點或截圖行為。只變更權限仍不需重啟或重新連接 MCP；安裝新執行檔則需重新啟動桌面程式一次。

檢查器並不知道 ChatGPT 已載入哪些工具。開發連接在中繼資料變更後須 Refresh；已發佈連接可能需要重新掃描、審查、發佈並啟用新操作，亦要在對話選擇正確連接。能識別 mention、隧道正常或服務端有目錄，都不證明指定對話已載入。不要為排錯刪除／重建正常連接，亦不要把寫入工具偽裝為唯讀以繞過用戶端批准。雙語工具公開指南附有官方設定來源及依證據排錯方法。

本次 Windows 修正版以真實表單回歸（先失敗再通過）、實際元件操作（明確使用模擬 Tauri IPC）、兩項 Rust 目錄／即時權限回歸、既有 HTTP 連線測試、前端及實際安裝包檢查作為發佈關卡。沒有驗證你的真實 ChatGPT／OAuth／隧道連接、原生電腦輸入或推論；檢查不啟動 Codex 執行檔、模型或付費供應商。建置保留前版已驗證的 Windows 原生命令雜湊，不會換成未驗證版本。

選 Full 不會加入 Paseo／Anneal 自主引擎或尚未公開的 Codex 內部功能；這些仍不在本次發佈範圍。亦不會假稱靜默完成 ChatGPT 帳戶註冊／重新授權或發佈者簽署。Windows 沒有發佈者簽署；本版提供 Windows x64 安裝程式，先前 macOS 附件保留在前版。既有檔案、憑證及 Release 均保留，測試／建置資料置於 aiTemp。
