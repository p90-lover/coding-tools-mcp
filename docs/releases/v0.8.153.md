# Coding Tools v0.8.153

## English

- **Approve for me** can run up to four native Codex Guardian reviews at once. Eligible requests wait for a review slot instead of going straight to a manual approval prompt. These native reviews use the signed-in Codex CLI, not CPA.
- With **Let the model judge** and **Allow quota-based reviews** both on, an eligible shell request Guardian cannot decide can go to the quota-based reviewer. A confirmed allow or decline is sent to the agent and the approval card clears after acknowledgment. Explicit denials and high-risk findings cannot be overridden; requests that need a person still wait for one.

Everything in 0.8.152 is included.

## 繁體中文

- **代我核准**現在可同時進行最多四項原生 Codex Guardian 審查。符合條件的請求會等待審查名額，不會直接跳出手動核准提示。原生審查使用已登入的 Codex CLI，不會透過 CPA。
- 同時開啟**讓模型判斷**與**允許使用配額審查**時，Guardian 無法判定的合格 Shell 請求可交由配額審查。代理程式收到核准或拒絕並確認後，核准卡片會關閉。明確拒絕與高風險判定不會遭覆寫，需要人工決定的請求仍會等待你。

包含 0.8.152 的所有變更。
