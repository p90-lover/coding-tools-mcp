# Coding Tools 0.8.27

## English

### Improvements
- Choose a context window for every Claude model in Claude Code chats, including CPA aliases such as "Claude Opus 5.5". The composer's window picker was off for all of them. A recognized Claude model compacts at the chosen window, capped at its own, and automatic compaction stays on (PR #616).
- Keep timers and approval reviews off synchronous disk calls on the main process, which reduces desktop freezes (PR #611).

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from this branch and confirm CI before publication.
- Everything in 0.8.26 is included.

## 繁體中文

### 更新內容
- Claude Code 對話中的所有 Claude 模型（包括 CPA 別名，例如「Claude Opus 5.5」）現在都可以選擇上下文視窗；之前輸入框的視窗選項對這些模型全部停用。已識別的 Claude 模型會在所選視窗壓縮對話，但不會超過模型本身的上限，自動壓縮功能保持開啟（PR #616）。
- 主程序的計時器及審批檢查不再進行同步磁碟讀寫，減少桌面程式卡頓（PR #611）。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由本分支編譯及通過 CI 才能公開。
- 包含 0.8.26 的所有內容。
