# Coding Tools MCP v0.3.4-rc.1 — local Windows control and memory-only live view

## English

Adds a native Windows UI Automation + SendInput control layer to the prior memory-only vision release. This is actual local execution, not Codex inference or a Codex agent/plugin bundle. No Codex model session or API call is used by the added tools or build workflow.

The workspace panel lets the local user select one application and enable a ten-minute session. A separate visible monitor displays live target pixels or the exact latest image sent to the agent, with timestamp, action status, Pause/Resume, Stop, and Ctrl+Alt+Escape emergency Stop. Control stays off until explicitly enabled locally; lost visibility/heartbeat, paused/expired grants and changed foreground targets block input. Screenshots and control progress stay in RAM; no screenshot files, disk cache or screenshot gallery are written.

Includes status/routing, snapshots with optional UIA structure, unique control finding, check-first event-assisted waits, real mouse/Unicode keyboard input, and bounded sequences with explicit resume and non-replaying request IDs. Native OS calls can block and submitted inputs cannot be recalled. This is foreground window-scoped automation, not a full OS sandbox or background virtual desktop. The existing assistant setup does not bypass ChatGPT login/consent.

The Windows installer is publisher-unsigned. macOS builds retain memory-only vision but do not support Windows input; the macOS bundle is ad-hoc signed, not notarized. Checksums and exact source/build provenance accompany assets. This is a release candidate; the user's actual ChatGPT connection and desktop permissions are not validated by CI. See the attached verification evidence for which native fixture checks actually ran.

## 繁體中文

在原有僅限記憶體的視覺版本上，加入真正的 Windows UI Automation＋SendInput 本機操作層。這不是 Codex 推理、Agent 或官方插件套件；新增工具與建置流程不啟動 Codex 模型會話或呼叫模型 API。

使用者可在工作區選擇一個應用程式，於本機確認啟用十分鐘操作會話。獨立即時控制視窗可切換即時目標畫面與模型最近收到的完全相同圖片，並顯示時間、操作狀態、暫停／繼續、停止，以及 Ctrl+Alt+Escape 緊急停止。未經本機明確啟用不會操作；畫面失去可見性／心跳、會話暫停／過期或前台目標改變時會阻止輸入。截圖及操作進度只留在 RAM，不寫入截圖檔、磁碟快取或圖庫。

包含狀態／能力選擇、可附 UIA 結構的截圖、唯一控制項尋找、先檢查再等待的事件輔助等待、真實滑鼠／Unicode 鍵盤輸入，以及有上限、須明確恢復且不重播輸入的動作序列。原生 OS 呼叫可能阻塞，已提交輸入不能撤回。這是指定視窗的前台自動化，不是完整 OS 沙箱或背景虛擬桌面；既有輔助連接設定不繞過 ChatGPT 登入／授權。

Windows 安裝程式未有發行者數位簽署。macOS 版本保留僅限記憶體的視覺功能，但不支援 Windows 輸入；Mac 套件使用 ad-hoc 簽署，未經公證。資產附雜湊校驗與確切原始碼／建置來源。本版本為候選版本；CI 不等於已驗證使用者的 ChatGPT 連接及實機權限。實際執行的原生測試項目請參閱附帶驗證紀錄。
