# Coding Tools 0.8.25

## English

### Fixes and improvements
- Restore the Coding Tools window and taskbar identity, and recover split-chat panes when switching projects, including project-load retry controls (PR #593).
- Preserve richer ChatGPT Web answer output and source previews without exposing private connector metadata or binary resource payloads in plain-text prompts (PR #597).
- Improve failed WebGPT draft continuation and continue persistently interrupted responses in one fresh conversation, preserving the Codex task and completed tool results (PRs #594 and #610).
- Fix message copy and rewind, provider credential persistence and model labeling (PRs #595, #598 and #600).
- Fix model-switch failures caused by missing workspace context or oversized history messages (PRs #601, #604 and #607).
- Restore cross-Codex-chat message delivery and ordinary WebGPT prompt retry (PRs #599 and #602).

### Validation and release safety
- The merged PRs passed their relevant GitHub checks. This release includes the verified merged main branch and does not bundle unfinished draft changes.
- The `/goal` route on ChatGPT Web passes the existing native-goal and compaction regression checks. Interactive long-horizon end-to-end behavior requires a subsequent installed-app run.
- Windows installer, portable archive and update packs must be built from this exact source and verified before publication.
- WebGPT tool-discovery and receipt changes from PR #596 remain under separate review and are **not included** until conflict resolution and connector consent verification.

## 繁體中文

### 修正與改進
- 修正 Coding Tools 視窗及工作列名稱，改善切換專案後分割對話空白問題，並加入專案載入失敗重試功能（PR #593）。
- 保留更完整的 ChatGPT Web 回覆及來源預覽，同時避免在純文字 Prompt 暴露私人 Connector 資料或二進位資源內容（PR #597）。
- 改善 WebGPT 草稿復原；持續顯示連線中斷時，會在新對話中延續原有 Codex 任務及已完成的工具結果（PR #594、#610）。
- 修正訊息複製及回溯、Provider 憑證儲存及模型名稱（PR #595、#598、#600）。
- 修正切換到 ChatGPT Web 時因工作區資訊缺失或歷史訊息過長而失敗的問題（PR #601、#604、#607）。
- 修復跨 Codex 對話傳送訊息與一般 WebGPT Prompt 重試機制（PR #599、#602）。

### 驗證與發佈安全
- 已合併修正通過相關 GitHub 檢查。此版本以已驗證的 main 分支為準，不包含尚未完成的草稿。
- ChatGPT Web 的 `/goal` 路徑已通過現有原生 Goal 與上下文壓縮回歸測試；長時間任務的真實端到端體驗仍需安裝後測試。
- Windows 安裝檔、免安裝壓縮包及更新套件必須從相同來源編譯並核實後才可公開。
- PR #596 的 WebGPT 工具搜尋及執行回執改動仍待衝突解決與 Connector 確認機制驗證，因此暫未包含。
