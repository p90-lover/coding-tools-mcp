# Coding Tools v0.8.151

## English

- **Silent chat automation:** Wake-ups, command watches, monitors, and automatic follow-ups still reach the agent, but no longer appear as messages from you. Your messages and steers, the agent’s responses, and approval requests stay visible. Existing chat history is not rewritten.

Everything in 0.8.150 is included.

## 繁體中文

- **靜默聊天自動化：** 喚醒、指令監看、監控事件及自動延續仍會送達代理程式，但不再顯示成你發送的訊息。你發送的訊息和即時指示、代理程式的回覆，以及需要你核准的請求，仍會正常顯示。既有聊天記錄不會被改寫。

包含 0.8.150 的所有變更。
