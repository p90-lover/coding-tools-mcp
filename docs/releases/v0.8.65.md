# Coding Tools 0.8.65

## English

### Chats
- A reply's file changes sit right beside its runtime, on one row. Hover over them (or focus or tap them) for a card that follows your theme and lists each file's name, full path and lines added and removed, plus the turn's totals. The separate list of files under the reply is gone. Escape, a click elsewhere, resizing or scrolling closes the card (PR #972).
- Hidden secrets stay hidden. When the agent hid a credential in a message, the label put in its place could contain that same credential, and so could the "Worked" row. Labels are now checked against the hidden values, and a value that would show through is refused instead of being reported as hidden (PR #963).

### Workspaces
- A workspace can be created from a drive or a share root (such as `D:\` or `\\server\share\`). Its trailing separator was removed, which left an invalid path. Root workspaces also get a name (PR #966).

### Verification and limitations
- File changes: 136 tests pass. Checked in a browser preview in light and dark themes and in a 280 px team card. Not yet checked in the installed app (PR #972).
- Secrets: 156 tests pass across the redaction, upstream and lifecycle files, including three new ones that failed before the fix. They use fake secrets (PR #963).
- Workspace roots: a new Rust test runs in the Windows, macOS and Linux CI jobs (PR #966).
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.64 is included.

## 繁體中文

### 對話
- 回覆的檔案變更會緊貼在其執行時間旁，排成一行。將滑鼠停在上面（或聚焦、輕觸）會顯示一張跟隨你主題的卡片，列出每個檔案的名稱、完整路徑、新增及刪除的行數，以及該回合的總數。回覆下方另外列出的檔案清單已移除。按 Escape、點擊其他地方、調整大小或捲動都會關閉卡片（PR #972）。
- 已隱藏的機密會保持隱藏。過去代理在訊息中隱藏憑證時，取代它的標籤可能包含同一個憑證，「Worked」一行亦然。現在標籤會與隱藏的值比對，會洩露出來的值會被拒絕，而不是報告為已隱藏（PR #963）。

### 工作區
- 現在可以從磁碟機或共用資料夾的根目錄（例如 `D:\` 或 `\\server\share\`）建立工作區。過去其結尾的分隔符號會被移除，留下無效的路徑。根目錄工作區也會有名稱（PR #966）。

### 驗證及限制
- 檔案變更：136 項測試通過。已在瀏覽器預覽中以淺色及深色主題和 280 px 的團隊卡片檢查。尚未在已安裝的應用程式中檢查（PR #972）。
- 機密：遮蔽、上游及生命週期檔案中的 156 項測試通過，包括三項在修正前失敗的新測試。測試使用假的機密（PR #963）。
- 工作區根目錄：一項新的 Rust 測試在 Windows、macOS 及 Linux 的 CI 工作中執行（PR #966）。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.64 的所有內容。
