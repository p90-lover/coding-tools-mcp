# Coding Tools 0.8.98

## English

### Sign in with your existing Chrome profile
- **No disposable sign-in profile.** Chrome sign-in now opens a normal Chrome tab instead of creating a fresh browser profile. Existing Chrome windows stay open; the app does not add debugging, automation, profile-directory or proxy overrides (#1107).
- **Verify automatically after sign-in.** Once the approved connector detects a valid ChatGPT session, Coding Tools imports the requested session into its selected account and independently checks authentication and session details. There is no close-Chrome or Continue step in this flow. Receiving a session is not treated as a verified login.
- **One-time, explicit setup.** Choose **Install connector**, then in the Chrome profile you use open `chrome://extensions`, enable Developer mode and choose **Load unpacked** for that folder. Compare and approve the matching four-group pairing code the first time. Chrome chooses its usual/default or last-used profile when opening a tab; if that is not the intended profile, copy the connection link into the profile with the connector installed. The app does not silently install an extension or read the profile database.
- **Narrow, encrypted handoff.** Only non-partitioned ChatGPT/OpenAI cookies are transferred. The short-lived, one-use connection is bound to an OS-protected app identity and the exact approval code, and the capture is encrypted for that app. No Google cookies, passwords, unrelated sites, other profiles, local storage or access-token JSON is exported. Normal Chrome routing is unchanged; the app retains its own selected-account route and fresh verification.
- **Clear controls and slow-check handling.** Open Chrome, Install connector and Cancel remain available in the global sign-in notice. A slow app check does not hold a Chrome extension worker open or cause a repeated credential import. The app and normal connection tab show the final verification result automatically.

### Verification and limitations
- GitHub Actions remains unavailable. Publication is gated on local desktop tests, renderer type checks, release identity checks, `bun run package:win`, package/source verification, and downloaded release-asset checksums rather than a claimed CI pass.
- Focused integrated browser/runtime/connector checks: 400 tests, 399 passed, one existing skip, no failures. Native Electron/Chromium fixtures cover OS-protected identity persistence, extension-origin loopback transport, positive and rejected session evidence, and the actual sign-in/approval UI. These fixtures and worker simulations are not a live-account end-to-end Chrome test.
- The connector must be installed and approved in Chrome by the person using it. After an app update changes its files, use **Reload** in `chrome://extensions`. No installed app, personal browser profile or live account was modified as part of development verification.
- Includes all changes in 0.8.97. The legacy standalone capture remains unchanged for its existing runtime paths.

## 繁體中文

### 使用現有的 Chrome 設定檔登入
- **不再建立臨時登入設定檔。** Chrome 登入現在會開啟一般的 Chrome 分頁，而不是建立全新的瀏覽器設定檔。現有視窗會保持開啟；應用程式不會加入除錯、自動化、設定檔目錄或代理覆寫參數（#1107）。
- **登入後自動驗證。** 已批准的連接器偵測到有效的 ChatGPT 工作階段後，Coding Tools 會將要求的工作階段匯入所選帳戶，並獨立檢查身分驗證及工作階段資料。這個流程不必關閉 Chrome 或按「繼續」。收到工作階段並不代表登入已通過驗證。
- **首次使用須明確設定。** 選擇「安裝連接器」，然後在平常使用的 Chrome 設定檔開啟 `chrome://extensions`，啟用開發人員模式並以「載入未封裝項目」選取該資料夾。首次連線時，核對並批准相同的四組配對碼。Chrome 會按其一般預設或上次使用的設定檔開啟分頁；若不是所需設定檔，請將連線連結複製到已安裝連接器的設定檔。應用程式不會靜默安裝擴充功能或讀取設定檔資料庫。
- **範圍有限的加密傳送。** 只會傳送未分割的 ChatGPT/OpenAI Cookie。短效、一次性的連線綁定受作業系統保護的應用程式身分及確切的批准碼，擷取資料會加密給該應用程式。不會匯出 Google Cookie、密碼、無關網站、其他設定檔、本機儲存資料或存取權杖 JSON。一般 Chrome 的網路路由不變；應用程式仍使用所選帳戶的路由重新驗證。
- **清楚的控制及較慢檢查的處理。** 全域登入提示提供「開啟 Chrome」、「安裝連接器」及「取消」。較慢的應用程式檢查不會持續佔用 Chrome 擴充功能工作者或重複匯入憑證；應用程式及一般連線分頁會自動顯示最終驗證結果。

### 驗證及限制
- GitHub Actions 仍無法使用。發佈須通過本機桌面測試、渲染器型別檢查、版本身分檢查、`bun run package:win`、套件及原始碼驗證，以及重新下載發佈資產的校驗和檢查；不會宣稱 CI 已通過。
- 整合後的瀏覽器／執行階段／連接器重點檢查共有 400 項測試：399 項通過、1 項原有略過、沒有失敗。原生 Electron/Chromium 測試涵蓋作業系統保護的身分保存、擴充功能來源的本機傳輸、有效及拒絕的工作階段證據，以及實際登入／批准介面。這些測試與工作者模擬不等於使用真實帳戶的完整 Chrome 端到端測試。
- 使用者必須在 Chrome 內安裝並批准連接器。應用程式更新連接器檔案後，請在 `chrome://extensions` 選擇「重新載入」。開發驗證沒有修改已安裝的應用程式、個人瀏覽器設定檔或真實帳戶。
- 包含 0.8.97 的所有變更。原有獨立執行階段的擷取流程保持不變。
