# Coding Tools 0.8.57

## English

### Chats
- The automatic stall recovery added in 0.8.56 stops only the turn it found hung. A late check could interrupt, or shut down the agent of, a newer turn in the same chat, or a turn that had started working again. The check now records the turn it judged and looks again just before it acts: at the saved card, its latest activity and any tool still within its timeout. A check that can't confirm the turn is still that one and still hung does nothing. A Stop you press while a check is skipping still does its own stop (PR #948).
- Deleting a reply from a chat removes only the message you picked. A message list or picker that had gone stale could remove a different prompt while hiding the selected reply. Deleting is now tied to the exact chat and message shown, and refuses if that has changed. Two deletes at once can no longer undo each other (PR #942).
- A DeepSeek chat's reply shows on a single card even when the card has no step timeline yet. The reply was stored but the card's body stayed blank or showed only "Loading" or "Deep diving". The reply now shows once, a finished answer isn't repeated, and a card still waiting for its first output says so (PR #947).

### Verification and limitations
- Built and published by GitHub CI from main; no local build was made for this version.
- The stall recovery fence is covered by tests of a newer turn, renewed activity, a tool within its timeout, a missing turn ID, and a Stop pressed during a check; the installed app's recovery has not been exercised (PR #948).
- Everything in 0.8.56 is included.

## 繁體中文

### 對話
- 0.8.56 新增的自動停滯恢復現在只會停止它判定為卡住的回合。過去較遲執行的檢查可能會中斷同一對話中較新的回合，或已恢復工作的回合，甚至關閉其代理。現在檢查會記下它判定的回合，並在行動前再次確認：已儲存的卡片、最近的活動，以及仍在逾時範圍內的工具。若無法確認仍是同一回合且仍然卡住，檢查便不會採取任何行動。檢查略過期間你按下的「停止」仍會照常執行（PR #948）。
- 從對話刪除回覆時，只會刪除你所選的訊息。過去已過時的訊息列表或選擇器可能會在隱藏所選回覆時，刪除另一則提示。現在刪除會綁定到畫面上顯示的對話及訊息，若內容已改變便會拒絕。兩個同時進行的刪除不會再互相復原（PR #942）。
- DeepSeek 對話的回覆即使卡片尚未有步驟時間軸，也會在單一卡片上顯示。過去回覆已儲存，但卡片內容仍是空白，或只顯示「Loading」或「Deep diving」。現在回覆只會顯示一次，已完成的答案不會重複，仍在等待第一個輸出的卡片亦會如實顯示（PR #947）。

### 驗證及限制
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 停滯恢復的防護已由較新回合、恢復活動、仍在逾時範圍內的工具、缺少回合 ID，以及檢查期間按下「停止」的測試涵蓋；尚未在已安裝的應用程式中實際觀察恢復過程（PR #948）。
- 包含 0.8.56 的所有內容。
