Coding Tools 0.7.0-rc.25

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Fixes:
- Chat Preview: approving the first page no longer crashes the app, and background screenshots, scrolling, input and navigation keep working when the Preview pane is closed.
- Chat Terminal: completed and cancelled commands release the workspace before the next command starts.
- Chat tools: files returned by a root directory listing can be opened directly.
- Subagents: routes with None effort can be saved and launched.

Everything in rc.24 is included.
