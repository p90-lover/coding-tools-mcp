# Coding Tools v0.8.129

## English

### Approvals

- **Approve for me and Let the model judge work again with "Allow quota-based reviews" off.** Since 0.8.122 that switch, off by default, stopped every review before a model saw it. Approve for me then answered nothing and every request waited for you, and Let the model judge never judged. Choosing Approve for me for a chat, or turning on Let the model judge, is choosing a model review, so those reviews now run with the switch off. They go through CPA and use account quota.
- **What the switch still covers.** Reviews nobody chose: a screen action (computer use) in a chat on another permission mode. While the switch and Let the model judge are both off, those wait for you. Codex's own Auto-review in Codex chats is separate and unchanged.
- **What you will see.** The permission chip no longer turns amber or says "Approve for me (paused)" when the switch is off. Settings > Chat says which reviews each switch covers.

## 繁體中文

### 核准

- **關閉「Allow quota-based reviews」時，「替我核准」和「讓模型判斷」恢復運作。** 從 0.8.122 起，這個預設關閉的開關會在模型看到要求之前就停止所有審查。於是「替我核准」什麼也不回答，每個要求都等你處理；「讓模型判斷」也從未判斷。為對話選擇「替我核准」，或開啟「讓模型判斷」，就是選擇由模型審查，所以現在即使開關關閉，這些審查也會執行。它們經由 CPA，會使用帳號配額。
- **開關仍然涵蓋的範圍。** 沒有人選擇的審查：在其他權限模式的對話中進行的螢幕操作（電腦操作）。開關和「讓模型判斷」都關閉時，這些操作會等你處理。Codex 對話中 Codex 自己的 Auto-review 是獨立的，沒有改變。
- **你會看到的變化。** 開關關閉時，權限標籤不再變成琥珀色，也不再顯示「替我核准（已暫停）」。「設定 > 對話」會說明每個開關涵蓋哪些審查。
