# Coding Tools 0.8.96

## English

### Chat
- **Replies no longer sit inside a box.** Each agent reply was drawn as a framed card: a border, a coloured left edge, a tinted background and inner padding. The answer itself read as if it were placed inside a box. A reply now reads as plain text, like your own messages.
  - Everything under the reply stays: the model, the status (Done, Working, Failed, Stalled), how long it took, the files it changed, and the activity line (steps, failures, LLM time, tokens).
  - A failed or stuck reply is still easy to spot: its status pill keeps the colour that the card's edge used to carry.

### Verification and limitations
- Previewed in the running app by applying the new style to all 144 replies on screen: no border, fill or padding, and every reply's summary and activity line still showed.
- A new test checks that no reply rule draws a border or fill, in any chat style. It fails on the previous style. 169 chat layout and view tests pass.
- Not checked in the installed app after updating.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.95.

## 繁體中文

### 對話
- **回覆不再放在方框內。** 每個代理回覆過去都以卡片形式顯示：有邊框、彩色左邊、淺色背景及內邊距，看起來就像答案被放進方框裡。現在回覆會像你自己的訊息一樣，以一般文字顯示。
  - 回覆下方的資料全部保留：模型、狀態（完成、進行中、失敗、停滯）、所用時間、更改的檔案，以及活動行（步驟、失敗次數、LLM 時間、token）。
  - 失敗或卡住的回覆仍然容易看見：狀態標籤保留了原本卡片邊緣的顏色。

### 驗證及限制
- 在執行中的應用程式中，把新樣式套用到畫面上全部 144 個回覆進行預覽：沒有邊框、背景或內邊距，每個回覆的摘要及活動行仍然顯示。
- 新測試確認在任何對話樣式下，回覆規則都不會加上邊框或背景；舊樣式會令測試失敗。169 項對話版面及檢視測試均通過。
- 更新後未在已安裝的應用程式中確認。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.95 的所有內容。
