# Coding Tools 0.8.41

## English

### Computer control
- The control bar's Stop button works. Before, pressing Stop did nothing, because the click never reached the app. In 0.8.39 the same flaw meant the picker's Start did nothing, so control could not be turned on at all. In 0.8.40, chats ask for control on a card in the chat (PR #725). Ctrl+Alt+Escape still stops control at once (PR #729).

### Chats
- New chat opens in the chat pane you are in, in place of its chat. Before, in split view each New chat added one more pane, and it had to load a whole chat view before the chat could start. Dragging a chat and Ctrl+Alt+\ / Ctrl+Alt+- still open more panes.

### Verification and limitations
- Build the Windows installer, portable ZIP and update packs from main, and confirm CI before publication.
- The PR #722 notes move from 0.8.39 to 0.8.40: it merged after 0.8.39 was built.
- Everything in 0.8.40 is included.

## 繁體中文

### 電腦控制
- 控制橫條的「停止」按鈕現在可以使用。過去按下「停止」沒有任何作用，因為點擊從未傳達到應用程式。在 0.8.39 中，同一問題令選擇器的「開始」無效，因此根本無法開啟控制。0.8.40 起，對話改為在對話中以卡片要求控制（PR #725）。Ctrl+Alt+Escape 仍可立即停止控制（PR #729）。

### 對話
- 「New chat」會在你目前所在的對話窗格中開啟，取代該窗格的對話。過去在分割檢視中，每次按「New chat」都會多開一個窗格，而且要先載入整個對話檢視才能開始對話。拖曳對話及 Ctrl+Alt+\ / Ctrl+Alt+- 仍會開啟更多窗格。

### 驗證及限制
- Windows 安裝程式、免安裝 ZIP 和更新檔需由 main 編譯及通過 CI 才能公開。
- PR #722 的說明由 0.8.39 移至 0.8.40：它在 0.8.39 編譯之後才合併。
- 包含 0.8.40 的所有內容。
