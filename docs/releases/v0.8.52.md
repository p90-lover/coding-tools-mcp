# Coding Tools 0.8.52

## English

### Chats
- Stopping a native Codex chat while it was compacting no longer leaves the compaction pending. The next message used to fail with `AO_HARNESS_NOT_CONNECTED`; now the pending entry is released once the stop is confirmed. A stop that can't be confirmed keeps its receipt without running the model again, and late replies can't overwrite a newer compaction (PR #906).

### Diagnostics
- Freeze, memory and error events, which stay in memory since 0.8.49, can be read through the app's local control server (`POST /v1/launcher/activity`, owner token only). Checks outside the app can now track freezes without file logs; nothing else in the Activity log is shared, and nothing is written to disk (PR #907).

### Verification and limitations
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.51 is included.

## 繁體中文

### 對話
- 在原生 Codex 對話壓縮期間停止對話，不會再令壓縮一直處於等待狀態。之前下一則訊息會以 `AO_HARNESS_NOT_CONNECTED` 失敗；現在確認停止後會釋放等待中的項目。無法確認的停止會保留其收據而不會再次執行模型，較晚的回覆亦不會覆蓋較新的壓縮（PR #906）。

### 診斷
- 自 0.8.49 起只保留在記憶體中的停頓、記憶體及錯誤事件，現可透過程式的本機控制伺服器讀取（`POST /v1/launcher/activity`，只限擁有者權杖）。程式外的檢查不需檔案記錄亦可追蹤停頓；「活動」記錄中的其他內容不會外流，也不會寫入磁碟（PR #907）。

### 驗證及限制
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.51 的所有內容。
