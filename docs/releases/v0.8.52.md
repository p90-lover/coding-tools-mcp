# Coding Tools 0.8.52

## English

### Agent Orchestrator
- Agent Orchestrator now runs the fork's main branch, which includes upstream AO through 2026-10-01 alongside every Coding Tools change: automations, cues, rich session links, PR references reported by workers, and the fx, Gemini, MiMo Code, DeepSeek and OpenCode v2 harnesses.
