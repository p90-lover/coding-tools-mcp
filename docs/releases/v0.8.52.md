# Coding Tools 0.8.52

## English

### Web GPT
- WebGPT's bundled runtime moves from codex-chatgpt-web v5.0.6 to the latest v6.1.17, and Coding Tools' own WebGPT fixes are kept. New from upstream: separate GPT-6 Sol and GPT-5.6 Sol rows with selectable effort, a Zero Risk mode, a "New browser chat for each turn" option, and a tunnel-client update to 0.0.16. Task turns still run in saved ChatGPT chats by default, because ChatGPT refuses connectors in Temporary Chat. A "Something went wrong" retry in a fresh conversation now counts toward the turn's three automatic retries, so a ChatGPT outage costs at most four sends (PR #NNN).

## 繁體中文

### Web GPT
- WebGPT 內附的執行環境由 codex-chatgpt-web v5.0.6 更新至最新的 v6.1.17，同時保留 Coding Tools 自己的 WebGPT 修正。上游新增：可選擇推理強度的 GPT-6 Sol 與 GPT-5.6 Sol 獨立項目、Zero Risk 模式、「每個回合使用新的瀏覽器對話」選項，以及升級至 0.0.16 的 tunnel-client。任務回合預設仍在已儲存的 ChatGPT 對話中執行，因為 ChatGPT 不允許在臨時對話中使用連接器。在新對話中重試「Something went wrong」現在會計入該回合的三次自動重試，因此 ChatGPT 故障時最多只會傳送四次（PR #NNN）。
