Coding Tools 0.8.11

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Approve for me spends far less of your Codex account:

- "Approve for me" now answers the common read-only shell commands itself instead of asking its model reviewer (codex-auto-review, billed to your Codex account): a leading `cd` into the project, `&&` chains, try/catch, multi-line scripts, git's read commands, process and port checks, and status requests to services on this machine. On one busy day this would have answered 268 of 862 commands itself instead of 38.
- Anything that writes, other git commands, POST requests, other hosts and paths outside the project still go to the reviewer. A variable in double quotes (`"$env:KEY"`) no longer counts as a read.

Chats that look stuck:

- A running turn says at its foot how long it has worked, how long nothing new has come, and when its model is being retried, instead of only at the top of a long turn.
- When a turn has shown nothing for 10 minutes, a message you send stops it and goes in as the next turn, even when a tool call never returned.

Also:

- Claude Code sessions keep their preset identity, so Antigravity models work with them.
- Agent hosts of chats that exit while the Agent Orchestrator runs are stopped.
- The Subagents page runs up to 100 at once, with shorter text and plain model names.
- Windows launcher startup fixes, and an update keeps retrying after a passing network failure.

Everything in 0.8.10 is included.
