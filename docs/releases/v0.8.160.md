# Coding Tools v0.8.160

## English

- **Automatically generated handoffs respect the chat secret-hiding setting.** When it is on, Coding Tools masks recognized credentials in older context before sending it to a summary model. It masks the model's summary too, and protects copied history when there is no summary. A handoff made while the setting was off is not reused after you turn it on.
- Your new message is unchanged. This does not remove credentials from old transcripts or revoke exposed keys.

Includes all changes from v0.8.159.

## 繁體中文

- **自動產生的對話交接會遵守聊天的隱藏機密設定。** 開啟設定後，Coding Tools 會先遮蔽舊對話中可辨識的憑證，再把內容交給摘要模型。模型產生的摘要也會遮蔽憑證；無法產生摘要時，直接複製的舊對話也受到保護。開啟設定後，不會沿用設定關閉時產生的交接摘要。
- 新送出的訊息不會被改寫。此修正不會移除既有對話記錄中的憑證，也不會撤銷已外洩的金鑰。

包含 v0.8.159 的所有變更。
