# Coding Tools 0.8.53

## English

### Chats
- A chat's earlier replies no longer disappear, and a project's quieter chats no longer open empty. The project's run read returns only its newest 100 runs, shared by all of its chats; each chat now reads its own runs, and the open chat restores replies that fell out of that window (PR #915).
- A native chat start that was waiting for its account or page is refused if the thread was moved, forgotten or reset meanwhile, instead of resuming on the old account and conversation. A failed start releases only the tab it still owns, so a later request keeps its tab (PR #913).

### Verification and limitations
- Built and published by GitHub CI from main; no local build was made for this version.
- Everything in 0.8.52 is included.

## 繁體中文

### 對話
- 對話較早的回覆不會再消失，專案中較少使用的對話開啟時亦不會再是空白。專案的執行讀取只會傳回最新的 100 次執行，由專案內所有對話共用；現在每個對話都會讀取自己的執行，開啟中的對話會補回已超出該範圍的回覆（PR #915）。
- 原生對話在等待帳號或頁面期間，若對話串已被移動、遺忘或重設，該次啟動會被拒絕，不會再以舊帳號及舊對話繼續。失敗的啟動只會釋放仍屬於它的分頁，較後的請求可保留其分頁（PR #913）。

### 驗證及限制
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.52 的所有內容。
