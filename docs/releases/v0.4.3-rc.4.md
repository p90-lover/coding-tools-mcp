# v0.4.3-rc.4 — Preserved features, OAuth and file-safety repair

## English

This candidate extends main at `07faa97255e6b60d909f956fa2cebd3b829bbf97`; it does not replace main with an older minimal branch. The released computer-use controls, remembered and live permissions, local vision/memory, tool-profile inspector, native-command adapter, Paseo/Anneal control-center adapters and shared workflow board remain present. The release gate checks unchanged implementation paths for computer use, native commands, tool definitions, redirect validation and refresh-token storage. Presence in the source is not proof that every optional service is configured or running on the user's computer.

OAuth fixes include scoped acceptance of exact ChatGPT origins on GET/POST `/oauth/authorize` only, and trusted tunnel-origin rotation derived from application-owned state rather than caller-controlled Host/Forwarded headers. The authorization form's CSP permits only its already-validated callback origin, preserving the browser's normal form-action checks. Password, request-bound nonce/cookie, client/redirect validation, PKCE, one-use authorization codes and authenticated tool access remain enforced. General MCP routes do not inherit a global ChatGPT-origin exception.

The corrected browser fixture follows a real popup, same-origin consent POST and 303 callback GET. It verifies that credentials are not forwarded in the callback body and unrelated destinations remain blocked. Its CDP redirect interception fixes a replay limitation; it does not disable CSP, force navigation or contact a real ChatGPT account. External browser traffic is blocked during this check.

File-safety fixes reject oversized text input before decoding, enforce the 16 MiB limit on the actual read even if a file grows, reject unsafe internal staging/Trash symlink ancestry, and refuse to replace a directory with a file. The three focused regressions also verify UTF-8 truncation, ordinary successful updates and recovery of the original bytes. Existing patch permissions and workspace path validation remain in place. This is not a claim that every filesystem race or OS sandbox boundary has been audited.

The existing 70-definition catalogue is retained: Core advertises 57 and Advanced/Full 70. Catalogue visibility does not grant execution permission. `sandbox_exec` remains an explicitly unavailable stub; no unverified autonomous engine or old quota-consuming Codex-runtime branch is silently merged. The previous native-command binary identity is retained, not revalidated as a new operating-system sandbox in this release.

Publication is gated on scoped-origin checks, the production OAuth-to-catalogue flow, the three browser-policy cases, the three file-safety regressions, existing connection checks, frontend checking/building and inspection of the actual Windows installer. Source commit, packaged EXE, release tag and non-forced main update must agree. Assets are uploaded to a draft, downloaded and hashed again before publication. No Codex executable, inference model, paid provider, live ChatGPT account or native computer input is invoked by this release verification.

Windows x64 installer only; publisher-unsigned. Earlier releases and files are preserved. Test/build fixtures live under aiTemp; retired originals are retained in Trash. This release does not install itself on the user's computer, verify that user's live tunnel/OAuth session, complete full Paseo/Anneal engines, or guarantee that every previously requested feature is finished.

## 繁體中文

此候選版本以 main 的 `07faa97255e6b60d909f956fa2cebd3b829bbf97` 為基礎擴充，不會用較舊的精簡分支覆蓋 main。已發佈的電腦操作、記住授權及即時權限、本機視覺／記憶、工具目錄檢查、原生命令介接、Paseo／Anneal 控制中心介接及共用工作流程看板均保留。發佈檢查會核對電腦操作、原生命令、工具定義、redirect 驗證及 refresh-token 儲存等實作路徑沒有改動。原始碼存在某項功能，不代表使用者電腦上的選用服務已設定或正在運行。

OAuth 修正包括：只在 GET／POST `/oauth/authorize` 接受明確列出的 ChatGPT Origin；隧道來源更新改為讀取程式管理的可信狀態，不再依賴呼叫端可控制的 Host／Forwarded。授權表單的 CSP 只允許已驗證 callback 的來源，保留瀏覽器正常的 form-action 檢查。密碼、請求綁定 nonce／cookie、client／redirect 驗證、PKCE、一次性授權碼及工具存取驗證均保留；一般 MCP 路由不會獲得全域 ChatGPT-origin 例外。

修正後的瀏覽器測試使用真正彈出視窗、同來源授權 POST 及 303 callback GET，核對 callback 不會攜帶密碼本文，且不相關目的地仍被阻擋。CDP 轉址攔截只修正重播工具漏接 redirect 的限制，不會停用 CSP、強制導向或連接真實 ChatGPT 帳戶。測試期間會封鎖對外瀏覽器流量。

檔案安全修正會在解碼前拒絕過大文字輸入；即使檔案讀取期間增長，實際讀取仍受 16 MiB 上限約束。另外會拒絕不安全的內部 staging／Trash 符號連結路徑，並阻止以檔案取代整個資料夾。三項集中回歸測試亦核對 UTF-8 截斷、正常更新及原始內容可恢復。原有補丁權限及工作區路徑驗證保留；這不代表所有檔案系統競爭條件或作業系統沙箱邊界均已完成審核。

保留原有 70 個工具定義：Core 公開 57 個，Advanced／Full 公開 70 個。顯示工具不等於授予執行權限；`sandbox_exec` 仍明確標示為不可用，不會暗中合併未驗證的自主引擎或會消耗配額的舊 Codex-runtime 分支。原生命令保留先前的執行檔識別值，本版本並未重新驗證新的作業系統沙箱。

發佈須通過限定來源檢查、正式 OAuth 至工具目錄流程、三種瀏覽器策略情況、三項檔案安全回歸、既有連線檢查、前端檢查／編譯，以及實際 Windows installer 檢查。原始碼 commit、封裝 EXE、release tag 及非強制更新的 main 必須相符。檔案先上傳至草稿，再重新下載及核對雜湊後才公開。此發佈驗證不會執行 Codex、推論模型、付費供應商、真實 ChatGPT 帳戶或原生電腦輸入。

僅提供 Windows x64 installer，未有發行者數碼簽章。保留舊版本及檔案；測試／編譯資料放於 aiTemp，退役原件保留於 Trash。本版本不會自行安裝到使用者電腦、不代表其真實隧道／OAuth 連線已驗證，亦不代表完整 Paseo／Anneal 引擎或所有曾要求的功能均已完成。
