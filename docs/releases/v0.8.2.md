Coding Tools 0.8.2

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Chat:

- The Chat window no longer crashes and reloads while a request waits for an answer ("Cannot access … before initialization").
- A black window recovers by itself, and the app logs why it happened.
- Agents can end a turn and be woken after the minutes they choose (schedule_wakeup) instead of polling a build or CI; a pending wake-up shows in the chat and can be cancelled.
- A steer waits for the agent instead of failing, queued messages keep trying until they are sent, a long quiet turn says it is still working, and a stuck card elsewhere settles.
- Projects open in place in the sidebar, and the one you use moves to the top, as in Codex.
- Archived chats are listed by project and deleted after the number of days you choose.
- No more double confirmation dialogs; Clawd drops where you let go of it.

WebGPT:

- A Codex chat whose context is compacted with a screenshot no longer fails: ChatGPT's redesigned composer shows attachments differently, and the bridge now waits for each upload to finish before sending.
- A healthy turn keeps its browser diagnostics in memory instead of writing them to disk.

Speed:

- Typing no longer lags while a task runs: new log lines no longer redraw the whole window.
- AO writes streaming chats to disk in batches and compacts its provider archive, so it writes far less.
- Chat host processes stop when their chat ends instead of running on.

Everything in 0.8.1 is included.
