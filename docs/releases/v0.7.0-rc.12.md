# Coding Tools v0.7.0-rc.12

## English

This prerelease publishes the verified browser-surface ownership and complete Network Proxy localization repairs on top of the unified five-stack application.

### Browser surface ownership

- Switching away from Browser now hides the native ChatGPT WebContentsView instead of leaving it above Provider, Network, Paseo, Anneal, or other React surfaces.
- Matching app versions use the dedicated browser-surface ownership IPC.
- Split-version updates fail over narrowly to the compatible show/hide channels only when that exact IPC handler is missing.
- Rapid tab changes are serialized, failed hide operations do not arm a later restore, and failed restores remain retryable.
- Unrelated IPC errors remain visible rather than being silently swallowed.

### Network Proxy localization and routing

- Profile management, field labels, statuses, scopes, validation, notices, routing modes, provider routing, account routing, and action buttons are fully localized.
- Traditional Chinese, Simplified Chinese, Japanese, and English are supported.
- The typed subagent traffic scope is now visible and included in new global proxy profiles.
- Loopback control traffic remains direct and protected.

### Release integrity

- The existing v0.7.0-rc.11 tag is retained unchanged as immutable history.
- v0.7.0-rc.12 uses a new exact-source tag and installer identity.
- Release gates cover browser ownership, Network Proxy localization, five-stack contracts, strict TypeScript, production renderer, Rust headless build, Windows packaging, packaged-launcher smoke, legacy migration, checksums, provenance, remote asset readback, and no-file-deletion enforcement.
- Generated and superseded material remains under aiTemp and Trash.

Live OAuth, paid-provider quota, and local third-party runtime credentials remain user-machine validation boundaries.

## 繁體中文

今次預覽版本會喺統一五項系統應用程式之上，正式發佈已驗證嘅瀏覽器介面擁有權修正，以及完整網路代理本地化。

### 瀏覽器介面擁有權

- 離開「瀏覽器」分頁時，原生 ChatGPT WebContentsView 而家會正確隱藏，唔會再覆蓋供應商、網路代理、Paseo、Anneal 或其他 React 畫面。
- 版本一致時會使用專用 browser-surface ownership IPC。
- Split-version 更新只會喺精確 IPC handler 缺失時，有限度轉用相容嘅顯示／隱藏通道。
- 快速切換分頁會順序處理；隱藏失敗唔會錯誤安排稍後恢復；恢復失敗亦可以重試。
- 其他 IPC 錯誤唔會被靜默隱藏。

### 網路代理本地化同路由

- 設定檔管理、欄位名稱、狀態、流量範圍、驗證訊息、通知、路由模式、供應商路由、帳戶路由及操作按鈕已完整本地化。
- 支援繁體中文、簡體中文、日文同英文。
- 已補回有型別保護嘅子代理流量範圍，並加入新全域代理設定檔。
- Loopback 控制流量繼續保持直接連線及受保護。

### 發佈完整性

- 既有 v0.7.0-rc.11 Tag 會原封不動保留做不可變歷史記錄。
- v0.7.0-rc.12 使用全新 exact-source Tag 同安裝程式身份。
- Release gate 會驗證瀏覽器擁有權、網路代理本地化、五項系統 contracts、Strict TypeScript、Production Renderer、Rust Headless Build、Windows Packaging、Packaged-launcher Smoke、舊版 Migration、Checksum、Provenance、遠端資產回讀同禁止刪檔規則。
- 產生及已取代嘅材料會保留喺 aiTemp 同 Trash。

真實 OAuth、付費供應商額度同本機第三方 runtime 憑證仍然係使用者電腦上嘅驗證邊界。
