# Coding Tools v0.7.0-rc.12

## English

This prerelease is the next exact-source Windows publish after frozen `v0.7.0-rc.8`, `v0.7.0-rc.9`, `v0.7.0-rc.10`, and `v0.7.0-rc.11`. Those tags are never force-moved.

### Why a new version

- `v0.7.0-rc.11` shipped the one-app managed five-stack and in-process `codingTools.apps` host.
- This revision completes CPA/Router provider ops, Desktop MCP `apps_*` tools, IPC `apps.invoke` optionals, and ships `resources/app-handler` plus `resources/app-modules` (with `resources/modules` shims) so a packaged install can run handlers offline.

### Desktop contents

- Product identity `0.7.0-rc.12`. Tauri `0.4.11` is unchanged.
- In-process `window.codingTools.apps` (`list` / `catalog` / `call` / `invoke`). No new HTTP listen ports for apps.
- CPA provider ops: `listProviders` (`providers`), `linkProvider`, `unlinkProvider`, `providerStatus`.
- Desktop MCP overlay: `apps_list`, `apps_catalog`, `apps_call`, `apps_invoke`, `apps_status`.
- CT-hosted visuals for CPA, Codex Router, Paseo, Anneal, and CommandCode.
- Packaged extraResources: `resources/app-handler/` (canonical `require("../../app-handler/host.cjs")`), `resources/app-modules/` (offline alias), and `resources/modules/` (temporary shims for older simon asar packs). preferLocal / noDownload: do not git-clone handlers.

### Packaging and migration

- Electron Builder publication autodetection stays disabled; only the exact-source release publisher may upload GitHub assets.
- The Windows installer keeps the validated legacy NSIS and MSI migration path, the stable Electron app id, and user data.
- Frozen tags `v0.7.0-rc.8`, `v0.7.0-rc.9`, `v0.7.0-rc.10`, and `v0.7.0-rc.11` are not retargeted.

### Exact-source provenance

- The publisher checks out the immutable triggering SHA and refuses publication if remote `main` advances during verification.
- Existing tags are never force-moved: if `v0.7.0-rc.12` already exists on another SHA, publication fails closed.

### Validation boundary

Automated validation does not consume paid provider quota. Live account login, Anneal WSL2/Docker prerequisites, and external local-service acceptance remain explicit manual boundaries.

## 繁體中文

呢個 prerelease 係凍結咗 `v0.7.0-rc.8`、`v0.7.0-rc.9`、`v0.7.0-rc.10`、`v0.7.0-rc.11` 之後嘅下一個 exact-source Windows 發佈，永遠唔會被 force-move。

### 點解要用新版本

- `v0.7.0-rc.11` 已經有 one-app five-stack 同 in-process `codingTools.apps`。
- 今次補齊 CPA／Router provider ops、Desktop MCP `apps_*`、IPC `apps.invoke` optionals，同把 `resources/app-handler` 加 `resources/app-modules`（同 `resources/modules` shim）打進安裝包，離線都可以跑 handlers。

### Desktop 內容

- 產品身份 `0.7.0-rc.12`。Tauri `0.4.11` 不變。
- In-process `window.codingTools.apps`。Apps 唔再開新 HTTP listen port。
- CPA：`listProviders`／`linkProvider`／`unlinkProvider`／`providerStatus`。
- MCP：`apps_list`／`apps_catalog`／`apps_call`／`apps_invoke`／`apps_status`。
- 畫面仍然托管喺 Coding Tools 入面。
- 安裝包 extraResources：`resources/app-handler/`（canonical）、`resources/app-modules/`（offline alias）、`resources/modules/`（舊 asar shim）。preferLocal／noDownload：唔好 git clone handlers。

### 打包同 Migration

- 仍然停用 Electron Builder 自動推斷 publication。
- Windows installer 保留已驗證嘅舊 NSIS／MSI migration、穩定 app id，同使用者資料。
- 唔會改寫已凍結嘅 `v0.7.0-rc.8`、`v0.7.0-rc.9`、`v0.7.0-rc.10`、`v0.7.0-rc.11`。

### Exact-source 來源保證

- Publisher 只會 checkout 觸發 workflow 嘅固定 SHA。
- 現有 tag 永遠唔會被 force-move。

### 驗證邊界

自動驗證唔會消耗付費 provider quota。真實帳戶登入、Anneal 嘅 WSL2／Docker 前置，同外部本機服務驗收仍然係明確人工邊界。
