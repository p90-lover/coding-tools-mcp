Coding Tools 0.7.0-rc.22

Updates in-app from rc.19 and later. On rc.18 or earlier, install it once by hand: Coding.Tools_0.7.0-rc.22_win_x64_portable.zip (unzip it over your portable folder, with the app closed) or Coding.Tools_0.7.0-rc.22_win_x64.exe (the installer).

Fixes:
- Chat: an agent stuck retrying ("Retrying Claude, attempt n of 10") counts as stuck: a message you send after 3 minutes of only retries stops that turn and starts a new one with your message. The retry notices kept the turn looking alive before.
- Chat: after a stuck turn is stopped (or any interrupted turn), the next message continues the same agent and conversation instead of starting over without it.
- Chat: coming back to a chat whose agent was released while idle and sending at once no longer starts a second agent beside the one coming back.
- Subagents: several subagents started at the same moment respect the "Running at once" and "Per chat" limits; a subagent whose session ended (or with Agent Orchestrator stopped) finishes instead of holding its place until the time limit; a request too long to check whole is denied, never approved for it.
- Subagents page: models are the selected agent's own (no WebGPT, which subagents cannot use), and unsaved edits survive visiting another page.
- The app's command rules no longer break for good after Agent Orchestrator failed to start once.

Everything in rc.21 is included.
