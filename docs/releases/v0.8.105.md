# Coding Tools 0.8.105

## English

### Chats: a reply's changed files open in the side panel
- **Click a file in a reply's "N files" list to see its diff.** The side panel opens on its **Changes** tab, in the worktree of the agent whose edit wrote the file, with that file selected.
  - **View all changes** opens the whole diff.
  - Since 0.8.65 the list only showed names and line counts: nothing was wired to open them.
  - The tab reads the diff again on each click, so a file the reply has just written is there.
  - The agent's edit can name a file as an absolute Windows path (`G:\…\src\App.tsx`). It still finds the diff's `src/App.tsx`, with or without matching case.
  - If the worktree no longer lists the file, for example because it was committed since, the tab opens on its first file.
  - A ChatGPT web turn has no worktree diff, so its files stay plain text, as before.
- **Claude style: the jump-to-latest button has no shadow,** like the default style's.

### Verification and limitations
- New tests cover: the click opening the Changes tab on the right agent and file; View all changes; ChatGPT web turns keeping plain text; the pane picking the file only once its diff has loaded, keeping your own choice through Refresh, reading a new file whole, and falling back to the first file; and the path matching.
- The full desktop suite and the renderer typecheck pass locally. GitHub Actions is unavailable for this repository.
- Not checked in the running app: the tests render the real chat and Changes pane, not the packaged window.
- Two fix notes that missed their releases are added: `docs/fixes/annotation-message.md` (0.8.49) and `docs/fixes/cpa-quota-refresh-delay.md` (0.8.49).
- Includes everything in 0.8.104.

## 繁體中文

### 對話：回覆變更的檔案可在側邊面板開啟
- **在回覆的「N 個檔案」清單中點一個檔案，即可查看它的差異。** 側邊面板會開啟在 **Changes** 分頁，位於寫入該檔案的代理的工作樹中，並選取該檔案。
  - **View all changes** 會開啟完整差異。
  - 自 0.8.65 起，這個清單只顯示檔名與行數，沒有任何動作可以開啟它們。
  - 每次點擊都會重新讀取差異，所以回覆剛寫入的檔案也會出現。
  - 代理的編輯可能以 Windows 絕對路徑（`G:\…\src\App.tsx`）指稱檔案，仍可找到差異中的 `src/App.tsx`，大小寫不同也可以。
  - 若工作樹已不再列出該檔案（例如之後已提交），分頁會開啟在第一個檔案。
  - ChatGPT 網頁回合沒有工作樹差異，因此它的檔案仍是純文字，與之前相同。
- **Claude 樣式：跳到最新的按鈕不再有陰影，** 與預設樣式相同。

### 驗證與限制
- 新測試涵蓋：點擊會在正確的代理與檔案上開啟 Changes 分頁；View all changes；ChatGPT 網頁回合保持純文字；面板只在差異載入後才選取檔案、重新整理時保留你自己的選擇、完整讀取新檔案，以及退回第一個檔案；還有路徑比對。
- 完整桌面測試套件與介面型別檢查在本機通過。此儲存庫無法使用 GitHub Actions。
- 未在執行中的應用程式內檢查：測試呈現的是真實的對話與 Changes 面板，而不是封裝後的視窗。
- 補上兩份錯過發佈的修正說明：`docs/fixes/annotation-message.md`（0.8.49）與 `docs/fixes/cpa-quota-refresh-delay.md`（0.8.49）。
- 包含 0.8.104 的所有內容。
