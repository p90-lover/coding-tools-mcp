# Coding Tools 0.8.24

## English

### Fixes and improvements
- Keep ChatGPT answer images and descriptive logos in responses shown to Codex, while excluding transient media URLs.
- Avoid WebGPT token-counting stalls on repetitive context and recover exact native root-task context after follow-ups.
- Show complete command and tool input in scrollable approval cards.
- Preserve unread steering messages in the original turn, including across subsequent missions.
- Highlight every open chat in split view and provide agents a `rename_chat` tool for task titles.
- Require confirmed agent shutdown before replacing an unrestored agent, and renew stale background grants when the agent build changes.
- Add a quick project picker and missing-project recovery guidance for new chats.
- Keep Clawd animations aligned after window resize or interrupted transitions.
- Advertise the existing Coding Tools icon in MCP server metadata for clients that support it.

### Update notes
- Includes the v0.8.23 update-button queue/cancel fix and the v0.8.22 ChatGPT conversation URL reuse changes.
- Windows x64 installer, portable archive and in-app update packs are validated by SHA-256 before public publication.
- The app checks GitHub Releases for updates; an installation with an older disabled update button may need the official installer once.

## 繁體中文

### 修正與改進
- 在 Codex 回覆中保留 ChatGPT 答案的圖片、圖表及標誌描述，同時避免傳送無法重用的臨時媒體網址。
- 加快 WebGPT 重複內容的 Token 計算，並正確復原原有 Codex 根任務的上下文。
- 審批卡片以可捲動方式顯示完整指令及工具輸入。
- Steering 訊息固定在原本的任務回合，不會因新任務開始而移到其他位置。
- 分割畫面中標示所有已開啟的對話，並新增讓代理按任務名稱重新命名對話的 `rename_chat` 工具。
- 更換無法復原的代理前必須確認舊代理已停止，並在代理程式版本變更後重新取得背景執行授權。
- 新對話加入快速選擇專案及缺失專案的復原提示。
- 修復視窗縮放及動畫中斷後 Clawd 寵物移動方向失準。
- 在 MCP 伺服器資訊中提供 Coding Tools 圖示，供支援此欄位的客戶端使用。

### 更新須知
- 包含 v0.8.23 更新按鈕排程／取消修正，以及 v0.8.22 的 ChatGPT 對話網址重用修正。
- Windows x64 安裝檔、免安裝壓縮檔及程式內更新套件在公開前會通過 SHA-256 驗證。
- 程式會從 GitHub Releases 檢查更新；若舊版更新按鈕無法按下，可先使用官方安裝檔升級一次。
