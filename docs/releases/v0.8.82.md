# Coding Tools 0.8.82

## English

### Subagents
- **One model list with every model a subagent can run (#1052).** The page used to choose an agent first (Claude Code by default), and Claude Code's list leaves out Antigravity's models, which refuse its requests. So Gemini 3.8 Flash and the other Gemini models were missing, and the saved default read "cpa/gemini-3.8-flash-high (no longer listed)". The list now holds the models of Claude Code, Codex and opencode together, each once, grouped by who serves them (Gemini, Claude, OpenAI, DeepSeek…). A model runs on an agent that offers it, so a Gemini model goes to Codex.
- A subagent or default saved on an agent that cannot run its model moves to one that can, and saves itself. The Gemini default saved on Claude Code used to fail when a subagent started.
- CPA's GPT models and Codex's own models no longer show the same name twice: Codex's own are in their own "Codex" group.
- **A cleaner page.** The on/off switch sits beside the title. One panel holds the default model and the limits. Each subagent is its name, a switch, its purpose, its instructions and its model.
  - Removed: the status pills, the Harness field, the model search, the context window and tuning box, the "Choose/Clear default model" buttons, the subagent's letter badge and id, and the "Default / Its own model" switch (a subagent's model list starts with "Default").
  - Runs show only when there are some. The save bar shows only while saving or after a failed save.
  - The effort picker appears beside a model only when the model offers efforts.

### GPT Browser
- Switching account no longer fails with "Error invoking remote method 'launcher:browser-account-switch': Error: (-3) loading 'https://chatgpt.com/'". When Cloudflare's check or a ChatGPT redirect took over the page's first load, the switch counted that as a failure; the page was still opening (#1052).

### Verification and limitations
- Tests:
  - 916 tests in the 8 test files that cover the model lists and labels pass, including new ones: each model listed once, Gemini moving to Codex, a saved route moving with an effort its new agent takes.
  - 237 browser tests pass, including the aborted-load case.
- The page was checked in a preview with the live model catalogs (86 models in 7 groups, Gemini 3.8 Flash High among them), not in the installed app.
- Built and published by GitHub CI from main; no local build was made for this version.
- Includes all changes in 0.8.81.

## 繁體中文

### 子代理
- **單一模型清單，列出子代理可使用的所有模型（#1052）。** 過去頁面要先選代理（預設為 Claude Code），而 Claude Code 的清單不包含 Antigravity 的模型，因為 Antigravity 會拒絕它的請求。因此 Gemini 3.8 Flash 等 Gemini 模型都不見了，已儲存的預設顯示為「cpa/gemini-3.8-flash-high (no longer listed)」。現在清單合併了 Claude Code、Codex 和 opencode 的模型，每個只列一次，並按提供者分組（Gemini、Claude、OpenAI、DeepSeek…）。模型會在提供它的代理上執行，所以 Gemini 模型會交給 Codex。
- 若子代理或預設儲存在無法執行其模型的代理上，會自動改到可以執行的代理並儲存。過去儲存在 Claude Code 上的 Gemini 預設，會在子代理啟動時失敗。
- CPA 的 GPT 模型和 Codex 自己的模型不會再出現兩個相同名稱：Codex 自己的模型歸入獨立的「Codex」組別。
- **更簡潔的頁面。** 開關移到標題旁邊。一個面板放預設模型和各項上限。每個子代理只有名稱、開關、用途、指示和模型。
  - 已移除：狀態標籤、「Harness」欄位、模型搜尋、上下文視窗和調校區塊、「選擇／清除預設模型」按鈕、子代理的字母標記和 ID，以及「預設／自己的模型」切換（子代理的模型清單第一項就是「預設」）。
  - 只有在有執行記錄時才顯示「執行」區塊。儲存列只在儲存中或儲存失敗後顯示。
  - 只有模型提供推理強度時，模型旁邊才會出現推理強度選單。

### GPT 瀏覽器
- 切換帳戶時不會再出現「Error invoking remote method 'launcher:browser-account-switch': Error: (-3) loading 'https://chatgpt.com/'」錯誤。當 Cloudflare 檢查或 ChatGPT 的重新導向接手了頁面的首次載入時，切換過去會把它當成失敗，但頁面其實仍在開啟中（#1052）。

### 驗證及限制
- 測試：
  - 涵蓋模型清單及名稱的 8 個測試檔案共 916 項測試均通過，包括新測試：每個模型只列一次、Gemini 改到 Codex、已儲存的路線改到新代理時保留其支援的推理強度。
  - 237 項瀏覽器測試均通過，包括載入被中止的情況。
- 頁面已在使用實際模型目錄的預覽中檢查（7 個組別共 86 個模型，包括 Gemini 3.8 Flash High），而非在已安裝的應用程式中。
- 由 GitHub CI 從 main 建置及發佈；此版本沒有在本機建置。
- 包含 0.8.81 的所有內容。
