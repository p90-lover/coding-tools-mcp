# Coding Tools v0.7.0-rc.7

## English

This prerelease restores the complete merged desktop source after an over-broad release-identity materialization reduced the Provider Center, Paseo, Anneal, upstream-tool, localization, and Windows migration surfaces.

### Integrated desktop work

- Restores the CPA-style multi-account Provider Center, CommandCode Proxy account binding, OAuth providers, API-key providers, Web GPT, Gemini reverse proxy, and global proxy routing controls.
- Restores the pinned Paseo and Anneal desktop surfaces, their Electron bridge, task controls, orchestrator configuration, and embedded upstream metadata.
- Restores the full English and Traditional Chinese UI contracts, including Provider Center and orchestration copy.
- Retains the project updater, upstream tools, vendor metadata, package resources, and Windows upgrade migration sources.
- Keeps temporary and retained material under `aiTemp/` and `aiTemp/Trash/`; the repair commit removes no tracked files.

### Installer compatibility

- Detects historical Tauri-based `Coding Tools MCP` NSIS registrations in HKCU/HKLM and both registry views.
- Validates the exact legacy display name and uninstall metadata before execution.
- Runs the registered legacy uninstaller silently, waits for registration removal, and preserves fixture payloads in `aiTemp/Trash/`.
- Keeps GUID-based legacy MSI detection and command-line contract tests in the exact-source gate; the dedicated Windows production-macro harness remains available in the repository.
- Preserves application data and never manually deletes old directories, files, or registry keys.

### Validation boundary

The exact-source release workflow runs focused Provider Center, CommandCode, Paseo, Anneal, upstream-tool, localization, updater, packaging, and migration contracts. It then builds and verifies the Windows x64 installer, performs launcher smoke testing, executes a real retained NSIS upgrade fixture, produces checksums and provenance, and publishes only when the branch head still matches the validated source commit. Live external-account acceptance remains an explicit manual boundary.

## 繁體中文

今次 prerelease 修復咗一個過度縮減 source 嘅 release identity materialization，完整還原已合併嘅 Provider Center、Paseo、Anneal、upstream tools、繁體中文介面同 Windows 升級流程。

### 已整合桌面功能

- 還原 CPA 形式多帳戶 Provider Center、CommandCode Proxy 帳戶綁定、OAuth providers、API key providers、Web GPT、Gemini reverse proxy，同全域代理路由控制。
- 還原固定版本嘅 Paseo／Anneal 桌面介面、Electron bridge、task controls、orchestrator 設定，同內嵌 upstream metadata。
- 還原完整英文同繁體中文 UI contracts，包括 Provider Center 同 orchestration 文案。
- 保留 project updater、upstream tools、vendor metadata、package resources，同 Windows upgrade migration source。
- 所有臨時及保留資料放喺 `aiTemp/` 同 `aiTemp/Trash/`；今次修復 commit 冇移除任何 tracked file。

### Installer 相容性

- 會喺 HKCU／HKLM 同兩種 registry view 偵測舊 Tauri `Coding Tools MCP` NSIS 記錄。
- 執行前會驗證精確嘅舊版顯示名稱同解除安裝資料。
- 會靜默執行已登記嘅舊版 uninstaller、等待舊記錄消失，並將 fixture payload 保留喺 `aiTemp/Trash/`。
- exact-source gate 會保留 GUID-based legacy MSI 偵測同命令列 contract tests；專用 Windows production-macro harness 仍然保留喺 repository。
- 保留應用程式資料，唔會自行刪除舊資料夾、檔案或 registry key。

### 驗證邊界

精確 source release workflow 會執行 focused Provider Center、CommandCode、Paseo、Anneal、upstream-tool、繁體中文、updater、packaging 同 migration contracts；之後建立同驗證 Windows x64 installer、執行 launcher smoke、真實 retained NSIS upgrade fixture、產生 checksum 同 provenance，而且只會喺 branch head 仍然等於已驗證 source commit 時發佈。真實外部帳戶驗收仍然係明確人工邊界。
