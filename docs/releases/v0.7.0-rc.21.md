Coding Tools 0.7.0-rc.21

Updates in-app from rc.19 and rc.20. If you are on rc.18 or earlier and "Update" fails, install this release once by hand: Coding.Tools_0.7.0-rc.21_win_x64_portable.zip (unzip it over your portable folder, with the app closed) or Coding.Tools_0.7.0-rc.21_win_x64.exe (the installer).

Fixes:
- CPA: a temporary upstream error (a 502, a timeout, an upstream that cannot be reached) no longer puts the model on cooldown. Before, a few such errors made CPA stop offering the model for a while: the chat's model showed "not offered right now", every request got a 503, and the agent sat in "Retrying Claude, attempt n of 10". The next request now simply tries again. Quota limits (429) and rejected keys still pause the account.
- Chat: a provider-plugin model (Cline Pass, CommandCode, Grok, Kimi) that is missing because its account in CPA is disabled, or because none was added, now says so in the model chip and when a send is refused, instead of only "not offered right now".

Everything in rc.20 is included.
