## Dependency audit scope and remaining upstream warnings

The v0.3.2 release gates run npm audit against the installed lockfile and Cargo audit against the Rust lockfile. The npm remediation updates compatible SvelteKit, NanoID and PostCSS dependencies. SvelteKit's older cookie requirement is overridden with cookie 0.7.2; a focused parse/serialize and attribute-injection test guards compatibility. ChaCha20 is updated from the yanked 0.10.1 to 0.10.2, whose upstream fix avoids an SSE4.1 intrinsic in the SSE2 backend.

Cargo audit also reports informational warnings inherited from the framework dependency graph. These include unmaintained GTK3 binding crates, proc-macro-error, and the unic family. The cross-platform lockfile contains glib 0.18.5 with RUSTSEC-2024-0429, an unsound VariantStrIter implementation fixed upstream in glib 0.20.0. This warning is not hidden or described as fixed by this release.

The shipped installers are Windows x64 and macOS universal only. Native release validation records the dependency trees for x86_64-pc-windows-msvc, aarch64-apple-darwin and x86_64-apple-darwin, and rejects the release if glib is present in any of those resolved trees. No Linux installer is published in this release. The Linux source-validation environment still uses the GTK3 stack; Linux packaging needs a separate review of those upstream bindings.

The credential screen checks selected high-confidence token and private-key patterns in reachable Git history. Its output contains object IDs and finding classes, never matched values. A clean result is not proof that every possible credential format is absent, and it does not replace rotation of any credential previously exposed elsewhere.

No advisory-ignore rules are added. Informational maintenance warnings remain visible in the retained audit evidence; neither a passing build nor a passing default Cargo audit should be interpreted as a guarantee of zero security risk.

### 繁體中文

發佈檢查會對鎖定依賴執行 npm audit 及 Cargo audit。npm 修正涵蓋相容的 SvelteKit、NanoID、PostCSS 更新，並以 cookie 0.7.2 取代舊版 cookie；另有針對解析、序列化及欄位注入的相容性測試。已撤回的 ChaCha20 0.10.1 則更新至修正 SSE2 後端指令使用問題的 0.10.2。

Rust 依賴仍有上游資訊性警告，包括停止維護的 GTK3、proc-macro-error 及 unic 套件。跨平台鎖定檔亦包含 glib 0.18.5 的 RUSTSEC-2024-0429；本版本沒有聲稱修復或隱藏這項上游警告。

本次只發佈 Windows x64 及 macOS universal 安裝程式。原生建置會記錄三個目標架構的依賴樹，若其中包含 glib，便拒絕發佈。本次不提供 Linux 安裝程式；Linux 打包需要另行審查 GTK3 綁定問題。

憑證掃描只涵蓋可達 Git 歷史中的特定高可信度模式，不會輸出命中的密鑰值；沒有命中不代表所有憑證格式都不存在。沒有新增忽略安全公告的規則，資訊性警告會保留於審查證據中。
