# Coding Tools v0.8.155

## English

- **Context panel** is cleaner: the model, one provider card, the context bar and a single **Details** fold. For a model on a CPA Codex or Claude sign-in account, the card shows that account's 5-hour and weekly limits with when each resets, the Codex credits balance, and every account as a chip, with how many CPA can route requests to now (or, when all are at a limit, when the first is back). CPA lists Codex models under OpenAI and Claude models under Anthropic; those now show the limits too. The limits come from the headers of each account's latest reply, which CPA keeps, so reading them sends no provider requests. API keys show their credits or key budget, and Cline Pass shows its keys.
- **Approve for me** handles bursts: native Codex Guardian reviews run on up to two long-lived reviewers, eight at a time each, and further requests wait in line for up to five minutes instead of timing out into a manual approval prompt. A review's 40-second limit starts only once the review begins. A reviewer that fails is replaced and the review tried once more. The verdict rule is unchanged. Guardian reviews use Codex quota, about 1% of a Plus 5-hour window per 100 reviews. (#1359)

Everything in 0.8.154 is included.

## 繁體中文

- **情境面板**更簡潔：只顯示模型、一張供應商卡片、情境用量列與一個**詳細資料**摺疊區。使用 CPA Codex 或 Claude 登入帳號的模型，卡片會顯示該帳號的 5 小時與每週額度及各自的重設時間、Codex 點數餘額，並以標籤列出每個帳號，標示 CPA 目前可轉送請求的帳號數量（全部達到上限時，則顯示最快恢復的時間）。CPA 把 Codex 模型列在 OpenAI、把 Claude 模型列在 Anthropic 底下，這些模型現在也會顯示額度。額度來自 CPA 保存的各帳號最近一次回應標頭，讀取時不會向供應商發出請求。API 金鑰會顯示點數或金鑰預算，Cline Pass 則顯示其金鑰。
- **代我核准**可應付大量同時送來的請求：原生 Codex Guardian 審查最多由兩個常駐審查程序執行，每個可同時審查八項，其餘請求最多排隊五分鐘，不會因逾時而改成手動核准提示。每項審查的 40 秒時限從審查開始時才計算。審查程序失敗時會換新並重試一次。判定規則不變。Guardian 審查會使用 Codex 額度，每 100 次審查約占 Plus 5 小時額度的 1%。（#1359）

包含 0.8.154 的所有變更。
