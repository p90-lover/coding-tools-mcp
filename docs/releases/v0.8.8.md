Coding Tools 0.8.8

Updates in-app from rc.19 and later. On rc.18 or earlier, install the Windows installer or unpack the portable ZIP with the app closed.

Chat:

- Steered and queued messages look and act as in Claude Code: a message sent while the agent works waits in a queue bar above the composer, with Remove, Edit and Send now; a steer on its way pulses there, and once the agent takes it, it is an ordinary sent message.
- A message sent just as a failed step retries itself is no longer refused ("This chat is still running") and thrown back into the box: it waits in the queue and is steered in, or sent when the turn ends. One refused only because the window was in the background waits until it is in front again.
- A steer that waits for the agent's own request to be answered stays on its way, instead of popping up as "Queued".
- After you send, the chat stays on your new message; it used to stop partway and rest on an older one.
- A long task's approvals are screened and shown again.

Models and CPA:

- Command Code models take a reasoning effort from None to Max; the level you picked used to be dropped on the way (Command Code plugin 1.0.0-codingtools.2).
- Claude through Antigravity takes an effort from Low to Max, which turns its thinking on; CPA lists no levels for it.

Less disk writing:

- The Agent Orchestrator writes a chat's streamed output and its host journal far less often, and keeps each update once.
- The managed CPA runs without its request logger, and the Cline Pass switcher writes less.

Everything in 0.8.7 is included.
